# exQ5 收益来源与可执行性审计 · 最终报告

- 课题：exQ5 收益来源与可执行性审计（非实盘开发、非找新因子）
- 生成时间：2026-10-23
- 审计范围：冻结证据 → 基线复现 → 时间集中度 → 个股/流动性 → 资金/佣金/现金 → 成交假设 → 统计口径 → 前瞻方案
- 纪律：只读审计；未修改任何冻结产物、预登记与判定规则；全部新结果写入 `research/exq5_audit_2026-10-22/`
- 判定口径：NW(3) 双侧 1.96；MDE = 2.8016×se；功效 = Φ(|t|−1.96)+Φ(−|t|−1.96)

## 〇、一句话结论

**exQ5 作为统计异象是稳的（A 类 8 条全网格稳健，最小 t=2.36），作为成本后策略是边缘的（BASE +0.1360/t=4.04，但 BASE 是上界），作为可依赖的收益来源则尚未成立（现代段脆弱、时间高度集中、前瞻需 17 年才够功效）。**

## 一、五个必答问题

### Q1：历史收益来自哪里？

| 维度 | 结论 | 证据 |
|---|---|---|
| 相对谁 | 池内等权基准（alpha = R_exQ5 − R_bench），不是绝对收益 | 恒等式精确式偏差 6.75e−07 |
| 靠什么 | 低 MAX5 组相对跑赢 Q5，效应集中在**最低流动性组**（g1 占 44.1%，c1/c5=2.3072） | A3 独立复现 |
| 靠几只股票 | **不是靠个股**：top10 仅占 \|贡献\| 1.31%，top50 5.40%，5,362 只参与 | A3 |
| 靠哪几个月 | **高度集中**：现代段 top1 月占 13.7%，3 个月凑出累计一半；2020-02 单月 = 13.5 倍月均 | A2 |
| 毛 vs 净 | 毛 alpha 在 99.4% 滚动窗显著，净只剩 36%（现代段 12.9%）——**成本与集中度杀死稳健性，不是信号消失** | A2 |

### Q2：对哪些条件敏感？

按敏感度排序：

1. **极端月份**（最敏感）：剔 6 个先验极端月，t 从 2.22 → **1.92**（不显著）。
2. **NW 滞后选择**：S 现代段仅 L≥2 过（L=0/1 不过）；T1a 仅 L≥4 过——**双向脆弱**。
3. **资金规模**：1000 万未投资 12.32%，3000 万 4.75%；最低佣金影响 0.0274 → 0.0045pp。
4. **费率假设**：BASE +0.1360（t=4.04）→ STRESS +0.0424（t=1.27）；盈亏平衡 0.4129%。
5. **执行口径**：T+1 缺口 −0.0108pp/月（约 4.7% 高估）；卖不掉 1.93%；退市 69 只-月。
6. **流动性分组**：把 g1 拿掉，剩余 alpha 约 0.129pp 但 t 显著下降（g2–g5 的 t 为 3.87/2.25/1.19/1.42）。

### Q3：现有证据能支持多强的结论？（五层次）

| 层次 | 结论 | 强度 | 关键数字 |
|---|---|---|---|
| ① 统计异象存在 | **成立** | 强（A 类全网格稳健） | V0 +0.2307, t=6.36；A 类最小 t=2.36 |
| ② 历史收益为正 | **成立但集中** | 中 | 净 +0.1360（BASE@3000万, t=4.04）；top1 月 13.7% |
| ③ 成本后为正 | **在真实费率下成立** | 中偏弱（依赖费率口径） | CONS +0.1315 (t=3.90)；STRESS +0.0424 (t=1.27) |
| ④ 执行可信 | **上界，非真值** | 弱（四项缺口全为高估） | T+1 −0.0108pp；卖不掉 1.93%；ST 未量化 |
| ⑤ 未来持续 | **未知，且短期无法验证** | 无 | 现代段 T_FRAGILE；前瞻 36 月功效 21% |

**表述规范**：
- 可说：「在 2007–2026 历史样本、真实费率、3000 万资金下，exQ5 净 alpha 显著为正（+0.1360, t=4.04），但现代段边缘且脆弱。」
- 不可说：「exQ5 可用」「已验证」「未来能赚 0.136pp/月」。

### Q5：下一步怎么走？

1. **不新增因子、不启动实盘**（铁律不变）。
2. **停止在历史上继续挖 exQ5**：S/T/U 已把能问的问完，继续切段只会增加多重检验负担。
3. **把工作转到「记录」而不是「发现」**：建纸面台账，等未来数据；这不需要新假设。
4. **唯一可加速项是交割单**：拿到后可直接校准 BASE 与实际成本的差（当前 BASE 是**理论**费率）。
5. 若要继续研究，优先级最高的是**低流动性组（g1）的机制**——44.1% 的 alpha 来自这里，而它也是最难执行的组（这是本审计暴露的核心张力）。

## 四、对既有结论的影响

**无任何判定被推翻或修改**。本审计改变的是「解读精度」：

1. 引用 BASE 净值时必须带「上界」限定（四项缺口全为高估）。
2. 引用 S 现代段必须带 L 剖面（仅 L≥2 过）与剔极端月结果（t=1.92）。
3. 引用 T3 必须换算单位。
4. 引用 Gate 6 必须注明 iid（NW3 = 4.6443）。
5. 「成本吸收」结论由 0.3% 压力费率驱动，真实费率下显著——这一点在 O 已说明，本审计用独立实现再次确认。
