## 二、实验设计（冻结项）

### 2.1 策略定义（与历史完全一致，不得调整）

- 池：as-of 全 A，上市 ≥252 日，信号日有有效收盘
- 信号：MAX5 = 21 个交易日内最大 5 个日收益均值；等频分 5 组
- 持仓：剔除 Q5 后**等权**持有；基准 = 池内等权
- alpha = R_exQ5 − R_bench
- 调仓：月末信号，**t+1 开盘执行**（与历史口径的差异在此显式建模，不再用 t 日收盘）

### 2.2 成本（Decimal 金额路径）

- 佣金 0.025% 双边，**每笔最低 5 元**
- 印花税 0.05% 仅卖出；过户费 0.001% 双边
- 冲击：√ 模型 η=1（阶段 S 口径）；同时报 Amihud 线性作为上界
- **金额一律 `Decimal(str(x))` + ROUND_HALF_UP + 2dp**，禁止 float 与内置 `round`

### 2.3 执行模拟（拒单词表，采用港大 pt-v1.1）

固定决策顺序（先命中先返回）：

```
unknown_symbol → non_trading_day → suspended → corporate_action_unresolved
→ lot_size → limit_up → limit_down → limit_not_marketable
→ t_plus_1 → insufficient_position → insufficient_cash
```

- T+1：卖出可用 = 总持仓 − 当日买入
- 涨跌停：买对 up_limit、卖对 down_limit；band 为 `None` 时**不伪造拒单**
- ST：日度表取值，5% 覆盖；无表则排除该股（**不用代码段猜**）
- 整手：100 股，违规**拒单不四舍五入**
- 溯源：每行记 `stk_limit / heuristic / unavailable`、`st:stk_st_daily`、`suspend:*`

### 2.4 台账与可复现

每月一行，字段：
`signal_date, exec_date, n_pool, n_keep, gross_alpha, cost, net, cash, uninvested, n_rejected{code}, state_hash`

- `state_hash = sha256(JCS(输入：账户状态 + 费率 + 日期区间))`
- 警告文本禁止含时间戳（同输入同字节）
- 每月产物落独立目录 + `sha256` 清单

## 三、统计计划（预登记）

### 3.1 主检验

- 指标：月度净 alpha（BASE@3000万，Decimal 成本）
- 统计量：NW(3) 双侧 1.96
- 最小读数期：**36 个月**（首读，不判定通过）
- 必报：均值、se_nw、t、**MDE**、事后功效、n

### 3.2 功效的诚实计算（关键）

以现代段观测值（mean 0.1112pp，se_nw 0.0501，n=129）外推：

| 前瞻月数 | se ≈ 0.569/√n | MDE = 2.8016×se | 真实效应 0.111 时的功效 |
|---:|---:|---:|---:|
| 36 | 0.0949 | 0.266 | **≈ 21%** |
| 60 | 0.0735 | 0.206 | ≈ 33% |
| 120 | 0.0520 | 0.146 | ≈ 55% |
| **206** | 0.0397 | 0.111 | **≈ 80%** |

**结论（必须写进协议）**：按当前效应量，**36 个月的前瞻几乎必然 inconclusive**；达到 80% 功效需要约 **206 个月（17 年）**。因此前瞻的目标不是「确认」，而是：
1. 捕捉制度性断裂（连续负收益、成本恶化）；
2. 累积真正的样本外月度观测；
3. 用同一口径排除事后解释。

### 3.3 判定矩阵（预登记，不得事后修改）

| 条件（36 个月首读） | 判定 |
|---|---|
| t ≥ 1.96 且 MDE ≤ 0.15 且 未触发退出规则 | `FORWARD_CONSISTENT`（继续观察，不称确认） |
| t < 0 且 累计净 alpha < −1.0pp | `FORWARD_BROKEN`（停止） |
| 触发退出规则（§3.4） | `FORWARD_STOPPED` |
| 其余 | `FORWARD_INCONCLUSIVE`（继续积累） |

### 3.4 退出规则

- 连续 12 个月净 alpha 为负 → 停止并复核
- 滚动 24 月净值回撤 > 8pp → 停止并复核
- 成本实际值（交割单）> BASE 的 2 倍 → 停止并重估

## 六、风险与限制

1. **功效不足是结构性**：除非效应变大，否则短期前瞻无法给出结论（§3.2）。
2. 未来数据可能含制度变化（涨跌停规则、T+1、印花税），需在台账记录规则版本。
3. 纸面撮合无法模拟排队与部分成交，1.93% 的卖出不可成交仍是缺口。
4. 本协议不接券商、不下单，**不构成实盘方案**。
