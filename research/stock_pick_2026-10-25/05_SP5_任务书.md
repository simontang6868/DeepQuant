## 0. 这份任务书是什么，不是什么

**是**：把「SP-4 审计发现了什么漏洞」逐条翻译成**可执行、可判定、可验收**的开发任务，并明确每项的完成标准与「无法验证」分支。

**不是**：
- 不是新一轮策略搜索 → **不新增因子、不改参数、不做收益优化**；
- 不是把 20% 仓位包装成可投方案 → 20% / 7~11% 只能以**「研究情景假设」**字样出现；
- 不是「把未解决项标为通过」的进度表 → **允许并预期得出「SP-4 主线不成立」**。

三条 SP-5 新增纪律（在既有铁律 R2/R3/R5/R7/R12 之上）：

| 编号 | 纪律 |

| S-1 | **口径先行**：可执行规则、判定阈值、指标定义必须在跑之前写死并冻结哈希；跑完不得改 |

## 2. 三口径定义（跑前冻结，见 `SP5_预登记.md`）

专家要求把结果拆成三种口径。**定义在此写死，不允许在看到结果后调整。**

| 口径 | 定义 | 允许用途 | 禁止 |
|---|---|---|---|
| **A 全样本研究** | 257 个月全跑，**逐月标注是否可执行** | 研究历史现象、看机制 | ❌ 不得作为「策略表现」对外引用；必须同时报不可执行月数 |
| **B 可执行月份** | 仅统计满足 E1–E3 的月份（下节） | 主口径，SP-5 全部判定基于它 | ❌ 不得按月挑好坏（只能整月进/出，规则先定） |
| **C 连续可执行区间** | 满足 E1–E2 的**最长连续**月份区间，长度 ≥ 36 | **唯一可对外引用的「表现」口径** | ❌ 不得因结果不好而移动起点；起点由 E 规则自动产生 |

**可执行规则（预登记，写死）：**

- **E1 决策可执行**：决策日 `pool_n ≥ 5`（池 = 价格 1~50 元 ∩ `amt20>500万` ∩ 流动性分位<20% ∩ `f3pct≤0.70`）；
- **E2 买入可执行**：次一交易日实际**可买**只数 ≥ 5（可买 = 有成交 ∩ 非一字涨停 ∩ 非停牌）；
- **E3 卖出可执行**：换出标的在次一交易日**可卖**（非一字跌停 ∩ 非停牌）；
- **E4 区间**：E1∧E2 连续满足的最长月份段，长度 ≥ 36 才可称「连续可执行区间」。

> ⚠️ 反滥用条款：不得「删掉表现差的月份提高收益」、不得「看完结果再挑起始日期」。E 规则一旦冻结，输出的月份集合是**机械结果**，不接受人工调整。

### P0-3 涨跌停 / 停牌 / 未成交约束

**这是当前净收益最可能被高估的一环。** 原则：**不能建模的部分写「无法验证」，不能用一个更高的滑点参数假装覆盖。**

**方法（算法写死）**

1. **限价档 `limit_pct(code, date)`**
   | 板块 | 档位 | 备注 |
   |---|---|---|
   | 主板 600/601/603/605/000/001/002/003 | 10% | |
   | 创业板 300/301 | **2020-08-24 起 20%**，此前 10% | 制度变更必须分档 |
   | 科创板 688/689 | 20% | |
   | 北交所 8xx/4xx | 30% | |
   | 深市 ST（有真值表） | 主板 5% / 创业板 20% | 来自 P0-2 |
   | 沪市 ST | **未知 → 按 5% 档做上下界双跑** | 标注为区间而非点 |
2. **涨停不可买**：次一交易日 `high == low`（一字）且 `close/prev_close − 1 ≥ limit_pct − 0.2pp` → `FAIL_LIMIT_UP`；
3. **跌停不可卖**：同理 `FAIL_LIMIT_DOWN`；
4. **停牌**：次一交易日无记录或 `volume == 0` → `HALT`；
5. **三档建模**（必须全跑，不得只跑一档）：
   - **宽松档**：失败顺延至下一可成交日，顺延期间按原持仓/现金计收益；
   - **严格档**：当日失败 → 该笔不建仓，资金留现金至下次月末；
   - **最坏档**：整月不建仓（近似上界损失）；
6. **逐笔台账**：每笔订单 `order_status ∈ {FILLED, FAIL_LIMIT_UP, FAIL_LIMIT_DOWN, HALT, NO_PRICE}`，落 `sp5_out/sp5_fill_ledger.csv`；
7. **部分成交**：无委托簿 → 只能用容量约束（`W/ADV`，现行参与率中位 0.0054%）判定「理论可成交」，**必须写明这是假设**，不是实测。

**完成标准**
- [ ] 逐笔台账：笔数、状态分布、按年 × 状态交叉表；
- [ ] 三档净年化 + 日频 MDD + 换手 + 现金残留；
- [ ] `FAIL_*` 合计比例与最集中的年份；
- [ ] **未建模项清单**（排队位置、盘中撤单、集合竞价撮合、复牌跳空）逐条写明「无法验证」；
- [ ] 失败订单在净值里**实际未被计入成交**（用一个可复现的用例证明，进入测试）。

**判定**
- `FILL_ABSORBED`：三档净年化均 > 8% 且日频 MDD ≥ −20%；
- `FILL_KILLS`：最坏档净年化 ≤ 0（或净超额 ≤ 0）→ SP-4 主线不可执行；
- `FILL_PARTIAL_CANNOT_VERIFY`：失败率数据不可靠或无法区分「排队未成」与「未下单」→ 只保留纸面前瞻。

**禁止**：用滑点替代未成交；删除失败订单；把失败单按理论价成交；只跑宽松档就宣布通过。

### P0-4 20% 仓位四道验证（派生于专家 §二.1）

**为什么必须有**：专家明确「不能仅因为 20% 仓位的历史回撤低于 20%，就认为未来也满足约束」。当前 −14.05% 只来自**全样本单一起点 + 缩放口径**。

**四道验证**
1. **起点敏感性**：7 个起点（2005 / 2008 / 2010 / 2013 / 2015 / 2018 / 2021）各自跑到 2026-08，报 20% 仓位日频 MDD **分布**，不只报全样本；
2. **市场阶段**：2008 崩盘、2015H2、2018、2022、2024 初 逐段 MDD；
3. **真实组合净值**：股票市值 + 现金 + 成本 + 整手残差**同一时间轴**对齐（应收/应付、T+1、现金利息按日）；回撤基于**组合净值**，不是「股票收益 × 0.2」；
4. **再平衡真实执行**：月度再平衡的换手成本与失败成交计入；与「不再平衡（漂移）」对照（审计已给漂移 −42.99%，此处要含成本版本）。

**完成标准**
- [ ] 7 起点 × 1 张表 + 5 个阶段 × 1 张表；
- [ ] NAV 对账 CSV：`date, 股票市值, 现金, 累计成本, 组合净值, 回撤, 是否再平衡日`；
- [ ] 明确回答：20% 是「已解决风险」还是「仅观察仓位」。

**判定**
- `DD_ROBUST_20PCT`：**全部 7 个起点**日频 MDD ≥ −20%，且最差起点余量 ≥ 2pp；
- `DD_NOT_ROBUST`：任一主要起点破 −20% → 20% **不得**写成「方案」，只能写「待观察仓位」。

**禁止**：只报全样本一个数；用缩放代替组合净值；把「起点挑到最好」当结论。

### P1-2 行业暴露

**先做可得性核查，不预设能做。** 现状：`tdx` 只返回**当日**行业归属，无历史映射；用当前行业回填历史 = 前视 + 错分（公司会改行业/重组）。

### P2-1 前瞻结果评估方案冻结

**必须把「四层」拆开**（专家 §三.1），禁止用「跑满 36 个月且收益为正」一把过：

| 层 | 判定内容 | 判据（预定义） |
|---|---|---|
| L1 **运行成功** | 系统按计划生成信号并保存台账 | 缺月 ≤ 1 次/年、哈希无漂移 |
| L2 **执行可行** | 交易规则、数据、成交约束得到验证 | P0-3 的失败订单可记录且可复现 |
| L3 **策略有效** | 样本外表现支持预登记收益假设 | 净年化 > 8% **且** 相对档内等权超额 > 0，且统计功效足够 |
| L4 **风险可接受** | 回撤等风险指标符合要求 | 日频 MDD ≥ −20%（组合净值口径） |

**必须先写死功效事实**：36 个月对 8%/年的检验功效约 **21%**；要达到 80% 需约 **206 个月**。⇒ **36 个月即使收益为正，也不构成「策略有效」的证明**，最多证明 L1/L2。

**完成标准**
- [ ] `SP5_FORWARD_EVAL_SPEC.md` 写明：四个层的独立判据、样本量要求、停止规则、多重比较处理；
- [ ] 冻结哈希落盘，**冻结日期 ≤ 首次非 dry-run 记录日**；
- [ ] 明确写入「36 个月后若功效不足，继续观察，不得宣布成功」。

**判定**：`SPEC_FROZEN`

## 5. 执行顺序与门禁

```
P0-1（立即，可并行）
P0-2 ──┐（ST 真值表已完成预探）
       ├─> P0-3（成交约束）──┬─> P0-4（20% 四道验证）
       │                     └─> P1-1（三口径）
P1-2（行业，独立核查）
P2-1（评估方案冻结）──> P1-3（真实前瞻启动）
```

**门禁**：
- 只有 **P0-1 ~ P0-4 全部有结论**（含 `*_CANNOT_VERIFY` 分支）才允许写「SP-5 阶段结论」；
- 在此之前，**禁止任何形式的资金配置讨论**；
- P0 期间**禁止**开新因子、禁止调 `amt20>500万` / `f3pct≤0.70` / 5 只 等任一参数——它们是「策略定义」，不是可优化参数。
