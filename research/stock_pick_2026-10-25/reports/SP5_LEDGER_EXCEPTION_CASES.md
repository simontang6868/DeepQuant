## 1. A 类：建仓日不可买，账本仍成交

### 1.1 事实

`p04_position_dd.simulate()` 与独立账本 `p04b.simulate()` 结构一致：卖出端调用 `_ok(tabs, c, d, "sell")` 校验，**买入端只校验价格是否为有限值，从不调用 `_ok(..., "buy")`**。因此：

- 涨停日（`LIMIT_UP`，`buy_ok=False`，一字板买不到）→ 账本照买；
- 停牌日（`HALT`，无量）→ 账本用前向填充价照买；
- 无 bar 日（`NO_BAR`，该股当日无任何行情记录）→ 账本用更早的填充价照买。

### 1.2 案例（path-0，共 99 笔，覆盖 74 个月）

| 月份 | 建仓日 | 代码 | 原因 | 账本成交价 |
|---|---|---|---|---|
| 2005-04 | 2005-05-09 | 600006 | NO_BAR | 2.1239 |
| 2005-06 | 2005-07-01 | 600121 | NO_BAR | 2.8877 |
| 2006-04 | 2006-05-08 | 600136 | NO_BAR | 1.8156 |
| 2006-05 | 2006-06-01 | 600136 | NO_BAR | 1.8156 |
| 2006-06 | 2006-07-03 | 600136 | NO_BAR | 1.8156 |
| … | | | | |
| 2026-08 | 2026-09-01 | 300117 | NO_BAR | **NaN**（该股 2025-03-31 后再无 bar） |

- 分布：`NO_BAR 89 / HALT 7 / LIMIT_UP 3`（path-0）；50 路径合计 `NO_BAR 3,412 / HALT 134 / LIMIT_UP 92`。
- 集中月份：2013-12（3 笔）、2015-06/07/08/09（各 3 笔）——与 2015 年股灾期间大面积停牌一致。
- 典型持续案例：600136 连续 3 个月在无 bar 日被"买入"（价格恒为 1.8156，即停牌前收盘）。

明细：`sp5_out/p04c_exc_fillfail.csv`。

### 1.3 量化影响（path-0，w=0.20 rebal）

施加 `buy_ok` 约束（涨停/停牌/无 bar 不买）后：

| 起点 | BASE 年化 | BUY_OK 年化 | Δ年化(pp) | BASE MDD | BUY_OK MDD | ΔMDD(pp) | 期末未投资 BASE→BUY_OK |
|---|---|---|---|---|---|---|---|
| 2005 | +9.21% | +9.13% | −0.07 | −14.73% | −14.59% | +0.14 | 80.17%→82.87% |
| 2008 | +8.00% | +7.93% | −0.08 | −13.66% | −13.65% | +0.00 | 81.45%→83.71% |
| 2010 | +7.24% | +7.19% | −0.05 | −7.09% | **−11.21%** | **−4.12** | 81.53%→84.03% |
| 2013 | +7.78% | +7.73% | −0.05 | −7.34% | **−10.83%** | **−3.48** | 81.24%→84.19% |
| 2015 | +7.24% | +6.10% | **−1.14** | −7.09% | −7.20% | −0.11 | 80.89%→85.59% |
| 2018 | +5.73% | +5.76% | +0.02 | −6.02% | −6.01% | +0.00 | 82.58%→85.06% |
| 2021 | +6.25% | +6.28% | +0.03 | −6.13% | −6.13% | +0.00 | 81.63%→84.07% |

三点评注：

1. **年化方向不统一**（−1.14pp ~ +0.03pp），说明买入约束不是单向"高估"，而是**改变了暴露时点**——不加约束时账本在崩盘后立即满仓买入，加约束后延迟建仓。
2. **MDD 在 2010/2013 起点恶化 3.5~4.1pp**，因为延迟建仓使部分现金留在账户外更久、而反弹初期仓位不足，峰谷形态改变；但仍远离 −20% 阈值。
3. **未投资比例上升 2.4~4.7pp**（现金从 ~81% 升至 ~84%），是"不可买"的直接代价，与阶段 S 已记录的「现金残留恶化」同源。

结果文件：`sp5_out/p04d_bias_sensitivity.json`。

## 2. B 类：长期停牌缺口被前向填充

| 代码 | 缺口起 | 缺口止 | 交易日数 | 缺口前最后收盘 |
|---|---|---|---|---|
| 000622 | 2006-05-08 | 2013-02-07 | **1,648** | 1.1200 |
| 000156 | 2006-04-03 | 2012-10-18 | 1,591 | 0.9588 |
| 000672 | 2007-04-24 | 2013-04-25 | 1,458 | 2.9154 |
| 000403 | 2007-04-11 | 2013-02-07 | 1,419 | 2.0861 |
| 000757 | 2007-04-24 | 2013-02-07 | 1,410 | 3.1833 |

- 全部 ≥5 日缺口：**12,391 段 / 2,594 只**；前 300 段的交易日数中位数 204、均值 306、最长 1,648。
- 被静默填充的日历天数：path-0 **69,933**、path #26 **80,388**、50 路径合计 **644,713**。
- 机制：`p04_position_dd.py` 对整条日历数组做 `pd.Series(arr).ffill()`，会把「上月最后一个已知价」跨月带入本月首个缺口日，因此**停牌数年的个股在账本中保持最后价不变，仍按该价参与月末调仓与卖出**。独立账本为复现该行为显式实现了同一 carry（并计数），故 NAV 对账一致——**这是对账一致的原因，不是正确性的证明**。

明细：`sp5_out/p04c_exc_gaps.csv`（前 300 段）。

## 3. C 类：末段无行情代码仍被列为持仓（新发现）

判定：`个股最后 bar 日期 < 建仓日` ⇒ 该槽位为幽灵仓位（该股当日已无任何行情，账本仍以最后价持有/买入）。

| 指标 | 数值 |
|---|---|
| 幽灵槽位 | **724 / 64,250 = 1.127%** |
| 涉及代码 | **18 只** |
| 最长连续 | 600647（末 bar 2024-06-26，首次幽灵 2024-06-28，**81 个月**） |
| 次长 | 000606（末 bar 2023-07-05，76 个月）；600891（2021-04-30，65 个月） |
| 其他 | 000613、600890、300367 各 51 个月 |

要点：

- 这些代码**不是**"整段历史都没行情"（那会在取数阶段被 `miss` 计掉），而是**中段有行情、末段断供**，因此能通过 `p03` 的池筛选并持续出现在目标列表里。
- 300117 是极端例子：末 bar 2025-03-31（0.43 元），但 2026-05 至 2026-09 连续 5 个月仍是目标持仓，账本按 0.43 元买卖。
- **根因未确定**：可能是退市、代码变更（换代码后旧代码停更）、或 `data/exec_all` 末段覆盖缺失。三种含义完全不同（前两者是真实不可交易，后者是数据缺陷），标 **UNVERIFIED**，需在 P1-2 中用独立来源（交易所退市清单 / 代码变更表）判定，不在本阶段猜。
- 影响量级：1.127% 的槽位 × 单票目标权重（20%/5=4% 名义）≈ 0.045% 的组合权重，对 NAV 影响 <0.3pp/年量级；但**方向不清**（若这些股实际已退市归零，账本高估）。

明细：`sp5_out/p04d_dead_codes.csv`。

## 4. D 类：最差回撤路径 #26 拆解

| 项目 | 数值 |
|---|---|
| 路径 | #26（50 条中的最差），起点 2005-01 全样本，w=0.20 rebal |
| 年化 | +8.41% |
| MDD | **−20.65%** |
| 峰 | 2008-03-11（NAV 峰值） |
| 谷 | 2008-11-04 |
| 历时 | 168 个交易日 |

峰→谷逐窗口收益（buy[t] → buy[t+1]）：

| 窗口（月末） | 收益 |
|---|---|
| 2008-03 | +2.01% |
| 2008-04 | −1.64% |
| 2008-05 | −4.55% |
| 2008-06 | +2.17% |
| 2008-07 | −5.77% |
| 2008-08 | −1.56% |
| **2008-09（2008-10-06→2008-11-03）** | **−7.52%（最大）** |
| 2008-10（谷后反弹窗口） | +5.02% |

最大亏损窗口的个股拆解（5 只持仓，**5/5 全部下跌**）：

| 代码 | 窗口收益 |
|---|---|
| 600340 | −41.7% |
| 000815 | −41.2% |
| 600571 | −29.5% |
| 600081 | −27.7% |
| 002031 | −22.9% |

解读：

- 破界（MDD < −20%）只发生在**包含 2008 年 10 月的路径**：2005 起点破界占比 4%（2/50），2008 起点 2%（1/50），其余 5 个起点 **0%**。
- 这是「20% 仓位 + 5 只等权」在系统性崩盘中的**结构性暴露**，不是选股或账本缺陷：单月全持仓 −22.9%~−41.7%，20% 仓位即 −4.6%~−8.3%，与观察到的 −7.52% 吻合。
- 因此 `DD_ROBUST_20PCT` 的正确表述是：**除 2008 年级别的系统性崩盘外，20% 仓位在 7 个起点上 MDD 中位数均 ≥ −15.92%，未触及 −20%**；不能表述为"任何情况下回撤不超过 20%"。

文件：`sp5_out/p04c_exc_worstdd.json`、`sp5_out/p04c_exc_worst_windows.csv`。
