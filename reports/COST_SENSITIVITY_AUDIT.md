## D1. 现有成本实现审计

`scripts/run_phase_c.py::cost_of`：

```python
cm = 2.0 * to * rate * 100.0        # 月度成本（pp）
net = mean_d * 100.0 - cm
```

| 问题 | 审计结果 |
|---|---|
| 佣金是否为**单边**费率 | 是。`rate` 是单边费率 |
| 买卖两侧如何计费 | 乘 `2` → **两侧对称、各按单边费率** |
| 印花税如何处理 | **未单独建模**（被 implicitly 包含在 `rate` 里，且按双边对称计） |
| 过户费及其他费用 | **未单独建模** |
| 换手率分母 | 单边换手 = `0.5×(新增+剔除)/持仓数`；乘 2 得双边成交额占比 |
| 成本是否重复扣除 | **否**（`net + cost == gross` 恒等，变异测试第 7 项已验证） |
| 冲击成本单位 | 与成交额/参与率一致：Amihud `ILLIQ = |r|/成交额(元)` × 交易额 `P` → 收益单位 ✓ |

⚠️ **审计发现：印花税的不对称性被忽略。**
A 股印花税**仅对卖出方征收**，而我们按买卖两侧对称计费。
这在本项目（再平衡时买卖金额近似相等）下影响有限，但属模型简化，须声明。

## D2. ⚠️ 0.3% 究竟是实际费率还是压力测试参数？

**A 股真实综合成本（2023-08-28 印花税减半后）：**

| 费用 | 费率 | 征收方向 |
|---|---:|---|
| 佣金 | ~0.025% | 双边 |
| 印花税 | 0.05% | **仅卖出** |
| 过户费 | ~0.001% | 双边 |
| 冲击成本 | 本样本测得 0.0003~0.0008pp/月 | — |

折算为**等价对称单边综合费率**：

```
r_eq = (2×(0.025% + 0.001%) + 0.05%) / 2 = 0.051%
```

> **原报告使用的 0.3% 是这个等价值的 5.9 倍 → 属压力测试参数，不是可实际获得的报价。**

实测验证：按 A 股真实结构计算，成本 **0.0192pp/月**，净 **+0.1260pp**，t(NW) = **+4.02**。

## D4. ⚠️ 对原结论的影响评估（最重要）

原报告的判定 `NET_AFTER_EXECUTION_ABSORBED` 与
专家报告的「不存在成本后 ≥0.30pp 的单边 alpha」
**都是在 0.3% 费率下得到的**。

| 费率情景 | 净值 | t(NW) | 结论 |
|---|---:|---:|---|
| 0.30%（压力测试） | +0.0324 | 1.04 | 不显著 → "不可用" |
| **0.051%（A 股真实等价）** | **+0.1260** | **+4.02** | **显著** |
| 0.051% + 最低佣金（1,000 万） | +0.0990 | — | 仍为正且大幅 |

**因此：现有的"不可用"结论不能被解释为"在真实成本下不可用"。**
准确的表述是：

> 在 **0.3% 单边综合费率（约为 A 股真实综合成本的 5.9 倍，属压力测试）** 下，
> 净值不显著；**在真实费率情景下净值显著为正**（t≈4.0）。
> 结论对费率假设**高度敏感**，费率是本结论最主要的驱动变量。

**但这不构成"可用"的确认**，因为仍有未解决项（见阻塞清单）：
- 0.025% 佣金与无最低佣金是情景假设，取决于实际账户；
- 现金残留与容量约束仍在（W=1,000 万 时 12.32% 闲置）；
- 样本内，"不衰减"未被证明，多重检验下需带限定。
