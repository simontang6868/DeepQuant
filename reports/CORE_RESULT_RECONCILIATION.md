## 2. ⚠️ 发现的一处报告缺陷

专家报告与阶段 J 归因表中出现的 **0.0507pp** 是
`0.1634（阶段 I 的 alpha） − 0.1127（阶段 J 的佣金）` 的**手工近似**，
**混用了两个实验的口径**。

阶段 I 的**实际**成本后净值是 **0.050239**。

| | 值 |
|---|---:|
| 报告中出现的 0.0507 | 近似值（跨实验混用） |
| **阶段 I 产物实际值** | **0.050239** |
| 差 | 0.0005 |

影响评估：**不影响任何判定**（两者都远低于 0.30pp 门槛，且都不显著），
但属于"报告数字未追溯到产物"的缺陷，需更正。
