## 1. 规则清单（全部显式，无隐含分支）

| 规则 | 取值 | 依据 | 可测 |
|---|---|---|---|
| 上市判据 | 首个行情日 ≤ 当日 | 数据起点即上市起点（**近似**，见 §4.1） | ✅ |
| 上市满 N 日 | 截至当日有效交易日 ≥ 252 | Gate 1~6 统一约定 | ✅ `test_min_listed_days_boundary` |
| 当日可交易 | 当日必须有行情行 | 无行情 = 不可定价 = 不可交易 | ✅ `test_suspension_excluded` |
| 序列终止 | 末日 < 当日 → **不入池** | 无法区分退市与数据中断 | ✅ `test_no_after_last_data_option` |
| 最低历史 | 总行情行数 ≥ `min_history_days` | 独立规则，不与上市天数混用 | ✅ `test_min_history_days` |
| 价格口径 | **只用 EXEC（不复权）** | 交易状态必须用真实成交价判；ADJ 是构造量 | 代码层强制 |

服务端不做任何"补偿性放宽"：没有隐式的"允许用最后价"、没有"停牌按 0 收益处理"。

## 2. 五态枚举的必要性（与布尔返回的对比）

同一天的同一个代码，`not in universe` 可能是五种情况：

| 状态 | 若压成 False 会怎样 |
|---|---|
| `BEFORE_LISTING` | 无影响（确实不在） |
| `AFTER_LAST_DATA` | **把"抓取失败"当成"已退市"** → 该股票被永久排除，且无人知道 |
| `SUSPENDED_LIKELY` | **把"停牌"当成"不存在"** → 无法区分"当时买不到"与"当时没有" |
| `NO_DATA` | **把"未知"当成"没有"** → D-1 事故的同构错误 |
| `HAS_DATA` | — |

**实测（2026-09-30）**：

```
HAS_DATA 5212 | SUSPENDED_LIKELY 5 | BEFORE_LISTING 2 | AFTER_LAST_DATA 253 | NO_DATA 0
```

`NO_DATA = 0` 是好事（没有"文件存在但空"的标的），但也说明**五态的价值在这批数据上主要体现在
`AFTER_LAST_DATA`（253 只）与 `SUSPENDED_LIKELY`（5 只）的区分上**——而这 253 只里，
真正能确认退市的只有 249 只（§3）。

## 3. 退市判定的三态结论（本审计最重要的一张表）

`AFTER_LAST_DATA` 的 253 只（末日 < 2026-09-16），逐一归类：

| 类别 | 只数 | 依据 | 性质 |
|---|---:|---|---|
| **确认退市** | **249** | 与 `data/qfq_mult/delist/` 名单**100% 交集**，且名单内 0 只被漏判 | **已核实** |
| 面值退市候选 | 2 | 688496.SH 末日前一日 −37.6%（0.93→0.58）、002731.SZ 0.77 元 | **未知**（很可能退市，但无独立证据） |
| 疑似临时停牌 | 1 | 000016.SZ 末日 2.46 元、无暴跌 | **未知** |

**因此正确表述是"252 只终止 + 1 只待核"，不是"252 只退市"。**

这 1 只（000016.SZ）与 2 只面值退市候选，**在 Gate 6 里被当作"不在池内"处理**——
方向上安全（不给它们估值），但要知道：**它们不是"已确认退市"，是"无数据"。**

## 4. ⚠️ 三个必须随结论引用的问题

### 4.1 "首个行情日"不等于"上市日"

本接口用**首个有行情日**近似上市日。差异场景：

- 上市后立即长期停牌 → 首个行情日可能晚于真实上市日（少见）；
- 数据源左截断 → 2005-01 之前上市的标的，首个行情日都是 2005-01-04（**普遍**）。

**后果**：`min_listed_days=252` 在 2005-2006 会被系统性满足得更晚。
实测：**2005 年末只有 6 只可投资**（因为到 2005-12 只有约 240 个交易日 < 252）。

→ **2005-2006 的池规模不可用于任何跨期比较**。这也是 Gate 6 从 2007-01 起跑的真正原因
（数据可用性驱动，与收益无关）。

### 4.2 B 股是被"ADJ 缺失"偶然排除的，不是显式规则

`data/qfq_all` 5,444 只 = `exec_all` 5,472 − 28 只。这 28 只的构成：

| 类别 | 只数 | 原因 | 是否应进 A 股宇宙 |
|---|---:|---|---|
| **B 股**（200xxx / 900xxx） | **14** | `div_source_unavailable`（东财/新浪均无分红表） | **否**（外币计价、独立市场） |
| **新股**（301xxx / 688xxx / 601xxx 等） | **14** | `too_few_rows`（仅 2~28 行，2025-2026 上市） | **否**（不满 252 日，本就不入池） |

**问题**：Gate 6 的宇宙是"有 ADJ 文件的 5,239 只（当时）"，B 股因**分红数据缺失**而被排除。
**这是隐式排除**——如果哪天补上了 B 股分红，它们会**静默进入 A 股宇宙**，而没有任何规则阻止。

**处置**：
1. Gate 6 已冻结，**不改**；在报告中声明"宇宙事实上不含 B 股"；
2. **阶段 C 起的新实验必须在规则里显式排除 B 股与非 A 股代码**（`is_a_share()`）；
3. 已在本文件登记为强制规则，见 §5。

### 4.3 Gate 6 的宇宙与 as-of 接口的宇宙不是同一个

| | 来源 | 只数 |
|---|---|---:|
| as-of 接口 | `exec_all`（有 EXEC 即可） | **5,472 → 有效 5,118**（2026-09-30） |
| **Gate 6** | `qfq_all`（必须有 ADJ） | **5,239**（第二次重跑）；**5,444**（第三次，补分红后） |

差异来源：ADJ 依赖分红事件，而分红缺失不等于"无公司行为"。
**这正是 §4.2 的隐式排除机制**，也是为什么补分红后宇宙从 5,239 跳到 5,444。

## 5. 强制规则（阶段 C 起生效）

```python
# 新实验的宇宙必须满足全部条件，缺一不可
1. 代码形如 \d{6}\.(SH|SZ)
2. 排除 B 股：不以 200 / 900 开头
3. 排除科创板/北交所（如研究范围不含）：688 / 689 / 8xxxxx
4. 用 exec_all 判交易状态，用 qfq_all 算收益；**两者必须都能覆盖**
5. 收盘价 ADJ 与 EXEC 都必须存在（否则无法同时研究 + 模拟）
6. 上市满 252 个有效交易日（用 exec 的日期计数）
7. 当日有行情（否则不可交易）
8. 序列终止后一律不入池
```

**第 4、5 条是新增的**：原接口只要求 EXEC。理由是——如果一只标的没有 ADJ，
它的收益**无法与研究层的其他标的口径一致**（未复权的收益含除权跳变）。
所以"能用 ADJ 算收益"必须是与"能交易"并列的入池条件。

## 7. 审计结论

| 项 | 结论 |
|---|---|
| 规则是否显式 | **是**（`EligibilityRule` 可序列化，无隐含分支） |
| 状态是否区分 | **是**（五态；`NO_DATA` 与 `AFTER_LAST_DATA` 分开） |
| 退市判定是否可靠 | **对已知 249 只 100% 命中、0 假阴性**；对未知标的**不臆断** |
| 是否有单元测试 | **12 个，全通过** |
| 是否有隐式排除 | **有 1 处：B 股靠 ADJ 缺失被动排除**（§4.2，已登记待修） |
| 是否可直接用于新实验 | **不能直接用**——须先实现 §5 的第 2、4、5 条 |
