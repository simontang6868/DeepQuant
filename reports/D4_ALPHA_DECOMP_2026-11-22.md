## 5. worked example：`sell < len(dates)` 是点内排除，不是全样本排除

### 5.0 先回答"`ok` 是哪个维度"（本轮最要紧的一问）

`build_panel.py:152-169`，逐只股票循环：

```python
for i, p in enumerate(files):                      # ← 股票在**外层**
    ...
    dates = df["date"].to_numpy()                  # 该股自己的交易日
    pos = np.searchsorted(dates, ME_arr, side="right") - 1     # shape (n_ME,)
    ok = pos >= W - 1                                          # shape (n_ME,)  ← 一维
    ok &= (stale <= MAX_STALE)                                 # 仍是 (n_ME,)
    buy, sell = pos + 1, pos + 1 + HOLD
    ok &= (sell < len(dates))                                  # 仍是 (n_ME,)
    idx = np.where(ok)[0]
    rows.append(pd.DataFrame({..., "date": ME_arr[idx], "code": code, ...}))  # 每只股一段
```

**答案：`ok` 是一维 `(n_ME,)`、按股票各自计算。** `ME_arr` 是广播的常量轴，`dates` 是标量长度，所以 `ok` 上不是 `(N_stocks, N_ME)` 的二维矩阵，**`ok &=` 绝不可能把一只股的失败广播到别的股票**；每只股票各 append 自己的一段 `DataFrame`。

⇒ 专家担心的"**池内任一只 21 天内退市 ⇒ 整个 ME 全删**"**不成立**。偏差是**股票级**的（"该股的末 1~2 个月"），且**同 ME 其他股票完全不受影响**。这比"ME 级偏差"小一个量级。

### 5.1 真实样本

**真实样本：000018（神州长城），2020 年退市**

| 项 | ME=2020-01-23 | ME=2019-12-31（上一月） |
|---|---|---|
| 该股 K 线根数 | 3,424 | 3,424 |
| 首/末交易日 | 2005-01-04 / **2020-01-06** | 同 |
| `pos` | 3,423 | 3,420 |
| `buy` / `sell` | 3,424 / 3,444 | 3,421 / 3,441 |
| `sell < len(dates)`？ | **否**（3,444 ≮ 3,424） | **否**（3,441 ≮ 3,424） |
| 面板有行？ | **无** | **无** |

**结论**：
1. 排除是**点内**的——只影响"该股数据结束前的最后 1~2 个月"，**不是整段历史**。2019-11 及更早的行都在（`sell` 仍 < 3,424）。
2. **判定确实用到"决策日之后的信息"**（`len(dates)` 包含 ME 之后的数据），但用途只是"**是否存在 21 个交易日的可测窗口**"，不涉及未来价格进入选股。性质是**可测性条件**，不是价格前视。
3. 因此偏差是"**末期 1~2 个月不可持有**"，量级远小于"整只股票消失"。这一点我上一版没有说清，导致您怀疑方向相反——**您的怀疑合理，结论是方向未反、量级更小**。

**不能**：说"d4 有 11%/年的 alpha"；不能进实盘背书；不能外推到 1 亿（低流动性溢价，阶段 R 已显示 1 亿转负）。
**另加一条（本轮新增）**：不能因为"被过滤的票事后涨过"就说"过滤器误杀"——现代段那批是 **−0.46pp**，过滤器在干活。
