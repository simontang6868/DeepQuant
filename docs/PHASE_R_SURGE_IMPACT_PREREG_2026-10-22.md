## 0. 为什么开这一阶段

**它是决定 SURGE 生死、也是进入任何前瞻验证前必须补的最后一个数。**

背景链条：

1. 阶段 L 判 `SURGE_AVOID_ABSORBED`，依据是 0.3% 费率下净 −0.0385pp。
2. 阶段 N 审计查明 **0.3% 是压力参数**（A 股真实等价对称单边约 0.051%，0.3% 是其 5.9 倍）。
3. 券商费率测算（2026-10-21）显示：在**东方财富官方默认**（万2.5 全佣 + 5 元下限）下，
   SURGE 净 **+0.0694pp，t=+2.134**——**由负转正**。
4. ⚠️ 但那次测算里 **SURGE 的冲击成本 = 0，因为从未建模**（阶段 L 没算过）。
   且 CI 下界仅 **+0.0057**，非常贴边。

SURGE 的换手是 **24.09%/月**（exQ5 是 18.3%，1.32 倍），
参与率与冲击都会相应更高。**这个数加上去，它可能又翻回不显著。**

本阶段把它算出来。

## 4. 主检验

逐月：

```
net_t(W) = f_inv,t × alpha_V1,t  −  comm_t(W)  −  impact_t(W)
```

- `f_inv` 由阶段 I 的 `capacity_of()` 得出（整手取整后的已投资比例）
- `comm` 按 §3 情景，含单笔最低 5 元
- `impact` 分 A（Amihud）与 B（平方根 η=1）两列

**主口径 = EM_DEFAULT + 冲击 A（Amihud，无自由参数）**。

### 判据（写死，三态）

记 `pass(W)` = 该资金档下 |t(NW)| ≥ 1.96。

| 档位 | 条件 |
|---|---|
| `SURGE_EXECUTABLE_UNDER_REAL_FEES` | **全部**资金档在主口径下 pass |
| `SURGE_SCALE_DEPENDENT` | 部分 pass（只在某个资金量上成立） |
| `SURGE_IMPACT_MODEL_DEPENDENT` | 主口径 pass，但换成冲击 B（η=1）后**不** pass |
| `SURGE_NOT_EXECUTABLE` | 主口径下全部不 pass |

⚠️ 若主口径 pass 而 B 口径不 pass → 判 `SURGE_IMPACT_MODEL_DEPENDENT`
（与 `SURGE_EXECUTABLE_...` 互斥，取更保守者）。

### 必报

1. 参与率 `P/ADV` 分布（中位 / P90 / P99 / 最大）
2. 冲击 A 与 B 各档数值
3. **打平 η\***（反解使 mean(net)=0 的 η）——不猜 η，把不确定性交给读者
4. 各档 net 的 NW t、iid t、95% CI
5. 两段（2007-2015 / 2016-2026）各自的 net 与 t（**描述性**，见 §6）

## 5. 预期方向（用可算的量判断）

exQ5 的已知基准：换手 18.3%，`P/ADV` 中位 0.0054%，
冲击 A@3000万 = 0.000784pp，冲击 B(η=1)@3000万 = 0.018996pp。

SURGE 的换手 24.09% = **1.317 倍**；持仓只数与 ADV 量级相近 →

- 冲击 A ≈ 0.000784 × 1.317 ≈ **0.00103 pp**
- 冲击 B(η=1) ≈ 0.018996 × 1.317 ≈ **0.0250 pp**

主口径 @3000万：
`f_inv(0.9519) × alpha(0.106057) = 0.10095`，减佣金 0.0316、减冲击 A 0.0010
→ **net ≈ +0.0683pp，t ≈ +2.10 → 显著**

换冲击 B(η=1)：0.10095 − 0.0316 − 0.0250 → **net ≈ +0.0443pp，t ≈ +1.37 → 不显著**

→ **预期判定：`SURGE_IMPACT_MODEL_DEPENDENT`**
  （无参数的 Amihud 口径下显著；文献最悲观端 η=1 下不显著）
→ 打平 η\* ≈ (0.10095 − 0.0316)/0.0250 ≈ **2.77**，高于文献区间 [0.1, 1.0]
  → **经济上**冲击打不死它，**统计上**取决于模型选择。

⚠️ **诚实声明**：这个预期部分建立在上一轮券商费率测算（+0.0694/t=2.134）之上，
而那次是**情景分析、无预登记**。本阶段是它的正式化。
若实测与预期一致，它是"对既有情景分析的确认"，不是前瞻预测。

## 6. 分段只作描述性（不许当结论）

阶段 P 已确立：**两段各自显著 ≠ 稳定**，且 SURGE 的两段之差本身只是边缘显著
（β1 −0.1292，t=−1.9605，|t|−1.96 仅 +0.0005）。

因此本阶段对两段的 net 与 t **只报告、不判据**，
且**不得**据宣称"SURGE 衰减"或"SURGE 不衰减"。
