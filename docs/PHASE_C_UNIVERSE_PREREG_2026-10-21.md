## 2.0 ⚠️ v1.0 → v1.1 修订记录（必须保留，因为预登记改过）

v1.0 的第 5 格是 **E = 全 A 宇宙 ∩ 518 名单**。冻结后复查发现**它与格 A 语义重复**：

- 格 A（518 固定名单）在每个信号日照样要按"当日有价 + 252 日"动态筛选；
- 格 E（全 A 再过一遍 518 交集）筛完的成员集合**完全等于** A。

→ **E ≡ A，冗余格，无独立信息。**

改为 **格 A0 = 518 名单 + 不要求 252 日**（即 Gate 3 的真实口径）。
这样每格都有独立含义，且能把"入池门槛"这个第三个混杂因素量化：

```
门槛效应 = spread(A) − spread(A0)      （252 日这道门槛值多少）
池效应   = spread(B) − spread(A)
构造效应 = spread(C) − spread(A)  或  spread(D) − spread(B)
```

**修订发生在运行之前，且原因已量化（E 与 A 必然同值），不是看到结果后改设计。**

`dc1ac8589cc550a1668292f972e55f29e90be697ea6866b8feda804d1c7e7ea5`（518 只纯 A 股）

> 已实测的分解（**四个数全部来自独立复算，不是估计**）：
>
> | 池 | 无 252 日 | 有 252 日 | 门槛效应 |
> |---|---:|---:|---:|
> | 518（纯 A 股） | **+0.4598** | **+0.4450** | **−0.0148** |
> | 532（含 14 B 股） | **+0.4841** | **+0.4379** | **−0.0462** |
>
> B 股效应（无门槛口径）= 0.4841 − 0.4598 = **−0.0243**
>
> ⚠️ 门槛效应在两种池下相差 3 倍（−0.0148 vs −0.0462）→ **两者有交互作用**，
> 不能简单相加。这正是必须用五格交叉、而不能只减两个数的原因。
>
> **可加性检验（这一步是我第一版写错的地方，改准）**：
>
> 若两个效应可加，则「532 池 + 门槛」应为
> `0.4598 + 0.0243 − 0.0148 = 0.4693`。
> **实测是 0.4379**，差 **−0.0314** —— 这就是交互项，**不是 0.0071**。
>
> 意思是：B 股在高门槛池里的破坏力比在低门槛池里更大（0.0462 vs 0.0148）。
> **两个效应不可加，必须用五格交叉实测，不能拆成单项相加。**
> 这条本身就是"为什么需要这个实验"的最直接理由。

## 3. 主检验（唯一）

### 3.1 定义

```
Δ_t = spread_t(B) − spread_t(A) = 2 × [d_t(B) − d_t(A)]
```

- 只在 A、B 都有观测的月份上配对（预期 237 个月）
- `mean(Δ)` 的显著性：**Newey-West，滞后 3 期**，双侧

### 3.2 判据（三条档位，机械判定）

| 档位 | 条件（全部满足） |
|---|---|
| **POOL_EFFECT_CONFIRMED** | `n ≥ 150` **且** `\|NW t\| ≥ 1.96` **且** `\|mean(Δ)\| ≥ 0.30 pp/月` |
| **POOL_EFFECT_NOT_DETECTED** | `n ≥ 150` **且** `\|NW t\| < 1.96` |
| **INCONCLUSIVE** | `n < 150` 或 NW 有效样本 < 100 |

**经济意义门槛 0.30pp/月 的依据**：它约等于 Gate 6 净效应（0.548pp @0.1% 成本）的 55%，
即"如果池效应不到净效应的六成，它就不是主要解释"。**这个门槛在看到结果前写死。**

### 3.3 交叉验证（必报，不参与判定）

```
Δ'_t = spread_t(D) − spread_t(C)      （比例 20% 口径下的池效应）
```

- `Δ` 与 `Δ'` **同号** → 主结论标注"两口径一致"
- **异号** → 主结论**降级为 `EVIDENCE_CONFLICT`**，两级结果并列报告，**不得只报一个**

### 3.4 为什么主检验用固定 110（不改为比例 20%）

| 项 | 固定 110 | 比例 20% |
|---|---|---|
| 两格持仓数 | **110 vs 110** | 518 池：38~77；全 A：186~1,020 |
| 配对差含什么 | **只有池效应** | 池效应 + 规模效应（5~25 倍） |

Gate 6 §6 已承认规模漂移是设计局限。**把已知混杂放进主判定是不可接受的**，
所以主检验选规模一致的固定 110，代价（偏离 quintile）由交叉验证承担。

## 5. 交易约束（本实验新增，比 Gate 2~6 更严）

| 约束 | 处理规则 |
|---|---|
| **停牌** | 信号日无行情 → 不入池（`SUSPENDED_LIKELY`） |
| **涨停** | 建仓日（下月首个交易日）**涨停或一字板** → 该标的**不可买入**，从多头腿剔除 |
| **跌停** | 平仓日跌停或一字板 → **不可卖出**，该标的从空头腿剔除 |
| **一字板** | 开=高=低=收 且 涨跌停 → 完全无法成交，按涨停/跌停处理 |
| **B 股** | **显式排除**（`is_a_share`） |
| **退市** | 序列终止 → 不入池（不用最后价估值） |
| **ST** | **无历史 ST 标记 → 不做区分**，声明为限制 |
| **涨跌幅阈值** | 主板 10%；科创板 20%；创业板 2020-08-24 前 10%、之后 20% |
| **豁免** | 新股上市前 5 日、复牌首日（间隔 >5 自然日）、除权日 |

**已实测的阻塞率**（`docs/LIMIT_BLOCK_RATE_2026-10-21.json`）：
正常月份 1~2.5%，**2015-06-30 达 15.2%**（60/400 涨停）。
且阻塞是**单向**的：反转策略做多"跌最多的"，反弹日最容易涨停买不到 → **与信号正相关**。

### 5.1 复牌首日

**已实测可忽略**（`docs/GATE6_SENS_RESUME.json`）：把复牌首日收益置 0 只让 d 变化
**+0.0026pp（+0.4%）**。本实验仍**标准输出**该口径（S2 口径），供对照。

## 8. 预期方向与"结果变差"的允许性声明

### 8.1 预期方向（写死，防止事后合理化）

- `mean(Δ) = spread(B) − spread(A)` **预期为正**：全 A 池比 518 只池更分散、选择偏差更小，
  按 Gate 6 的证据（532 池把 t 从 4.5 压到 2.1），池效应应为正。
- `mean(Δ') = spread(D) − spread(C)` **预期同样为正**。

### 8.2 允许结果变差（**这一段是本预登记最重要的部分**）

加入涨跌停/一字板/B股/双覆盖约束后，**效应很可能低于 Gate 6 的 1.417pp**：

1. 涨跌停阻塞率 1~2.5%（极端月 15.2%），且**与信号正相关**（输家腿的反弹日涨停买不到）；
2. B 股剔除已实测让 518 池效应降 5%；
3. 双覆盖会再剔掉少量只有单边数据的标的。

**本实验明确声明**：

- **不以"找到正收益"为目标**。若加约束后主检验不显著，**如实报告并停止该方向**；
