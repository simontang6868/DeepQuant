# L3r 选择效应检验：设计与验收

> 定位：**新实验**（不是审计）。L3q 证明 L3p 的 `per_invested = −7.87pp` 不可解释，
> 本实验换两把不依赖「现金可投」假设的尺子重新回答同一个问题：
> **ma_cross 的选股，相对「在池内当期能成交的标的上等权」，有没有正贡献？**
>
> 预登记：`docs/gates/l3r_prereg.json`（sha256 `b5cfca55…`，脚本启动校验）。
> 产物：`reports/gates/H-L3R-SELECTION/{l3r_result.json,l3r_report.md,periods.json}`、
> `reports/L3R_SELECTION_EVIDENCE.json`。

## 1. 两把尺子

| 尺子 | 定义 | 保留什么 | 丢掉什么 |
|---|---|---|---|
| **R1 组合级** | 策略臂 S（L3p 基线）vs 对照臂 **C_t**（每期只在当期能成交的标的上等权） | 真实费用、0.20 上限、整手、现金流 | 不受控的稀释差异（C_t 现金仍有 1pp 左右） |
| **R2 截面级** | 逐调仓期，`r(策略持仓等权) − r(可成交池等权)`，不进账户 | 纯选择效应 | 费用、整手、现金、可实现性 |

**为什么把对照臂换成 C_t**：原对照臂等权持有全部 30 只，未上市与已终止的标的也各得
1/30 权重，钱买不进只能趴在账上——实测它 95% 的现金来自不可成交标的（L3q）。
把标的限制在「当期能成交」，两臂的现金来源就只剩上限与费用：C_t 现金中位 **1.02%**。

**为什么还要 R2**：R1 再干净也要经过账户，任何现金/整手/上限的差异都会混进差额。
R2 直接比两个等权组合的毛收益，是「选得准不准」的最短路径。

**两把尺子的关系**：若 R1 与 R2 的折级 Δ 相关低，说明 R1 被执行结构改写，R1 不能单独
当证据。实测 r = **0.715**（28 折，23 折同号），说明 R1 在 C_t 口径下可信——这条本身
就是 L3p 时代做不到的（那时的对照臂 r 无从谈起，因为两臂现金不可比）。

## 2. 三个容易做错的口径

1. **匹配剔除**：标的必须在期初与期末**两端都有有效价**才计入两臂。替代做法（缺价
   ffill 成 0 收益）会把死票当成"横盘股"，系统性抬高两臂收益并压低差异。代价是 R2
   只回答「在能成交的标的中选股是否优于等权」，**不含**「持有到退市」的真实损失。
   实测策略持仓的可定价比例 **88.45%**，即约 11.6% 的目标持仓因两端缺价被剔除。
2. **R2 用目标持仓，不用实际成交**：选择是"想买什么"，执行摩擦属于 R1 的口径。
   若两者偏离太大（P5 相关低），那是另一个发现，不是可以随手抹平的差异。
3. **`newey_west` 入参必须是小数**。传 pp 会让 `se` 与 `mean` 同时放大 100 倍，`t`
   不变——判定不错、量级全错，所以 MDE 必须与 t 同时报。

## 3. 判据顺序（不许改）

```
1. mean > 0 且 t_iid ≥ 2 且 t_nw3 ≥ 1.645 且 R1 折胜率 ≥ 0.60 → SELECTION_EFFECT_DETECTED
2. mean ≤ 0 且 t_iid ≤ −2 且 t_nw3 ≤ −1.645                    → SELECTION_EFFECT_NEGATIVE
3. MDE ≤ 0.5pp/月                                               → NO_SELECTION_EFFECT（有功效地排除）
4. 其余                                                          → INCONCLUSIVE_POWER
```

先给「检出」留最严门槛（双口径 + 折级一致），再给「有功效地排除」，最后才允许
「功效不足」。反过来写会让每一轮都落在 INCONCLUSIVE，「没检出」被读成「没问题」。

前序（L1a/L1b/L2/L3/L3p）任一未 PASSED ⇒ 终态降级为 `L3R_BLOCKED_PREREQUISITE`。
**降级不改变初判文字**，只标注「不代表可用」。

## 4. 五条预登记预测

| 编号 | 预测 | 实测 | 结果 |
|---|---|---|---|
| P1 | R2 月均 Δ ∈ [−0.40pp, +0.40pp] 且 \|t_iid\| < 2 | −0.329pp，t = −0.994 | 未反驳 |
| P2 | R1 折均 Δ ∈ [−0.5pp, +1.0pp]，折胜率 40~62% | −0.807pp，胜率 53.57% | **被反驳**（均值越过下界） |
| P3 | C_t 现金中位 ≤ 4pp，两臂现金差中位 ≥ 5pp | 1.02% / 10.19% | 未反驳 |
| P4 | R2 胜率 ∈ 40~58% | 51.78%（197 期） | 未反驳 |
| P5 | R1 折级 Δ 与 R2 折内均值相关 > 0.5 | r = 0.715 | 未反驳 |

P2 被反驳的原因写进报告：R1 的均值被少数大负折拖垮（最差折 8 −26.1pp、折 6 −21.3pp），
而中位是 **+1.10pp**、15/28 折为正。当时的机制推断（"R1 只比 R2 偏负一点"）低估了左尾。

## 5. 结果落点

**初判 `INCONCLUSIVE_POWER`，终态 `L3R_BLOCKED_PREREQUISITE`。**

- R2：月均 **−0.329pp**，t_iid **−0.994**、t_nw3 −0.965，197 期，bootstrap 95% CI
  **[−1.13pp, +0.35pp]**，MDE **0.926pp**，事后功效 **16.9%**。
- 这条设计**结构性地**答不了这个问题：逐期 Δ 的 sd = 4.64pp（≈12 只组合 vs 24 只组合的
  等权差噪声）。要把 MDE 压到 0.5pp/月需 **676 期（≈56 年）**；要检测当前点估计需
  **1564 期（≈130 年）**。
- 因此正确表述是：**「不能排除 ±0.9pp/月 的选择效应，点估计略负但中位略正」**，而不是
  「选股没用」，也不是「选股有用」。

## 6. 明确不做的事

- **不改 L3p 结论**：L3p 仍是 `L3P_BLOCKED_PREREQUISITE`；本实验的结论也不得反过来
  用于放行 L3p。
- **不调判据救显著性**：看到 MDE 太大就去改阈值（比如把"有功效"从 0.5pp 放宽到 1pp），
  等于用结果反过来改预登记。要改就另开一份。
- **不换池子凑样本**：把 30 只扩到 500 只会降低横截面噪声，但同时换了实验对象（池效应
  已在阶段 C 证明存在），必须新预登记。
- **不把 R2 当可实现收益**：R2 是毛收益，不计费用、整手、现金。

## 7. 已知限制

- 匹配剔除让 R2 不含「持有到退市」的真实损失（对两臂对称，但不等于完整收益）。
- 折边界截断使 197 期序列有 28 个小缺口，t 的独立性只是近似。
- 逐折使用不同 `best_params`（walk-forward 固有），"策略"在不同折上是同族的不同参数。
- R1 不含涨停买不进的摩擦（组合层未启用涨跌停判据）。
- 本实验只回答「选择有没有用」，不构成策略可用性证据。
