# 预登记：A 股「每年买上一年涨幅冠军」回测（2026-10-20）

> **状态**：`FROZEN_BEFORE_RESULTS`
> 用途：回答用户转述的一个美股说法（"每年买上一年冠军，十年 127 倍"）。
> DeepQuant **没有美股个股行情**（只有 Shiller 宏观面板），所以美股版本**跑不了**；
> 本文件登记的是**在 A 股上跑同策略**的口径。

---

## 1. 为什么在跑之前先写这个

这类"漂亮得不像话"的回测，结果对三个口径极其敏感：

| 敏感项 | 影响方向 |
|---|---|
| **池的构成**（是否含已衰落/已退市的） | 池越"今日化"，冠军候选越牛 → **美化结果**。这正是阶段 0a 研究过的 `bias_survivorship` |
| **起点年份** | 换起点结论可能完全反转（已有反例：同一策略 2000 起跑输、2016 起跑赢） |
| **冠军排名档位**（第1/2/3名） | 不同档位结果可能差很多 |

所以口径必须在看到结果前定死，且**池的问题单列两版**。

## 2. 策略定义（逐条固定，跑完不得改）

| 项 | 定义 |
|---|---|
| 排序期 | 第 `T-1` **自然年**全年（1/1~12/31）涨幅 |
| 排名 | 涨幅降序；**同时输出第 1 / 2 / 3 名**三档（预先定死，不是事后加的） |
| 买入 | 第 `T` 年**首个交易日的开盘价** |
| 卖出 | 第 `T` 年**最后交易日的收盘价** |
| 持仓 | 单只全仓，每年换仓一次 |
| 起始 | **2017**（需要 2016 全年涨幅做第一次选择） |
| 截止 | **2025**（9 个完整年）；2026 不足整年，另列不并入 |
| 复权口径 | **乘性前复权** `qfq_mult`（不用腾讯加性 qfq —— 那个会让价位变负） |
| 排序期资格 | 该标的在 `T-1` 年交易日 **≥ 200 天**，且上年末有收盘价 |
| 持有期退市/停牌终止 | 用该股**最后一个有数据的交易日收盘价**卖出，不填充、不剔除 |
| 费用 | **不计**（如实标注：A 股实际单边约 0.1~0.15%，每年一次换仓，影响约 0.1~0.3pp/年） |
| 一字涨停 | 记录买入日开盘涨幅；若开盘涨幅 ≥ 9.8%（主板）标注"可能买不进"，**不建模** |

## 3. 两个池（这是本次唯一的自变量）

| 池 | 构成 | 能说什么 |
|---|---|---|
| **P_L（在市）** | `data/qfq_mult/listed/` 全量（csi300 **当日**成分） | **有幸存者偏差** —— 相当于"从今天的赢家里挑冠军"，会美化结果 |
| **P_F（并集）** | P_L + `data/qfq_mult/delist/`（2017 年后退市全量） | 补进了衰落到退市的样本，**仍不是时点无关全市场**（缺"衰落但未退市"的） |

两版都要跑。**P_F 更可信，但它仍不是全市场** —— 真正的时点无关池是立项书的阶段 0b，未做。

## 4. 基准

沪深300（`data/benchmark/hs300_daily.csv`），**同口径**：每年首个交易日开盘 → 最后交易日收盘。
同时给出"买入持有沪深300"的净值，用于对比。

## 5. 必报项

1. 逐年：冠军代码 / 上年涨幅 / 本年持有收益 / 累计净值
2. 三档排名（1/2/3 名）各自的全程净值、年化、最大回撤
3. 两个池的结果差别（**这是幸存者偏差的直接量化**）
4. 沪深300 同期净值
5. 每一年的冠军是谁（可核查）
6. 买入日一字涨停的年数

## 5.5 事后注记（2026-10-20 跑完补记，口径未改）

**实际执行的是 2018–2025 共 8 年，不是 9 年。**

原因：行情数据从 `2016-01-04` 起，而算「2016 年涨幅」需要 **2015 年末收盘价**作分母，
该基准不存在 → 2016 年涨幅不可得 → 2017 年无冠军可选。脚本如实记为「候选不足 1 个」，
**未做任何填充或变通**（若改用"年内首日开盘价"作分母就能凑出第 9 年，但那属于改口径，不做）。

口径本身一字未改，年化按实际 8 年计算。
