## 1. 先纠正上一轮的一个事实错误

`PRICE_CALIBER_SPEC` §4 曾写：「真不复权末行（v0.9.0 备份里）= `10.72, 10.49`」。
**这句话错了。** 实测 000001.SZ：

| 来源 | 2016-01-04 | 2024-12-31 | 2026-10-16 |
|---|---:|---:|---:|
| 腾讯**不复权**（本轮新取） | **11.30** | **11.70** | **11.50** |
| 乘性 qfq（当前 served 源） | 7.1974 | 10.7409 | 11.50 |
| 加性 qfq（`data/step75`） | — | 10.49 | — |

备份里的 **10.49 是加性 qfq（也是 ADJ），不是真不复权**。

**结论修正**：`data/raw/*.raw.csv` 从来就不是真不复权——它是**摄入源副本**（先装加性 qfq，2026-10-20 起装乘性 qfq）。
**这个仓库在本轮之前从来没有过真不复权层**，所以「EXEC 层缺失」比我原先判断的更彻底，不是"切数据时弄丢的"，是"一直没建"。

### 2.2 三条工程坑（已修，写进脚本注释）

1. **分页会被截断**：不能用"本页无新数据"当终止条件（接口偶发返回整页重复），否则序列被砍。实测 600104 第一次只拿到 640 根（2021-07 起），修后 2618 根。
2. **缺口探测**：真实长期停牌在缺口窗口里探不到数据；**缺口里探到数据 = 分页漏取**。这条哨兵正是抓到 600104 的原因。
3. **基准比值必须在共同日期上算**：拿两条序列各自的首日比，起止不同时会算出假比值（002165 曾假报 0.545，共同日期上实为 1.0913）。

## 3. 用 EXEC 当标尺，量出 ADJ 的四个缺陷

### 3.1 缺陷一：2 只隐含"负股息"（数学上不可能）

| 代码 | 期初 EXEC / ADJ | 期初比值 | 价格收益 | ADJ 收益 | 隐含股息 | 判定 |
|---|---|---:|---:|---:|---:|---|
| 601899.SH 紫金矿业 | 3.31 / 3.5503 | **0.9323** | +803.9% | +742.7% | **−0.79 pp/年** | ❌ 不可能 |
| 000807.SZ 云铝股份 | 6.47 / 6.8006 | **0.9514** | +289.6% | +270.7% | **−0.52 pp/年** | ❌ 不可能 |

`ADJ` 起点高于真不复权，等于说"分红让股东亏钱"。这正是 `MEMORY §7` 记录过的失效模式（当年红宝丽 0.963 同款）。

### 3.2 缺陷二：日收益被系统性压制（43/52）

回归 `ADJ 日收益 = β × EXEC 日收益`：

| 统计 | 全样本回归 | 截尾回归（剔每日最大 40 天，排除除权日） |
|---|---:|---:|
| β 中位数 | 0.876 | **0.9115** |
| β 最小 | 0.553（601009） | **0.5855（600028）** |
| β < 0.95 只数 | 43 / 52 | **32 / 52** |

**截尾后仍压制**，说明不是除权日离群点造成的假象。最严重的一批是高股息大盘：

| 代码 | β（截尾） | 价格收益 | ADJ 收益 |
|---|---:|---:|---:|
| 600028.SH 中石化 | 0.5855 | +16.2% | +63.4% |
| 600104.SH 上汽 | 0.6594 | −44.7% | +1.9% |
| 601398.SH 工行 | 0.6621 | +90.6% | +118.7% |
| 601988.SH 中行 | 0.6612 | +78.8% | +108.3% |
| 600000.SH 浦发 | 0.7208 | −45.1% | +8.4% |

**直接证据**（600104 连续 6 日）：ADJ 日内振幅只有 EXEC 的 **0.83 倍**，且 `k = ADJ/EXEC` 在无除权的 15 个连续日内漂移 ±0.6%。
真正的乘性前复权在无除权日**必然**是严格等比（比值为常数、日收益完全相等）。**漂移 = 失真。**

### 3.3 缺陷三：3 只残留未抹平的跳变（违反涨跌停）

主板单日收益不应超过 ±10%。统计 |日收益| > 10.5% 的天数：

| 代码 | 板块限幅 | ADJ 超限天数 | ADJ 最大单日 |
|---|---|---:|---:|
| 000977.SZ 浪潮信息 | ±10% | **48** | +11.7% |
| 002074.SZ 国轩高科 | ±10% | **43** | +12.5% |
| 000657.SZ 中钨高新 | ±10% | **13** | +10.8% |

而同期 **EXEC 只超限 1~2 天**（且都是送转除权日，参考价重设属合法）。→ ADJ 在这三只上"除权没除干净"。

> 参照：`300xxx`（创业板 ±20% 自 2020-08-24）与 `688xxx`（科创板 ±20%）的 15~31 天超限属**合法**，不作缺陷。
> 这三只正好是 β 截尾后 **>1.03 的"放大"组**（1.0314 / 1.0758 / 1.0905）——放大与残留跳变同源。

## 4. 根因

当前 `qfq_mult` 的构造式是：

```
qfq_mult(t) = hfq(t) × raw_anchor / hfq_anchor
```

这个式子成立的**前提**是「`hfq` 是严格的乘性后复权，且与 `raw` 同一股本基准」。
`MEMORY §7` 早已记录腾讯「不复权」与 `hfq` 股本基准不一致；本轮进一步证明：**腾讯 `hfq` 本身也带加性残留**
（高股息股上，`hfq(t) = raw(t) + 累计股息` 的加性形态更贴合观测到的比值漂移与收益压制）。

后果：
- **加性残留** → 高股息股日收益被压缩（股息/价格越大压得越狠）→ 与 β 最低的那批（中石化/工行/中行/上汽/浦发）完全吻合；
- **基准不一致** → 个别股比值反了（紫金/云铝）或残留跳变（浪潮/国轩/中钨）。

**一句话**：切换到 `qfq_mult` 只解决了"负价"（P1-2 的原症状），没解决"复权口径本身不对"（更深的问题）。

## 6. 修复方案（P1-4 立项）

### 6.1 原则

**不要再用第三方"复权"序列。用 EXEC + 分红送转事件，自己算前复权。**
这是唯一口径可控的做法：输入是"真不复权价"和"每股派息/送股/转增"两类**原始事实**，中间不做任何黑箱复权。

### 6.2 数据源（本轮已验证可取）

东财分红送配 API，**免费、无 token**：

```
reportName = RPT_SHAREBONUS_DET
字段：EX_DIVIDEND_DATE（除权日）PRETAX_BONUS_RMB（每股派息）
      BONUS_IT_RATIO（送股）BONUS_RATIO（转增）EQUITY_RECORD_DATE（股权登记日）
```

实测 600104 返回 **28 条**完整历史（2023-07-19 至 2026-08-07 抽样可见）。

### 6.3 构造式

对每个除权事件 `s`（除权日），取 `P(s−1)` = 除权前一日收盘（EXEC）：

```
f_s = ( P(s-1) - D_s ) / ( P(s-1) × (1 + n_送s + n_转s) )
ADJ(t) = EXEC(t) × Π_{s : s > t} f_s
```

`D_s` 用**税前**每股派息（与价格同口径；税后口径会引入持股期限差异，不适合做序列）。

### 6.4 验收判据（机械可执行，不达标就不换）

| # | 判据 | 阈值 |
|---|---|---|
| A1 | 无负价、无零价 | 100% |
| A2 | 无除权日的相邻两日：`ADJ` 日收益 == `EXEC` 日收益 | 差 < 1e-9（严格等比） |
| A3 | `ADJ/EXEC` 比值在无除权区间内**严格为常数** | 区间内极差 < 1e-9 |
| A4 | 主板股票 `ADJ` 单日 \|收益\| 超 10.5% 的天数 | = 0（创业板/科创板按 20% 判） |
| A5 | 隐含股息 ≥ 0（ADJ 年化 ≥ EXEC 年化） | 52/52 |
| A6 | 回归 β（不截尾） | 落在 [0.999, 1.001] |
| A7 | 与 `TOTAL_RET` 口径自洽：`ADJ` 年末收益 ≈ `EXEC` 收益 + 股息再投资 | 差值方向一致 |

> A2/A3/A6 是**定义级判据**：正确的前复权必须逐日等比，任何偏离都是失真。这一条就能一次性抓出本轮所有四类缺陷。

### 6.5 不做什么

- **不回算 Gate 1**（C2 红线）；
- **不把新 ADJ 悄悄塞进 served**——先出独立目录 `data/qfq_rebuilt/`，跑完 §6.4 全部判据再切；
- 切换本身作为一次**数据版本变更**记录（不是研究结论变更）。
