## 4. 这次调整为什么不是「为提高通过数」

三条约束同时成立才算数，逐条对账：

1. **判据与 p 无关**：判据只问「数值是否逐位相同」。闸门 G8 把它应用到一个全部 p > 0.05 的子集上，
   合并照常发生——它不可能是被 p 挑出来的。
2. **四种口径全部并报**：m=25 / 26 / 27 / 29 的结果都在 `L3AD_MULTIPLICITY_M25.md` 里，差异逐条写明。
3. **新增的那条不是正面结论**：7 条正面结论在 m=25 与 m=27 下完全相同。通过数从 7 变 8，
   多出来的是 `phasel_alpha`，判定为 `SURGE_AVOID_ABSORBED`（净效应被吸收）。

如果这三条里任何一条不成立，就不该采用 m=25。

   毛 alpha 显著（+0.106pp、t=+3.13）但净效应被吸收。不得改写成收益证据。
