## 摘要

本项目在 A 股全样本上系统检验了价量异象的**可执行性**，共完成 **23 项预登记实验**
（Gate 1~6 + 阶段 C / C-2 / C-3 / E / F / G / I / J / K / L / M / O / P / Q / R / S / T）
+ **1 项只读审计**（阶段 N）+ **1 项评估**（阶段 H）。

**三个能站住的结论：**

1. **股票池的选择比因子本身更主导结果。** 同一信号、同一规则，只换池，符号相反（配对差 +1.939pp/月，t=6.37）。此前"反转在 2016 年后消失"的结论是 532 只定名单池的伪影。
2. **横截面异象是"空头侧现象"。** 三个彼此独立的信号，单边多头只能拿到多空价差的 21%~38%（反转 0.21、MAX5 0.245、异常放量 0.375）。效应最强的那一层，单边 alpha 恰为零。
3. **两个新变量（MAX5、异常放量 SURGE）在控制波动率后仍显著**
   —— ⚠️ **但"彼此独立"对两者不成立度不同，见阶段 Q 更正**：
   **SURGE 独立且稳健；MAX5 仅在"非参数控制波动率"时成立。**

> **在纯价量空间里，不存在成本后 ≥0.30pp/月的单边 alpha**

## 一、研究问题

文献里的横截面异象通常报告**多空价差**（spread）。但在 A 股，个股做空基本不可得，这个价差的相当一部分无法被获取。本项目问的不是"异象是否存在"，而是：

> **去掉不可实现的部分之后，还剩多少？够不够覆盖成本？**

由此派生三个子问题：结论是否只是股票池的伪影？效应在长边还是短边？执行摩擦（冲击、换手、整手约束）各吃掉多少？

## 三、方法

### 3.1 预登记协议

每个实验在**运行前**冻结一份预登记文档，计算 SHA-256 并写入脚本常量；脚本启动时校验，不符即拒绝运行。预登记必须包含：

- 固定的样本、池、窗口、构造参数；
- **写死的判据与判定档位**（例如"五态，按顺序判定"）；
- **预期方向与机制**（这是最重要的一条——见 §3.6）；
- 明确列出的"不许做的事"。

### 3.2 统计口径（三个易错点，均已写死）

| 项               | 规定                                                                                         |
| --------------- | ------------------------------------------------------------------------------------------ |
| `d` vs `spread` | `d = 0.5×long − 0.5×short`（自融资对半）与文献 `spread = long − short` **相差 2 倍**。跨文献比较必须先换算并同时列出两个数 |
| 单侧 / 双侧         | Gate 1~4 曾用单侧 1.645；Gate 5/6 及之后**统一用双侧 1.96**。引用旧结论时必须说明                                  |
| 标准误             | 主检验用 Newey-West（滞后 3 期）；成本后检验同时报 **iid 与 NW 两套**（本项目序列存在负自相关，`se_NW < se_iid`）             |

### 3.3 交易约束与成本

- 建仓日涨停 / 一字板向上 / 停牌 / 序列终止 → 剔除（跌停**不**剔除，跌停可买入）；
- 月度成本 = `2 × 单边换手 × 费率`；`×12` 是年化；
- 换手**按各构造实测**，禁止沿用统一值（实测跨度：低波动 23% ~ 反转 80%）。

### 3.4 容量口径（必须两个指标）

- `weight_mae`：权重偏离（pp）；
- **未投资比例**：整手取整后趴在账上的现金。

⚠️ **只看 `weight_mae` 会误判**：在 W=1,000 万时，覆盖 98.5%、`weight_mae` 仅 0.0053pp（看似完美等权），但**未投资 12.32%**。权重偏离指标抓不住现金残留。

### 3.5 纪律

R2/R11 禁调参择优；R3 不编造数据；R5 不删失败记录；R7 不弱化测试。
  
换窗口 / 换基准 / 换池 = 新实验，必须新预登记。选题前先查文献。
  
**改检查器前必须先跑变异测试**（证明真缺陷仍抓得到）。

### 3.6 关于"预测方向"的一条经验

本项目共做了 5 次方向预测：**3 次错、2 次对**。

- 靠"机制直觉"猜的三次全错；
- 靠**可计算的量**（参与率量级、换手/alpha 对比）猜的两次全对。

这条已写入项目规范：预测方向时使用可算的量，不使用机制直觉。

## 五、结果（二）：两个新信号

### 5.1 MAX5（前 5 大日收益均值）

文献：Bali et al. (2011)；A 股因 T+1 与涨跌停须用"前 5 大"而非单日（Zhu & Zhang 2020）。

**可行性检查先发现一个致命问题**：MAX5 与 21 日波动率的秩相关是 **+0.88**。若直接测原始 MAX5，无法区分"MAX 效应"与"波动率效应"（后者本项目已测为 FAIL）。故主检验改成**波动率分层后的层内价差**。

|              |           Δ |         t |
| ------------ | ----------: | --------: |
| 原始 MAX5（不分层） |     +1.0800 |     +4.16 |
| **分层后（主检验）** | **+0.7405** | **+3.41** |
| 比值           |   **0.686** |           |

→ 波动率吃掉 31%，**还剩 69% 且高度显著**：MAX5 不是波动率的影子。

**分层后各层（Δ）**：L1 **−0.2923**（最低波动层为负）/ L2 +0.2595 / L3 +0.7681 / L4 +1.0528 / L5 **+1.9155**。效应随波动率单调递增。

**稳健性自查**：换五种聚合规则全部显著，且**同时去掉最低与最高波动层（只用 L2~L4）仍有 +0.6935（t=2.662）**——所以"最低波动层为负"没有撑起结论。

> 阶段 Q 用 Fama-MacBeth 横截面回归（逐月、237 月、NW(3)、秩 z-score）

| M  | 异常放量   | 0.7216 |  +0.2704 | 2.06 | **0.375** |

## 七、综合结论与两次修正

### 7.1 横截面异象是"空头侧现象"（成立，但比例不是常数）

A 股个股做空不可得 → 高估无法被套利（空头侧有收益）、低估无集中买入力量（多头侧微弱）。

三个独立信号的 ratio：**0.210 / 0.245 / 0.375**。
  
（SURGE 的 bootstrap 95% 区间为 **[0.161, 0.474]**；阶段 M 预登记的判定区间是 [0.10, 0.35]，
  
点估计 0.375 略越上界 → 严格判为否证，但区间完全覆盖 0.35，属**边缘否证**。）

→ **定性成立且加强**：三者都远低于 1，单边拿不到全部。
  
→ **定量修正**：1/5~1/4 **不是普适常数**。SURGE 拿到 0.375，因为它**长边也有真实内容**（低异常放量有"关注度/不确定性溢价"，与文献的倒 U 形一致）。

### 7.2 ⚠️「避免型优于买入型」——两次修正

原始观察：阶段 G（**买**最低 MAX5）→ 2016 后归零；阶段 H（**不买**最高 MAX5）→ 2016 后不动。

- **第一次修正（阶段 L）**：SURGE **也是**避免型动作，但它**衰减了**（+0.1764 → +0.0472，−73%）。→ 避免型**不等于**不衰减。（⚠️ 阶段 P 补注：该衰减经正式检验为**边缘显著**，p=0.0499、|t|−1.96 仅 +0.0005、CI 上界 −0.000035，事后功效 50%。作为"现象存在"的观测可用，但**不构成被检验确认的衰减**。）（⭐ 阶段 S 补注：SURGE 后段**净** alpha 仅 +0.0109（t=0.26，任何资金档不显著）；而 exQ5 同口径后段仍 +0.1112（t=+2.218）——**衰减是 SURGE 的实测，不是避免型的必然**。）
- **第二次修正（阶段 M）**：SURGE 的 avoid(0.155) **小于** buy(0.375)，与 MAX5 的模式相反。→ 避免型**也不必然优于**买入型。

**最终表述（最弱但正确）**：

> 在**同一信号内部**比较时，避免型与买入型的优劣由"效应集中在哪一边"决定：
>   
> 效应全在短边（MAX5）→ 避免型更优；两端都有内容（SURGE）→ 买入型更优。
>   
> **不能用动作类型预判，必须实测。**

## 八、我们主张什么 / 不主张什么

### 主张

1. 池的选择偏差可以主导因子结论，且已实测（Δ=+1.939pp，t=6.37）；
2. 三个独立信号一致显示：单边 alpha 只占多空价差的 21%~38%；

5. 本轮检验**否定的是"可用"，不是"存在"**。

## 附录 C：术语

- **spread**：`long − short`（各投全额）；**d**：`0.5×long − 0.5×short`（自融资对半）。两者相差 2 倍。
- **as-of 全 A**：按当月可得信息（上市满 252 日、未退市）确定的股票池，不用事后存活名单。
- **避免型 / 买入型**：剔除最差 20%（avoid）vs 买入最好 20%（buy）。
- **ratio**：单边 alpha / 多空价差。
- **MDE**：在给定样本与标准误下，能以 80% 功效检出的最小效应（本项目用 2.8016×se）。
