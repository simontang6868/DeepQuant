## 3. 这个数字意味着什么（也意味着什么不）

### 3.1 意味着

- 阶段 C 的 D 格 spread **1.3164 是偏保守的**，不是偏乐观的。
  按"停牌买不到、退市卖不掉"处理，真实可成交口径下是 **1.4233**。
- 缺口的影响 **+0.107pp**，是主效应（1.32pp）的 **8.1%**。
- 成本后同样成立：净@0.1% 从 +0.4971 升到 +0.5503，t 从 3.11 升到 3.39。

### 3.2 不意味着

- **不推翻阶段 C 的主结论。** 阶段 C 的主检验是配对差 `spread(B) − spread(A)`，
  A 格和 B 格**同样承受**这个缺口，大部分会互相抵消。本实验只处理了 D 格。
- **不改变 M1/M2 的层级。** V1 的净@0.3% t=1.40，仍然不显著 → M2 仍不过。
- **不是"能交易了"。** M4 结构阻塞（做空腿不可得）一寸没动。
- **不是"停牌不影响结论"。** 它影响方向是**改善**，但幅度到不了经济门槛。

## 4. ⚠️ 为什么方向反了（机制）

预登记猜"被剔的输家会反弹，买不到就少赚"。**实测不是这样。**

| 诊断 | 被剔 | 保留 | 差 |
|---|---:|---:|---:|
| **D2** 多头腿 fwd 收益 | **+1.2249pp** | +1.7451pp | **−0.5202pp** |
| **D3** 空头腿 fwd 收益 | **+5.7034pp** | +0.3218pp | **+5.3816pp** |

**被剔的多头（停牌/退市）收益比保留的低 0.52pp；被剔的空头收益比保留的高 5.38pp。**

机制：

1. **多头腿**：停牌期间价格被冻结，`fwd` 拿不到反弹（实际是"零收益"），
   所以它们是多头腿里的**拖累**，不是收益来源。剔掉 → 多头腿均值上升。
2. **空头腿**：这是更主要的一项。反转策略做空"赢家"，而**涨到停牌**的赢家
   （重大事项停牌前暴涨）收益高达 +5.70pp。做空它们等于在 ffill 冻结的高位上**锁定亏损**。
   剔掉这些"卖不掉的赢家" → 空头腿的亏损大幅减少 → spread 上升。

所以预登记那句「买不到输家会少赚」的直觉，在**空头腿这一侧完全反了**——
被冻结在高位的是**赢家**，不是输家。

其余诊断支持这个解释：

| # | 诊断 | 值 | 读法 |
|---|---|---|---|
| D4 | 每月被剔比例 vs 当月 Δ 的相关 | **r = +0.4458** | 剔得越多的月份，Δ 越正 → 与机制一致 |
| D5 | 腿规模中位（多头/空头） | 484→478（−1.24%）/ 486→469（**−3.50%**） | 空头腿缩得更多，正是它的贡献所在 |
| D1 | 被剔只次按年 | 2014-2015 空头被剔 **250 / 307** 次 | 与 2014-2015 停牌潮吻合 |

D1 的年度分布：空头侧被剔最多的是 2015（307 次）和 2014（250 次）；
多头侧 2007（42）、2022（41）、2023（43）较多。**不是均匀噪声，有明确的市场状态对应。**

## 5. 结论的边界

| 项 | 说明 |
|---|---|
| 只处理了 D 格 | A、B、C 三格未做同样处理，所以不能说"阶段 C 全部偏保守" |
| 只剔除、不补位 | 腿规模缩了 1.2%~3.5%，没有引入替代标的（补位会用到剔除结果这个事后信息） |
| 只剔除、不顺延 | 顺延成交是另一个实验，需要改收益起算点 |
| `after_last_data` 不可区分 | 74 只次里含"真退市"与"抓取截断"，本数据集已知 249 只退市名单，另有 3 只 `UNKNOWN` |
| ST 无历史标记 | 5% 涨跌幅未区分 |
| 做空腿不可得 | M4 结构阻塞，`d` 不是可实现组合收益 |

**一个必须强调的方法论点**：
本实验的价值不在 `+0.1069` 这个数，而在**它证明"偏乐观"这个担心本身没有机制支撑**。
方向不仅不是负的，而且是正的，且正得可以解释。这比"补一个敏感性分析交差"有用得多。
