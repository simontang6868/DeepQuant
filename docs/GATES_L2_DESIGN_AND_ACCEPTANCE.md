## 1. 表 7 只给了两句话，第二句必须被翻译成可计算的判据

表 7 对 L2 的要求是：

- 通过标准：**收益分布尾部风险在容忍区间**
- 一票否决：**分布形态显示策略依赖极端路径**

第一句容易做。第二句如果不落成可算的东西，就永远无法执行——每次评审都可以说"看起来像依赖极端路径"或"看起来不像"。所以本闸门的主要工作是把第二句拆成两条**可复算**的判据（第 4 节）。

---

## 2. 三个方法学决策（每个都排除了替代方案）

### 2.1 重抽样单位是日收益，不是权益曲线

对净值**水平**做重抽样会拼出"昨天亏 30%、今天又从 100 万开始"这种不存在的路径。正确做法：算 `r_t = E_t / E_{t-1} - 1`，重抽样 `r`，再累乘重建净值。

估值缺失日**必须剔除并计数**，不能用 0 顶替——填 0 等于宣称"那天没涨没跌"，会人为压低波动率，让尾部看起来更安全。

### 2.2 必须用块重抽样，不能用 IID

IID 重抽样会打散波动聚集，也会打散"连续持仓 / 连续空仓"的节律。

这里不是"理论上更好"的问题，而是 IID 根本**做不了这件事**：

> **IID 置换不改变复合收益**——`prod(1+r)` 与顺序无关。所以在 IID 下，2000 条路径的期末收益完全相同，分布方差为 0。

实测（真实序列，2000 次）：

| 指标 | 块抽样 | IID |
|---|---|---|
| 期末收益分布标准差 | **1.4791** | **0.000000** |
| 最大回撤 95% 分位 | **0.5380** | 0.4877 |

即：IID 对"收益分布"零信息，只在回撤上给出**系统性偏低 9.3%** 的估计。用 IID 做这道闸门，等于什么都没做，还会显得风险更低。

本闸门用 **stationary bootstrap**（Politis & Romano 1994）：块长服从几何分布、期望为 `mean_block_length`，块首尾相接、索引循环回绕，因此既保留序列相关，又不产生块边界跳变。

### 2.3 块长必须做敏感性

块长是最主观的参数。只报一个块长下的结论，等于把结论押在这个选择上。默认同时跑 10 / 20 / 40 / 60 四档，任一判据在四档下方向不一致就记 `block_length_stable = False` 并显式提示。

## 3. 可实现性的细节

`stationary_bootstrap` 首版用逐元素循环，2000×1200 的规模要跑一分多钟——慢到会让人不想跑敏感性。改成"先定位块重启位置、再按块内偏移传播"的向量化写法后降到约 0.2 秒：

```python
restart = rng.random(n) < 1.0 / mean_block_length
restart[0] = True
last_reset = np.maximum.accumulate(np.where(restart, positions, 0))
index = (starts[last_reset] + (positions - last_reset)) % n
```

这不是纯粹的工程优化：**如果做敏感性要一分钟，就不会有人做**。

## 4. "依赖极端路径"的两条判据，以及它们为什么互补

### E1 极端日依赖

把收益最好的 `top_day_fraction`（默认 1%）的交易日**置零**后重算累计收益。

- **为什么置零而不是删除**：删除会让复合次数减少（1200 天变 1188 天），剩下的日子更容易凑出正收益——方向恰好相反。置零等价于"那几天放假，钱没动"，复合次数不变。
- 判据：剔除后收益必须仍 $>0$。

### E2 可重复性

`repeatable_ratio = 重抽样收益中位数 / 实际收益`。它回答"如果历史重来一次，还能拿到多少比例的收益"。

### 两者为什么不能互相替代

**块重抽样会保留极端日**（它们仍在样本里被抽到），所以 E2 可能在中位数不低于实际值时给出"可重复"的假象。反过来，E1 只看"收益是否集中在少数日子"，无法识别"收益依赖特定顺序"。

本仓库真实用例就出现了这种分离：

> 可重复性 **1.0412**（大于 1，看起来完全可重复），但剔除 1% 交易日后收益从 **+102.31%** 变成 **−27.88%**。

所以两条判据**互补而非冗余**，缺一条都会漏。这一条已无条件写进每次运行返回的 `limitations`。

## 5. 真实用例：ma_cross / 000001.SZ / 2016–2021

曲线取 L1b 精验档（含摩擦，10 万资金），1460 个日收益观测，无估值缺失日。

| 指标 | 取值 |
|---|---|
| 实际累计收益 | **+102.31%** |
| 实际最大回撤 | **32.09%** |
| 重抽样收益中位数 | +106.53% |
| 重抽样 5% 分位 | −14.66% |
| CVaR5（最差 5% 平均） | −29.91% |
| 最大回撤 95% 分位 | **53.30%** |
| 负收益路径占比 | 9.1% |
| 可重复性 | 1.0412 |
| 块长稳定性（4 档） | 全部达标 |

### 5.1 剔除剖面：依赖到什么程度

单一阈值只能回答"是/否"。剖面能回答"临界点在哪"：

| 剔除最好的比例 | 天数 | 剔除后累计收益 | 被剔除日合计贡献 |
|---|---|---|---|
| 0.2% | 3 | **+56.44%** | +29.32% |
| 0.5% | 7 | **+16.79%** | +73.23% |
| 1.0% | 15 | **−27.88%** | +180.50% |
| 2.0% | 29 | −61.84% | +430.19% |
| 5.0% | 73 | −91.23% | +2206.50% |

**临界点在 7 到 15 个交易日之间。** 策略的全部正收益来自这十几个交易日，其余 1445 天合计是缓慢失血的。终态 `L2_REJECTED_EXTREME_DEPENDENCE`。

### 5.2 这个结论该怎么读

- 对趋势跟踪类策略，"少数大趋势贡献全部收益"是**其本质特征**，不是实现缺陷。但表 7 的否决项就是"依赖极端路径"——所以按该标准，**单标的 ma_cross 无法通过 L2**。
- 这不等于"趋势跟踪不能用"，而是说：它不属于"稳定收益"这一类，不该用 8%/年这类稳态目标去衡量它，也不该按固定仓位长期持有。
- 注意这是**单标的、满仓**结果。组合化会摊平单标的的极端依赖，但本项目尚未做组合层 L2。

## 6. 验收（六项，全部实测）

| 验收项 | 结果 | 取证方式 |
|---|---|---|
| 块抽样保留自相关且 IID 摧毁它 | PASS | AR(1) φ=0.8 序列：原 0.80+，块抽样 0.4+，IID ≈0 |
| 同种子重跑逐位一致 | PASS | 两次 `simulate` 的 terminal 数组完全相同 |
| 剔除剖面单调 | PASS | 5 档剔除比例下收益严格递减 |
| 终态覆盖无静默缺口 | PASS | 覆盖 6/7，`PATH_DEPENDENCE` 的构造用例在测试里且会先撞 E1，理由已登记 |
| IID 期末收益分布退化为单点 | PASS | std = 0.000000（证明 IID 对本闸门无信息） |
| IID 在回撤上系统性低估 | PASS | 0.4877 vs 0.5380 |

回归：backend **2618 passed / 1 skipped**（+18）；property 9/9；scripts 332；`verify_exec_all` PASS。

## 7. 踩坑记录

1. **测试数据本身必须满足"不依赖极端日"**。首版用 `mean=0.0008, vol=0.01` 造"稳定序列"，1200 天净收益只有 +2.78%，而最好 12 天贡献 +34.5%——E1 正确地判它依赖极端日。是**测试数据错了**，不是判据错了。改用 `mean=0.001, vol=0.004` 后通过。
   - 顺带得到一个真实结论：**期望收益接近 0 时，收益必然集中在少数几天**。这不是噪声，是右偏分布的必然。
2. **高波动序列测不到尾部判据**。`vol=0.03` 会先撞 E1，根本走不到尾部三项。要测 TAIL，得用稳定序列配极紧阈值。
3. **`cvar5 < p5` 的断言在离散分布下会失败**。最差 5% 全部相等时 `CVaR5 == p5`，断言必须写 `<=`。
4. **循环版 bootstrap 慢到没人愿意跑敏感性**（90 秒 vs 5.6 秒）。这类性能问题会直接决定"会不会做稳健性检查"。
5. **差点把 IID 的退化误读成"更乐观"**。首版取证只写"IID 与块抽样有差异"，而实际是 IID 的期末收益分布方差为 0——不是低估，是**没有信息**。两句话的差别决定了这个证据能不能用。
