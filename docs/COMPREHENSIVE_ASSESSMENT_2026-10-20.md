## 1. 执行摘要

### 1.1 系统定位

DeepQuant 是一个**本地单机、A 股日线级、以可复现与可证伪为核心**的量化研究平台。它的设计目标不是"多快好省地跑出漂亮曲线"，而是：

> **让一个策略假设在跑之前就被冻结，跑完之后无论结果好坏都不得修改判据，从而得到一个不会被自我欺骗污染的答案。**

这个目标已经达成。它的副产品是一个能用的回测软件（Web 界面 + REST API + 历史库）；它的**未达成部分是"找到可交易策略"**，而这一部分受限于数据而非代码。

### 1.2 五条硬结论

| # | 结论 | 证据强度 |
|---|---|---|
| **C1** | 软件可运行、可回归、可复现：**1997 passed / 1 skipped / 0 failed**，非 research 覆盖率 **96.81%**，45/76 模块 100%；单端口启动、界面/API/历史库全链路实测通过 | **实测**（作者机 + 独立沙箱双环境） |
| **C2** | 回测引擎的**记账与对账已闭合**：单标的路径与组合路径对同一笔交易必须给出相同成交价/股数/费用/逐日权益（3 条断言），权益恒等式违反即抛错 | **实测** |
| **C3** | 横截面动量 Gate 1 实验的机械判定为 **`failure`**：mean(d) = **−0.003961/月**，t = **−0.5687**，p = 0.5723，胜率 41.67%，**95% CI 跨 0**（[−0.017974, +0.010051]），12 组敏感性仅 2 组为正，BH 校正后 0 组显著 | **预登记 + 机械判定 + ✅复算** |

## 3. 第 2 层：回测计算是否可信

### 3.1 记账口径（写死在 `docs/A3_ACCOUNTING_SPEC.md`）

| 口径 | 规则 | 为什么重要 |
|---|---|---|
| 现金释放顺序 | **卖出先于买入** | 否则同日调仓会假性资金不足 |
| 最小佣金 | 权重记账下仍生效 | 否则小额成交成本被低估 |
| 停牌估值 | 冻结上一价 + 计数 | 否则停牌期净值凭空跳动 |
| 涨跌停 | 无法成交则**顺延**到下一可成交日 | 否则高估策略的成交能力 |

### 3.2 三重对账机制

| 机制 | 内容 | 状态 |
|---|---|---|
| 双路径对账 | 同标的、同一天、同一笔交易，单标的与组合路径的**成交价/股数/费用/逐日权益必须一致** | 3 条断言全过 |
| 权益恒等式 | 每日 `现金 + 持仓市值 = 权益`，违反即 `RuntimeError` | 不产出可疑净值 |
| 运行指纹 | 每次回测记录参数指纹与数据指纹，同参数二次运行**逐位一致** | 实测通过 |

### 3.3 成本模型（**含假设，必须随结论引用**）

| 项 | 值 | 性质 |
|---|---|---|
| 佣金 | 券商参考值（`broker_reference_common_2024`） | 可核实到"参考"，不可核实到"你的账户" |
| 印花税 / 过户费 | 按现行规则 | 规则性，可信 |
| **滑点** | **单边 0.1%** | ⚠️ **纯研究假设，无法核实** |
| 涨跌停 | **flat 10%**，无 per-symbol 通道 | 主板正确；2020-08-24 后对 9 只双创**偏严 = 悲观方向** |
| 停牌 | 以"当日无行情行"近似，无标记 | 会低估停牌期间的机会成本 |

> **因此**：任何结论都**不得**写成"按真实成本回测"。正确写法是"按含 0.1% 单边滑点假设的成本模型回测"。

### 3.4 明确不可信的边界

- **容量 / 冲击成本**：完全未建模。50 只池里若有大资金，结论不成立。
- **券源**：未涉及（当前无融券逻辑）。
- **实盘滑点**：未校准，0.1% 是行业惯例值，不是本项目实测值。
- **分红再投**：前复权为减法复权，长区间会出现非正价格（600809 有 131 行为负），因此**低价股研究不能复用这批数据**。

| 执行后复核 | 2026-10-18 23:59 | 本地文件 sha256 与冻结值**逐字符相同** |

**协议先于结果的证据链完整**。这不是形式主义：它排除了"跑完再改判据"这种最常见、也最难自察的作弊。

### 4.2 三档机械判定 + 多重检验

- 档位：`success` / `failure` / `inconclusive`，冲突优先级 `failure > inconclusive > success`。
- 12 组敏感性**预先写死**，不是根据结果挑的；BH 校正后 q 全为 0.8744（这是 BH 取右侧最小值的**正确性质**，不是 bug；应看原始 p 区间 0.3436–0.8744）。
- 主实验**自由度 = 0**（单参数组合），因此不存在"换组参数再试试"的解释空间。

### 4.3 十二条纪律（R1–R12，节选最关键的）

| 规则 | 内容 |
|---|---|
| R2 / R11 | 禁止调参、禁止择优、禁止事后换窗口 |
| R3 | 禁止编造数据（缺失就报缺失） |
| R4 | 占位费率必须显式标注 |
| R5 | 禁止删除失败结果 |
| R6 | 禁止 reset / clean / restore 掉历史 |
| R7 | 禁止弱化测试来让结果变绿 |
| R8 | 禁止 push main / 禁止 merge |
| R12 | **窗口级统计 ≠ 连续账户收益**，不得混用 |

> 这十二条不是装饰。它们直接对应量化研究里最常见的七种自欺：择优、删失败、改判据、弱化测试、混口径、编数据、悄悄重跑。

### 5.3 Gate 1 详解（本轮唯一一个"协议完整"的实验）

#### 5.3.1 假设（先于结果写死）

> 在 A 股 50 只样本池上，过去 **60 个交易日**（跳过最近 **5 日**）的收益率排序，取前 **20%** 等权持有一个月，
> 其月度收益**优于同池等权基准**。
> 可证伪点：`d_t = r_strategy,t − r_benchmark,t` 的均值是否显著为正。

#### 5.3.2 设计约束

| 项 | 设定 |
|---|---|
| 主实验参数 | **单组，自由度 0** |
| OOS | 2021-01 ~ 2024-12，**48 个月** |
| 基准 | **同池等权**（当时无指数数据） |
| 交易 | 次日开盘、月度调仓、等权 |
| 判定 | 三档机械判据 |
| 多重检验 | 12 组敏感性 + BH |

#### 5.3.3 结果（`gate1_out/032a11f591553e25/summary.json`）

| 指标 | 值 |
|---|---|
| n | 48 个月 |
| mean(d) | **−0.003961 / 月**（−0.40pp/月） |
| std(d) | 0.048257 |
| t | **−0.5687**（p = 0.5723） |
| 胜率 | **41.67%**（20/48） |
| **95% CI** | **[−0.017974, +0.010051] / 月 → 跨 0** |
| 敏感性 12 组中为正 | **2 组**（S5、S8） |
| BH 后 q ≤ 0.05 | **0 组** |
| 排除 `600809.SH` 重跑 | mean(d) = −0.003284，t = −0.4644，**符号未翻转** |

**判定：`failure`**，命中三条：`mean(d) ≤ 0`、`t < 1.0`、`敏感性正组数 = 2 ≤ 4`。

#### 5.3.4 这里有一个必须点名的陷阱

B 线报告表里曾列 **`+331.43%` / `+357.89%`**。那是**全程（2017-02 ~ 2024-12）累计**，不随判定窗口截断 —— 看起来像"大幅跑赢"。

✅复算后的真实数字：

| 口径 | 策略 | 基准 | 差额 |
|---|---:|---:|---:|
| **OOS 48 个月（正确口径）** | **+35.2%** | **+66.36%** | **−31.2pp** |
| 全程累计（会误导的口径） | +331.43% | +357.89% | −26.5pp |

**方向一致（跑输），但幅度不构成统计显著（CI 跨 0）。** 该缺陷已修：列名拆成 `*_total_return_eval`（窗口内）与 `*_total_return_full`（全程）。

#### 5.3.5 这个"失败"到底有多强

1. **`t = −0.57` 远未达显著** → 不能说"已证明显著跑输"。
2. **功效不足**：σ ≈ 0.048/月，要检出 0.003/月 的边际需约 **160 个月**；本轮只有 **48 个月（30%）**。
   → **"失败"判定比"成功"判定可靠，但两种判定都不强。**
3. **自由度已为 0**，所以"换组参数就有效"不成立 —— 那属于**新实验**，不属于本研究。

### 5.4 一个容易被忽略的现实检验：资金充足性

`research/capital_adequacy.py` 的结论：**6 只池从 2021 年起实际只有 4 只在跑 —— 茅台一手买不起。**

这不是模型问题，是**可负担性断崖**：1 手 > 本金即完全无法交易，是**二值而非梯度**。任何"组合等权"的结论，在小资金下都会失真。这类检验比多跑 100 组参数更有价值。

### 6.3 数据偏差的方向（这一点决定结论怎么读）

| 偏差 | 方向 | 后果 |
|---|---|---|
| 幸存者偏差（无 PIT） | **系统性高估**策略与基准的绝对收益 | 只有"策略 − 基准"的**配对差额**可讨论 |
| 减法复权负价 | 价格水平失真 | 信号只用收益率时影响有限 |
| 涨跌停 flat 10% | 对双创**偏严 = 悲观** | 不会高估成交能力 |
| 滑点 0.1% | **不确定** | 可能高估或低估，取决于真实成交 |
| 停牌无标记 | **偏乐观** | 低估停牌机会成本 |

> **结论**：绝对收益不可信；**配对差额方向相对可信**；一切结论只能写成"在这批数据、这个成本假设下"。

## 10. 三条候选路径（成本 / 收益 / 风险）

### 路径 A：修完 + 结项归档（1–2 人日，低成本）

**做什么**：归档本轮结果为 v1.3 协议下的正式结论；合并 11 个 PR；统一 git 仓库；写结项说明。
**收益**：得到一个**干净、可复现、有审计链**的阶段性成果，可作为后续任何研究的基线。
**风险**：低。**但不会带来任何新策略结论。**

### 路径 B：补数据，重做一轮（成本取决于数据源，唯一能实质提升证据强度）

**做什么**：
1. 行情延到 2026-10（**零成本**，改 `end_date`）；
2. 建沪深300 基准（**零成本**，但需解决全收益口径）；
3. 获取 **PIT 成分股**（唯一需付费项）；
4. **重新预登记**（不得在 v1.3 上改参数），再跑一轮。

**收益**：消掉 V1/V5/V6 三条硬约束，样本从 48 个月扩到 ~110 个月，功效显著改善。
**风险**：中。数据质量与口径一致性是主要风险；**不建议**多源拼接（复权与停牌处理不同，拼出来无法自证一致）。

### 路径 C：换假设，不换参数（中等成本，风险较高）

**做什么**：针对**新的可证伪假设**（残差动量 / 行业中性后动量 / 事件驱动）重新冻结预登记。
**风险**：在 V1 未解决时，新假设同样只能得到"测不出来"，容易变成**无限试错**。
**我的判断**：**在路径 B 完成前，不建议做 C。**

- ❌ 在 v1.3 上换 lookback / skip 再试（R2/R11 明令禁止的择优）

### 11.4 术语

| 术语 | 含义 |
|---|---|
| PIT（Point-in-Time） | 时点数据：当时能看到什么，而不是今天回看能看到什么 |
| 幸存者偏差 | 只用"今天还活着"的股票回测，系统性剔除输家 |
| 预登记 | 跑之前冻结假设、参数、判据，防止事后择优 |
| 配对差额 `d_t` | 策略月收益 − 基准月收益，本研究的主统计量 |
| 功效（power） | 在给定噪声下检出真实效应的能力；样本越短越低 |
| xfail(strict) | 把"当前错误行为"钉成会喊的断言；修好后会 XPASS 并强制移除标记 |
| 窗口级统计 | 每个 walk-forward 窗口独立的收益统计，**不等于**连续账户收益 |
