## 2. 三套费率口径（跑前写死，全报）

| 代号 | 定义 | 等价对称单边费率 |
|---|---|---:|
| **BASE** | 佣金 0.025% 双边 + 印花税 0.05% **仅卖出** + 过户费 0.001% 双边 | **0.051%** |
| **STRESS** | 单边综合费率（对称计两侧） | **0.30%** |
| **CONSERVATIVE** | BASE + **最低佣金 5 元/笔**（按 W 分档） | 随 W 变 |

⚠️ **BASE 的 0.025% 佣金是情景值，不是所有账户都能获得的报价。**
⚠️ 印花税**仅对卖出方征收**，故 BASE 的成本公式为（不对称）：

```
月度成本 = 2 × to × (佣金 + 过户费) × 100  +  to × 印花税 × 100
```

**不得为保持对称而忽略卖出单边性。**

CONSERVATIVE 下，单笔佣金 = `max(单笔金额 × 佣金率, 5 元)`。

## 3. 资金档位与现金残留

`W ∈ {1,000 万, 3,000 万}`，现金残留用阶段 I/J 的 `capacity_of` 规则
（按一手金额从高到低剔 + 整手取整），**逐月计算**，不取中位数近似。

同时报 `未投资比例` 与 `weight_mae`（两个都报，缺一不可）。

## 5. 判据（四条，跑前写死）

以 **BASE 口径、W = 3,000 万** 为主口径：

| 条件 | 内容 |
|---|---|
| **A 统计** | `\|t_NW\| ≥ 1.96` |
| **B 稳定** | 两段（2007-2015 / 2016-2026）各自符号与全样本一致 **且** `\|t\| ≥ 1.96` |
| **C 保守正值** | **CONSERVATIVE 口径下净值 > 0**（只要求经济为正，不要求显著） |
| **D 强制披露** | 必须同时报 STRESS 口径结果（预期不显著），**D 不是通过条件，是披露义务** |

| 判定 | 条件 |
|---|---|
| `EXECUTABLE_UNDER_BASE_FEES` | A ∧ B ∧ C |
| `MARGINAL_UNDER_BASE_FEES` | A ∧ C ∧ ¬B |
| `NOT_EXECUTABLE_UNDER_ANY_FEE` | ¬A ∨ ¬C |

## 6. 预期方向与机制（写完再跑）

### 6.1 预期 A 过、C 过；B 是主要不确定性

依据阶段 N 审计的逐月复算：
- BASE 口径净值 **+0.1260pp**，t(NW) **+4.02** → A 过；
- CONSERVATIVE（W=3,000 万）净值 **+0.1232pp** > 0 → C 过；
- **B 未知**：阶段 J/K 在 0.3% 下两段都不显著（净值太小），
  但 BASE 下净值放大约 4 倍、se 不变 → 两段 t 预计升至 2.5~3。

→ **正式预期：`EXECUTABLE_UNDER_BASE_FEES`**（A∧B∧C）。

### 6.2 ⚠️ 这个预期必须带三条限定（写下来）

1. **BASE 的 0.025% 佣金是情景值**，取决于实际账户；若真实佣金更高，结论会退回；
2. **即使 A∧B∧C 全过，也不等于"可用"**——纪律第 7 条：
   统计显著 ≠ 可交易。样本内、无前瞻验证、现金残留仍在；
3. STRESS 口径下仍将**不显著**，必须披露，不得只报好看的那套。

### 6.3 预期失败模式

若 ¬B（两段不都显著），说明"不衰减"在 BASE 口径下**仍未被统计确认**，
那将回到阶段 N 的阻塞项 B4，决策应转向"先做样本外"而不是"下结论"。
