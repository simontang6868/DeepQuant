# H3 价格模式预登记增补（2026-11-22，施工单 v2 P1-2）

> 性质：参数模式定义，**不选择、不启用**。账户持有人未定 A/B/C 前，11-25 买腿执行前必须 `NO_PRICE_MODE` HALT。
> 本文件不改任何已冻结预登记；只增补 H3 的可切换模式定义。

## 1. 互斥模式

| 模式 | 定义 | 代码行为 |
|---|---|---|
| A | 人工读价 | 读取外部输入 `PRICE 601398=x.xx 600000=x.xx`（兼容 JSON 价格文件）；两码缺一 ⇒ `MISSING_PRICE` 零报单 |
| B | 静态价 | 买入限价 = 11-24 收盘价 × `buy_factor`（默认 1.01），**向上取整到 0.01**；卖出限价 = 卖出日收盘价 × `sell_factor`（默认 0.99），**向下取整到 0.01** |
| C | 现场安排 | 第二人在线；**不提供价格**，单独选 C 时买腿仍 `NO_PRICE_MODE` HALT |

## 2. 切换留痕（谁 / 何时 / 依据）

- 模式文件：`forward/probe_price_mode.json`；切换审计：`forward/probe_price_mode_audit.jsonl`。
- 只能由本人明确指令后调用 `probe_automation.py set-price-mode --mode X --by <本人> --basis <依据>`；脚本不代填 `by`/`basis`。
- 默认（文件不存在或 `mode` 为空）：`NO_PRICE_MODE`、零报单、rc≠0。

## 3. 系数可配置

`buy_factor` / `sell_factor` 为模式文件里的可配置常量，默认 1.01 / 0.99；本人确认前不启用，不得由执行方先填一个“看起来合理”的值。

## 4. 成本基线隔离（写死）

**PROBE 成交价可能劣于当日最优，不作为成本基线。** 任何后续对账/成本口径引用（含 §6.5 的真实综合费率）不得拿 PROBE 成交价做校准；B 模式的 1% 让价只是提高链路验证的成交概率。
