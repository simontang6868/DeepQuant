## 1. 研究对象与待估计量（必填）

- 一句话问题、预期用途
- 样本区间、决策日、执行日、as-of 截断、数据时点可用性
- 基线、主指标、辅助诊断
- **必报 MDE**；若 n=1 或 se 不可估 ⇒ 明确写 `MDE_NOT_ESTIMABLE`，并给借用口径且标「不同信号、仅量级参考」

## 2. 口径冻结（必填）

窗口／基准／池／成本／估计量（iid vs NW、单侧 vs 双侧、pp vs 小数）／换手／费率来源。
任一改动 ⇒ **新实验 + 新预登记**。成本必须指定 `cost_of()` 调用点，**不许就地手写**。

## 3. 成功标准与不做清单（必填）

判据、谁判、失败/异常如何留痕（保留原产物 + 出更正，原文不改写）、明确不做的事。

## 4. 预期方向 + 机制 + 结构假设（必填，落在**可算量**上）

每条预测写成可对错的数值／恒等式／不等式，**不写「应该会抗跌」这类不可证伪的话**；
每条注明机制与**结构假设**；⭐ **不得替规则添加它没有的性质**（P3 教训：把「只补低于目标的」推成「不会超目标」）。

### ⭐ 4-A 符号与幅度约定（**Q6 新增，必填，缺此项不得冻结**）

| 量 | 必填内容 | 示例（PA-OCT2026-1 的反面教材） |
| --- | --- | --- |
| 每个带方向的统计量 | **符号约定**：负值表示损失／回撤，还是幅度用正数？ | `MDD` 在 PA-OCT2026-1 用**负值**（`MDD(B) > −5%` 已暴露该约定） |
| 每个比较式 | **比较的是有符号数还是幅度**？明确写 `|x|` 或 `abs()` | 原式 `MDD(B) < MDD(A)` 按负值是「更负」，与机制「回撤更小」相反 ⇒ 被反驳 |
| 若两者都可能 | **同时冻结两套判据**，并写明哪一套是头条判定 | 头条：`MDD_signed(B) > MDD_signed(A)`；补记：`|MDD(B)| < |MDD(A)|` |
| 幅度补记的引用边界 | 明确写「补记**不得**被引作头条判定的支持」 | P3 头条保持 `REFUTED`，补记只说明机制未失效 |
| 单位 | pp / 小数 / 百分比，逐项标注 | `newey_west` 入参必须小数；`cost_of` 的 `rate` 必须小数 |
| 方向一致性自检 | 冻结前用一组**已知数值**代入比较式，确认方向符合机制直觉 | −2.92 与 −3.69 代入 `B < A` ⇒ 假 ⇒ 应在冻结前发现 |

> ⚠️ 冻结前的自检必须用**独立算术或产物**，**禁止调用被测函数**推导期望值
> （L3ac M6 / L3ae M3）。

## 5. 变异与闸门（必填）

- 改检查器前先跑变异测试；变异必须**真改行为**（不接受「换个拒绝理由」的假变异）
- 容差按**产物存储精度**定（6 位小数 ⇒ 相对下限 4e-6；三个量相加 ⇒ 绝对上限 1.5e-6）
- 「文件不存在」≠「确认无事件」；「输出为空」必须失败关闭
- **变异脚本原地改源码期间禁止任何其他 pytest/提交**

## 6. 引用与更正（必填）

- 引用带：预登记哈希 + 产物目录 + `StatisticalVerdict` + `MaturityLevel` + MDE
- 发现错误：保留原始结果 + 出更正，**原文不改写**
- ⭐ **预登记有缺陷也不改**：另立缺陷记录段 + 按字面执行 + 如实报「预测被反驳」
