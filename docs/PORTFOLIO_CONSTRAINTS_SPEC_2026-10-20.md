## 0. 这一节要回答什么（不问收益，只问能不能建仓）

旧结论（`CAPITAL_TIER_2026-10-19.md`）只回答了一个问题：**6 只池里，多少钱才买得起每一只**，答案是
独立账户 30 万 / 等权 150 万。它没有回答的是：**在 k=110 这种真组合里，整手约束会带来多大偏离、多少钱才够**。

本节只测四件事，**全部与收益率高低无关**：

| # | 问题 | 指标 |
|---|---|---|
| Q1 | 给定资金 W 与持仓数 k，有多少只**根本买不起**（连 1 手都不够） | `buyable_ratio` |
| Q2 | 整手取整后，实际权重偏离等权多远 | `weight_mae_pp` |
| Q3 | 建仓后有多少钱**躺在现金里** | `cash_pct` |
| Q4 | 整手 + 现金残留 + 换手成本，让组合收益比"理论等权"差多少 | `excess_vs_theory_pp_per_year` |

并给出一个机械定义的档位：**W\*（可用档）= 使 `holdings_actual ≥ 0.95k` 且 `weight_mae ≤ 0.5pp` 的最小 W**。

## 1. 口径（写死，跑完不得改）

### 1.1 持仓集合（中立规则，与 alpha 无关）

> **每月最后一个交易日，按成交额代理 `close × volume` 降序取前 k 只。**

选这条规则的理由：本节研究的是**执行机制**，不是选股能力。用任何策略信号都会让结论绑在一个已经死掉的
假设上（Gate 2/3 的反转在 2016 后已失效）。成交额前 k 是"大盘 + 活跃"的中立代理，
且**恰好是整手约束最紧的一类**（高价股多）。

- 数据：`data/exec_long/`（真不复权 EXEC），研究池 532 只（同 Gate 3 §2.1 剔 17 只）
- 窗口：主 **2016-01 ~ 2026-09**（近十年，高价股最集中）；辅 2007-01 ~ 2015-12（对照）
- 停牌/无价：当日无价的标的不入候选

### 1.2 交易与记账

| 项 | 设定 |
|---|---|
| 建仓价 | 调仓日 **EXEC 收盘价**（乐观假设：无冲击、无滑点、无涨跌停约束——**已知局限**） |
| 最小单位 | **100 股/手**，只能整手买卖 |
| 单只预算 | `W / k` |
| 可买手数 | `floor(budget / (price × 100))`；为 0 则该只**不建仓**（不计入 holdings_actual） |
| 现金 | 未投入部分，收益按 **0** 计 |
| 再平衡 | 每月一次，先卖后买，目标权重仍为等权 1/k |
| 成本 | 单边费率 × 换手额（档位 0 / 0.1% / 0.3%） |
| 对照基准 | **理论等权**：无整手、无成本、永远满仓 |

### 1.3 场景网格（跑前固定，不许事后挑）

- k ∈ **{10, 30, 110}**
- W ∈ **{5万, 10万, 20万, 30万, 50万, 100万, 150万, 300万, 1000万, 3000万}**
- 成本档：**0（只算整手）** 与 **0.1%**（净口径）
- 共 3 × 10 × 2 = 60 组，全报，**不挑**。

### 1.4 指标定义（逐项可复算）

| 指标 | 定义 |
|---|---|
| `buyable_ratio` | 目标集合中 `floor((W/k)/(price×100)) ≥ 1` 的只数 / k，逐月平均 |
| `holdings_actual` | 实际建仓只数，逐月平均 |
| `weight_mae_pp` | `mean_i |w_i − 1/k| × 100`（未建仓的 w=0），逐月平均 |
| `cash_pct` | `(W − Σ持仓市值)/W × 100`，逐月平均 |
| `excess_vs_theory_pp_per_year` | 组合年化收益 − 理论等权年化收益（同持仓集合、同窗口） |
| `W\*` | 网格中满足 `holdings_actual ≥ 0.95k` 且 `weight_mae ≤ 0.5pp` 的最小 W；网格内无解则记 `>3000万` |

## 2. 明确不做（防止这一节变成第二个策略研究）

1. ❌ 不做任何**选股**优化：持仓集合由成交额规则唯一确定，不试第二个排序因子；
2. ❌ 不做冲击成本/市场容量建模（属阶段 5 交易可行性），本节只算整手与现金残留；
3. ❌ 不测"哪个 k 收益最高"——k 是约束参数，不是调优参数；
4. ❌ 不因为某档结果好看就改档位；网格全报。

## 3. 已知局限（跑前声明）

1. **收盘价成交**是乐观假设：真实执行会有滑点，尤其成交额前 110 之外的标的；
2. 未建模**涨跌停不可成交**、**T+1**、**券源**（做空腿）——这三条会让实际可行性比本节更差；
3. 成交额用 `close × volume` 代理（volume 为手），未剔除大宗/竞价差异；
4. 持仓集合每月完全按当期成交额重排，换手率天然偏高，成本估计偏保守；
5. 现金按 0 收益计，未考虑货币基金/逆回购（会让现金拖累高估约 1.5~2pp/年，仅影响 W 极小的档位）。
