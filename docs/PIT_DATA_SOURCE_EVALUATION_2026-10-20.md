# PIT 数据源采购评估（阶段 2 · P1-3）

> 生效日期：2026-10-20 ｜ 阶段：数据体系修复（路线图 §6 · P1-3）
> 性质：**评估，不采购、不报价、不承诺**。产出是"候选数据源 × 关键能力"的对比表，供决策。
> 硬约束（路线图 §10）：**在拿到 PIT 成分股之前，不扩池、不堆因子**（V1 偏差随样本放大）。

---

## 1. 为什么需要 PIT（一句话）

现有池是"2026 年仍在市的 50 只 csi300 样本"，**没有时点成分信息**。同一策略在"在市 292"与"+退市 236"两池上
8 年净值 **6.85 vs 1.81（差 3.8 倍）**（见路线图 §6 V1 证据）。所以任何横截面结论，在缺 PIT 的情况下都可能高估 3~4 倍。
PIT 要解决的是：**"在历史上某一天，哪些股票真的是指数成分、且当时就能知道"**，含剔除日期与退市股。

## 2. 评估维度（每个源都按这 6 项打）

| 维度 | 为什么关键 |
|---|---|
| 含**剔除日期** | 没有它就只知道"曾在池"，不知道"何时出池"，无法重建时点池 |
| 含**退市股** | 不含退市股 = 幸存者偏差没解决，等于白买 |
| **PIT 真实性**（当时可得 vs 事后修正） | 事后修正的成分表 = 前视偏差 |
| **粒度** | 日 / 月 / 半年调整；临时调整（退市/风险警示）能否捕捉 |
| **可得性/成本** | 免费 / 学术授权 / 商业采购（不在此报价） |
| **验证状态** | 本轮实测过 / 仅文档确认 / 待抽验 |

| 源 | 剔除日期 | 含退市股 | PIT 真实性 | 粒度 | 可得性 | 验证状态 |

**排序建议（性价比）**：
1. **先试 ② 新浪历史成分表**（免费、有纳入/剔除日期、含旧名）——若抽验确认覆盖完整，直接可重建 PIT，零成本。
2. **②不行→试 ① 中证官网公告**（最权威，免费，但要抓历史公告，工作量中等）。
3. **要事件级精确 + 本校有 CSMAR 订阅**→用 ④（最省事、最权威的事件级）。
4. **③ Tushare** 仅作月度快照补充（2000 积分），不单独作为 PIT 主源（无剔除字段）。
5. **⑤ 商业源**仅在免费/学术路径都不可行时才考虑（不在此报价）。

## 5. 本轮硬结论

1. **C1 的"无全收益基准"已解除**：`H00300.CSI` 免费可取，实测价格/全收益年化差 **2.40pp**（2016-2026）。
   → 阶段 3 新预登记**可以**用全收益基准；但 Gate 1 旧结论仍在同池等权下，不回改。
2. **PIT 成分股仍未解决**，但**有免费可行路径**（新浪历史表 / 中证公告），**无需采购即可先试**。
3. **扩池继续冻结**：在 PIT 抽验通过前，不扩池、不堆因子（V1）。
4. **下一步（P1-3 之后）**：
   - 抓取新浪历史成分表 → 抽验 3~5 个调整期的"纳入/剔除"是否与中证公告一致；
   - 若一致 → 重建 2016-2026 时点池 → 进阶段 3 新预登记（PIT 池 + 全收益基准）；
   - 若不一致 → 转中证公告解析或 CSMAR（视订阅）。

## 6. 不做的事（写死）

- ❌ 不报价、不承诺任何商业数据源的价格或效果；
- ❌ 不在 PIT 抽验通过前扩池；
- ❌ 不用"当前成分表回填历史"冒充 PIT（那是前视偏差）；
- ❌ 不把 `H00300` 的可用性误读为"Gate 1 可以重算"（换基准=新实验，C1）。
