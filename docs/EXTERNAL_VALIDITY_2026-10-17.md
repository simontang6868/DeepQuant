# 外推有效性检验：180 个 OOS 窗口的结论能推广到 A 股吗？

> 日期：2026-10-17 ｜ 执行者：B 线（量化研究分析师） ｜ 性质：**诊断**，不是解决
> 数据：全部为**真实行情**（akshare 腾讯源 `stock_zh_a_hist_tx`，qfq 前复权，2018-01-01~2024-12-31）
> 红线自检：不调参（沿用原研究配置，一字未改）｜ 不动引擎 ｜ 不用于择优 ｜ R5 保留全部推翻记录

---

## 0. 一句话结论

**原研究的核心判断「无稳定 alpha」成立，但它的表述方式错了，且理由不完整。**

- 收益中位数不是"全为 0"，而是 **"要么 0，要么负，从不为正"**——22 只标的里，中位收益 > 0 的有 **0 只**；
- 在随机抽样的 16 只普通 A 股上，"中位数 = 0" 只占 **9/16（56.2%）**，白马组才是 6/6；
- 但那些**不为 0 的，7 只全部为负**。

所以正确的表述是**"零或负 alpha"**，而不是"零 alpha"。这个差别很重要：它不是"没赚到"，而是"参与了的那些标的在扣费后系统性亏损"。

---

## 1. 为什么做这个检验

此前所有结论（36 组研究、180 个 OOS 窗口）都建立在 **6 只标的**上：

```
贵州茅台 / 平安银行 / 中国平安 / 宁德时代 / 五粮液 / 长江电力
```

这 6 只不是随机抽的，是**按知名度挑的**（大盘白马）。在量化研究里，这叫 **selection bias（标的选择偏差）**——结论可能只是这 6 只的特性，而不是 A 股的共性。

本轮回答两个问题：

| # | 问题 | 假设 |
|---|---|---|
| Q1 | 「收益中位数全 0」是这 6 只特有的，还是 A 股普遍现象？ | 待检验 |
| Q2 | 成因 B（一手买不起）在价格谱上是孤例，还是系统性梯度？ | 待检验 |

## 2. 样本怎么构造的（方法学，每一条都在防偏差）

### 2.1 抽样框

- 来源：`stock_info_sh_name_code`（沪 1702）+ `stock_info_sz_name_code`（深 2906）= **4608 只**
- 筛选：**2018-01-01 之前上市**（保证回测期全程有数据）→ 剩 **3235 只**
- 剔除：科创板 688（2019 年才有，且 200 股起）、北交所

> 筛选依据全部是**非收益属性**（上市日期、板块）。绝不按历史表现挑票——那才是 R11 要防的东西。

### 2.2 分层依据：用回测期**开始之前**的价格

这里有个陷阱差点踩进去：

- `stock_zh_a_spot` 接口能拿到 5576 只 A 股，但**只有当前（2026-10）价格**；
- 用它分层 = 拿 2026 年的价格去挑 2018-2024 的回测样本 = **前视偏差（look-ahead bias）**。

所以改用一个绕弯但干净的办法：

1. 随机抽 **80 只**候选（固定种子 `SEED=20261017`）；
2. 只拉它们 **2018 年 1 月**的行情（回测期开始前）；
3. 按 2018-01 的 qfq 均价做**四分位分层**；
4. 每档随机抽 4 只 → **16 只**。

> 分层依据发生在回测期之前，且不含任何收益信息 → 既无前视偏差，也无收益选择偏差。

### 2.3 对照组

原研究的 6 只白马全部保留，作为对照。合计 **22 只**。

### 2.4 已知局限（无法在本数据源下消除，如实记录）

| 局限 | 说明 |
|---|---|
| **幸存者偏差** | 交易所名录只含**截至 2026-10 仍在交易**的标的，2018-2024 期间退市股不在框内。<br>注意：原研究 6 只同样有此偏差，故**相对比较仍成立**，绝对外推要打折。 |
| 价格谱覆盖不足 | 80 只随机候选里最贵的才 57.94 元（一手 5,794 元）。<br>**高价股在 A 股是极少数，随机抽样够不着**——见 §4.2，这个"缺陷"反而变成了有用的设计。 |

## 3. 结果

### 3.1 分组对比

| 指标 | 随机样本组（16 只） | 白马对照组（6 只） |
|---|---|---|
| 参与率（均值 / 中位） | **57.5%** / 56.7% | **41.5%** / 46.7% |
| 收益中位数 = 0 的比例 | **9/16 = 56.2%** | **6/6 = 100%** |
| 正收益比例（均值） | 33.7% | 32.1% |
| 总笔数（均值 / 中位） | 25.9 / 24 | 17.7 / 20 |
| 买不起一手 | **0/16** | 1/6（茅台） |

### 3.2 中位收益的符号分布（全 22 只）

| 符号 | 数量 |
|---|---|
| **> 0** | **0 只** |
| = 0 | 15 只 |
| < 0 | 7 只 |

七个非零中位数，全部为负：

```
拓日新能 -0.01442   太阳电缆 -0.00509   青山纸业 -0.00055
胜利股份 -0.00135   天山生物 -0.03137   莱绅通灵 -0.01273   首旅酒店 -0.00694
```

**没有任何一只标的的 OOS 收益中位数为正。**

## 4. 两个待检验问题的答案

### 4.1 Q1：不是这 6 只特有的，但也不是它们说的那样

| | 随机样本 | 白马 | 判断 |
|---|---|---|---|
| 中位数 = 0 的比例 | 56.2% | 100% | **原结论外推失败** |

"收益中位数全 0" 在随机样本上**不成立**。但把它换成"收益中位数从不 > 0"就**完全成立**（22/22）。

> ⚠️ 口径提醒（R12）：以上全部是**窗口级统计**，不是连续账户收益。
> 30 个 OOS 窗口是相互独立的片段，不能拼成一个账户净值曲线来读。

### 4.2 Q2：成因 B 是**断崖**，不是梯度

| 标的 | 研究期均价 | 一手成本 | 买得起？ | 参与率 |
|---|---|---|---|---|
| 青山纸业 | 2.26 | 226 | ✅ | 73.3% |
| 拓日新能 | 4.19 | 419 | ✅ | 76.7% |
| 东睦股份 | 8.68 | 868 | ✅ | 50.0% |
| 莱克电气 | 19.30 | 1,930 | ✅ | 46.7% |
| 山东药玻 | 25.45 | 2,545 | ✅ | 50.0% |
| 中国平安 | 47.55 | 4,755 | ✅ | 46.7% |
| 五粮液 | 135.50 | 13,550 | ✅ | 53.3% |
| **贵州茅台** | **1,243.67** | **124,367** | ❌ | **16.7%** |

**在 2.26 ~ 135.50 元这个 60 倍的价格跨度内，参与率在 46.7%~76.7% 之间无规律波动。** 真正的跳变只发生在茅台——唯一的买不起。

这与引擎代码完全一致（`backtest/engine.py`）：

```python
# engine.py:132-141  _affordable_buy_quantity
max_lots = target // lot_size
for lots in range(max_lots, 0, -1):
    ...
    if gross + fees.total <= cash + _EPS:
        return qty
return 0          # 买不起 1 手

# engine.py:252-254
if qty < lot_size:
    pending.status = OrderStatus.REJECTED
    pending.reason = REASON_INSUFFICIENT_CASH
```

引擎是**满仓下单**（`_target_buy_quantity` 按全部现金算最大整手数），只有**买不起 1 手**才拒单。所以价格对参与率的影响必然是**二值断崖**，不可能是连续梯度。

> **本轮的意外收获**：随机 16 只**全部买得起一手**（§2.4 的"缺陷"），
> 正好构成一组**排除成因 B 的干净对照组**——它们参与率 46.7%~76.7%，
> 说明**低参与现象独立于高价股问题而存在**。

## 5. 参与率由什么驱动？（三次自我推翻）

相关性分析先给了三个诱人的结果，然后被稳健性检验逐个打掉。

### 5.1 第一版：看起来很强

| 关系 | r | \|t\| | 结论 |
|---|---|---|---|
| 对数均价 → 参与率 | **−0.772** | 5.43 | 显著 |
| 对数均价 → 总笔数 | −0.669 | 4.03 | 显著 |
| 年化波动 → 参与率 | −0.358 | 1.71 | 不显著 |
| 参与率 → 中位收益 | −0.429 | 2.12 | 显著 |

### 5.2 剔除离群点后：大半塌了

| 口径 | n | 对数均价→参与率 | 波动→参与率 | 参与率→中位收益 |
|---|---|---|---|---|
| 全体 | 22 | −0.772 显著 | −0.358 不显著 | −0.429 显著 |
| 剔除宁德 | 21 | −0.737 显著 | +0.241 不显著 | −0.424 边缘 |
| **剔除宁德+茅台** | 20 | **−0.449** | +0.214 不显著 | **−0.496 显著** |
| **仅 16 只随机样本** | 16 | **−0.432 不显著** | −0.015 不显著 | −0.475 边缘 |

> t 临界值（双侧 5%，df=20）≈ 2.09

### 5.3 结论

| # | 判断 | 结果 |
|---|---|---|
| ❌ | 波动率驱动参与率 | **证伪**。剔除异常值后 r = +0.241，不显著，且方向都不对 |
| ❌ | 价格连续影响参与率 | **证伪**。−0.772 **全靠茅台一个点**，剔除后腰斩到 −0.449，随机样本上直接不显著（−0.432） |
| ✅ | **参与率与收益质量负相关** | **成立且稳健**。剔除两个极端后 r 仍为 −0.496（显著），三个口径下都是 −0.42~−0.50 |

**第三条是唯一活下来的**，而且它印证了上一轮的结论：

> 参与率是**数量**指标，不是质量指标。提高参与率的代价是单笔质量下降。
> → 参与率**只能披露，禁止用于择优**（已写进 `design_audit.py` 的模块 docstring）。

那么参与率到底由什么驱动？在 46.7%~76.7% 之间无规律波动、与价格/波动率均无关 →
**更可能是 MA 交叉事件在不同价格路径上的随机稀疏性**（即上一轮确认的"事件稀疏"成因），
而在 n=22 的样本量下**无法用标的属性预测**。

## 6. 顺带查出的数据质量问题（本轮最有操作价值的发现）

### 6.1 现象：腾讯源 qfq 会产生非正价格

检查全部 22 只标的 2018-2024 的 qfq 行情：

| 标的 | 总行数 | 非正价行数 | 最小收盘价 | 最早非正日 |
|---|---|---|---|---|
| 宁德时代 | 1594 | **2** | **−2.07** | 2018-06-11 |
| 其余 21 只 | ~1699 | 0 | — | — |

宁德时代上市初期（2018-06-11、06-12）的 qfq 收盘价为 **−2.07 / −0.06**，开盘价 **−5.42 / −0.06**。

成因：qfq 前复权在高送转 + 高涨幅标的上，会把早期名义价减过头，**减成负数**。

**普遍性**：
- 22 只标的里 1 只（4.5%）；
- 但抽样时的 80 只候选中，2018-01 均价最低即为 **−2.16**，说明这个现象不只宁德一例。

### 6.2 真正的问题：校验器报了，研究流程没拦

**好消息**：项目的校验器**是能报出来的**——

```python
# data/validation/checks.py:107-113
nonpositive = (price_df <= 0).any(axis=1)
invalid_price = rows_complete & (nonpositive | ~finite)
if invalid_price_count:
    ValidationIssue(ERROR, "invalid_price", "价格非正或非有限", invalid_price_count)
```

实测 22 只全部通过校验器检查，宁德被正确标记为 `invalid_price`（ERROR 级）。

**坏消息**：原研究脚本**只保存 warning，不检查 error**——

```python
# data/step75/research.py:88  ← 只收 warning
"warnings": [{"code": i.code, "msg": i.message[:200]}
             for i in report_ext.issues if i.level == "warning"],
```

于是失真的宁德数据照样进了 walk-forward。而且原研究自己记下的这条警告，摆在那里没人管：

```
step75_research_summary.json → stocks[300750.SZ].warnings:
  price_jump: 存在 1593 个相邻收盘价跳变 > 15%（最大 3683.33%）
```

**1594 行数据里有 1593 次跳变 > 15%，等于每天都在跳变**——这是极其刺眼的异常信号，
却因为是 warning 级别，被记录、被保存、然后被忽略。

> **因果链**：数据源产生非正价 → 校验器正确报 ERROR → 研究脚本只收 WARNING →
> 失真数据进入研究 → 产出"收益中位数 0"的结论。

### 6.3 这条不修的后果

**原研究 6 只标的里有 1 只是拿失真数据跑出来的。** 这不影响其他 5 只的结论，
但意味着 36 组结果里有 6 组（宁德 × 2 策略 × 3 费率）是建立在可疑数据上的。

修复方向（**本轮不实施，需批准**）：

1. 研究脚本在 `validate_daily_extended` 之后，检查 `i.level == "error"` 并**中止该标的**；
2. 或对 qfq 数据改用**分段校验**（negative price 检测）+ 数据源切换。

## 7. 本轮推翻的自身判断（R5：全部保留，不删不改口）

| # | 我原先以为 | 实际 |
|---|---|---|
| 1 | 波动率驱动参与率（低价小盘波动大 → 交叉多） | **证伪**，r = +0.241 不显著 |
| 2 | 价格对参与率是连续梯度影响 | **证伪**，−0.772 全靠茅台单点，剔除后不显著 |
| 3 | 22 只行情数据都可用 | **1 只含非正价**，且原研究已知却未拦截 |

加上此前几轮，累计推翻 12 条。方法论教训（已刻进记忆）：

> **相关性出来先做剔除离群点的稳健性检验，再决定报不报。**
> 本轮若不检验，就会把 −0.772 当成重大发现写进结论——那是假相关。

## 8. 局限与未做的事

- **样本量 22 只**：相关性检验的统计功效有限，多个结论落在 |t| ≈ 2.0~2.4 的边缘区间，
  显著性判定**脆弱**，不宜当作强证据使用。
- **幸存者偏差**：无法在现有数据源下消除（§2.4）。
- **只跑了 ma_cross + simulation 费率**：未跑 mean_reversion、未做三费率敏感性
  （时间约束，非方法学限制）。
- **未做的细分**：未区分"无成交导致的 0" 与"有成交但收益为 0"的窗口
  （需要 window 级明细，本轮未采集）。
- **宁德 2018-06 才上市**：数据只有 1594 行（其余 1699），且含非正价，
  其结论（参与率 32.1%）应视为**不可靠**。

## 9. 对原研究结论的最终修正

| 原表述 | 修正后 |
|---|---|
| 「180 个 OOS 窗口收益中位数**全为 0**」 | 「收益中位数**从不 > 0**：22 只中 15 只为 0、7 只为负、0 只为正」 |
| 「无稳定 alpha」 | 「**零或负 alpha**：参与了交易的标的在扣费后系统性亏损」 |
| 隐含「这是 6 只标的的普遍规律」 | 「参与率不足是共性（随机样本 57.5% vs 白马 41.5%），<br>但'中位数全 0'是白马组的特性，随机样本上只占 56.2%」 |
| 「成因 B = 高价股买不起一手」 | 「成因 B 是**断崖**不是梯度：仅影响极少数标的（随机样本 0/16），<br>且与引擎的满仓下单逻辑一致（只有买不起 1 手才拒单）」 |

**一句话**：结论方向没变（确实没有可交易的正 alpha），
但**理由、表述、和适用边界都需要照上面改**。
