> 起草：2026-10-25 ｜ 用途：直接发给回测执行方
> 代码已由通达信检索核实；窗口约束由 600938 的年线数据确认；分红贡献引自项目既有三年体检 `docs/STOCK_REVIEW_3Y_OIL_2026-10-20.md`、`docs/STOCK_REVIEW_3Y_2026-10-20.md`

## 一、任务（一句话）

在指定 7 只 A 股上按给定规则回测，**判断该策略是否稳定跑赢"买入持有"**。
这是历史证据检验，不是涨跌预测，不构成下单依据。

## 二、标的（7 只，全部沪市 setcode=1）

| 代码 | 名称 | 备注 |
|---|---|---|
| 600938 | 中国海油 | **2022 年上市，是全篮子共同窗口的短板** |
| 600968 | 海油发展 | 2019 年上市 |
| 601808 | 中海油服 | 油服，收入受中国海油资本开支驱动 |
| 600583 | 海油工程 | 油气工程，同上 |

| 601668 | 中国建筑 | 建筑、高股息 |
| 601398 | 工商银行 | 银行、高股息 |

⚠️ **已知结构（务必在结论里体现）**：4 只油气 + 1 只煤炭高度同向。本项目 2023-10-16→2026-10-16 的三年体检结论是 **"这五只是同一笔交易"**——油气链五只的最高点与最低点几乎同时发生。
→ 所以 7 只**不是 7 个独立样本**。若策略是"7 选 1 轮动"，实质是在同一个因子（油价/煤价/周期）上重复计数，有效独立样本远小于 7。

## 三、数据与窗口

| 项 | 要求 |
|---|---|
| 周期 | **日线**为主；另用**周线**跑一遍做稳健性复核 |
| 复权 | **前复权**（等价于分红按除权日收盘价再投资） |
| 共同窗口 | **2022-04-21 → 2026-10-23**（约 4.5 年 / 约 1100 个交易日） |
| 数据末端 | 通达信日线数据截至 **2026-10-23** |

**为什么不用"近一年 / 今年以来"作主窗口：**

1. **看交易次数，不看 K 线根数。** 1 年有约 240 根日线，看似多；但如果策略一年只触发 3~5 次交易，**独立样本就是那 3~5 次**。以 7 只票共 21 次交易、13 次盈利（胜率 62%）为例——抛硬币也能以约 14% 的概率得到这个结果，无法区分能力与运气。
2. **周期股尤其危险。** 油/煤周期通常 3~5 年一轮，只测一年大概率只覆盖半个周期，结论会系统性偏误。
3. **样本已证实的量级**：本项目实测，月度序列 36 个月的检验功效只有 **21%**，要达到 80% 功效需要 **206 个月**。语境不同，但"短样本什么都证不了"是同一条规律。
4. 2026 年单只中国海油就走出了 25.11 → 43.25 → 33.72（先 +72% 再回撤 22%），"今年以来"的曲线是少数事件驱动的，**不能外推**。

→ 若因数据限制只能出短窗口结果：**必须同时报告长窗口**，并明确标注"短窗口仅作参考"。

## 四、策略规则（需填写，不得使用未来数据）

必须逐项写清，缺一项结果就不可复核：

1. **信号定义**：用什么指标/条件，参数值多少
2. **信号确认时点**：收盘后确认，还是盘中触发
3. **下单时点与成交价假设**：建议 `T 日收盘确认 → T+1 开盘成交`。
   ⚠️ **禁止**用"当日收盘算出的信号，在当日收盘价成交"——那是前视偏差
4. **持仓数量与权重**：等权，还是按信号强度加权
5. **空仓规则**：无信号时持币还是持有
6. **止损 / 止盈**：有无；触发后是否允许再入场
7. **调仓频率与再平衡规则**：买入持有，还是定期重置回等权（两者成本不同，必须择一）
8. **参数来源**：参数是否在本窗口内调出来的？若是，必须做样本外（见第七节）

## 五、交易与成本假设

- **T+1**：当日买入当日不可卖出
- **整手 100 股**；资金分 **1000 万** 与 **1 亿** 两档各跑一遍
- **涨跌停 / 停牌**：当日不成交，顺延，并**单独计数**报出次数
- **成本口径**（与券商实际一致，建议主口径）：
  佣金 0.025% 双边 + 印花税 0.05% **仅卖出** + 过户费 0.001% 双边
  ≈ 等价**对称单边 0.051%**；另跑一档 **0.30% 单边** 的压力测试
- **滑点**：按成交金额 0.05% 单边的保守档并列报告（这几只是大盘股，实际冲击远小于此，故保守档与主口径都要给）

## 六、基准与必报指标

**基准（两条都要）：**
- **B1** = 7 只**等权买入持有**（同一个窗口、同一套前复权口径）
- **B2** = 沪深300 价格指数（或中证红利，二选一并注明）

**必报指标（每只 + 组合）：**

总回报、年化收益、年化波动、最大回撤、Calmar、
**相对 B1 / B2 的年化超额**、**交易次数**、胜率、平均持有天数、
年化双边换手、期末未投资比例、**费用合计占毛收益的比例**

⚠️ **只报收益率、不报交易次数与成本占比的结果不可接受**——
这几只分红高、波动大，绝大多数"策略收益"其实来自 beta 与分红。

## 七、稳健性（必做）

1. **分段**：2022-2023 / 2024 / 2025 / 2026 各段单独报
2. **参数敏感性**：主参数 ±20% 各跑一遍，标注结论是否翻转
3. **极端日剔除**：去掉收益最好/最差各 3 个交易日，看结果是否由少数几天驱动
4. **样本外**（若参数在窗口内调出）：`2022-04 → 2024-12` 样本内 / `2025-01 → 2026-10` 样本外，两段分别报告

## 八、交付物

1. 逐月净值序列（CSV）
2. **逐笔交易明细**（日期、代码、方向、价格、数量、费用）——缺此项无法复核
3. 指标汇总表
4. **明确列出未建模项**：分红税、冲击成本、涨跌停未能成交的次数、样本外缺失等

---

**结论口径提醒**：回测是历史证据，不构成"可用"的确认。任何"策略年化 X%"的表述都必须同时给出窗口、交易次数与相对买入持有的超额。
