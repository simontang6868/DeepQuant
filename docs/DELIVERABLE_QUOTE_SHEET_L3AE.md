本清单只服务一个问题：**`phasei` 这两条序列在扣成本后到底怎样**。
统计层面的可引状态（是否通过多重检验）由 `docs/DELIVERABLE_QUOTE_SHEET_L3AD.md` 管，不在这里重复。

## 1. 一句话结论

> exQ5 可成交（V1）在 **真实费率** 下净 alpha 约 **+0.14pp/月**
> （t = +2.98，iid 口径），在 **5.9 倍压力费率** 下转为不显著
> （+0.05pp，t = +1.04）。全部为样本内。

## 2. 可以怎么引

| 想说的话 | 允许的写法 | 必须附带 |
| --- | --- | --- |
| 真实费率下为正 | 「1 亿资金档、等价单边 0.051% 下净 alpha +0.14pp/月（t=2.98）」 | 资金档、费率、iid 口径、样本内 |
| 中等资金也站得住 | 「3000 万档（含 5 元最低佣金，等效 0.0585%）净 +0.14pp（t=2.92）」 | 说明最低佣金已计入 |
| 小资金仍为正 | 「1000 万档（等效 0.1234%）净 +0.12pp（t=2.41）」 | 同上，并说明这是成本最重的档 |
| 压力测试不通过 | 「0.3% 档（真实费率 5.9 倍）净 +0.05pp、t=1.04，不显著」 | 说明这是预登记的判定档，`C_cost=false` 由它出具 |

## 3. 不允许的推论

| 不能写 | 为什么 |
| --- | --- |
| 「成本吸收已被推翻」 | 判定按预登记主成本 0.3% 出具，仍为 `EXQ5_COST_ABSORBED`；本阶段只补披露档 |
| 「成本后为正」不带费率档 | 0.051% 与 0.3% 的结论方向相反；不带档位等于让读者自己猜 |
| 「0.051% 下净 alpha 0.14pp」不带资金档 | 0.051% 只在 1 亿档成立；3000 万是 0.0585%，1000 万是 0.1234% |
| 「扣除成本后年化 X%」 | 这是月度 alpha 的均值，不是连续账户收益（MEMORY R12） |
| 「可实盘」 | 样本内、无前瞻证据；通过成本检验 ≠ 可交易 |
| 「t=3.99 所以更强」 | 那是 NW(3) 口径；判定用的是 iid 的 2.98。两套都报，不能挑大的 |

## 5. 与统计层面清单的关系

`phasei_v0` / `phasei_v1` 在 L3ad 的 m=25 家族里通过 Bonferroni/Holm/BH/BY 四种校正，
属于「可引 7 条」里的两条。**统计通过**回答的是「这两条是不是噪声」，
**本清单**回答的是「扣掉成本还剩多少」。两件事都要说，缺一条就会被误读。
