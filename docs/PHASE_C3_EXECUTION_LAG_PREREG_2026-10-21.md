## 0. 这个实验要回答什么

Gate 2/3/6 与阶段 C 的全部收益，都是这么算的：

```
fwd = ffill(月末最后交易日 nxt) / ffill(信号日 pos) − 1
```

**信号在 pos 日收盘生成，成交价也用 pos 日收盘。** 这隐含了一个不可能的操作：
在看到收盘价的同时按这个收盘价成交。

真实最早只能 pos+1 成交。对反转策略这不是小事——**短期反转的效应在第 1 天最强**，
而这一天恰好被这个口径吞掉了。

本实验量化：**把成交推迟到真正可执行的那一天，效应还剩多少。**

### 0.1 为什么要分成 V1 / V2 两格

「晚一天」和「顺延」是两件不同的事，混在一起就说不清：

- **V1**：无条件按 `pos+1` 成交。测的是**纯时间延迟**的代价，不掺交易可行性。
- **V2**：从 `pos+1` 起找**第一个真正可成交**的日子（跳过涨停/一字板/停牌），最多 5 个交易日，
  超时剔除。测的是**真实可执行**的代价。

两者相减（`V2 − V1`）才是"顺延"的净成本。**这个拆分是本实验的主要设计点。**

## 1. 统一口径（与阶段 C 完全一致）

| 项 | 写死取值 |
|---|---|
| 信号 | `score = close(t−1) / close(t−21) − 1` |
| 排序 | 做多低分（输家）、做空高分（赢家） |
| 有效数据 | 21 日窗口内 ≥ 19 个有效交易日 |
| 入池门槛 | 截至信号日累计有效交易日 ≥ 252 |
| 宇宙 | 纯 A 股，ADJ/EXEC 双覆盖 |
| 价格层 | 收益用 `data/qfq_all`；交易状态用 `data/exec_all` |
| 再平衡 | 月末最后交易日收盘定信号 |
| 窗口 | 信号日 **2007-01-01 ~ 2026-09-30** |
| 构造 | 比例 `k = max(1, min(round(0.20×n_pool), n_pool//2))` |
| 主口径 | 含阶段 C §5 的交易约束（建仓日涨停剔多头等） |

**不变的是信号与选股**：三格用**同一批**持仓，只改收益起算点。
这样 Δ 里不含选股差异。

## 2. 三个格

| 格 | 成交价 | 可成交性 | 说明 |
|---|---|---|---|
| **V0** | `ffill(pos)` | 阶段 C §5 字面 | **必须逐位复现**阶段 C 的 D 格 |
| **V1** | `ffill(pos+1)` | 不筛（只要求 pos+1 有价） | 纯延迟一天 |
| **V2** | `ffill(e)`，e = 首个可成交日 | `tradable=True`，最多顺延 5 个 ADJ 交易日 | 真实可执行 |

`e` 的定义（写死）：

```
从 pos+1 开始，沿 ADJ 交易日历向后找，
取第一个满足 flags(code, day).tradable == True 的 day；
若 5 个交易日内找不到 → 该标的当月剔除，计入超时。
```

顺延的**平仓日仍为 nxt**，不顺延——买入是入场的唯一延迟来源。
（平仓延迟是另一个问题，且做空腿不可得，测它没有现实意义。）

### 2.1 V0 的复现要求

V0 必须与阶段 C 的 D 格**逐位一致**：`mean_d = 0.65818965`、`spread = 1.31637930`、`t = 4.11104858`。
不一致就拒绝继续，**不许解释成"数据变了"**。

## 3. 主检验与交叉验证

### 3.1 主检验（唯一）

```
Δ_t = spread_t(V1) − spread_t(V0) = 2 × [d_t(V1) − d_t(V0)]
```

**测的是"晚一天"的代价**，不含可成交性筛选。NW 滞后 3，双侧。

### 3.2 交叉验证（必报，不参与判定）

```
Δ'_t = spread_t(V2) − spread_t(V1)
```

**测的是"顺延到可成交"的额外代价。**

- `Δ` 与 `Δ'` **同号** → 标注"两段一致"
- **异号** → 主结论降级为 `EVIDENCE_CONFLICT`，两级并列报告

> 异号并非不可能：V1 无条件在 pos+1 成交，可能买到当天涨停的票；
> V2 顺延后避开涨停，但价格可能更高。两种偏差方向相反，正是要分开测的理由。

## 4. 判据（四档，机械判定）

| 档位 | 条件（全部满足） |
|---|---|
| **LAG_COST_MATERIAL** | `n ≥ 150` **且** `\|NW t\| ≥ 1.96` **且** `\|mean(Δ)\| ≥ 0.30 pp/月` |
| **LAG_COST_SMALL_BUT_SIGNIFICANT** | `n ≥ 150` **且** `\|NW t\| ≥ 1.96` **且** `\|mean(Δ)\| < 0.30 pp/月` |
| **LAG_COST_NEGLIGIBLE** | `n ≥ 150` **且** `\|NW t\| < 1.96` |
| **INCONCLUSIVE** | `n < 150` 或 NW 有效样本 < 100 |

0.30pp/月的依据：等于阶段 C 主检验经济门槛的一半，也等于 D 格 spread（1.32）的 23%。
延迟若吃掉超过 23% 的效应，就属于"口径决定结论"的级别，必须写进任何对外材料。

## 5. 诊断（描述性，不参与判定）

| # | 诊断 | 为什么重要 |
|---|---|---|
| **D1** | **持有期收益的时间分解**：把持有期切成 `pos→pos+1`（第 1 天）、`pos+1→pos+5`、`pos+5→nxt`，分别算多头/空头/spread | 直接检验"反转在第一天最强"这个前提。如果第 1 天贡献极小，那整个实验的动机就不成立 |
| D2 | V1 相对 V0 的逐月 Δ 与第 1 天收益的相关 | 若高度相关，说明 Δ 完全由第 1 天驱动 |
| D3 | V2 的超时剔除数与顺延天数分布 | 顺延多少天、多少标的超时 |
| D4 | V2 的腿规模与 V0 对比 | 确认剔除没把腿削到失真 |
| D5 | 分年度 Δ | 2008 / 2015 等极端年份是否异常 |

**D1 是本实验的地基**：如果反转效应在持有期内的分布是均匀的，那么晚一天只损失 1/21 的效应，
Δ 应该很小；如果集中在开头几天，Δ 就会很大。两种结果都有信息量。

## 6. 预期方向（写死，防止事后合理化）

**`mean(Δ)` 预期为负**，依据：

1. 短期反转在 1 日尺度上最强（这是"21 日反转"这个构造的文献共识）；
2. `pos→pos+1` 这一段在多头上是输家反弹的第一天，在空头上是赢家回落的第一天，
   两者都是 spread 的主要来源；
3. V1 把这一段完整放弃。

**幅度不确定**：若第 1 天贡献 15%，Δ 约 −0.20pp；若贡献 30%，Δ 约 −0.40pp。

**`mean(Δ')` 预期为负但更小**：顺延主要发生在涨停日，而涨停日买不到意味着
"当天已经涨过了"，顺延后买入价更高，多头腿吃亏；空头腿则相反。净效应方向不明，
**这一项不设方向预期，只报数值**。

## 7. 允许结果

- 若 Δ 接近 0：说明反转不是"第一天现象"，本项目的 21 日构造对 1 日延迟不敏感。
  **这是好结果**，因为它意味着既有结论对成交延迟稳健。
- 若 Δ 显著为负：**必须写进所有对外材料**，因为它说明 Gate 2/3/6 与阶段 C 的效应有相当部分是
  "不可执行的第一天"。
- **不得**因为 Δ 太大就改成"pos+0.5 日"之类的中间口径——那是看到结果再调参。
- **不得**把 V2 的结果说成"可控成本"，除非它真的小。
