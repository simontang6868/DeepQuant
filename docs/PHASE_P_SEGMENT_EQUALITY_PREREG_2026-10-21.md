## 0. 为什么开这一阶段

项目纪律第 8 条：**不得将"未拒绝原假设"解释为"证明原假设成立"。**

而"exQ5 不衰减"是本项目**唯一贯穿 H→I→J→K→O 反复被引用**的性质，同时
阶段 N 审计（§10.3b）已指出：三段的两段之差 Welch t 分别为
−0.16 / +1.09 / −1.77，**全不显著**。

也就是说：

- 我们**从未正式检验过**"两段是否相等"；
- 已有的只是**探索性**的 Welch 检验，且是在 0.3% 费率口径下做的；
- 但报告里多处写着"不衰减"，读起来像结论。

本阶段把这件事做成正式检验。

**本阶段不新增策略、不调参数、不换窗口、不换构造。**
只对一个已经被反复讨论的性质做统计检验。

## 1. 主检验（唯一）

### 1.1 数据

`phaseo_out/ac7aa2830ab0/monthly.csv` 的 `net_BASE_3000w` 列，共 237 个月。
口径 = 阶段 O 的 BASE（佣金 0.025% 双边 + 印花税 0.05% 仅卖出 + 过户费 0.001% 双边）、
W = 3,000 万、含现金残留与冲击上界。

**读取前必须校验该文件 sha256 与 `phaseo_out/ac7aa2830ab0/manifest.json` 一致**
（期望 `768e49a9462cd7c00f3aacfcdb1e87bbe37bb75b348cd6fd85809e12493a4152`）。
不一致则拒绝运行。

### 1.2 模型

哑变量回归（等价于两样本均值差，但便于做 HAC）：

```
net_t = β0 + β1 · D_t + ε_t
D_t = 1  当 signal_date ≥ 2016-01-01
D_t = 0  否则
```

- β0 = α_early（2007-2015）
- **β1 = α_late − α_early（这是主检验量）**

估计用 OLS；标准误用 **Newey–West（Bartlett 核，滞后 L=3）**，
经 Frisch–Waugh–Lovell 残差构造：

```
ỹ_t = y_t − ȳ ,  D̃_t = D_t − D̄
β1 = Σ D̃ỹ / Σ D̃²
û_t = ỹ_t − β1 D̃_t                （等于全回归的 OLS 残差）
z_t = D̃_t · û_t
Ω̂  = Σ z_t² + 2 Σ_{j=1..L} (1 − j/(L+1)) Σ_{t>j} z_t z_{t−j}
Var(β1) = c · Ω̂ / (Σ D̃²)² ,  c = n/(n−2)   （有限样本修正）
```

用 `run_phase_c._p2` 的双侧 p（正态近似），临界 **1.96**。

> **为什么不用现成的 `newey_west()`**：它只能给序列均值的 se，
> 给不出"两组之差"的 se。这里必须自己构造 HAC 三明治。
> 该构造的 L=0 特例**精确等于** HC0 两样本 se（`A/n2² + B/n1²`），已用单测钉死。

### 1.3 必报：MDE（这是判读"未拒绝"的唯一依据）

```
MDE = 2.8016 × se(β1)      # 双侧 5%、功效 80%
```

**必须报。** 理由：若 MDE 是 0.3pp 而实测差只有 0.014pp，
则"未拒绝"根本不意味着"没有衰减"，只意味着"衰减没大到 0.3pp"。

### 1.4 判据（三档，写死）

记 `d = β1`，`sgn = sign(α_early)`。

| 档位 | 条件 | 含义 |
|---|---|---|
| `SEGMENT_DIFFERENCE_DETECTED_OPPOSITE` | \|t\| ≥ 1.96 **且** d 与 α_early **反号** | 检出衰减（或翻转） |
| `SEGMENT_DIFFERENCE_DETECTED_SAME_SIGN` | \|t\| ≥ 1.96 **且** d 与 α_early **同号** | 检出变化，但不是衰减（是放大） |
| `SEGMENT_DIFFERENCE_NOT_DETECTED` | \|t\| < 1.96 | **不拒绝相等** |

⚠️ 三档**都不得**表述为"证明了不衰减"或"证明了衰减"。
第三档的标准表述只能是：

> "在 MDE = X pp 的检验能力下，未能拒绝两段相等；
>  实测差 d = Y pp，**无法**区分'真的相等'与'存在小于 X pp 的变化'。"

## 2. 正对照（预登记内的效力验证，关键设计）

**问题**：如果检验本身效力不足，那么"未检出"毫无信息量。
必须用一个**已知大幅变化**的序列来校准。

**正对照序列**：`phasel_out/9ffc3710cf6f/monthly.csv` 的 `alpha_v1_pp`
（SURGE 可成交口径 alpha，237 月）。
阶段 L 报告：2007-2015 **+0.1764pp** → 2016-2026 **+0.0472pp**，
**实测差 −0.1292pp（衰减 73%）**，是本项目报告过的最大衰减。

**判读规则（写死）**：

- 若正对照**检出**显著差异（|t| ≥ 1.96）→ 检验有足够效力，
  则主检验的"未检出"**有信息量**（可说"未发现衰减"）。
- 若正对照**未检出** → 检验效力不足，
  则主检验的"未检出"**无信息量**，必须在结论中明确声明：
  **本项目无法用现有样本量分辨任何信号是否衰减。**

**无论哪种结果都照实报告，不得挑选。**

## 5. 预期方向（必须写，跑完不得改口）

用**可算的量**判断（项目经验：靠机制直觉猜的三次全错，靠可算量猜的两次全对）。

粗算：exQ5 月度净值序列的 sd 约 0.6~1.0pp →
`se(β1) ≈ sqrt(s²/108 + s²/129) ≈ 0.08~0.13pp` →
**MDE ≈ 0.22~0.36pp**。

实测差（阶段 O 已给出）= 0.129408 − 0.143784 = **−0.0144pp**，
**远低于 MDE**。

→ **预期判定：`SEGMENT_DIFFERENCE_NOT_DETECTED`，且 MDE 远大于实测差。**

正对照：SURGE 实测差 −0.1292pp，若 se(β1) 同样在 0.08~0.13 量级，
则 |t| ≈ 1.0~1.6，**大概率也达不到 1.96**。

→ **预期正对照也"未检出" → 预期结论是「检验效力不足」。**

如果实测与此相反（比如 se 小得多），照实报告。

**预期结论（写死）**：本项目**很可能**无法用 237 个月分辨任何信号是否衰减；
"exQ5 不衰减"应被降级为"未发现衰减，但检验能力不足以排除最大至 MDE 的变化"。
