## 0. 为什么是这个信号

1. **文献**：A 股换手率效应在月度与日度两个频率都有独立证据；
   异常换手率 ATR 十等分最高−最低 **−1.87pp/月**（中央财经大学），控制常见因子后仍显著。
2. **机制同源**：薛冰、张兵、王婉菁（《金融评论》2021）给出的机制是
   **T+1 + 卖空约束** → 高换手当日价格被乐观者推高、次日隔夜反转；
   **A+H 交叉上市检验：港股（T+0、卖空约束弱）不存在此效应。**
   这与本项目 §9.1「横截面异象天然是空头侧现象」是同一个机制。
3. **形态正确**：是 **避免型**（排除最高），不是买入型（§9.2）。
   ⚠️ 上海财大《换手率：流动性还是不确定性》发现换手率**水平**是**倒 U 形**
   （低段正向、高段负向，分界点在 36% 分位）→ **因此本阶段只做"排除最高"，
   不做"买最低"**，后者会落在方向相反的那一段上。
4. **不是旧因子的影子**（可行性检查实测）：

| SURGE vs | Spearman 秩相关 |
|---|---:|
| 波动率（21 日） | **+0.3513** |
| MAX5 | +0.4607 |
| 21 日反转（过去收益） | +0.4809 |

对比：MAX5 vs 波动率是 **+0.8796**。SURGE 与三者都只有中等相关 → **是独立的变量**。

## 1. 构造（写死）

| 项 | 值 |
|---|---|
| 日成交额 | `DV = volume × 100 × close`（⚠️ volume 单位是**手**，见阶段 J） |
| **SURGE** | `mean(DV 近 21 个交易日) / mean(DV 前 21 个交易日)` |
| 有效日门槛 | 近窗口与前窗口**都**要 ≥ `MIN_VALID = 19` 个有效交易日 |
| 分组 | 池按 SURGE 等频 5 组，**排除最高的 20%（Q5）** |
| 组合 | 其余全部等权 |
| 基准 | 池内全部等权 |
| 池 | as-of 全 A + `MIN_LISTED_DAYS = 252` |
| 样本 | 月末信号 `2007-01-01 ~ 2026-09-30` |
| 收益期 | `ffill(t_next) / ffill(t_pos) − 1`（与阶段 C~K 一致） |
| 可成交约束 | 与阶段 I 的 V1 相同：建仓日涨停 / 一字板向上 / 停牌 / 序列已终止 → 剔除 |
| 统计 | Newey-West 滞后 3，**双侧** 1.96 |

### 1.1 为什么要求"前窗口也有 19 个有效日"（这是可行性检查逼出来的）

可行性检查发现 SURGE 的**右尾极长**：逐月最大值中位数 34.2，个别月份达到 **2990 倍**。

原因是：停牌期间成交量为 0 → 复牌后比值爆炸。这些**不是"投机性放量"，是数据口径产物**。

→ 要求**两个窗口都 ≥19 个有效交易日**（沿用项目本身的 `MIN_VALID` 约定，不引入新参数），
把停牌复牌的标的排除在 SURGE 可算之外。

⚠️ **不做缩尾（winsorize）**：本构造只用 SURGE 的**秩**来做等频分组，
而秩对任何单调变换（log、缩尾）都不变 → 缩尾对结果没有影响，只是多一个自由参数。
尾部只作为诊断报告。

## 2. 判据（四条**并列必要条件**，跑前写死）

| 条件 | 内容 | 立论 |
|---|---|---|
| **A 统计** | `\|t_NW\| ≥ 1.96` | 双侧 5% |
| **B 稳定** | 两段各自符号与全样本一致 **且** `\|t\| ≥ 1.96` | §9.2：稳定性是避免型唯一卖点 |
| **C 成本** | `net @0.3%` 的 `\|t_net\| ≥ 1.96` | 与阶段 I/J 同口径 |
| **D 量级** | `net @0.3% ≥ 0.30pp/月` | ⭐ **本轮新增的准入门槛**（筛选文档 §0） |

**D 是本轮与以往最大的不同。** 它的立论：
阶段 I/K 已经证明，0.16pp 量级的单边 alpha 在 0.3% 成本后只剩 0.05pp，
**统计上再显著也没有可执行价值**。所以本轮把"量级够不够"写成**判据**，而不是事后讨论。

### 2.1 五态（按顺序判定）

| 判定 | 条件 |
|---|---|
| `SURGE_AVOID_CONFIRMED` | A ∧ B ∧ C ∧ **D** |
| `SURGE_AVOID_SIGNIFICANT_BUT_SMALL` | A ∧ B ∧ C ∧ ¬D |
| `SURGE_AVOID_UNSTABLE` | A ∧ C ∧ ¬B |
| `SURGE_AVOID_ABSORBED` | A ∧ ¬C |
| `SURGE_AVOID_NOT_DETECTED` | ¬A |

**没有第六态。** 若 D 不过，即使 A/B/C 全过也**不算"找到了可用信号"**。

## 3. 预期方向与机制（写完再跑）

### 3.1 方向：alpha > 0

排除异常放量最高的 20% → 组合跑赢池等权。机制：T+1 + 卖空约束下的高估无法被套利，次日反转。

### 3.2 量级：预期 **D 不过**，判定落在 `SURGE_AVOID_SIGNIFICANT_BUT_SMALL`

按可行性 + 阶段 I/K 的折损经验推算（**这是算出来的，不是直觉**）：

```
文献 ATR 十等分价差            1.87 pp/月
本构造用五分位 → gap 估计        ≈1.3 ~ 1.4 pp/月
alpha ≡ 0.25 × gap（恒等式）    ≈0.33 ~ 0.35 pp/月   [理想口径]
可成交折损（阶段 I 实测 −29%）   → ≈0.24 pp/月
佣金 @0.3%（换手未知，按 18%）   −0.11 pp/月
────────────────────────────────────────────
净值估计                        ≈0.13 pp/月   ← **低于 D 的 0.30pp**
```

→ **预期 A 过、B 可能过、C 可能过、D 不过 → `SURGE_AVOID_SIGNIFICANT_BUT_SMALL`。**

### 3.3 这个预期的含义（写下来）

如果 §3.2 成立，那本轮的意义不是"找到一个信号"，而是**把"纯价量空间里
不存在成本后 0.3pp 的单边 alpha"这条结论再往前推一步**——
在目前量级最大的 A 股纯价量异象（ATR，1.87pp 十等分价差）上也够不着。

## 4. 诊断（必报）

1. **共线性复核**：SURGE 与波动率 / MAX5 / 21 日反转的秩相关（应与可行性检查一致 ≈0.35/0.46/0.48）；
2. **波动率分层后的版本**：先按波动率分 5 层、层内再排除 SURGE 最高 20%。
   若 `|分层后 alpha| < 0.5 × |全池 alpha|` → 必须打上 `ABSORBED_BY_VOL` 标记
   并写进结论正文（即使判定是 CONFIRMED）；
3. **被排除组的构成**：其 SURGE 分布、其中"近 5 日有涨停"的比例；
4. 换手、分年度、分段；
5. **Q5 的绝对收益**：确认是"高放量跑输池"而不是"高放量下跌"（阶段 I 的措辞教训）。
