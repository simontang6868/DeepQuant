# 基准口径定档（阶段 2 · P0-3）

> 生效日期：2026-10-20 ｜ 决策出处：路线图 §12 D-2（用户已拍板）
> 性质：**研究设计决策，不是 bug 修复**。本文件一经生效，所有引用 Gate 1 及此后结论的文本必须遵守。
> 对应基线标签：`v0.9.0-gate1-closed`

---

## 1. 一句话定档

> **主基准 = 同池等权**。沪深300 **仅作辅助参考**，且任何引用它的超额数字必须标注
> 「价格指数、未计股息、年化约低估 2pp」。换基准 = 新实验，不得把旧结论在新基准上重算。

---

## 2. 为什么是这条决策（C1 的根因）

外部专家建议「建统一指数基准」，但**没有区分价格指数与全收益指数**。沪深300 在公开免费渠道只能取到**价格指数**（不含股息再投资）。股息是 A 股回报的重要组成（年化约 2pp），拿价格指数当基准会把基准**系统性压低约 2pp/年**：

> 策略什么都不改，只把基准从「同池等权」换成「沪深300 价格指数」，
> 超额收益**凭空多出约 2pp/年**。

这是「制造假 alpha」的经典路径。在数据约束未解除（拿不到沪深300 全收益指数、或拿不到股息再投资数据）之前，**不得启用沪深300 作为主基准**。

## 3. 三类口径的字段命名（落地 A1 两层数据架构的基准侧）

| 口径 | 含义 | 用途 | 本项目当前状态 |
|---|---|---|---|
| **同池等权（PRIMARY）** | 池内所有在市标的每日等权再平衡 | 主超额基准 | ✅ 已启用，Gate 1 以此为准 |
| **沪深300 价格指数（AUX-PRICE）** | 不复权、不含股息的指数序列 | 辅助参考 | ⚠️ 仅辅助，必须标注股息口径 |
| **沪深300 全收益指数（AUX-TOTAL）** | 含股息再投资的总回报序列（`H00300.CSI`） | 理想辅助 / 可作新预登记基准 | ✅ **已可用（2026-10-20 实测中证 API 免费可取）** |

> **2026-10-20 更新（重要）**：此前判断"无可靠免费全收益源"已被推翻。中证指数官方 API
> `https://www.csindex.com.cn/csindex-home/perf/index-perf?indexCode=H00300` **免费返回沪深300全收益指数**
> （`H00300.CSI`，实测 2016-01-01~2026-10-16 共 2620 条）。因此 `AUX-TOTAL` 从"不可得"升级为"可用"。
> **但"可用"≠"现在换"**：换基准仍是新实验（见 §7），Gate 1 旧结论继续用同池等权，不回改。

### 股息口径差的实测值（替换"约 2pp"的估计）

用中证 API 拉同区间 000300（价格）与 H00300（全收益），2016-01-01 ~ 2026-10-16（10.79 年）：

| 口径 | 起 | 末 | 年化 |
|---|---:|---:|---:|
| 000300 价格指数 | 3469.07 | 4170.61 | **1.72%** |
| H00300 全收益指数 | 4056.17 | 6270.45 | **4.12%** |
| **股息口径差** | | | **+2.40 pp/年** |

逐年差（全收益 − 价格）：2016 +2.18 / 2017 +2.45 / 2018 +1.65 / 2019 +3.16 / 2020 +2.65 /
2021 +1.66 / 2022 +1.80 / 2023 +2.23 / 2024 +3.60 / 2025 +3.42 / 2026 +1.74 pp。
**区间 1.65~3.60pp/年，均值约 2.4pp** —— 这就是"拿价格指数当基准会凭空多出的年化超额"的实测幅度。

命名约定：任何字段、图表、报告若引用沪深300，**字段名或脚注必须写明 `AUX-PRICE` 或 `AUX-TOTAL`**，不得只写「沪深300」或「基准」。

## 4. 四条硬性要求（写进执行口径，不可绕过）

1. **主基准 = 同池等权**。它是**唯一不存在股息口径问题**的基准；Gate 1 结论（`failure`，月超额 −0.3961pp，95% CI [−1.7973, +1.0051]pp）继续以它为准，不受本文件影响。

2. **沪深300 只作辅助参考**。任何引用它的超额数字必须附带标注：
   > 「基准为沪深300 **价格指数**，未计股息，年化约低估 2pp；该超额数字含约 +2pp/年的口径虚高，不可直接与同池等权口径的超额比较。」

3. **换基准 = 新实验**（见路线图 C1）。不得把 Gate 1 在同池等权下的旧结果，改到沪深300 口径下重算后当作「延续」。若要换，走**新预登记**（路线图阶段 3），旧结论保留不动。

4. **若日后要建全收益基准**，先解决股息再投资数据或找到全收益指数源，否则**不启用** `AUX-TOTAL`。在解决前，所有涉及沪深300 的结论默认按 `AUX-PRICE` 处理并标注。

## 5. 引用 Gate 1 结论时的强制格式

引用 Gate 1（v1.3 协议）结论时，必须同时给出以下六要素，缺一不可：

| 要素 | 本基线值 |
|---|---|
| 预登记 sha256 | `8b0115517a7ae35df20250c0fdf04736cfa99d9bfd570b89f0d93bc29ec88d63` |
| run 目录 | `gate1_out/032a11f591553e25/`（主实验） |
| 判定档位 | `failure` |
| 95% CI | [−1.7973, +1.0051] pp/月（跨 0） |
| 样本外窗口 | 2021-01-01 ~ 2024-12-31，n = 48 月 |
| **基准口径** | **同池等权（PRIMARY）** |

**标准引用句式**：
> 「在预登记 `8b011551`（run `032a11f591553e25`）下，A 股横截面动量相对**同池等权**基准的样本外检验判定为 `failure`，月超额 −0.3961pp，95% CI [−1.7973, +1.0051]pp 跨 0（n=48 月，2021-01~2024-12）。」

**禁止**的引用方式（缺口径）：
> ~~「Gate 1 失败，月超额 −0.3961pp。」~~ ← 没说基准是同池等权，读者无法判断是否含股息口径虚高。

## 7. 何时可以重新评估这条决策

满足以下**任一**条件，可提请重新评估基准口径（仍走新预登记，不回改旧结论）：

1. ~~取得可靠的沪深300 **全收益指数**数据源（含股息再投资）~~ → **✅ 已于 2026-10-20 满足**：中证 API 免费取 `H00300.CSI`（实测 2620 条，2016-2026）。**若要用它当基准，须在阶段 3 新预登记里写明，不得把 Gate 1 旧结果在它上面重算。**
2. 取得成分股级股息数据，可自行构造全收益基准（`Tushare dividend` / `Baostock` / CSMAR 均有候选，见 P1-3）；
3. 池口径变更（扩池 / 换池）使「同池等权」语义改变——这本身就是新实验。

**当前有效口径不变**：Gate 1 及此前结论仍以**同池等权**为准。`H00300` 的可用性只改变"未来能否用全收益基准"，
不改变"旧结论怎么算"。在阶段 3 新预登记落地前，本文件 §4 的四条硬性要求仍全部有效。
