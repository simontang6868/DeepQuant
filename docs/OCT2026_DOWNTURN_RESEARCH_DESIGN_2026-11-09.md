## 1. 问题复述与方法论

**一句话**：用户想用现行策略回测 2026 年 10 月，判断它在下跌行情中的表现。
**研究类型判定**：**描述性事件研究 / 单窗口绩效归因**，不是预测、分类或时序建模 ⇒ **按专家工作流不调用建模/评估技能，不训练模型**。用户要的是「那一个月发生了什么」，不是「拟合一个能预测下跌的模型」。

| 方法要素 | 设定 |
| --- | --- |
| 研究对象 | SP-5 现行策略（`sp4_config_v2`：20% 仓、5 只、月末信号、次月首日执行、3% 现金收益） |
| 待估计量 | ① 市场跌幅（背景事实）② 策略组合月度收益 ③ 持股端收益 ④ 相对基准超额 ⑤ 日频 MDD ⑥ 月换手与成本 |
| 数据 | 本地 `qfq_all`（前复权研究层）；`exec_all` 仅作交叉验证，不作收益口径 |
| 基准 | 配置写的是「**等权持有全部可买股票（档内等权）**」；本阶段用「全池等权」只是**描述性替身**，两者不同，正式回测须冻结真实基准 |
| 验证方式 | 双数据口径独立复算 + 个股抽查；单月**无法**做统计显著性检验 |
| 主指标 | 组合净值月收益、相对基准超额、MDD；**必报 MDE / 功效** |
| 交付物 | 本任务书；若继续，另出预登记 + 逐日净值 + 成本明细 + 结论卡 |
| 替代路线 | ① 用既有 44 月回测的**下跌月份子样本**做条件分析（样本更多，但仍是事后选择，须预登记）；② 用 **2024-01 微盘急跌**既有归因直接回答（已有结论，见第 4 节）；③ 等 11-30 起的前瞻记录自然累积（最干净但慢） |

## 3. 四个实质阻断点（不解决就不能出「回测结论」）

1. **配置错配（最要命）**：两份台账的 `config_path` 都是 **`sp4_config_v1.json`**（25% 仓，`config_sha256=d4dacb71…`），而现行策略是 **11-03 才冻结的 v2**（20% 仓）。用 v2 去"回测" 9-30 决策，是**用后验配置重演历史**，不是样本外验证；用 v1 台账又答非所问。
2. **台账是事后补跑**：`20260930.json` 为 `mode=SELFTEST`、`counts_toward_observation=false`、`record_time=2026-11-02`；`20261030.json` 为 `LATE_RUN`、迟 3 个日历日。两者 `code_in_git=false`，且都加了 `LEGACY_NO_D4` ⇒ 项目已明确**11-30 前老台账不作证据**。
3. **数据穿越风险**：本地数据末日 10-30，但**云端 exec_all 已更新到 11-09**。`--asof 20260930` 若未严格按 as-of 截断输入，会用未来数据。重跑前必须验证截断，否则是穿越，不是回测。
4. **单月没有统计分辨力**：17 个交易日、1 条路径。项目 `GATE1_CLOSURE_STATEMENT`（样本外 <100 月且效应 <0.5pp/月 ⇒ 证据不足）与既有 MDE 量级（L3r 0.926pp、L3t 全项目 0.087~0.955pp）都说明：**一个月的涨跌无法判断「策略在下跌行情中是否抗跌」**。「功效不足 ≠ 无效应」，不得反写成「没用」。

⚠️ 另有**基准口径**：配置 primary benchmark 是「等权持有全部可买股票（档内等权）」，本阶段的全池等权只是描述性替身；成本必须走 `cost_of()`，本阶段**未计成本**。

## 4. 既有可引结论（这个课题其实已被回答过一部分）

引自 `RESULTS_INDEX.md`（引用需带口径 / `StatisticalVerdict` / `MaturityLevel`）：

- **SP-5（2023-01 起 44 月）** `RETURN_BELOW_8PCT` + `EXPLORATORY_ONLY`：25% 仓 +7.15%(t=2.24, MDD −8.60%)、**20% 仓 +6.29%(t=2.51, MDD −6.61%)**；44/44 月可执行。⭐ **MDD 几乎全由 2024-01 微盘急跌贡献 ⇒ 「抗跌」来自仓位（80% 现金），不是选股。**
- **8.4 措辞精确**：稳的是**相对差距**，不是绝对收益；不是「高 MAX5 会跌」，而是「Q5 系统性跑输池平均」。
- **8.5**：选择效应测不出来是**尺子分辨率**问题（压到 0.5pp/月需 676 期 ≈ 56 年），不得写「没用」。
- **已关闭的路**：风控择时、期指对冲、降换手、纯价量新信号等 ⇒ 本项目**没有**针对下跌行情的择时/防御模块，策略的"抗跌"只能是低仓位的机械结果。

**因此，对「下跌行情表现」最诚实的回答是**：现行策略在急跌月的回撤小，机制是 **20% 仓位 + 80% 现金**，不是选股能力；持股端本身不提供防御性。这与第 2.2 节那 5 只跌 −13.37% 的观察方向一致。
