## 0. 本阶段要回答的问题

阶段 H 的可行性检查给出 `alpha = +0.2307pp/月, NW t=+6.36`，且**是九个实验里唯一跨越 2016 不衰减的**。
但它有三个未解决的性质：

1. **实现不独立**：它直接 import 阶段 F 的 `split_equal`，两者同源。若分组函数本身有偏，
   两处会一起错。
2. **"不衰减"是事后发现的**：它是读结果时才注意到的性质，**没有被写进判据**。
   事后发现的性质不能当作证据，只能当作假设。
3. **不涉及交易约束**：它把建仓日涨停、停牌的标的都当作能买到。

本阶段做的事：**用独立实现、按跑前写死的判据、带交易约束，重做一次**。

## 1. 构造定义（写死，不许改）

| 项 | 值 |
|---|---|
| 窗口 | `WIN = 21` 个交易日 |
| MAX5 | 窗口内**最大的 5 个日收益的算术平均**（`TOP_N = 5`） |
| 有效日门槛 | 窗口内 ≥ `MIN_VALID = 19` 个有效日收益 |
| 分组 | 池按 MAX5 等频分 5 组（`N_GROUP = 5`），**Q1 最低、Q5 最高** |
| 排除比例 | `EXCLUDE_FRAC = 0.20`（= Q5，写死） |
| 组合 | **持有除 Q5 以外的全部标的，等权** |
| 基准 | **池内全部标的等权**（与阶段 E/G 同口径） |
| alpha | `R_exQ5 − R_bench` |
| 池 | as-of 全 A（`MIN_LISTED_DAYS = 252`），与 Gate 6 / 阶段 C 的 D 格同口径 |
| 样本 | 月末信号，`2007-01-01 ~ 2026-09-30` |
| 收益期 | `ffill(t_next) / ffill(t_pos) − 1`（与阶段 C~H 一致，便于对照） |
| 统计 | Newey-West，滞后 3 期；**双侧**，临界 1.96 |

**不允许改的**：排除比例、分组数、窗口、TOP_N、池门槛、样本起止、收益期定义。
任何一项要改 = 新实验 = 新预登记。

| 条件 | 内容 | 立论 |
|---|---|---|
| **A 统计** | `|t| ≥ 1.96` | 双侧 5% |

## 4. 预期方向与机制（**写完再跑，不许事后改**）

### 4.1 V0
必须**精确**等于 +0.230703pp / t=+6.357163 / n=237。这是复现，不是预测。

### 4.2 V1（主检验）：预期 **略高于 V0**，幅度 `+0.02 ~ +0.10pp`

**机制**：建仓日涨停 / 一字板的标的买不到，会被剔除。这些是当期最强的标的。
但依据阶段 C-2 的实测（被剔多头 fwd **+1.2249** vs 保留 **+1.7451**），
**被剔的标的后续反而更差** —— 因为"涨到涨停"之后动量耗尽。
所以剔掉它们会**略微提高**组合收益。

若 V1 反而低于 V0，说明上述机制不成立，必须在报告里单独解释，不许一句"接近"带过。

### 4.3 分段：预期两段都正、都显著

`2007-2015 ≈ +0.23`、`2016-2026 ≈ +0.22`，两段 `|t| > 3`。

### 4.4 预期的失败模式（写下来，好让将来无法狡辩）

最可能的失败是 **B 条件**：V1 的 2016-2026 段 t 值掉到 1.96 以下。
依据：阶段 C-2/C-3 都显示剔不可成交会让结果略动，而 2016-2026 段的 t 是 4.12，
留有余量，但若 V1 的段内波动上升，仍可能跌破。

次可能的失败是 **C 条件**：0.3% 成本后 t 掉到 1.96 以下。阶段 H 是 2.50，
若 V1 换手上升（剔票会改变成员集，可能增加换手），净 alpha 会被吃掉一部分。

### 4.5 预期不会失败的条件

- 容量：**预期 M1 不成立**。W_equal 中位 5,783 万，1,000 万买不到。
  所以本阶段最可能的结果是 `EXQ5_CONFIRMED` + **M0（容量阻塞）**。

## 5. 容量分析（描述性，不参与判定）

固定档位（沿用 4.1 的 150/300/1000 万，新增 500/3000 万作为前沿），报：

| 量 | 定义 |
|---|---|
| `n_hold` | 持仓只数 |
| `W_1lot` | 每只 1 手所需资金 |
| `W_equal` | 等权且每只 ≥1 手所需资金（`k × max(lot)` 的上界） |
| `未投资比例` | `1 − 实际投入 / W` |
| `weight_mae` | `mean(|w_i − 1/k|)`（pp） |
| `covered` | 实际能买的只数 / k |

**可负担子集规则（写死）**：按一手金额从高到低剔除，直到 `k × max(lot) ≤ W`。
不许按信号值剔（那会偷偷引入选择）。

## 6. 诊断（必报，不参与判定）

1. **逐月 alpha 与 R_Q5 的关系**：确认 alpha 来自"Q5 跌"而非别的。
2. **Q5 的构成变化**：每期 Q5 有多少只是上期也在 Q5（持续性）。
3. **换手**：成员变动比例（同阶段 H 口径）+ 剔除后的换手变化。
4. **分年度**：alpha 的逐年值，看有没有单年主导。
5. **两段的 Q5 平均收益**：若 2016 后 Q5 仍显著为负，则"不衰减"来自 Q5 而非基准。

## 7. ⚠️ 诚实限定（必须随结论引用）

**本阶段不能提供样本外证据。**

exQ5 是在**同一批数据**上、由阶段 F 的构造代数推出的。本阶段做的是：
- 用**独立的实现**复现（排除"同一个 bug 出现在两处"）；
- 用**跑前冻结的判据**（排除"看到结果才定标准"）；
- 加上**交易约束**（排除"买不到的标的被算成买到了"）。

**这些都不能替代样本外验证。** `EXQ5_CONFIRMED` 的准确含义是：

> 在 2007-2026 的既有样本上，由一个独立实现、按事前判据、在可成交口径下，
> 复现了一个统计显著、跨两段稳定、成本后仍显著的**单边** alpha。

真正的样本外验证需要：2026-10 之后的前瞻数据，或另一个市场。
**在那之前，本构造的成熟度不得高于 M1，且不得进入实盘。**
