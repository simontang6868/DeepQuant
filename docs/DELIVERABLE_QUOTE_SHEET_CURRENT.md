## 5. 不允许的推论

1. 统计显著 ≠ 经济有意义。S2 只过了 2 条，就是因为门槛是事前的。
2. 信号真实 ≠ 净收益为正。5 条正面结论的判定量是价差或差值，不是任何组合的收益。
3. 样本内 ≠ 前瞻有效。S4 全部为 0。
4. 通过多重检验 ≠ 可实盘。现金流、整手、限额、冲击都没有完整模拟。
5. `phasei_v1` 在真实费率下显著（t=+2.98 iid / +4.00 NW3），但**这不推翻**其冻结判定 `EXQ5_COST_ABSORBED`——判定档是 0.3%，不是 0.051%。
6. m=25 不是「唯一正确的 m」。它依赖「同一随机变量只占一个名额」这条判据；换成 m=27/29，7 条正面结论不变，但**不能**因此说「m 的问题解决了」。
