## 0. 这个实验要回答什么

阶段 F 证明：控制波动率后，MAX5 的多空价差还有 **+0.7405pp/月**（t=3.41）。
**但那个价差需要做空 Q5，而 A 股个股做空不可得（M4）。**

本实验只买，问：

> **只买低 MAX5 的股票，相对池内等权，还剩多少 alpha？**

### 0.1 事前必须承认的概率

阶段 E（21 日反转）的经验：alpha 只有多空价差的 **21%**（0.2767 / 1.3164）。

若 MAX5 也接近这个比例，`0.7405 × 0.21 ≈ 0.16pp`，扣掉 0.17pp 的成本（@0.1%）
**什么都不剩**，这条路同样走不通。

**所以本实验的主要产出很可能是否证。** 这个预期写在跑之前，不是事后找补。

## 1. 两个组合（主 + 对照）

### 1.1 V1（主检验）：分层后的 Q1 并集

```
每月：
  1. 池按 VOL 等频分 5 层
  2. 每层内按 MAX5 等频分 5 组，取 Q1（最低 20%）
  3. 组合 = 5 个层内 Q1 的并集，等权
```

与阶段 F 的主检验（分层内价差）严格同口径——它问的是"阶段 F 那个 +0.74 里，
多头侧能拿到多少"。

### 1.2 V0（对照）：原始 Q1

全池按 MAX5 等频分 5 组，取 Q1，等权。
这是**最自然、最可执行**的定义（"买 MAX5 最低的 20%"），但阶段 F 已证明它混了 31% 的波动率。

**两个都报，主检验用 V1。** 差异本身就是信息（分层对单边有没有帮助）。

### 1.3 诊断 V_L5：只在最高波动层内取 Q1

阶段 F 的 D1 显示 L5 的层内价差 +1.9155pp（是 L2 的 7 倍）。
若只在 L5 取 Q1，单边 alpha 会不会更大？**这是诊断，不参与判定**——
因为 L5 是流动性最差的一层，它的"高 alpha"很可能被冲击成本吃掉。

## 2. 基准与 alpha

```
R_bench,t = mean(fwd_i,t)   对当月池内全部可投资标的（与阶段 E 完全同口径）
alpha_t   = R_long,t − R_bench,t        算术差
```

**与阶段 E 用同一个基准定义**，所以两个实验的 alpha 可以直接对照。

## 3. 主检验

```
H0: E[alpha] = 0
```

- **双侧**（阶段 E 的教训：别预设方向）
- Newey-West 滞后 3
- 窗口 2007-01 ~ 2026-09，预期 237 个月

### 3.1 判据（四档 + 一个专用档位）

| 档位 | 条件（全部满足） |
|---|---|
| **MAX5_LONGONLY_CONFIRMED** | `n ≥ 150` 且 `\|NW t\| ≥ 1.96` 且 `\|alpha\| ≥ 0.30 pp/月` |
| **MAX5_LONGONLY_SMALL_BUT_SIGNIFICANT** | `n ≥ 150` 且 `\|NW t\| ≥ 1.96` 且 `\|alpha\| < 0.30 pp/月` |
| **`MAX5_LONGONLY_NOT_EXECUTABLE`** | `n ≥ 150` 且 `\|NW t\| < 1.96`，**且多空价差在同期显著** |
| **INCONCLUSIVE** | `n < 150` 或 NW 有效样本 < 100 |

**`MAX5_LONGONLY_NOT_EXECUTABLE` 这个档位在跑之前写死**：它的语义是
"多空价差是真的，但单边拿不到"——这比笼统的 `NOT_DETECTED` 准确，
也直接回答"这条路能不能走"。

判定这一档时**要引用阶段 F 的结论**（Δ=+0.7405，t=3.41）作为对照条件，
不能只看本实验自己的 t。

`0.30pp/月` = 月度成本（@0.1%，实测换手算）的两倍左右，与阶段 C/E 的经济门槛一致。

## 4. 必须同时报的

### 4.1 成本后 alpha

```
月度成本 = 2 × 单边换手 × 费率     （×12 是年化，不许当月度扣；必须走 cost_of()）
```

### 4.2 容量

```
lot_i     = 100 × close_exec(i, entry_t)
W_1lot,t  = Σ_i lot_i
W_equal,t = k_t × max_i lot_i
```

报中位与 P90。与阶段 E 同口径，便于对照。

### 4.3 beta

`OLS(R_long ~ R_bench)` 的斜率。**只报，不中性化。**

### 4.4 alpha 与多空价差的比例

```
ratio = alpha / (阶段 F 的 Δ)
```

**这是本实验的核心数字**。阶段 E 的 21 日反转是 0.21。
- 若 MAX5 的 ratio 明显 > 0.21 → 它的效应更多在多头侧，值得继续；
- 若接近或低于 0.21 → 与反转同命，关闭。

## 5. 诊断（描述性，不参与判定）

| # | 诊断 | 目的 |
|---|---|---|
| D1 | V0（原始 Q1）的 alpha 与 V1 对比 | 分层对单边有没有帮助 |
| D2 | V_L5（仅最高波动层 Q1）的 alpha | 效应最强的一层单边能拿多少 |
| D3 | 分段：2007-2015 / 2016-2026 | 阶段 F 已知 2016 后衰减，看单边是否更糟 |
| D4 | 分年度 alpha | 稳定性 |
| D5 | beta 与相关系数 | alpha 是不是风险补偿 |
| D6 | 组合的波动率 vs 池内波动率 | 低 MAX5 组合是不是"更安静所以赢"（若组合波动率显著低于池，需警惕） |

D6 是对照：若 V1 组合的波动率明显低于池中位，那它的 alpha 可能只是"低波动溢价"，
而 **Gate 4 已证明低波动在本项目上不成立**——这会削弱结论。
