## 0. 为什么开这一阶段

阶段 S 判定 exQ5 现代段（2016-2026）成本后 alpha **可检出**，但结论带着
三个已披露的保留：MDE 0.1405 > 点估计 0.1112、事后功效仅 0.60、
bootstrap 区间跨 0。在把它当作"可进入模拟盘评估"的依据之前，必须先回答
三个**从未被检验**的脆弱点：

| # | 脆弱点 | 为什么必须检 |
|---|---|---|
| **1** | **影响点**：t=+2.218 会不会由少数极端月份驱动？ | 阶段 R 杀 SURGE 用的是"后段整体不显著"，从没做过影响点诊断。exQ5 若也是 5 个月撑起来的，结论承重完全不同 |
| **2** | **分界点自由度**：2016-01-01 这个分界是**数据驱动**选出来的 | 它来自 Gate 2 对 532 池"2016 后翻负"的观察，**不是文献参数**（对比：MAX5 的 21 日 / 前 5 大 / 五分位全部来自 Zhu & Zhang 2020，且阶段 F 预登记明令不许事后改）。一个由结果选出来的分界点，是本案最真实的自由度 |
| **3** | **alpha 的流动性位置**：效应集中在多难买的股票里？ | 阶段 I/J/O 回答了"3,000 万能建仓、剩 7.2% 现金"，但从未回答"alpha 住在哪里"。若效应集中在最低 ADV 的 20%，3,000 万的容量结论要整体下调 |

本阶段**不新增策略、不调参数、不换选股构造**：T1/T2 只读阶段 S 已冻结的
逐月序列；T3 用阶段 I 已有的 `build_records()` 重建同一批持仓（V0 口径），
只增加一层 ADV 分层。**三个子检验的判据全部在本文件跑前写死。**

## 3. 副检验（判据同样跑前写死）

### T2 分界点敏感性

把分界点从数据驱动的 2016-01-01 换成 **6 个替代值**，各自检验
「该分界 → 2026-09」的 `net_S_3000w` 显著性：

```
2013-01-01, 2014-01-01, 2015-01-01, 2017-01-01, 2018-01-01, 2019-01-01
```

**必须同报每个分界的 n 与 MDE**——后段越短 se 越大、MDE 越大，
不报 MDE 就无法区分"不显著"与"没能力检出来"。

**判据（写死）**：6 个替代分界中 **≥ 4 个** 满足 t_nw ≥ 1.96 且 均值 > 0
→ **T2 通过**；否则不通过。

### T3 alpha 的 ADV 流动性分解

每月把池按**信号日前 21 个交易日平均日成交额（ADV）**等频分 5 组
（窗口与有效日要求与 MAX5 完全一致：≥19 个有效日），对 exQ5 的
V0 alpha 做**精确可加分解**：

```
contribution_g(t) = mean_{i∈K, g_i=g} r_i / n_K  −  mean_{i∈P, g_i=g} r_i / n
                    （g = 1 最低 ADV … 5 最高 ADV；K = exQ5 持仓，P = 全池）
Σ_g contribution_g(t) ≡ alpha(t)        （恒等式，逐月成立）
```

- 报告每组月均贡献、NW t、以及 `contribution_1 / contribution_5`
  （最低 ADV 组 ÷ 最高 ADV 组）。
- 同时报告**组内避免效应** `mean_{i∈K,g} r_i − mean_{i∈P,g} r_i`
  （即"只在第 g 组内部跑 exQ5"的局部效应），用于区分
  "贡献大是因为组内效应强" 还是 "因为组大/保留多"。
- ⚠️ T3 分解的是 **V0（无交易约束）口径**的信号横截面内容；
  可成交性与资金约束由阶段 I / J / O 单独处理，两者不混。

**判据（写死）**：`contribution_1 / contribution_5 ≤ 3` → **T3 通过**；
> 3 → 不通过（含义：alpha 过度集中于最难买的股票，容量结论需下调）。

## 6. 预期方向与机制（写死，跑完不得改口）

**可算量基础**（全部来自已披露数字，不新看结局变量）：

- 现代段点估计 +0.111196pp、se_nw ≈ 0.050133 → t ≈ 2.218
- 剔除 6 个极端月后 n=123：se 约放大 √(129/123) ≈ 1.024 倍
  → 若均值不变，t ≈ 2.17

→ **预期 T1a 通过**（t 落在 2.0 ~ 2.4）。

**机制**：exQ5 是月度等权 2,500+ 只的横截面构造，单月极端收益被高度分散；
阶段 S 已显示毛 alpha 后段 t=2.863 > 净值 t=2.218，说明信号层面比净值更稳，
成本侧不集中在少数月。**没有先验理由**预期 6 个人尽皆知的市场极端期
能单独撑起整个结论。

**T2 预期**：后段长度 2013→162 月、2014→150、2015→138、2017→114、
2018→96、2019→84。固定效应量 0.111pp 时 t ≈ 0.111/(0.050133×√(129/n))：

| 分界 | n | 预期 t |
|---|---:|---:|
| 2013 | 162 | ≈ 2.49 |
| 2014 | 150 | ≈ 2.39 |
| 2015 | 138 | ≈ 2.30 |
| 2017 | 114 | ≈ 2.09 |
| 2018 | 96 | ≈ 1.91 |
| 2019 | 84 | ≈ 1.79 |

→ **预期 T2 通过（≥4/6）**，且明确预期 2018、2019 两个分界**不通过**——
这不是失败，是 MDE 随样本长度上升的必然结果。因此判据设 4/6 而不是 6/6，
并强制同报 MDE。

**T3 预期**：彩票偏好文献的标准发现是"极端收益效应在小盘、高换手、
高 ADV 分位两端更强"，因此**预期 contribution_1 > contribution_5**；
但 exQ5 是等权全池构造、且阶段 I 实测各市值层均可买入，
**预期比值 ≤ 3**。若 > 3，说明效应过度集中于微盘，容量结论需下调。

**若实测与预期相反，照实报告，不得改口。** 尤其若 T1a 不通过，
结论必须写成"现代段显著性由先验极端期驱动，MDE=X pp"，
**不得**说成"效应衰减了"（衰减是阶段 P 的差值问题，本阶段不检验差值）。
