## 0. 为什么换假设（这一段必须连同结论一起引用）

Gate 1 检验的是**月频动量（60/5，单边多头 vs 同池等权）**，判定 **failure**。
复查文献后发现：**A 股月频动量不显著是已被反复记录的常态，不是异常**。

| 来源 | 结论 |
|---|---|
| 上海财经大学《中国 A 股市场动量效应的特征和形成机理研究》 | 「在月度频率上，我国股市并未表现出显著的动量收益」——与王永宏/赵学军(2001)、朱战宇等(2003)、潘莉/徐建国(2011) 一致 |
| 《Momentum Crashes: Evidence from the A-share Market》 | 36 个 J×K 组合中 **35 个负收益**，唯一正值组合 t=0.03 |
| 本项目 Gate 1 | mean(d) < 0，t = −0.5687，判定 failure |

> **含义**：Gate 1 的 failure **不是我们的实现有问题，而是复制了文献已知的事实**。
> 反过来说，Gate 1 花掉的功效测算成本，本质是"没有先查文献"的代价。
> 本预登记在选题阶段就引入了文献先验，这是流程改进。

### 0.1 新假设的先验依据（文献，非本项目数据挖掘）

**短期反转（short-term reversal）**在 A 股被多篇文献报告为显著，且**效应量在可检出区间内**：

| 来源 | 效应量 | 备注 |
|---|---|---|
| 《Anomalies in the China A-share market》（Erasmus, `pure.eur.nl`） | **1.42%/月**（t=4.35，等权）；0.80%/月（t=1.88，市值加权） | quintile 多空；引 Cakici et al.(2017)、Hsu et al.(2018)、Qiao(2019)、Liu et al.(2019) 为佐证 |
| 丁大鹏《个股反转策略与行业动量策略——基于 A 股市场的实证研究》 | 0.57%/月 | 短期（3 个月）反转 |
| 同 Erasum 论文，长期反转 | 0.71%/月（t=2.18） | 5 年减 1 年形成期 |
| 同 Erasum 论文，残差动量 | 0.66%/月（t=3.36） | 对冲 size/value 后 |

> ⚠️ **文献数字是引述，未经本会话核验原始论文的样本期与实现细节**。
> 因此本预登记**不把 1.42pp 当作预期值**，只用它来确认"效应量级落在可检出区间"。
> 判定不依赖文献数字，只依赖本项目数据算出的 t 统计量。

## 1. 研究问题

> 在 2016-05 ~ 2026-10 的 A 股全市场池上，**月度短期反转信号**（过去 1 个月跌得多的股票，
> 下个月是否跑赢跌得少的）是否存在**统计上可检出**的多空价差？

这是一个**确认性复现**（confirmatory replication），不是发现性研究。
文献已多次报告该效应；本实验检验它在**我们的数据口径（重建 ADJ）、我们的成本假设、我们的样本期**下是否仍成立。

## 3. 信号与组合构造（全部预先写死，不得事后调整）

| 项 | 设定 | 依据 |
|---|---|---|
| 信号 | `score = close(t−1) / close(t−21) − 1`（过去 21 个交易日收益，**跳过最近 1 日**） | Lehmann(1990)/Jegadeesh(1990) 标准设定；跳 1 日避免买卖价差反弹 |
| 排序方向 | **做多低分（输家）、做空高分（赢家）** | 短期反转定义 |
| 组合 | `0.5 × 等权(最低 k 只) − 0.5 × 等权(最高 k 只)`，自融资 | 文献用 quintile 多空价差 |
| 持仓数 k | **110**（≈ 当月池的 20%，即 quintile） | 文献 quintile 口径，**不是按 σ 挑的** |
| 再平衡 | 月度（每月最后一个交易日收盘价为信号基准，持有至下月末） | 与 Gate 1 一致 |
| 权重 | 等权 | 与 Gate 1 一致 |
| 有效数据要求 | 窗口内 ≥ 19/21 个有效交易日（90%） | 与 Gate 1 的 90% 规则一致 |
| 停牌处理 | 持有期内停牌，按最后一个可用价计（等价于无法卖出） | 保守 |

**不做的事（明确排除，避免事后扩大自由度）**：
不做行业中性、不做市值中性、不做残差化、不做波动率加权、不做交易成本择时、不剔除 ST。
这些都可能提高表现，但每一个都是一个新的自由度；要做就另开实验。

## 4. 判定判据（机械可执行，跑前冻结）

主检验：`d_m = r_多空,m`（m = 1..n），H0: `E[d] = 0`，H1: `E[d] > 0`（**单侧**，方向先验为正）。

| 档位 | 触发条件（全部满足） | 标签 |
|---|---|---|
| **SUCCESS** | `mean(d) > 0` **且** `t = mean(d)/(sd/√n) ≥ 1.645`（单侧 5% 显著）**且** `n ≥ 120` | 通过，可进阶段 4 |
| **INCONCLUSIVE** | `n < 120` 或 `sd(d) > 4.0pp`（超出本预登记的功效假设） | 证据不足，入档不推结论 |
| **FAILURE** | `mean(d) ≤ 0` **或** `t < 1.645`（且不满足 INCONCLUSIVE 条件） | 失败，效应不可确认 |

补充报告（**不参与判定**，只作描述）：

- 分年度 `mean(d)` 与胜率；
- 不同 k（50 / 110 / 200）的描述性结果；
- 不同 skip（0 / 1 / 5）的描述性结果；
- 双成本档（单边 0.1% vs 0.3%）的净效应描述。

> **补充报告不得用于推翻或修饰主判定。** 若主判定 FAILURE 而某个子集 SUCCESS，
> 一律以主判定为准，并在报告中明写子集结果为探索性发现、需另开实验确认。

## 5. 功效声明（本预登记最重要的一节）

用 548 只池实测（`docs/STAGE3_SIGMA_D_2026-10-20.md` 与 `STAGE3_SIGMA_D_REVERSAL_2026-10-20.json`）：

| 项 | 值 |
|---|---|
| 实测 `σ_d`（k=110，反转，21/1，多空，n=125） | **2.613 pp/月** |
| 标准误 `se = σ_d/√125` | **0.2337 pp/月** |
| **MDE（双侧 α=0.05, power=80%）** | **0.655 pp/月** |

**对文献效应量的功效**：

| 若真实效应为 | 功效 |
|---:|---:|
| 1.42 pp/月（Erasmus 等权口径） | **>99.9%** |
| 0.80 pp/月 | **92.8%** |
| 0.57 pp/月（丁大鹏口径） | **68.4%** |
| 0.50 pp/月 | 57.1% |
| ≤ 0.65 pp/月 | < 80%（**本设计检不出**） |

> **声明**：若真实效应 < 0.65pp/月，本实验极可能得 FAILURE —— 那不是"效应不存在"，
> 而是"本设计检不出"。报告必须同时给出 MDE，不得把 FAILURE 表述为"证明无效"。
>
> 与 Gate 1 对比：动量假设的合理效应量 0.3~0.5pp（文献甚至为负），MDE 0.81pp → 功效 18%，
> **设计上就不可能给出答案**。反转假设的合理效应量 0.8~1.4pp，MDE 0.655pp → 功效 93%+，
> **这是本项目第一次有资格做"成败判定"的实验**。

## 8. 冻结机制

批准后执行：

```bash
# 1) 计算全文 sha256（跨平台，且以二进制读、避免 CRLF 影响）
python -c "import hashlib,sys;d=open('docs/GATE2_REVERSAL_PREREG_2026-10-20.md','rb').read();print(hashlib.sha256(d).hexdigest(),' docs/GATE2_REVERSAL_PREREG_2026-10-20.md')" \
  > docs/GATE2_REVERSAL_PREREG_2026-10-20.sha256
# 2) 提交（预登记文件与 .sha256 均需在 .gitattributes 里保持 -text，防 autocrlf 漂移）
git add docs/GATE2_REVERSAL_PREREG_2026-10-20.md docs/GATE2_REVERSAL_PREREG_2026-10-20.sha256 .gitattributes
git commit -m "gate2-reversal-v2.0 预登记冻结"
# 3) 冻结完成后才允许写运行脚本
```

> ⚠️ **CRLF 坑（本项目已踩过两次）**：若预登记 md 未在 `.gitattributes` 里标 `-text`，
> Windows 下 `core.autocrlf=true` 会把它转成 CRLF，导致**干净 clone 后 sha256 漂移**、契约测试必红。
> 冻结前必须确认 `.gitattributes` 已覆盖（现有规则 `docs/*[Pp][Rr][Ee][Rr][Ee][Gg]*.md -text` 应已兜住）。

运行脚本必须在冻结之后写，且只能读预登记里声明的参数（脚本内硬编码，不提供命令行覆盖）。

## 9. 已知局限（跑前如实声明）

1. **无 PIT 成分股**：池是"曾存在过的 548 只"，不是历史时点的沪深300 成分。幸存者偏差部分缓解（含 248 只退市）但未消除；
2. **无成交额过滤**：源数据无 amount，未做流动性筛选，小盘低流动性股票可能进入组合，实际不可交易；
3. **成本未计入判定**：0.1%/0.3% 双档只作描述；A 股反转策略换手高（月度 100%+），真实成本可能吃掉大部分效应；
4. **多空不可实盘**：A 股融券困难，做空腿在实盘上基本不可得。本实验检验的是**信号是否存在**，不是**策略是否可执行**；
5. **文献数字未核验原始论文**：见 §0.1 警告。

> 第 3、4 条特别重要：即使 SUCCESS，也**不构成可交易策略的证据**，只说明"这个信号在我们数据里有可预测性"。
> 能否变成策略，属阶段 4（成本/容量/券源）与阶段 5（模拟盘）的事。
