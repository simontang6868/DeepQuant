## 0. 为什么不能直接回测那 17 只（必须先否决的方案）

W9 给出的 17 只，是用 **2026-10-23 的现价**筛出来的。如果拿这份名单从 2023-01 建仓，
等于**用 2026 年才知道的信息决定 2023 年买什么** —— 典型前视偏差（look-ahead bias）。
它必然好看，且必然无意义。

必须改成**时点化（point-in-time）规则**：每个决策点只用当时已可得的月末收盘价算 state，
按规则选出「当时」低于均线 8% 的票，而不是「今天」低于均线的那批。

> 这一步不改变用户的目标，只改变实现方式。用户要的是「挑票然后买一段就卖」，
> 规则版回答的正是「如果一直按这条规则做，结果会怎样」。

## 1. 这个回测能回答什么、不能回答什么（写在判据之前）

**不能**：不能作为「规则有效」的样本外证据。
理由：`bt_current_state.py` 得到「<−8% 档后续 12 月中位 +28.99%、亏损概率 19%」，
用的是 2007-2026 全样本 227 个月，**2023-2026 这 46 个月本来就在里面**。
用它去检验 2023-2026，是同一段数据的自我印证（样本内）。

**能**：回答下面三个具体问题，它们才是本阶段真实交付物 ——

1. 这条规则在 2023-2026 的实际路径长什么样：年化、最大回撤、逐月持仓数、空仓月数
2. 它是否满足用户锁定的硬目标：**回撤 > −20%**、**年化 > 3%**、**跑赢同期基准**
3. 它是否可执行：换手率、每期持仓只数、成本吃掉多少 alpha、有没有「信号出现但买不到」

## 2. 规则定义（跑前冻结）

| 项 | 定义 |
|---|---|
| 股票池 | 中证红利 100 只成分股（`pool/000922_components.csv`），**不做成分股时点还原**（见 §5 局限） |
| 价格口径 | 通达信后复权（`period=4` 日线 / `period=6` 月线，`tqFlag=2`）；月末收盘 = 该月最后一个交易日收盘 |
| 决策时点 | 每月**最后一个交易日收盘后**，用**已完结**的 12 个月末收盘算 `state = 月末收盘/MA12 − 1` |
| 建仓时点 | **次月第一个交易日收盘**成交（不用信号当日收盘成交，避免 1 日内的前视） |
| 选股条件 | `state < −8%`，等权配置，单只上限不设 |
| 持有期 | **主口径：12 个月**（对应「买一段就卖」）；**对照口径：1 个月再平衡** |
| 空仓处理 | 某决策点选出 0 只 → 全额现金，收益计 0（不计利息） |
| 成本 | 单边 **0.051%**（佣金 0.025% + 印花税 0.05% 仅卖出 + 过户费 0.001%，等价单边 0.051%，见 `MEMORY.md` §9）；按实际换手计 |
| 窗口 | 决策点从 **2023-01 月末** 起（需 2022-02 起月末数据做 warm-up），到 **2026-09 月末**止（2026-10 为未完结月，只用于估值不用于决策） |
| 基准 | **100 只等权买入不动**（同池同期，避免拿不同池子比）与 **同池按指数权重买入不动** 两条 |

## 3. 判据（预登记，跑前冻结）

三个目标同时报，缺一不可：

- **G1 回撤**：策略最大回撤 ≥ **−20%**（用户拍板的上限）
- **G2 收益**：年化 > **3%**
- **G3 相对**：区间累计收益 **> 基准（100 只等权买入不动）**

判定用语（严格按此表述，不新造词）：
- 三条全过 → `RULE_MEETS_TARGETS`
- G1 过、G2 过、G3 不过 → `RULE_ABSOLUTE_OK_RELATIVE_FAIL`
- G1 不过 → `RULE_DRAWDOWN_BREACH`
- 持仓月数 < 24 → 额外标注 `SMALL_SAMPLE`，且**不得**对年化做显著性断言

## 4. 预期方向与机制（必须写在跑之前，且建立在可算的量上）

**预期：12 个月持有口径会跑输「100 只等权买入不动」。**

机制（可算，不是直觉）：2023-2026 的红利行情是**大权重银行/能源/交运的趋势性上行**，
而 W9 名单里的票集中在化工、地产链、消费、机械，属于**趋势下行**而非超跌反弹。
若成立，可算的推论是：**state < −8% 的股票，次月/次季平均收益低于全池平均**，
即在这段行情里这条规则是**动量（跌的继续跌）而不是反转**。

**证伪条件**：若 state<−8% 组的次月平均收益 ≥ 全池平均，则上面的机制解释被推翻，
必须改写机制说明，不能保留解释。

> ⚠️ 按 `MEMORY.md` §3 的教训（T 的「均值不变」猜错、可算量才对），
> 这里给的是**可算的量**（分组次月收益差），不是「均值应该差不多」这类无内容预测。

## 5. 已知局限（不隐瞒）

1. **成分股未做时点还原**：用的是 2026-10 的 100 只名单，2023 年不在名单里的股票被排除、
   后来被剔除的股票也没算进去 → 存在**成分股幸存偏差**。这会使结果偏乐观，方向已知、幅度未知。
2. **样本内**：见 §1，不能当有效性证据。
3. **46 个决策点**：按 `MEMORY.md` §12（36 月功效 21%，80% 功效需 206 月），
   本窗口无能力识别小幅超额，只能识别大效应或给方向。
4. **停牌/涨跌停未做可成交检验**：本阶段先给「收盘价可成交」的理想口径，
   若结论为正，必须补 `exec_all` 真不复权逐日判定（`MEMORY.md` §6 铁律）。
5. **12 个月持有口径与成本口径的冲突**：alpha 按月度等权算会隐含月度再平衡，
   而持有 12 个月不动只按成分变动收费，两者互斥（阶段 V 已确认 1.15× 缺口）。
   本阶段对两个口径都报数，不择一隐藏。
