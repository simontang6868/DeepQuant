## 0. 一句话结论

```
主检验判定：MODERN_ERA_ALPHA_DETECTED
```

**exQ5 不是"前段驱动"型信号。** 在 BASE 真实费率 + √ 冲击 η=1（比阶段 O 收取的
Amihud 上界保守 24 倍）口径下，现代段（2016-2026，129 个月）成本后净 alpha
**+0.1112pp/月，NW t=+2.218**。这与阶段 R 对 SURGE 的判定（后段 t=0.26，任何档
不显著）形成直接对照——同一把尺子，两个信号结局不同。

⚠️ 但 MDE=0.140pp、事后功效仅 0.60，且 bootstrap 区间跨 0（见 §2.3）。
**本判定不构成"现代段可用"的证明。**

## 1. 为什么开这一阶段

阶段 R 用"后段单独是否显著"这把尺子杀死了 SURGE：它的全样本显著性完全由
2007-2015 驱动，后段任何资金档都不显著。而 exQ5——项目唯一存活信号——
从未被同一把尺子量过：

1. 阶段 O 的 B 判据只查了 `net_BASE_3000w` 后段 t=2.5813；
2. **更保守的 √ 冲击模型（η=1）从未进入过 exQ5 的净值**（阶段 O 只收 Amihud
   常数上界 0.000784pp；√ 模型全样本均值 0.018996pp，大 24 倍）；
3. 后段 MDE / 功效 / bootstrap / 其他费率口径从未报告；
4. 后段执行环境从未与净值一起评估。

本阶段只读阶段 O / 阶段 J 已冻结产物，不重算选股、不调参、不换构造。

## 2. 主检验

### 2.1 序列与口径

```
net_S_3000w = net_BASE_3000w + 0.00078376 − 0.01899561
```
BASE 真实费率（佣金 0.025% 双边 + 印花税 0.05% 仅卖出 + 过户费 0.001% 双边）
+ 现金残留 + **√ 冲击 η=1 @3,000 万**（两个冲击模型中更保守的一个）。

### 2.2 结果（现代段 n=129）

| 量 | 值 | 预登记预估 | 一致？ |
|---|---:|---:|:--:|
| 均值 | **+0.111196 pp/月** | +0.111196 | ✅ |
| se_nw（Bartlett, L=3） | 0.050133 pp | ≈0.0501 | ✅ |
| se_iid | 0.070436 pp | — | — |
| **t_nw** | **+2.2180** | ≈2.22 | ✅ |
| p（双侧） | 0.0266 | — | — |
| **MDE（80% 功效）** | **0.140452 pp** | ≈0.140 | ✅ |
| 事后功效 | 0.602 | ≈0.60 | ✅ |
| bootstrap 95%（2000 次, seed 20261022） | [−0.019084, +0.261533] | — | ⚠️ 跨 0 |

**判定：`MODERN_ERA_ALPHA_DETECTED`**（|t|=2.218 ≥ 1.96 且均值 > 0）。

**复现闸门全过**：G3 全样本 t_nw=4.0386、G4 后段 `net_BASE_3000w`
t_nw=2.5813（均逐位复现阶段 O）；G5 逐月 √ 冲击全样本均值 0.01131168
（= 阶段 J by_capital["1000万"]）。

### 2.3 判读（本阶段的核心）

**不允许的表述**：

- ❌ "exQ5 在现代段可用" —— 纪律 7：显著 ≠ 可交易；
- ❌ "证明现代段仍有 0.111pp alpha" —— MDE=0.140pp > 点估计，真实值可能小得多；
- ❌ "未衰减" —— 衰减是阶段 P 的差值问题，本阶段不检验差值。

**必须同时披露的两个限定**：

1. **MDE = 0.140pp，功效仅 0.60。** 若真值只有点估计的一半（0.056pp），
   这个检验有一半以上概率检不出。点估计 0.111 落在"能被检出"与"可能太小"
   的边界上。
2. **bootstrap 区间跨 0**（[−0.019, +0.262]），而 NW 区间
   [0.013, 0.209] 不含 0。差异来源：iid 月份重抽不建模序列的负自相关，
   给出更宽的区间（se 0.070 vs NW 0.050）。**哪个口径对，本项目无法用现有
   数据判定**——这是真实的统计张力，不是可以挑一个好看的空间的问题。
   项目一贯以 NW（Bartlett）为主口径，故主判定用 t_nw；bootstrap 作为
   稳健性参考并列报告。⚠️ 全部 20 个序列×分段组合的 bootstrap 区间**都**
   跨 0，说明这是系统性口径差异，不是主序列的偶然。

**读法**：

- 真实费率三档（BASE 两个资金档、CONS@3000万）现代段全部 t ≥ 2.2；
- **CONS@1000万（1,000 万 + 含 5 元最低佣金）t=1.76 不过**——小资金 +
  最保守费率是现代段唯一站得住的组合；
- **STRESS@3000万（0.3% 压力参数）t=0.97 不过**（与预登记预期一致）；
- **毛 alpha 后段 t=2.863，比任何净口径都高**——信号本身在现代段没有衰减，
  衰减全部来自成本（这与结构 9.1b 的 ratio 讨论一致）；
- 逐月精确版（1000万）t=2.419 > 常数版 t=2.306，证实主检验用常数是保守的。

## 5. 方法披露：本次测试自身的 3 个错误

单测首跑 3 处失败，**全部是测试写错，不是实现错**——按项目纪律记录：

| # | 错误 | 修正 |
|---|---|---|
| 1 | bootstrap 测试在列表推导里每次新建 `random.Random(5)`，129 个值全同 → 区间塌缩成点 | 改为先建 rng 再推导 |
| 2 | AR(0.9) 序列断言 se_nw/se_iid > 2.0；实际 L=3 Bartlett 截断只能抓住部分长程方差（≈1.82） | 阈值改 1.5 并补 iid 反向对照（0.8~1.25） |
| 3 | 断言 power(1.96)≈0.5 用 abs=1e-9；实际 0.5+Φ(−3.92)=0.500044 | 容差改 1e-3 |

这 3 处都是**测试自己的判据写错**，与项目历史上"检查器写错"的模式一致
（MEMORY §5）。实现代码未被这些错误污染：变异测试 9/9 通过，
G3/G4 闸门逐位复现阶段 O。

## 6. 不主张清单

1. **不主张"现代段可用"**——MDE 0.140pp > 点估计；功效 0.60；
   bootstrap 区间跨 0。
2. **不主张真实费率下所有组合都成立**——CONS@1000万 t=1.76 不过。
3. **不主张样本外**——全部为样本内；研究过程已看过现代段数据
   （阶段 P 等），本阶段不是干净 OOS。
4. **不主张冲击成本已测准**——√ 模型 η=1 是模型估计不是实测；
   3,000 万档用的是全样本常数（会高估后段成本，方向保守）。
5. **不主张现金残留已解决**——现代段 1,000 万档 14.5% 未投资。
6. **不主张"未衰减"**——本阶段不检验差值（阶段 P 的结论不变）。
