## 2. ⚠️ 口径错配的自我审查（本报告最重要的一节）

### 2.1 问题

Gate 2 预登记第 71 行自己写着：

> 组合 = `0.5 × 等权(最低 k 只) − 0.5 × 等权(最高 k 只)`，自融资 | 文献用 quintile 多空价差

**"自融资对半"与"多空价差"是两个不同的量**：

```
d      = 0.5 × r_long − 0.5 × r_short     ← 本项目一律用这个（各投一半资金）
spread =      r_long −      r_short       ← 文献 quintile 多空用的这个（各投全额）
⇒ spread = 2 × d
```

而 Gate 2/3/4/6 的预登记全部把 **MDE 与效应量和"文献 1.42pp"直接放在一起比较**，
等于拿"半个价差"去比"整个价差"。

### 2.2 两种口径下的真实量级

| 实验 | d（本项目口径） | spread = 2d | 占文献 1.42pp（价差口径） |
|---|---:|---:|---:|
| Gate 2（532 池，2016-2026） | −0.398 pp | −0.796 pp | 56%（反向） |
| Gate 3（532 池，2007-2015） | +0.484 pp | +0.968 pp | **68%**（当时写的是 34%） |
| **Gate 6（全 A，全段）** | **+0.708 pp** | **+1.417 pp** | **99.8%** |

### 2.3 影响范围

- **判定不受影响**。判定用的 `t` 与 `MDE` 都定义在 `d` 上，口径内部自洽。
  唯一边界是 `MDE ≤ 1.42pp`：若严格要求也对齐价差，门槛应改为 **0.71pp**。
  复核：**Gate 6 的 0.453 ≤ 0.71 ✅ 仍通过**；Gate 2（0.641）、Gate 3（0.655）同样 ≤ 0.71，
  历史判定一律不变。
- **叙事被推翻**（不改原文，加注）：
  1. Gate 3"只有文献 **34%**" → 同口径 **68%**；
  2. Gate 4"只有文献约 **1/6**" → 同口径约 **1/3**；
  3. "两次文献复现都远低于文献量级" → **反转不低（68%），全 A 上 99.8%**。
- **根因**：`d` 的好处是能算出可投资组合收益（资金各半），坏处是与文献的"价差"不同量纲。
  **以后任何跨文献比较，必须先做 ×2 / ÷2 换算，并在报告里同时列出两个数。**

> 这不是"改判据让结论好看"。方向相反：换成同口径后 Gate 6 更接近文献，
> 而我仍把 `MDE ≤ 0.71` 的更严门槛写进复核，两种口径下判定都不变。

## 3. 数据补全的三次重跑：效应单调走弱（本报告最有价值的发现）

预登记未改、参数未改，只补数据。三次版本：

| 版本 | 宇宙只数 | 补了什么 | mean(d) | spread | t | MDE | 胜率 |
|---|---:|---|---:|---:|---:|---:|---:|
| ① 01:18 | 5,209 | —（首跑） | +0.7407 | +1.481 | +4.539 | 0.457 | 62.0% |
| ② 01:47 | 5,239 | +30 只**退市股**（代理 502 未抓到） | +0.7383 | +1.477 | +4.524 | 0.457 | 61.2% |
| ③ **02:05** | **5,444** | **+205 只**（分红缺失导致 ADJ 未建） | **+0.7084** | **+1.417** | **+4.386** | **0.453** | 60.8% |

### 3.1 趋势是单调的，而且可解释

```
mean(d):  0.7407  →  0.7383  →  0.7084     （累计 −0.032 pp，−4.4%）
t:         4.539  →   4.524  →   4.386     （累计 −0.15）
胜率:      62.0%  →   61.2%  →   60.8%     （累计 −1.2pp）
```

**每补进一批"本该在池里但缺席"的标的，效应就变弱一点。**

补进去的是什么？**退市股、老股、长期停牌股**——恰好是输家腿里"跌得更多、反弹更弱"的那批。
把它们加回来 → 输家腿收益下降 → d 下降。

**这意味着：幸存者偏差的方向是"让效应看起来更强"，而本项目的 1.417pp 已经是修正过的值。**

### 3.2 但差距仍没消完，而且方向明确

| 项 | 状态 |
|---|---|
| 已知缺席（30 + 205 = 235 只） | **已补全** |
| 未知缺席（历史退市后数据被彻底删除） | **无法补**（代码表来自只含在市股的列表） |
| 补全的影响 | −0.032pp（−4.4%） |
| 若未知缺席的影响同量级 | 真实效应可能还要再低，**但无法估计** |

**结论**：1.417pp 应理解为"在可获取数据的全 A 宇宙上"的效应，**不是"全市场真实效应"的无偏估计**。

### 3.3 判定在三版下都不变

三版的 `judgement.rule_hits` 完全相同：`n=237 ≥ 200`、`MDE ≤ 1.42`、`|t| ≥ 1.96`、方向为正。
**这是本实验对数据补全稳健的直接证据**（也是唯一一次有机会验证的稳健性）。

旧产物完整保留：`gate6_out/b8c4f1ecba44_pre_datacomplete/`（①）、`_pre_divfix/`（②）。

## 10. 三条残余缺陷

1. **幸存者偏差未消除（最大残余）**。§3 证明补已知缺席会让效应降 4.4%，
   但"历史退市后数据被彻底删除"的标的**无法统计**。
   真实效应**很可能低于 1.417pp**，低多少无法估计。
2. **未建模 ST / 长期停牌 / 一字板 / 涨跌停无法成交**。
   1,122 只标的有 ≥120 自然日长停牌（抽样 120 只探针全为真实停牌，0 抓取漏段），
   复牌首日的巨幅跳变**计入收益且未剔除**。80.3% 月换手 × 1,021 只/腿，
   真实成交约束会显著侵蚀收益。
3. **微型股未区分**。全 A 含大量极小微盘，21 日反转可能主要是流动性/买卖价差效应。
   未做市值分层、未做行业中性，**因此 1.417pp 里有多少是"不可交易的流动性补偿"，本报告无法回答**。
