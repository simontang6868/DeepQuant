## 0. 假设与先验

**假设**：在**无选择偏差的 as-of 全 A 宇宙**上，短期反转（过去 21 日跌得多 → 下月跑赢）
存在可检出的多空价差。

**方向先验有歧义**（这一点决定了判据是双侧，见 §4.1）：

| 先验来源 | 方向 |
|---|---|
| 文献（Erasmus 等权 quintile，A 股短期反转 +1.42pp/月） | 正 |
| 本项目 Gate 2（2016-2026，532 只池） | **负**（−0.3846pp，t=−1.64） |
| 本项目 Gate 3（2007-2015，532 只池） | 正（+0.4841pp，t=+2.12） |

在一个**新的、大得多的宇宙**上，这三条先验不能简单加权 → **单侧检验会把一半先验错误当成零假设**，
因此判据用**双侧**（与 Gate 5 同一处理方式）。

> ⚠️ 文献数字为二手引述，未核验原始论文；**不把 1.42pp 当预期值**，只用于确认量级在可检出区间。

## 1. 宇宙（本预登记的核心，也是与 Gate 2/3 最大的差别）

每个调仓日 t 的候选集合，**只用 t 及之前可观测的信息**：

```
候选(t) = { 全部 A 股 c :
            c 的行情序列首日 ≤ t − 252 个交易日     # 上市满 12 个月
            且 c 的行情序列末日 ≥ t                # 当时仍在交易（未退市/未终止）
            且 c 在 t 有正的价格                    # 当日可定价
          }
```

- 序列首日/末日取自 **EXEC 真不复权序列**（`data/exec_all/`）的实际起止，
  **不依赖任何外部"上市日期/退市日期"名单**——这正是自建 as-of 宇宙的意义；
- 这不是"历史指数成分"，是"当时可投资集合"。它在解决 **PIT 的第 ①、② 条需求**
  （见 `PIT_DECISION_2026-10-21.md` §2），第 ③ 条（是否在沪深300 内）本实验不需要。

**与 532 只池的关系**：532 只 = 今日沪深300 + 曾退市股，是**按 2026 年信息**筛出来的；
本宇宙是按**当时**筛的。两者不可互相替代，也**不可把两个结果相减**当作"偏差量"。

## 3. 信号与组合（全部预先写死）

| 项 | 设定 |
|---|---|
| 信号 | `score = close(t−1) / close(t−21) − 1`（跳过最近 1 日），与 Gate 2/3 完全相同 |
| 排序 | **做多低分（输家）、做空高分（赢家）**，与 Gate 2/3 相同 |
| 组合 | `d = 0.5 × 等权(最低 k) − 0.5 × 等权(最高 k)`，自融资 |
| **持仓数 k（主）** | **比例 k = round(0.20 × n_pool)** —— 与文献 quintile 一致；全 A 宇宙下 20% 才是"五分之一分位" |
| k（对照，描述性） | **k = 110 固定** —— 与 Gate 2/3/4/5 同参数，仅用于横向对照 |
| 有效数据 | 21 日窗口内 ≥ 19 个有效交易日（90%），与 Gate 1/3 一致 |
| 再平衡 | 月度（月末收盘定信号，持有至下月末），等权 |

**为什么主设定改成比例 k**：532 只池里 k=110 占 27%~34%，全 A 宇宙里只占 4%~8%。
继续用固定 110，两条腿会从"五分之一分位"变成"二十分之一分位"——**设计与文献不同却沿用同一个数**，
效应量会比文献大但含义不同。主判定因此改用比例 k；固定 k=110 保留为对照，**不参与判定**。

## 4. 判定判据

### 4.1 主检验（**双侧**）

`MDE = 2.8016 × sd(d) / √n`（与 Gate 2~5 同一约定）。

| 档位 | 触发条件（全部满足） | 标签 |
|---|---|---|
| **SUCCESS** | `n ≥ 200` **且** `MDE ≤ 1.42pp` **且** `\|t\| ≥ 1.96` | 通过；必须写明**方向**（t>0 → 反转成立；t<0 → 反转反向成立） |
| **INCONCLUSIVE** | `n < 200` 或 `MDE > 1.42pp` | 证据不足 |
| **FAILURE** | 其余 | 失败（未检出） |

### 4.2 必报项：2016 分段（不参与判定）

段 A = 2007-01~2015-12；段 B = 2016-01~2026-09；报告两段 `n/mean/t/sd/MDE` 与 Welch p。
**四选一措辞（逐字照抄）**：

| 条件 | 措辞 |
|---|---|
| 两段差 p ≥ 0.05 且两段均 `\|t\| ≥ 1.96` | **"效应跨段持续"** |
| 两段差 p < 0.05 且仅段 A 达 `\|t\| ≥ 1.96` | **"效应在 2016 后断裂"** |
| 两段差 p < 0.05 且仅段 B 达 `\|t\| ≥ 1.96` | **"效应在 2016 后才出现"** |
| 其他 | **"不足以判断是否存在断点"** |

### 4.3 必报项：与 532 只池的对照（**描述性，不得相减**）

在同一窗口、同一分段下，并列 Gate 3/Gate 2（532 只池，k=110）与本实验（全 A，比例 k）的结果，
用于回答"池构成是不是偏差根源"。**两条结果不可相减，也不得挑一条当结论。**

## 8. 已知局限

1. **历史退市名单不完整**：as-of 宇宙靠"序列末日"判定退市，若某只退市后数据被删则它不会进入候选；
   现有 5,223 只表本身**不含**已退市股票（新浪列表只给在市股）→ 本宇宙**仍有幸存者偏差**，
   只是比 532 只池小得多。这是本实验**最大的残余缺陷**，必须写进结论。
2. 未建模 ST / 长期停牌 / 一字板（真实不可交易）；
3. 未做市值/行业中性；
4. 全 A 宇宙含大量微型股，微型股的 21 日反转可能主要是流动性/价差效应，本实验**不做区分**；
5. ADJ 依赖分红事件源，全 A 的东财/新浪覆盖率需在验收里报告（D-1 的残余风险外推到全 A）。
