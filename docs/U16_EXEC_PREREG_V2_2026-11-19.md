## 4-A 符号与幅度约定

| 量 | 约定 |
|---|---|
| 计数（笔数、差异条数、重定价次数、顺延天数） | 非负整数，判据 `==0` / `<=2` / `<=10` |
| 金额（现金、费用、成交额） | 元，两位小数；比较用 `Fraction`，相对容差下限 `4e-6`，绝对容差 `0.01` 元 |
| 金额差方向 | 有符号 `diff = 外部 − 本地`；`abs(diff)<=0.01` 且记录符号 |
| 数量 | 股（1 手=100 股），整除等式无容差 |
| 时间偏差 | 分钟，有符号（实际 − 意图）；`abs<=10` 为通过；`created_at` 同口径 |
| 收益率/净值/MDD | 不适用；引用须标 `NOT_FOR_ECONOMIC_INFERENCE` |
| 方向自检 | 冻结前手算：`diff=1005.00−1000.00=+5.00>0.01` ⇒ FAIL；`diff=0` ⇒ PASS。禁止调用被测函数推期望值 |

## 5. 变异与闸门

- 改检查器/闸门前先跑真变异；变异必须真改行为（DENY→ALLOW 必须被检出），不接受"换拒绝理由"。
- 必覆盖 **9 条**：① 幂等键随机；② 台账缺失放行；③ 授权缺失放行；④ 上取整超预算；⑤ 非目标不清仓；⑥ 静默超预算；⑦ 门控失败返 0；⑧ E4 恒通过；⑨ **旁证替换为过期 commit / 篡改哈希须检出**。
- 串行：变异脚本原地改源码期间禁止任何其他 pytest / 提交；结束后 sha 须回到冻结值。
- 容差按产物存储精度；"文件不存在/输出为空"必须失败关闭。
- 闸门禁止调用被测函数：期望值来自产物或独立算术（Fraction）。
