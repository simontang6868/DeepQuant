## 1. 为什么必须做这一阶段

项目纪律第 8 条：**不得将"未拒绝原假设"解释为"证明原假设成立"。**

而"exQ5 不衰减"是本项目**唯一贯穿 H→I→J→K→O 反复被引用**的性质。
阶段 N 审计（§10.3b）已指出三段的两段之差 Welch t 全不显著，但那次是
**探索性**的、且在 0.3% 费率口径下做的。

本阶段把它做成正式检验：**不新增策略、不调参数、不换窗口、不换构造**，
只读各阶段已冻结的逐月产物，检验"已有序列"的性质。

## 2. 主检验

### 2.1 结果

| 量 | 值 |
|---|---:|
| 序列 | exQ5 净 alpha，`net_BASE_3000w`（BASE 费率、W=3,000 万、含现金残留与冲击上界） |
| n | 237 月（早 108 / 晚 129），L=3 |
| α_early（2007-2015） | **+0.143784 pp** |
| α_late（2016-2026） | **+0.129408 pp** |
| **β1 = α_late − α_early** | **−0.014377 pp** |
| se（NW, Bartlett） | 0.066608 pp |
| **t** | **−0.2158** |
| p（双侧） | 0.8291 |
| 95% CI | **[−0.144928, +0.116175] pp** |
| **MDE（80% 功效）** | **0.186609 pp** |
| \|β1\| / MDE | **0.0770** |

**复现闸门**：两段均值与 t 逐位复现阶段 O 的 `segments_BASE_3000w`
（0.143784 / 3.3173；0.129408 / 2.5813）；
β1 与"两段均值直接相减"两条独立路径差 **0.00e+00**。

### 2.2 判读（这是本阶段的核心）

**不允许的表述**：

- ❌ "exQ5 不衰减"
- ❌ "证明了跨期稳定"
- ❌ "2016 后仍然有效"

**唯一允许的表述**：

> 在 MDE = 0.1866pp 的检验能力下，未能拒绝"两段相等"；
> 实测差 −0.0144pp（仅为 MDE 的 7.7%），
> **无法区分"真的相等"与"存在小于 0.1866pp 的变化"**。

一个直观的标尺：**MDE（0.187pp）比效应本身（0.144pp）还大。**
也就是说，这个检验连"变化量等于整个效应"这么大的变动都只有约六成把握检出。

## 3. 正对照（预登记 §2）：检验到底有多灵敏

用 SURGE 的可成交 alpha 做校准——阶段 L 报告过它衰减 73%（+0.1764 → +0.0472），
是本项目报告过的最大衰减。

| 量 | 值 |
|---|---:|
| α_early → α_late | +0.176383 → +0.047180 pp |
| β1 | **−0.129203 pp** |
| se | 0.065902 pp |
| **t** | **−1.9605** |
| p | **0.0499** |
| 95% CI | **[−0.258371, −0.000035]** |
| \|t\| − 1.96 | **+0.0005** |
| 事后功效 | **50.0%** |

### ⚠️ 正对照是"擦边通过"，不是"检验有效力"

t = −1.9605，仅比临界值高 **0.0005**；CI 上界 −0.000035，几乎贴着 0。
**事后功效恰好 50.0%——等于抛硬币。**

所以预登记 §2 里那句"若正对照检出 → 主检验的未检出有信息量"，
必须按实测修正为：

> 检验对 **0.13pp 量级**的差异只有约五成把握，
> 主检验的"未检出"**仅有弱信息量**。

**顺带修正阶段 L 的一个表述**：
"SURGE 衰减 73%"此前是作为观测事实陈述的。本阶段把它正式检验后，
结果是 **p = 0.0499、CI 上界 −0.000035**——**边缘显著**。
任何 lags/口径的轻微变动都可能让它翻转。
它应被标记为"边缘证据"，不是"已确认的衰减"。

## 4. 副检验（描述性，不参与判定）

| # | 序列 | α_early | α_late | β1 | t | MDE | \|β1\|/MDE | 事后功效 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| S1 | exQ5 **毛** alpha（V1，未扣费） | +0.1715 | +0.1566 | −0.0149 | −0.210 | 0.1991 | 0.0749 | 5.5% |
| S2 | exQ5 净（STRESS @3000万） | +0.0354 | +0.0483 | +0.0129 | +0.195 | 0.1853 | 0.0696 | 5.4% |
| S3 | **MAX5 层内价差 Δ** | **+1.2722** | **+0.2953** | **−0.9769** | **−2.279** | 1.2008 | 0.8136 | **62.5%** |
| S4 | SURGE 可成交 alpha（=正对照） | +0.1764 | +0.0472 | −0.1292 | −1.960 | 0.1846 | 0.6998 | 50.0% |

### 4.1 唯一被统计支持的分段结论是 MAX5 的衰减

S3 是四个序列里**唯一**达到常规的 |t| ≥ 1.96 且有余量的：
**t = −2.279**（余量 −0.319，事后功效 62.5%）。

所以"MAX5 在 2016 后衰减"是本项目**唯一**有统计支持的分段结论。
而 exQ5 的"不衰减"和 SURGE 的"衰减 73%"——**都达不到同等标准**。

### 4.2 S2（STRESS 口径）的方向是**正的**

β1 = +0.0129pp（t = +0.195）。即在 0.3% 压力费率下，后段净值反而略高于前段。
这与"衰减"叙事相反，但 t 极小、纯属噪声，不构成任何结论。
列出它只为说明：**换个成本口径，"衰减/不衰减"的符号就会变**——
这本身就是不要轻信分段比较的理由。

### 4.3 单位与口径的两处登记

1. **S3 的产物单位是小数**，不是 pp（`phasef/.../monthly.csv::delta` 全样本均值 0.007405）。
   本阶段 ×100 转为 pp，并用门控核对：缩放后全样本均值 0.740493
   复现阶段 F 的 `main.mean_pp = 0.7404926`（容差 5e-6）。
   **这正是"百分数与小数混用"那一类故障**——混在对比表里会让整行读错 100 倍。
2. **S2 与阶段 J 的 `segments_at_best` 差约 0.0002pp**（0.035404 vs 0.035234）：
   阶段 J 用**逐月** Amihud 冲击，阶段 O 用 3,000 万档的**常量上界** 0.000784pp。
   差异可解释，不影响任何结论。

## 5. 能说什么 / 不能说什么

### 可以主张

1. **exQ5 未出现 MAX5 那种量级的衰减**（−0.98pp）。
   若 exQ5 也衰减那么多，本检验会检出（MAX5 就是被检出的那个）。
2. exQ5 前后两段**各自**显著为正（阶段 O：t=+3.32 / +2.58），
   且**未能拒绝两段相等**——这两句合起来是本项目对"稳定性"能给出的**最强**表述。
3. **MAX5 的分段衰减是被统计支持的**（t=−2.28）。

### 不可以主张

1. ❌ "exQ5 不衰减" —— 只能说"未发现衰减，检验能力 0.187pp"。
2. ❌ "SURGE 确认衰减" —— p=0.0499、CI 上界 −0.000035，属边缘。
3. ❌ 任何形式的"样本外"——全部 237 个月都是样本内。
4. ❌ 把"两段各自显著"当成"稳定"的证明——那是两件不同的事。

## 6. 一个此前没人算过的数：对"完全归零"的检出功效

若 exQ5 在后段**完全归零**，β1 将等于 −0.1438pp，对应的
**检出功效 = 57.9%**。

也就是说：即便信号彻底消失，本检验也只有不到六成把握发现它。
**没有检出 → 对"完全归零"只是弱证据，不是强反驳。**

（对照：SURGE 对"完全归零"的检出功效为 76.3%，且它确实检出了显著的 β1。）
