## 4-A 符号与幅度约定（必填）

| 量 | 约定 |
|---|---|
| 计数（笔数、差异条数、重定价次数、顺延天数） | **非负整数**，无符号；判据 `== 0`（或 `<= 2`、`<= 10`）为通过 |
| 金额（现金、费用、成交额） | 单位 **元**，两位小数；比较用 `Fraction`，**相对容差下限 4e-6**（产物存 6 位小数）、绝对容差 `0.01` 元 |
| 金额差的方向 | 统一写**有符号差** `diff = 外部 − 本地`；判据 `abs(diff) <= 0.01`；**同时记录 `diff` 的符号**用于定位方向性错误（如费用单边漏算） |
| 数量（股／手） | 单位 **股**（A 股 1 手 = 100 股）；判据为**整除等式**，无容差 |
| 收益率／净值／MDD | **不适用**（本单不作经济性判断）；若他人引用 `SIM_DRILL` 净值，须标 `NOT_FOR_ECONOMIC_INFERENCE` |
| 方向一致性自检 | 冻结前用已知数代入：`diff = 1005.00 − 1000.00 = +5.00` ⇒ `abs(diff)=5.00 > 0.01` ⇒ 判 FAIL（方向与振幅均符合直觉）；`diff = 1000.00 − 1000.00 = 0` ⇒ PASS |

> 冻结前自检只用**手算**，**禁止调用被测函数**推导期望值（L3ac M6 / L3ae M3）。

## 5. 变异与闸门

- 改检查器/闸门前先跑变异；变异必须**真改行为**（DENY→ALLOW 必须被检出），不接受"换个拒绝理由"。
- 必须覆盖的变异（≥8 条）：① 幂等键改为随机 ⇒ P1 应失败；② 重定价计数每日清零 ⇒ P2 应失败；③ 把 `NO_INPUTS` 当 PASS ⇒ P2 判据应失败；④ `exec_type` 未知值默认映射为"已成交" ⇒ P6 应失败；⑤ 熔断闸门放在报单之后 ⇒ P5 应失败；⑥ 费率就地手写替代 `cost_of()` ⇒ 费用判据应失败；⑦ 金额比较用 `abs()` 套在差值上导致方向丢失 ⇒ 方向自检应失败；⑧ 授权重校跳过 `max_notional ≤ available` ⇒ 授权判据应失败。
- 容差按**产物存储精度**定；"文件不存在 / 输出为空"必须失败关闭。
- **变异脚本原地改源码期间禁止任何其他 pytest / 提交**（串行）。
