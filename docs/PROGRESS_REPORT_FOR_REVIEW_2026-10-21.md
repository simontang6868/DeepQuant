## 1. 治理与纪律（先看这个，否则后面读不懂）

| 规则 | 内容 |
|---|---|
| **预登记冻结** | 参数、判据、窗口、档位**全部跑前写死并计算 sha256**；运行脚本启动时校验，不一致**拒绝运行**。改设计必须新开预登记、重新冻结、重新编号 |
| **禁调参择优** | 敏感性分析**不参与判定**；主判定失败而某子集成功，一律以主判定为准，子集记为"探索性" |
| **不删失败记录** | 结论写错时**保留原文 + 加更正注**，不静默替换（本报告 §6 有两例） |
| **同假设再看一次 = 新实验** | 换窗口/换基准/换样本期都要新预登记，两次的结果**不得合并 t、不得挑选** |
| **修 bug 后重跑不算新实验** | 但必须并列报告前后差异 |
| **不编造数据** | 所有数字必须来自可复算的产物；发现未核算的数字必须主动撤回（§6） |

| 异象 | 2007-2015 | 2016-2026 |

## 4. 组合构建与风控（阶段 4.1 / 4.2）

**4.1 资金门槛**（`PORTFOLIO_CONSTRAINTS_REPORT`）：
一手成本中位 1,203 元，但**最大 22.2 万**（2021）；逐年最高 3.3 万（2016）→ 22.2 万。
- **k=110 要真正满仓（现金 ≤5%）需约 1,000 万**；只求"持仓够+权重不偏"则 300 万；
- **50 万只能建仓 4.1 只**（97% 是现金）；
- 成本不是瓶颈（0.6~0.8 pp/年），**现金残留才是**。

**4.2 风控：三条规则全部判"未验证"**（`MARKET_STATE_REPORT` + `MARKET_STATE_V2_REPORT`）：

| 规则 | 结果 |
|---|---|
| R1（vol60 > expanding 80% 分位 → 半仓） | 146 月只触发 11 次 → **分位"危机记忆"钝化** |
| R2（绝对阈值 35%） | 触发 35 次（钝化修好 ✓），但验证段只 2 次，MDD +0.00pp → 未验证 |
| R3（波动目标 20%） | 状态增量 **+0.004 ≈ 0** → 未验证 |

根因是**样本不是规则**：2016-2026 没有真危机；且**设计段 MDD 与全样本 MDD 完全相同**
（−71.53%/−64.49%/−63.77%）→ 全样本的"有效"全靠 2008 **一个样本点**。
另有一条描述性发现：**"相关性在下跌时上升"只在尾部成立**（极端下跌月 0.397 vs 0.301，p=0.017；普通下跌月无差异）。

## 5. PIT 决策（本轮拍板）

**结论：先自建，暂不采购。** 理由：PIT 的目的是"不用未来信息决定当时能买什么"，
**只需 ①上市日期 ②退市日**，**不必**拿到历史成分名单（"是否在沪深300 内"只在复制指数/成分内选股时才必要）。
- 全 A 代码 **5,223 只免费可得**（新浪 hs_a 列表，0 失败；东财 `f26` 带上市日期但 `pz≥100` 会断连）；
- 抓取实测 ≈0.68~0.9 只/秒 → 全量约 2 小时、磁盘 ~1.5 GB；
- **采购触发判据（写死）**：仅当某个新预登记的命题**依赖"是否在指数成分内"**才立项采购。

## 7. 我希望专家重点挑战的五个点

1. **D-1 的处置是否够**：用新浪补东财的空，我们没有第二源核验这 249 只退市股的事件。这个残余风险有多大？
2. **k=110 固定**是否合理：Gate 2/3/4/5 都用 k=110（占池 27%~72% 不等），导致跨窗口的**效应量（pp）不可比**，
   只有 t 可比。是否应该改用比例 k？（那会引入新自由度，需另开预登记）
3. **Gate 5 改双侧**是否恰当：文献方向先验冲突时，双侧是否会让我们错过一个真实但较小的效应？
4. **4.2 的"未验证"是否等于"已被证伪"**：我们的措辞是"证据不足"而非"规则无效"，这个区分是否站得住？
5. **池的构成是否是所有"低于文献量级"的共同原因**：反转是文献的 34%、低波动约 1/6、活跃度≈0。
   我们怀疑 532 只池（45% 最终退市）与文献的"全 A/大盘"差异太大，但**没有证明**。
