**这是本次实验最有价值的一个数。**

事前担心"MAX5 只是波动率的影子"（秩相关 0.88，0.88²≈0.77）。
实测：波动率**确实**吃掉了 31%，但**还剩 69% 且高度显著**。

换句话说：MAX5 与波动率相关，但它俩**不是同一个东西**。
一个只做低波动的策略（Gate 4，FAIL）拿不到这部分。

## 3. D1：效应随波动率**单调递增**，最低波动层里甚至是负的

| 层 | 层内 Δ（pp/月） | 层规模中位 |
|---|---:|---:|
| **L1（最低波动）** | **−0.2923** | 487 |
| L2 | +0.2595 | 487 |
| L3 | +0.7681 | 487 |
| L4 | +1.0528 | 487 |
| **L5（最高波动）** | **+1.9155** | 486 |

**这是本次实验信息量最大的一张表。**

- 5 层里 4 层为正，且**严格单调递增**；
- **L1 是负的**（−0.29pp）——在最安静的股票里，高 MAX5 反而跑赢；
- L5 的 +1.92pp 是 L2 的 7 倍。

**含义**：MAX5 不是一个"全局因子"，而是**在高波动股票里才生效的效应**。
等权平均（+0.74）把这个异质性抹平了。

这也解释了为什么它没被波动率完全吸收：在 L1 里 MAX5 效应**反向**，
如果 MAX5 真的只是波动率的单调变换，L1 里不该有方向相反的效应。

**但反过来说**：L5 是流动性最差、冲击成本最高的一层。
**效应最值钱的地方，也是交易最难的地方**——这与 Gate 6 的"最值钱的部分在空头腿"
是同一类讽刺。

按 M 体系：**M1 单项满足，M2 不满足**。但**这不是 M1**——见下。

## 6. 为什么这不能算 M1

M1 的定义是"扣 0.1% 成本后仍显著"，但它的前提是**该收益可实现**。

本实验的 `Δ = R(Q1) − R(Q5)` 需要：
- 做多最低 MAX5 的 20%（Q1）——**可以**；
- 做空最高 MAX5 的 20%（Q5）——**A 股个股做空基本不可得**。

**所以这仍然是多空价差，M4 结构阻塞一字未动。** 成熟度停在 **M0**。

要变成 M1，必须做**单边多头版**：只买 Q1，用池内等权作基准，与阶段 E 同口径。
**那个实验本报告没做**——预登记里也没有（预登记只定义了分层价差）。

## 7. 局限（必须一起读）

| 项 | 说明 |
|---|---|
| **多空价差** | 需要做空 Q5，M4 阻塞 |
| **单边多头未测** | 若单边 alpha 很小（像阶段 E 的 21% 比例），这条路同样走不通 |
| **L5 占权重高** | 效应集中在最差流动性的一层，冲击成本未建模 |
| **2016 后不显著** | +0.295，t=1.22 |
| 不做涨停剔除 | 分组价差是统计量；阶段 C 已量化 −5.83%/−7.09% |
| MAX5 用 21 日前 5 大 | A 股本地化口径（Zhu & Zhang 2020），不提供敏感性变体 |
| ST 无历史标记 | 5% 涨跌幅未区分；ST 股往往高 MAX，可能放大效应 |
| 2005-2006 | 左截断，不可用 |

## 8. 下一步（按信息量排序）

1. **单边多头版**（必须做，否则这个结果没有可执行含义）：
   只买 Q1，池内等权作基准，与阶段 E 完全同口径。
   如果单边 alpha ≥ 0.3pp 且成本后显著，这条路才第一次有可能走通。
   **这一步比任何进一步的分层细化都重要。**
2. **L1 的负效应值得单独看**：为什么在最安静的股票里高 MAX5 反而赢？
   可能与"安静股里的大涨是业绩驱动"有关，但那需要财报数据（本项目没有）。
3. 若要继续在这个信号上做，应该先解决 L5 的冲击成本，否则"效应最强的一层"永远只是纸面。
