## 0. 结论（三条，第二条最重要）

1. **"高波动预示低收益"在本池不成立**：高波动状态下月的平均收益是 **+3.32%**，比低波动状态的 **+0.72%** 还高
   （Welch t=+0.69，p=0.49）。高波动真正预示的是**方差变大**（sd 7.13% → **12.31%**），不是收益变差。
2. **事先写死的降风险规则 R 判"未验证"**：验证段（2016-11 ~ 2026-09）最大回撤改善 **+0.00pp**、
   Calmar **−0.003**，因为它**在后半段几乎从不触发**（146 个月里只触发 11 次，且全部集中在 2008/2015/2016/2024）。
3. **"相关性在下跌时上升"要加限定词**：普通下跌月**不成立**（0.296 vs 上涨月 0.319，p=0.30）；
   **极端下跌月（<−10%）成立**（0.397 vs 其余 0.301，t=+2.38，**p=0.017**）。
   → 常识不是错的，但只在**尾部**成立；用"下跌就相关性上升"去做日常风控是错的口径。

## 2. Q1：回撤与波动集中在哪些状态？（描述性，但用检验口径）

### 2.1 波动状态 → 次月收益

| vol_state | n | 次月均值 | sd | 胜率 | 最差单月 |
|---|---:|---:|---:|---:|---:|
| low（≤ 当期 80% 分位×0.7） | 117 | **+0.72%** | 7.13% | 51.3% | −17.84% |
| mid | 18 | −0.89% | 10.45% | 55.6% | −27.29% |
| **high（> 80% 分位）** | 11 | **+3.32%** | **12.31%** | 54.5% | −14.57% |

Welch t（high vs low）= **+0.69**，p≈0.49。

**读法**：高波动之后**收益既没变差也没显著变好，但波动明显放大**（7.13%→12.31%，1.7 倍）。
这条把"高波动 = 危险"的说法精确化了：**危险的是方差，不是均值**。
对风控的含义：波动率只能用来控**风险敞口**，不能用来判断**该不该看空**。

### 2.2 回撤状态 → 次月收益

| dd_state | n | 次月均值 | sd | 胜率 |
|---|---:|---:|---:|---:|
| shallow（> −8%） | 11 | **+5.93%** | 9.87% | 63.6% |
| mid（−20%~−8%） | 21 | **−2.30%** | 7.33% | 42.9% |
| deep（< −20%） | 114 | +0.77% | 7.79% | 52.6% |

**非单调**：浅回撤后最好，中回撤后最差，深回撤后又转正。
这符合"**中期下跌趋势最伤**（−20%~−8% 是趋势刚破位的区间），而跌到 −20% 以下往往已进入超跌反弹区"的直觉。
但 n=11 / 21 都很小，**不构成可操作结论**，只能作为"回撤档位不该被当作线性风险刻度"的证据。

## 3. Q1c/d：相关性到底在什么时候上升

| 分组 | corr60 均值 | n | Welch t | p |
|---|---:|---:|---:|---:|
| 全部下跌月 | 0.296 | 70 | −1.03 | 0.30 |
| 全部上涨月 | 0.319 | 76 | | |
| **极端下跌月（< −10%）** | **0.397** | 10 | **+2.38** | **0.017** |
| 其余月 | 0.301 | 136 | | |

秩相关（corr60 vs 同期收益）= **+0.093**（很弱，但方向与"跌时更相关"相反）。

按年看，相关性有清晰的**危机峰**：

| 年 | 均值 | 年内最高 | | 年 | 均值 | 年内最高 |
|---|---:|---:|---|---|---:|---:|
| 2008 | **0.595** | 0.622 | | 2017 | 0.174 | 0.239 |
| 2009 | 0.427 | 0.517 | | 2018 | 0.310 | 0.424 |
| 2011 | 0.412 | 0.511 | | 2019 | 0.312 | 0.400 |
| 2015 | **0.443** | 0.610 | | 2021 | **0.112** | 0.137 |
| 2016 | 0.406 | **0.651** | | 2023 | 0.158 | 0.191 |
| | | | | 2026 | 0.183 | 0.212 |

**结论**：`corr60` 的均值在 0.11（2021）到 0.60（2008）之间摆动，**跨度 5 倍**。
所以"相关性是个常数"是错的（分散化的效果时好时坏），但"下跌就相关"也是错的——
**只有极端下跌（月度 −10% 以下）才显著抬升相关性**。这条对组合风控的直接含义：
用"是否有下跌"当去杠杆信号太钝，要用"是否进入尾部"。

## 4. Q2：规则 R 的验证（判定：**未验证**）

### 4.1 触发情况——问题的根源

| 年 | 触发月数 |
|---|---:|
| 2008 | 3 |
| 2015 | 5 |
| 2016 | 2 |
| 2024 | 1 |
| **合计** | **11 / 146** |

平均仓位：**设计段 0.96 / 验证段 1.00**。

**为什么后半段完全不触发**：`vol_q80` 是 **expanding 分位**——2008 年那 80%+ 的年化波动一旦进入样本，
就把 80% 分位阈值永久抬到很高，此后十年的波动"再也算不上高"。
这是 **expanding 分位的结构性后果（危机记忆）**，不是规则写错了。

### 4.2 指标

| 段 | 策略 | CAGR | 波动 | MDD | Calmar | 累计 |
|---|---|---:|---:|---:|---:|---:|
| full | 满仓 | 12.30% | 27.33% | −71.53% | 0.172 | 827.1% |
| full | R 规则 | 11.64% | 25.58% | −71.44% | 0.163 | 727.3% |
| full | 固定半仓 | 6.98% | 13.66% | −45.15% | 0.155 | 265.0% |
| design | 满仓 | 27.61% | 33.68% | −71.53% | 0.386 | 939.0% |
| design | R 规则 | 26.29% | 30.89% | −71.44% | 0.368 | 839.8% |
| **valid** | **满仓** | **−1.19%** | 18.90% | **−40.86%** | **−0.029** | −10.9% |
| **valid** | **R 规则** | **−1.33%** | 18.80% | **−40.86%** | **−0.033** | −12.1% |
| valid | 固定半仓 | −0.15% | 9.45% | −22.38% | −0.007 | −1.4% |

### 4.3 判定（spec §4 三条全满足才算有效）

| 判据 | 结果 | 要求 | 通过 |
|---|---:|---:|---|
| ① MDD 改善 | **+0.00pp** | ≥ 3.0pp | ✗ |
| ② Calmar 提升 | **−0.003** | ≥ 0.10 | ✗ |
| ③ 年化不降超 | +0.14pp | ≤ 1.0pp | ✓ |

**→ 未验证。这条规则不能进任何策略。**

### 4.4 关键对照：它连"固定半仓"都打不过

验证段里固定半仓的 **MDD 是 −22.38%**（R 规则 −40.86%），CAGR −0.15%（R 规则 −1.33%）。
状态判断的增量为 **CAGR −1.18pp、Calmar −0.026**，即**负增量**。

> 注意：固定半仓本身**也没通过判据**（Calmar 提升只有 +0.022 < 0.10）——
> 因为 2016-2026 这个池的年化是负的，减半仓只是"少亏"，Calmar 分母（|MDD|）缩小得不够快。
> 这正好说明 spec §4 第 3 条（年化不降超 1pp）+ 第 2 条（Calmar 提升）是有效的护栏：
> **它能挡住"靠降敞口假装风控"的做法。**

## 5. 这份报告真正给出了什么（可复用的四条）

1. **波动率只能控敞口，不能预测收益方向**：高波动状态次月均值 +3.32%（不低），但 sd 放大 1.7 倍。
2. **历史分位阈值会随极端事件"钝化"**：2008 一旦进样本，expanding 80% 分位就把后续十年的规则废掉（触发 11/146）。
   要么改用**绝对阈值**（如年化波动 > 35%），要么用**波动率目标**（仓位 = 目标波动/已实现波动），
   但两者都是新的自由度，必须各自单独验证，**不能从这里顺势搬过去当结论**。
3. **相关性尾部效应是真的、日常效应是假的**：极端下跌月 corr 0.397 vs 0.301（p=0.017），普通下跌月无差异。
4. **同池等权在 2016-2026 的年化是 −1.19%**（含 240 只退市股）。这个基准近十年是亏的，
   任何"跑赢基准"的说法必须先扣掉这个背景。

## 7. 局限（spec §6 重申 + 新增）

1. 现金按 0 收益；等权组合隐含每日再平衡，**未计交易成本**；
2. `corr60` 用当日有价标的，极端月份（大面积停牌）样本变小、相关性被高估；
3. 532 只池含 240 只退市股，**退市过程本身推高组合波动**，与"市场状态"混淆。
   这解释了为什么 full 段 MDD 达 −71.53%——那更像"池子缩表"而不是指数级回撤；
4. 设计段/验证段各占 50% 是按**交易日**切的，不是按经济周期切；
5. 只验证了**一条**规则。这不代表"所有风控都无效"，只代表"这条没用"——
   但也意味着**不能**据此反推"风控无用"，那需要另一轮独立实验。
