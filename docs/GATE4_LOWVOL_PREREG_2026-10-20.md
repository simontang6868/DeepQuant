## 0. 为什么换假设，以及为什么**必须同时报分段**

### 0.1 换假设：文献先验 + 数据就绪

Gate 3 的结论是"短期反转在 2016 前存在、2016 后消失"。由此产生一个**更重要的新问题**：

> **2016 分界是"反转这个异象"特有的，还是整个 A 股横截面异象的共同现象？**

要回答它，需要一个**在文献里足够强、且在近十年仍然被报告为有效**的第二个异象作对照。
低波动是最合适的选择：

| 来源 | 结论 |
|---|---|
| Blitz, Hanauer & van Vliet (2021)《The volatility effect in China》, *Journal of Asset Management* | 2000-12 ~ 2018-12 A 股：**波动最低 1/10 跑赢最高 1/10 年化 12.9%**；控制六个学术因子后仍有 8.2%；VOL 因子在 FF-Carhart 诸因子中**独立表现最强** |
| 同上（Robeco 研究摘要） | 在**最大、流动性最好**的股票中依然显著；**换手率低**，可投资性好；不被动量/规模/价值/盈利/投资因子吸收 |
| 上引国际金融报综述（2025） | 低波动异象 **2015-2018 最突出**（超额 17.2%、波动 8.5%、夏普 >2） |
| Su (2025, NYU 荣誉论文，1995-2024) | 低 IVOL 股票**预测**下月更高收益（低 Beta 异象是同期的、IVOL 异象是**预测性**的）；**IVOL 异象随时间走强** |
| 中型样本研究（FF-3 / CH-3） | 高 E(IVOL) 组合月均收益显著低于低 E(IVOL) 组合 |

三条对本项目特别关键：

1. **效应量在可检出区间**：12.9%/年 ≈ **1.08pp/月**（decile 口径）；
2. **文献说它在 2015-2018 最有效**——那正好落在 Gate 2 判定"反转失效"的 2016+ 区间。
   **如果低波动也失效，说明是市场层面的机制变化；如果低波动仍在，说明 2016 分界是反转特有的**；
3. **只需价格数据**（ADJ），不需要财报、不需要市值、不需要 PIT 成分名单——
   这是本项目目前**唯一**能在现有数据上干净复现的横截面异象。

> ⚠️ 文献数字为二手引述，**未核验原始论文的样本、调仓频率与成本假设**。
> 本预登记**不把 1.08pp 当作预期值**，只用它确认量级落在可检出区间；判定只看本项目算出的 t。

### 0.2 为什么必须同时报分段（本预登记与前三份最大的不同）

前三份预登记都是"单窗口、单一主判定"。这次不行——**研究问题本身就是"有没有断点"**。

**分段结果作为"必报项"，并配一条跑前写死的判读规则**（§4.2），防止事后解读。

## 3. 信号与组合构造（全部预先写死）

| 项 | 设定 | 依据 |
|---|---|---|
| 信号 | `vol60 = std(过去 60 个交易日 ADJ 日收益) × √250`（年化） | Blitz et al. 报告 1 个月与 5 年的估计窗结论一致；取 60 日与本项目 Gate 1 的窗口一致 |
| 排序方向 | **做多 vol60 最低、做空 vol60 最高** | 低波动异象定义 |
| 组合 | `d = 0.5 × 等权(最低 k 只) − 0.5 × 等权(最高 k 只)`，自融资 | 与 Gate 2/3 同一口径，便于横向比较 |
| 持仓数 k | **110**（与 Gate 2/3 完全一致，不随池变） | 保持可比性 |
| 有效数据 | 60 日窗口内 ≥ 54 个有效交易日（90%） | 与 Gate 1/3 的 90% 规则一致 |
| 再平衡 | 月度（月末收盘定信号，持有至下月末） | 与前三份一致 |
| 权重 | 等权 | 与前三份一致 |

**不做的事**：不做市值中性、不做行业中性、不做 beta 中性（那是"低 beta 异象"，是另一个假设）、
不做波动率目标化的仓位管理（属 4.2 已验证的范畴）。每一项都是新自由度，要做就另开。

## 4. 判定判据（机械可执行，跑前冻结）

### 4.1 主检验（判定用，且**只有这一个**）

`d_m = r_多空,m`，H0: `E[d]=0`，H1: `E[d] > 0`（**单侧**，方向由文献先验给定）。
`MDE = 2.8016 × sd(d) / √n`（`2.8016 = z(1−α/2, α=0.05) + z(power=80%)`，与 Gate 2/3 同一约定）。

| 档位 | 触发条件（全部满足） | 标签 |
|---|---|---|
| **SUCCESS** | `n ≥ 200` **且** `MDE ≤ 1.42pp` **且** `mean(d) > 0` **且** `t ≥ 1.645` | 通过 |
| **INCONCLUSIVE** | `n < 200` 或 `MDE > 1.42pp` | 证据不足（**设计检不出**，不等于效应不存在） |
| **FAILURE** | 不满足 SUCCESS，且不满足 INCONCLUSIVE | 失败 |

### 4.2 必报项：2016 分段（**不参与判定**，但必须并列引用）

- 段 A = 信号月 **2007-01 ~ 2015-12**（预期 n = 108，与 Gate 3 同一窗口）
- 段 B = 信号月 **2016-01 ~ 2026-09**（预期 n ≈ 129，与 Gate 2 窗口近似）
- 报告两段各自的 `n / mean(d) / t / sd / MDE`，以及两段的 **Welch t 与 p**（双侧）

**跑前写死的判读规则**（四选一，逐字照抄进报告，不得临场改写措辞）：

| 条件 | 报告措辞 |
|---|---|
| 两段差 p ≥ 0.05 且两段均 `t ≥ 1.645` | **"效应跨段持续"** |
| 两段差 p < 0.05 且仅段 A 达 `t ≥ 1.645` | **"效应在 2016 后断裂"** |
| 两段差 p < 0.05 且仅段 B 达 `t ≥ 1.645` | **"效应在 2016 后才出现"** |
| 其他 | **"不足以判断是否存在断点"** |

> 为什么不给分段结果一个 SUCCESS/FAILURE 标签：两次判定的家族规模是 2，
> 会同时抬高假阳与"挑一个报"的风险。**主判定只有全段一个**，分段只按上表措辞定性。

## 8. 已知局限（跑前如实声明）

1. **池按 2026 年信息选取**（532 只 = 今日沪深300 成分 + 曾退市股），偏差方向不可先验确定，
   结论只能落在"本池"，**不可外推全市场**；
2. **无 PIT 成分股**：本异象不依赖财报，但池本身仍带选择偏差；
3. **无成交额过滤**：低波动腿可能包含流动性极差的股票；
4. **未对 beta / 市值 / 行业做中性化**——文献说 VOL 因子不被这些因子吸收，
   但本项目**没有**做这个检验，不能引用文献替自己背书；
5. **成本未计入判定**；
6. **文献数字未核验原始论文**。
