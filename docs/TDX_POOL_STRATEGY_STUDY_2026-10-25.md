## 2. ⚠️ 诊断二（新发现，致命）：前复权价格可以为负

把窗口从 4.5 年拉长到 17 年（月线）时，前复权序列出现**负价格**：

| 标的 | 前复权月线最低收盘 | 负值根数 / 总根数 |
|---|---:|---:|
| 工商银行 | **−1.47 元**（2006-10） | 43 / 241 |
| 潞安环能 | **−5.98 元**（2006-09） | 47 / 242 |
| 中国建筑 | −0.22 元（2010 区间） | 54 / 208 |
| 海油工程 | −0.02 元 | 1 / 260 |
| 中海油服 | 5.95（未穿零） | 0 / 230 |

**机理**：乘性前复权（= 分红按除权日再投资）把历史价按累计分红因子向下压。高股息标的在长窗口上，累计分红一旦超过早期股价，复权价就穿零。

**为什么交接文档没踩到**：它只跑 2022-04 → 2026-10（4.5 年），复权价尚未穿零。**任何把窗口拉长到 10 年以上的尝试都会爆炸**，而且症状不是报错，是"年化 −2633%"这类荒谬数字（我第一次跑就得到了 +166564%）。

**处置（已验证）**：改用 **后复权 `tqFlag=2`** 拉长窗口，5 只票全部为正（工行 3.30~13.54、潞安 13.29~152.02），结果立刻合理。

> ⛔ **新铁律**：前复权只能用于**短窗口**（且必须先扫一遍负值）；**长窗口一律用后复权**。跨周期比较不可混用。这条应补进交接文档 §4。

## 4. 对交接文档"参数敏感性红灯"的重新解读

原文：(16,48)=+6.83% → (20,60)=+21.81% → (24,72)=+33.68%，单调递增无平台，判为过拟合红灯。

**我认为这里还有一层更重要的信息**：参数越大 = 均线越长 = 交易越少 → 结果越好。把这个趋势外推，**极限就是"完全不交易"**，而"完全不交易"正是买入持有（+115.10%）。

→ 单调性不只是"过拟合警告"，它是在**指向答案**：**在这个样本上，最优交易量是零。**
§3 的长窗口检验（−2.88pp / −4.45pp）与这个指向一致。两条独立证据得出同一结论。
