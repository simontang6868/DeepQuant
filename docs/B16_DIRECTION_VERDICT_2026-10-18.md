## 2. 三个选项

### 选项 ① —— 换策略族 / 引入新因子

**做什么**：引入第三类信号（截面动量、波动率因子、基本面因子、多因子组合等），或转向截面/组合级研究。

| 维度 | 评估 |
|---|---|
| **成本** | **高**。当前研究层是**单标的 walk-forward**，而可信的因子研究需要：截面池的**时点成分快照**（否则幸存者偏差）、因子计算与标准化、组合构建与再平衡、连续账户收益曲线。这基本等于**重建研究平台**，不是加一个策略文件。数据侧还可能需要基本面/指数成分历史（当前数据源只有日线行情）。 |
| **风险** | **高，且性质不是「不确定」而是「不可测」**。见下方 §3.1。 |
| **上行** | 唯一有可能找到 alpha 的路径。外部文献对 A 股截面因子（价值 / 动量 / 质量 / 低波 / 特异波动率）有可复制证据。 |
| **前置条件** | 必须先解决 F5 / F8 / F10 / R12 四项结构性缺陷，否则新族跑出来的是**不可解释的零**。 |

### 选项 ② —— 承认无稳定 alpha，收尾当前研究线

**做什么**：停止在该设计空间内继续投入，产出结题报告（完整证据链终稿），并把「若要重启必须先修什么」写清楚。

| 维度 | 评估 |
|---|---|
| **成本** | **低**（一份文档，本轮即可交付）。 |
| **风险** | 放弃潜在 alpha。但**注意精确表述**：本选项承认的是「**在本设计空间内没有找到、且现有装置无法可靠测量**稳定 alpha」，**不是**「A 股无 alpha」。 |
| **上行** | 诚实结题；证据链与失败记录完整保留（R5），未来重启不必重走 15 轮。 |
| **可逆性** | **完全可逆**——结题报告本身就是重启的设计文档。 |

### 选项 ③ —— 改进现有策略（守 R2/R11，禁调参）

**做什么**：在 `ma_cross` / `mean_reversion` 框架内做结构性改动（仓位规则、退出规则、状态过滤等），不动参数网格。

| 维度 | 评估 |
|---|---|
| **成本** | **中**。 |
| **风险** | **高，且被证据直接否定**。见下方 §3.2。 |
| **上行** | 低。 |
| **前置条件** | 任何「结构性改动」的评估都要用同一段 OOS 数据 → 天然踩 R2/R11 雷区。 |

## 3. 为什么排除 ① 和 ③（这是本裁决的核心）

### 3.1 排除 ①：不是「有风险但值得一试」，是「**现有装置测不出来**」

这是本轮最重要的判断，也是它与「再试一次」的分界线。

四个叠加的**测量层面**缺陷（不是策略层面的）：

| 缺陷 | 后果 |
|---|---|
| **R12**：全部产出是**窗口级独立收益**，窗口之间不衔接 | **无法回答「这套东西能不能赚钱」**——没有连续账户曲线，就没有可实现回报的度量 |
| **F5** 事件稀疏：单窗口 0.6~1.9 笔成交 | 任何信号的统计功效都被压到极低；零假设与「真没信号」不可区分 |
| **F8** 可负担性断崖：10 万本金 + 满仓 + 100 股整手 | 高价股**完全不可交易**，样本内已非随机缺失 |
| **F10** 幸存者偏差 + 高分红被剔除 | 池子偏乐观且非随机缺失 |

**推论**：在这个装置上跑第三类信号，得到的「零」无法区分「信号无效」与「装置测不出来」。
也就是说 ① 在当前形态下的产出是**不可解释的**，而不只是**不确定的**。

要让它可解释，必须先做平台级改造（时点成分快照、连续账户回测、组合级仓位、真实成本模型）——
**那已经是一个新项目的立项决策，需要独立的预算与时间表，不该作为「换个信号接着跑」被默认通过。**

### 3.2 排除 ③：证据直接否定了它仅剩的抓手

| 常见改进动作 | 证据 | 判定 |
|---|---|---|
| 调网格 / 换阈值 | F1：亏损**均匀分布**在各窗口，不是参数没选好 | 无效 |
| 加止损 / 管尾部 | F1：分布**对称**（\|均值\|−\|中位数\| 在 ±1pp 内） | 无效 |
| 降费率假设 | F1：最低成本档（simulation）下**已经是** 56.5% 窗口亏损 | 无效 |
| 提高参与率（min_trades） | B8 实测：参与率↑ 时单笔质量↓（−0.0026 → −0.0225） | 反向 |
| 换仓位 / 退出 / 状态过滤 | 这些**不是参数而是新设计** → 本质上是 ①，但先验更差 | 归入 ① |

再加上 **禁调参（R2/R11）** 直接移除了 ③ 的主要杠杆，
而剩下的杠杆要么已被实测否定，要么本质上属于 ①。
**③ 是三个选项中唯一「既贵、又被证据直接反对」的。**

## 4. 倾向性推荐

> ## 推荐 **选项 ②**：承认在当前设计空间内无稳定 alpha，收尾当前研究线，产出结题报告。

### 4.1 推荐理由（按权重排序）

1. **两个策略族都已在该设计空间内被证伪，且机制清楚**（F1 方向错、F2 无幅度边际）。继续在已被证伪的空间里搜索，边际收益接近零。
2. **装置测不出第三类信号**（§3.1）。① 不是「值得一试」，是「得先重建平台」——这是立项决策，不是延续决策。
3. **③ 被证据直接否定**（§3.2），且禁调参后已无主要杠杆。
4. **② 完全可逆**：结题报告把证据链、失败记录、重启前置条件全部固化，如果日后决定投入 ①，不必重走这 15 轮。**选 ② 的成本几乎只有一份文档，选错的成本也只是延迟，不是损失。**
5. **诚实性**：继续跑下去最可能的结果是再得到一批「零」，然后被读成「信号无效」——而真因可能是装置。这比结题更糟。

### 4.2 推荐的精确表述（避免被误读）

- ✅ 「在单标的 · 日线 · 价格类技术信号 · walk-forward · 8 年 · 沪深300 池这个设计空间内，**未找到可交易 alpha**，且现有装置**无法可靠测量** alpha。」
- ❌ **不是**「A 股没有 alpha」。
- ❌ **不是**「均线/均值回归在所有市场、所有周期、所有标的上都无效」。
- ❌ **不是**「量化研究不值得做」。

### 4.3 什么时候应该推翻这个推荐（**预先登记，不事后调整**）

| 触发条件 | 应当改选 |
|---|---|
| 用户愿意投入**平台级改造**（时点成分快照 + 连续账户回测 + 组合级仓位 + 真实成本模型）的预算与时间 | ①（此时①的「不可测」风险已被消解） |
| 出现了**非价格类**的、可信且**时点对齐**的数据源（基本面 / 指数成分历史 / 另类数据） | ① |
| 有人能证明 R12 的窗口级统计**可以**重构为连续账户收益且成本可核 | ①，且优先级最高 |
| 结题报告审阅中发现本裁决遗漏了某条已落盘的相反证据 | 重开 B16 |
