## 0. 这个实验要回答什么

Gate 6 的 `d` 需要做空腿，而 A 股个股做空基本不可得（M4 结构阻塞）。
本实验只买多头腿，用等权基准减掉市场收益，问：

> **去掉空头腿之后，反转还剩多少 alpha？**

**不回答**：反转能不能赚钱（容量、冲击成本、T+1 仍未建模）。

## 1. 多头组合（与 Gate 6 / 阶段 C 的 D 格完全一致，不含任何新参数）

| 项 | 写死取值 |
|---|---|
| 池 | as-of 全 A：252 日门槛、ADJ/EXEC 双覆盖、纯 A 股 |
| 信号 | `score = close(t−1)/close(t−21) − 1` |
| 选股 | **最低分的 k 只**（做多输家） |
| k | `max(1, min(round(0.20 × n_pool), n_pool // 2))` |
| 交易约束 | 建仓日涨停/一字板 → 剔出（阶段 C §5） |
| 收益 | `fwd = ffill(nxt)/ffill(pos) − 1` |
| 窗口 | 信号日 **2007-01-01 ~ 2026-09-30** |

**与 Gate 6 的唯一差别：没有空头腿。** 因此多头持仓必须与阶段 C 的 D 格**逐位一致**。

### 1.1 V0 复现要求（前置，不过即拒跑）

阶段 C 的 D 格 `mean(d) = 0.65818965`、`spread = 1.31637930`、`t = 4.11104858`。
本实验的 `longs_c` 必须是阶段 C D 格 `longs_c` 的**同一个集合**（逐月比对，不允许差集）。

## 2. 基准

```
R_bench,t = mean( fwd_i,t )   对当月池内全部可投资标的 i
```

- "池内全部" = 当月能算出信号**且**有前瞻收益的标的集合，即 `month_rows` 里的 `pool`（与 `n_pool` 同源）
- **等权**，不用市值加权（本项目无流通市值数据）
- **同一个月、同一个 `fwd` 定义**，不做任何额外调整

### 2.1 为什么用等权而不是指数

1. 零新增数据依赖——本实验要回答的是**构造问题**，引入新数据源会把数据问题混进来；
2. 等权基准 = "在池里随机等权选股"的期望收益，是 alpha 的**天然零假设**；
3. 中证全指（000985）作为**对照**单独报（若能取到），不参与判定。

**局限（必须写进报告）**：等权基准不是可投资的指数，没有对应 ETF；
它系统性偏小盘，与"市场收益"的直觉不同。

## 3. 主检验

```
alpha_t = R_long,t − R_bench,t
H0: E[alpha] = 0
```

- **算术差**，不是几何差（几何差会引入"波动拖累"，那是另一个问题）
- **双侧**检验：方向先验已被 Gate 2 部分否证（2016 后在定名单池上为负），不能假设一定为正
- **Newey-West 滞后 3**
- 窗口 2007-01 ~ 2026-09，配对月份预期 237

### 3.1 判据（四档，机械判定）

| 档位 | 条件（全部满足） |
|---|---|
| **LONGONLY_ALPHA_CONFIRMED** | `n ≥ 150` **且** `\|NW t\| ≥ 1.96` **且** `\|alpha\| ≥ 0.30 pp/月` |
| **LONGONLY_ALPHA_SMALL_BUT_SIGNIFICANT** | `n ≥ 150` **且** `\|NW t\| ≥ 1.96` **且** `\|alpha\| < 0.30 pp/月` |
| **LONGONLY_ALPHA_NOT_DETECTED** | `n ≥ 150` **且** `\|NW t\| < 1.96` |
| **INCONCLUSIVE** | `n < 150` 或 NW 有效样本 < 100 |

0.30pp/月 = 阶段 C 的经济门槛 = 月度成本（@0.1% 单边）的两倍。
**连两倍成本都不到的 alpha，扣完成本什么都不剩。**

## 4. 必须同时报的三件事

### 4.1 成本后 alpha

```
月度成本 = 2 × 单边换手 × 费率        （×12 是年化，不许当月度扣——阶段 C 出过这错）
```

换手**实测**（权重漂移法），不套用"月度全换手"。两档费率 0.1% / 0.3%。

### 4.2 容量

```
lot_i      = 100 × close_exec(i, entry_t)      （一手成本，元）
W_1lot,t   = Σ_i lot_i                          （每只买 1 手的资金）
W_equal,t  = k_t × max_i lot_i                  （等权且每只 ≥1 手的资金下限）
```

报 `W_1lot` 与 `W_equal` 的**中位数与 P90**。若 `W_equal` 中位数 > 1,000 万，
则"等权 + 整手"在小资金下不可实现，须在小资金场景里放弃最贵的几只（另一套规则，本实验不做）。

### 4.3 beta

`beta = OLS(R_long ~ R_bench)` 的斜率（时间序列，月度）。

**只报，不中性化。** 中性化要选 beta 估计窗口，那是一个新的自由参数；
本实验不做，且**事后也不许用"中性化后就显著了"来救结论**。

## 5. 诊断（描述性，不参与判定）

| # | 诊断 | 目的 |
|---|---|---|
| D1 | 多头绝对收益 `mean(R_long)` 与基准 `mean(R_bench)` | 看 alpha 是"多头跑赢"还是"基准跑输" |
| D2 | 月度胜率：`R_long > R_bench` 的月份占比 | 检验是否靠少数月份 |
| D3 | 2007-2015 / 2016-2026 分段 alpha | 与 Gate 2/3/6 的分段结论对照 |
| D4 | 分年度 alpha | 稳定性 |
| D5 | `R_long` 与 `R_bench` 的相关系数与 beta | 判断 alpha 是否只是 beta 暴露 |
| D6 | 多头腿与空头腿收益之差（即 `2d`）| 验证"alpha 小于 spread"这个预期 |

## 6. 预期方向

- `mean(alpha) > 0` 且 **小于** Gate 6 的 `spread`（1.42pp）。理由：去掉一条腿等于去掉一半信息。
- `beta` 预期 **> 1**（输家 beta 高），若确实如此，alpha 里有一部分是"承担更多市场风险"的补偿，
  必须在报告里说清。
- 若 `alpha` 不显著：说明 Gate 6 的效应主要来自空头腿（"赢家回落"而非"输家反弹"）。
  **这是一个有价值的否证，必须如实报告，并意味着单边多头这条路走不通。**
