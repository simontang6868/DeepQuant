## 0. 需要先解决的一个技术点：信号该用价格还是全收益？

「远高于均线」判断的是**价格位置**，不是累计财富。而分红再投会让全收益序列持续上抬，
从而给 `价/MA12 − 1` 带来系统性偏高的偏移。

**实测（2022-01 ~ 2026-10，n=46 个月）**：

| 序列 | state 均值 | 中位 | 最大 | 最小 |
|---|---:|---:|---:|---:|
| 全收益 H00922 | **+4.40%** | +4.78% | +13.83% | −8.34% |
| 价格 000922 | **+1.60%** | +1.76% | +9.49% | −10.41% |

差值 **2.80pp**，与「股息率 5.58% ÷ 2 ≈ 2.79pp」（MA12 平均滞后半年）吻合。

**结论：B 的主口径信号必须用价格指数 000922。** 用全收益指数会把「分红累积」误读成「涨太多了」，
导致长期误减仓。这条是实测得出的，不是假设。

> 由此带来一个必须声明的后果：本项目早期分档表（`MEMORY.md` §7「状态—收益单调」）是在**总收益口径**下算的，
> 其「>+8%」约等于价格口径的「>+5.2%」。本预登记主口径阈值取 **+5%（价格口径）** 正是这个映射，
> 不是从多个阈值里挑出来的。

## 1. 研究问题与判据

**问题**：月末价格指数 state > θ 时把仓位从 100% 降到 w，state ≤ θ 时回满，能否让 Calmar 明显改善
且年化不明显下降？

**基准**：100% 持有中证红利全收益指数（= 买 ETF 且分红再投，与 A 的执行形态一致），同期同窗口。

| 判据 | 阈值 | 说明 |
|---|---|---|
| **G1 Calmar** | ≥ **0.576**（基准 0.48 × 1.2，即改善 ≥20%） | 主判据：风险调整后收益必须实质改善 |
| **G2 年化** | ≥ **6.04%**（基准 7.04% − 1.0pp） | 允许为降回撤付 1pp 年化的代价，但不能更多 |
| **G3 日频 MDD** | ≥ **−12.53%**（基准 −14.53%，改善 ≥2pp） | 减仓若连 2pp 回撤都换不来，就不值得做 |

判定用语：
- 三条全过 → `HEDGE_SIGNAL_USABLE`
- G1/G3 过、G2 不过 → `HEDGE_COST_EXCEEDS_BENEFIT`
- G1 不过（无论 G2/G3） → `HEDGE_SIGNAL_NO_EDGE`
- 空仓月数 > 50% → 额外标注 `MOSTLY_OUT_OF_MARKET`（这不是择时，是离场）

## 2. 规则定义（跑前冻结）

| 项 | 定义 |
|---|---|
| 信号 | `state_m = 价格指数月末收盘 / 其已完结 12 个月末均值 − 1`（000922） |
| 决策 | 每月最后一个交易日收盘后 |
| 调仓 | **次月第一个交易日收盘**执行（不用信号当日收盘成交） |
| 仓位 | `state_m > θ` → 仓位 w；`state_m ≤ θ` → 100%（无缓冲带，见 §5 局限 3） |
| 现金收益 | 0（不计利息，保守） |
| 成本 | 每次调仓按变动金额收 **单边 0.051%**（ETF 实际无印花税，此处偏保守） |
| 窗口 | 决策 2023-01 ~ 2026-09，持仓 2023-02 ~ 2026-10，日频估值 |
| 主口径 | **θ = +5%，w = 0%** |
| 对照 | θ ∈ {+5, +8, +10, +12}% × w ∈ {0%, 50%} |

## 3. 预期方向与机制（写在跑之前，建立在可算的量上）

**预期：B 会失败，判定为 `HEDGE_COST_EXCEEDS_BENEFIT` 或 `HEDGE_SIGNAL_NO_EDGE`。**

机制（不是直觉，是可算的推论）：

1. 早期分档显示「>+8%（总收益口径）」档后续 12 个月中位收益是 **+2.44%**——**正的**，不是负的。
   减仓等于**放弃一段正收益**去换回撤，性价比取决于回撤改善幅度。
2. 2023-2026 是红利上行期，state 长期在阈值上方 → 减仓会变成**长期低仓位**，
   系统性错过涨幅。可算的判据：`state > θ` 的月份占比，若 > 40%，则减仓在数学上就是「少赚」。
3. W10 已证「全样本规律在现代段失效」（`T_FRAGILE` 同模式），状态单调性很可能也是全样本幻觉。

**证伪条件（若成立则 B 可能有效）**：`state > θ` 月份的后续 1 个月收益**显著低于**
其余月份，且**回撤集中发生在这些月份**。两个条件必须同时满足。

## 4. 必须报的诊断量

- `state > θ` 的月份数 / 占比 / 最长连续月数
- 调仓次数（进出各几次）与累计成本
- 减仓期间的指数收益（错过多少）
- 分组收益差：`state > θ` 月份 vs 其余月份的次月收益（均值、t、n、MDE）

## 5. 已知局限（不隐瞒）

1. **样本内**：阈值映射来自 2007-2026 全样本分档，2023-2026 本就在其中，不能当有效性证据。
2. **3.72 年只有 45 个决策点**，按 `MEMORY.md` §12（36 月功效 21%）不足以识别小幅改善。
3. **无缓冲带**：state 在阈值附近震荡会导致频繁进出。本预登记坚持无缓冲（避免引入一个额外可调参数），
   但必须报进出次数；若次数异常多，作为结论的限定条件写进报告，不临时改规则。
4. **现金收益按 0**：实际可拿货币基金约 1.5~2%/年，这会让减仓变体**偏低估**。此偏差方向已知。
5. **只减不加**：本阶段只检验「高位减仓」，不检验「低位加仓」（那会与 W10 已被否决的规则重复）。
