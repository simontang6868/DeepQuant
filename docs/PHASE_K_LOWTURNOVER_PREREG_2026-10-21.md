# 阶段 K 预登记：低换手版本的 exQ5（换手—alpha 权衡）

> **冻结时间** 2026-10-21 15:15（跑前冻结，`docs/PHASE_K_LOWTURNOVER_PREREG_2026-10-21.sha256`）
> **上游** 阶段 I（`8f5c3512`）`alpha_V1 = +0.163411pp`、阶段 J（`f76de8a2`）归因：佣金占 69%
> **本阶段回答** 把换手降下来，佣金省下的钱能不能超过信号变陈旧的损失？

## 0. 动机（一个数字）

阶段 J 的归因：

```
起点 alpha_V1          +0.1634pp
佣金 @0.3%（换手 18.3%） -0.1127pp   ← 占 69%
现金残留（W=3000万）     -0.0075pp
冲击（Amihud）          -0.0008pp
─────────────────────────────────
净                     +0.0424pp   t=+1.269
```

**换手是唯一没动过的杠杆。** 阶段 I 实测 `Q5` 成员与上期的重叠只有 **36.5%**——
说明每月的换手里有相当一部分是"翻来覆去"（进出 Q5 边界附近），而不是真的换了标的。

## 1. 构造（写死，与阶段 I 完全一致的部分）

| 项 | 值 |
|---|---|
| 信号 | MAX5 = 21 日窗口内最大 5 个日收益的均值（与阶段 F/I 同定义） |
| 分组 | 池按 MAX5 等频 5 组，**排除 Q5（最高 20%）** |
| 池 | as-of 全 A，`MIN_LISTED_DAYS = 252` |
| 样本 | 月末信号，`2007-01-01 ~ 2026-09-30` |
| 可成交约束 | 与阶段 I 的 V1 相同：建仓日涨停 / 一字板向上 / 停牌 / 序列已终止 → 剔除 |
| 基准 | 池内等权 |

**上面任何一项都不得改动。**

## 2. 唯一的变量：调仓周期

在**同一批信号点**上，每 `m` 个月调仓一次：

```
m ∈ {1, 2, 3, 6}
```

- `m = 1`：每月调仓 = 阶段 I 的 V1（**复现基准**）
- `m > 1`：在第 `j·m` 个信号点按当时的信号重新选股并建仓，**持有 `m` 个月不动**

调仓周期是**唯一变量**。`m` 取 1/2/3/6 四档**全部报告**，不许挑最好的。

## 3. 观察量与统计量

- 每个 `m` 都产生一条 **237 个月的月度收益序列**（不是 `m` 月持有期收益）——
  这样四个变体在同一时间轴上、样本量相同，可以直接比较。
- `alpha_t = 组合月度收益 − 池等权月度收益`
- 组合月度收益 = 当前持仓篮子中**有价格的**标的等权平均
  （停牌/退市导致该月无价格的标的，当月剔除并计数报告，不许静默当 0 收益）

### 3.1 标准误：四档统一用 NW(6)

⚠️ 与阶段 I/J 的 NW(3) 不同，理由写在跑之前：

`m > 1` 时同一个篮子被持有 `m` 个月 → 相邻月份的收益因**共享篮子**而相关，
自相关可延伸到 `m−1` 阶。`m = 6` 时需要覆盖到 5 阶。

→ **四个变体统一用 NW(6)**（不按 `m` 各自选滞后阶数，那等于给每个变体调一个参数）。
→ 同时报 NW(3)（与阶段 I/J 可比）和 iid，三个都报。

### 3.2 换手与佣金

调仓时一次性换手 `churn_j = 0.5 × (|新−旧| + |旧−新|) / k_j`，
摊到该篮子持有的 `m` 个月上：`to_t = churn_j / m`。

`comm_t = 2 × to_t × 0.003 × 100`（pp/月）。

### 3.3 净值

与阶段 J 同口径，**固定 W = 3,000 万**（阶段 J 的最好档）：

```
net_t = f_inv,t × alpha_t  −  comm_t  −  impact
```

- `f_inv,t`：调仓日用阶段 I/J 的 `capacity_of` 规则算，整个持有期沿用；
- `impact`：**不重算**，直接沿用阶段 J 在 W=3,000 万、月调仓下测得的 **0.000784pp**
  作为**上界**——本阶段换手只会更低，冲击只会更小。这个单调性论证写在跑之前。

## 4. 判据（预登记写死）

令 `t(m)` = `net_t(m)` 的 NW(6) t 值，`net(m)` = 其均值。

| 条件 | 内容 |
|---|---|
| **A 统计** | `\|t(m)\| ≥ 1.96`（NW(6)） |
| **B 稳定** | 两段（2007-2015 / 2016-2026）各自符号与全样本一致 **且** `\|t\| ≥ 1.96` |

### 4.1 三态（按顺序判定）

| 判定 | 条件 |
|---|---|
| `LOW_TURNOVER_RESCUES` | **存在** `m > 1` 同时满足 A ∧ B |
| `LOW_TURNOVER_INSUFFICIENT` | 没有 `m` 满足 A∧B，但 `max_{m>1} net(m) > net(1)` |
| `LOW_TURNOVER_NO_GAIN` | `max_{m>1} net(m) ≤ net(1)` |

**不许把"某个 m 的 t 最大"当成结论**——必须同时过 A 和 B。

## 5. 预期方向与机制（写完再跑）

### 5.1 预期：`LOW_TURNOVER_RESCUES`，且落在 `m = 2` 或 `m = 3`

这个预期是**算出来的**，不是凭直觉（阶段 J 的教训：用可算的量判断）。

**省下的佣金**（换手近似 ∝ 1/m）：

| m | 换手 | 佣金 |
|---|---:|---:|
| 1 | 18.3% | 0.1127pp |
| 2 | ~9.2% | ~0.0564pp |
| 3 | ~6.1% | ~0.0376pp |
| 6 | ~3.1% | ~0.0188pp |

**损失的 alpha**：Q5 成员与上期重叠 36.5% → 边界附近的标的反复进出。
持有 `m` 个月后，篮子的信号年龄平均为 `(m+1)/2` 个月。
粗估 alpha 保留率 ≈ `0.65^(m−1)`（用 36.5% 的持续率粗推）：

| m | alpha 保留 | alpha | 佣金 | **净** |
|---|---:|---:|---:|---:|
| 1 | 100% | 0.1634 | 0.1127 | **+0.0507** |
| 2 | 65% | 0.1062 | 0.0564 | **+0.0498** |
| 3 | 42% | 0.0686 | 0.0376 | **+0.0310** |
| 6 | 12% | 0.0196 | 0.0188 | **+0.0008** |

⚠️ 按这个粗算，**m=2 打平、m≥3 变差** —— 与 §5.1 的预期**相反**。

**所以正式预期改为（以算出来的为准）：**

> **预期 `LOW_TURNOVER_INSUFFICIENT`**：换手降下来省的钱，
> **追不上** Q5 边界反复进出带来的信号衰减。
> 最好档仍将是 `m = 1`（或 `m = 2` 与之基本持平），净值与阶段 J 的 +0.0424pp 同量级。

### 5.2 为什么这个预期值得跑

如果 §5.1 成立，那说明 **exQ5 的 alpha 是"高频的"**——它依赖每月紧跟 Q5 边界的变动；
一旦放慢，效应就消失。这本身就是一条关于该信号性质的重要结论：
**它不是可以低频持有的价值型信号，而是必须高频跟踪的状态信号。**

### 5.3 预期失败模式（写下来）

若要翻盘，必须是：Q5 边界的进出**大部分是噪声**、而真正的"高 MAX5"状态是持久的。
那样低频调仓能滤掉噪声、几乎不损失 alpha，净就会显著上升。
本阶段不对这一点做任何选择性处理——只报四档的结果。

## 6. 诊断（必报）

1. 四档的**换手、佣金、alpha、净、t** 对照表；
2. **alpha 保留率** `alpha(m) / alpha(1)` —— 检验 §5.1 的 `0.65^(m−1)` 猜测；
3. **Q5 边界进出的持续性**：每月进出 Q5 的标的，下月是否又回去（"翻来覆去"的比例）；
4. 两段的净值与 t；
5. `m = 1` 必须**复现阶段 I 的 V1**（逐月对账）。
