## 5. ⭐ 两条结构性结论 + 一条修正

### 5.1 横截面异象天然是「空头侧现象」

A 股个股做空基本不可得 → 高估无法被套利（空头侧有收益）、低估无集中买入力量推动（多头侧微弱）。

| 信号 | 多空价差 | 单边 alpha | **ratio** |
|---|---:|---:|---:|
| 21 日反转（阶段 E） | 1.3164 | +0.2767 | **0.21** |
| MAX5（阶段 G） | 0.7405 | +0.1813 | **0.24** |

两个毫不相干的信号，单边都只能拿到 **1/5 ~ 1/4**。
→ **以多空价差筛因子、再指望单边落地，这条路系统性不成立。**
→ 最硬的证据：阶段 F 里效应最强的 L5 层（层内价差 +1.9155），**单边 alpha 是 −0.0144（=0）**——那 1.92pp 全部来自 Q5 大跌。

### 5.2 「避免型」比「买入型」稳健（⚠️ 已修正）

- 阶段 G **买** Q1（最低 MAX5）→ +0.18，2016 后**归零**
- 阶段 H **不买** Q5（最高 MAX5）→ +0.23，2016 后**不动**

→ 同一信号上，避免型比买入型稳定。

⚠️ **修正（阶段 L）**：SURGE **也是**避免型动作（排除最高 20%），但它**衰减了**（+0.1764 t=3.71 → +0.0472 t=1.04，−73%）。
→ 正确表述：**exQ5 的稳定性是它自己的性质，不是"避免型"这个动作类型保证的。**
   5.2 的观察**只在"同一信号内部比较"时成立**，不许外推成"任何避免型信号都不衰减"。

### 5.3 ⭐ 两个独立信号的同一结论

| | exQ5 | SURGE |
|---|---:|---:|
| 毛 alpha（理想） | 0.2307 | 0.1858 |
| 可成交 alpha | 0.1634（−29%） | 0.1061（**−43%**） |
| 换手 | 18.3% | **24.09%** |
| 佣金 @0.3% | 0.1127 | 0.1446 |
| **净** | +0.0507 | **−0.0385** |

> **纯价量空间里，不存在成本后 ≥0.30pp 的单边 alpha。**

且三条独立分析一致：冲击成本不是约束（阶段 J）、降换手救不了（阶段 K）、第二个信号同样为负（阶段 L）。

## 11. §10 自查结果

### 11.1 §10.1 聚合方式：**结论稳健**，且独立重算逐位复现

用**独立的重算**（非阶段 F 的代码）对 MAX5 重做分层，五种聚合规则全报不挑：

| 聚合规则 | Δ | t | 显著 |
|---|---:|---:|---|
| i 按层大小加权（**阶段 F 原口径**） | **+0.7405** | **+3.409** | ✓ |
| ii 各层等权 | +0.7407 | +3.410 | ✓ |
| iii 各层取中位数 | +0.6252 | +2.936 | ✓ |
| iv 只用 L2~L4（**去掉最低与最高波动层**） | +0.6935 | +2.662 | ✓ |
| v 全池不分层 | +1.0800 | +4.160 | ✓ |

- **i 与 v 逐位复现阶段 F**（0.7405 / t=3.409；1.0800 / t=4.160）→ 实现无误。
- **iv 是关键**：即使**同时去掉**最低波动层（那个 Δ 为负的层）和最高波动层，
  Δ 仍有 **+0.6935（t=2.662）** —— 所以"最低波动层为负"**没有**撑起结论。
- → **§10.1 的质疑不成立**：汇总方式的选择不改变结论。
