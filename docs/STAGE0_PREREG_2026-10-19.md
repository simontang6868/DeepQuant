## 1. 为什么做这个

`docs/PIT_EXPANSION_PROJECT_2026-10-19.md` §2① 说了一句关键的话：

> 偏差修正的价值与信号强度成正比 —— 信号是 0 的时候，修正的也是对 0 的估计。

这句话是对的，但它推出的是"**现在不值得花钱买 PIT**"，**不是**"偏差不存在"。
两件事必须分开：

| 命题 | 现在能不能回答 | 靠什么回答 |
|---|---|---|
| 买 PIT 值不值 | 不能（T1 闸门未开） | 等 `CONSISTENT`/`IMPROVED` |
| **幸存者偏差有多大** | **能**，且零成本 | **本探针** |

所以本探针的定位是：**在决定要不要为 PIT 付钱之前，先把"不付钱能测到的那部分偏差"测出来**。
如果这批退市股上的表现与在市股没有差别，那"偏差撑高结论"这个担忧本身就该降级；
如果差别很大，那 §2① 的"信号为 0"也可能有一部分是"幸存者池制造出来的假信号为 0"。

## 2. 设计（冻结）

| 项 | 取值 | 来源 |
|---|---|---|
| A 组（在市） | `csi300_50.json` 的 50 只 | 2026-10-17 抓取的 000300 当日成分，等距抽样 |
| B 组（退市） | `DELIST_UNIVERSE_2026-10-19.json` 中 `delist_date >= 2017-01-01` 的全部 | akshare 沪深退市名单，262 只全部拿到 qfq |
| 策略 | `ma_cross` | 与 `research.py` 同一实现 |
| 参数网格 | fast `(3,5,10,20)` × slow `(15,25,40,60)`，`min_train=150`，`min_oos=75`，`min_trades=2`，`max_combinations=50` | **逐项复制 `MA_GRID`，一个不改** |
| 费率 | `simulation_placeholder` | 与 OOS 检验同档 |
| 初始资金 | 100,000 | 与历史全部结论一致（茅台买不起的根源） |
| 区间 | 2017-01-01 ~ 2024-12-31 | 与 `b50_v3` 历史口径同区间，可作装置校验 |
| 涨跌停 | `board` 模式 | v3 已接线，逐标的解析 |

**为什么两组并集就是"时点无关池"**：每只标的只在"自己第一根 K 线到最后一根 K 线"上跑。
退市股的最后一行就是它的退市日，所以"某个时点池里应该有谁"这个问题被**行情文件本身的边界**回答了，
不需要额外的装配层。这是阶段 0 能零成本成立的核心原因。

## 3. 判据（机械，不看结果也能预先说出）

观测单元 = 每只标的每个 walk-forward 窗口的 `cumulative_return`，且须满足
`selection_success & oos_success & final_equity is not None & oos_is_complete`。
检验 = **Mann-Whitney U 单侧（B < A）**，α = 0.05，效应量 = `median(B) − median(A)`。

| 编号 | 判定 | 条件 | 含义 |
|---|---|---|---|
| S0 | `INSUFFICIENT_DATA` | 任一组有效窗口 < 30 | 样本不足，不出结论 |
| S1 | `SURVIVORSHIP_MATERIAL` | p<sub>单侧</sub> < 0.05 且 median(B) < median(A) | 退市股显著更差 → 既有收益类结论必须下调 |
| S2 | `SURVIVORSHIP_REVERSED` | p<sub>双侧</sub> < 0.05 且 median(B) > median(A) | 退市股反而更好 → 与直觉相反，需单独解释 |
| S3 | `SURVIVORSHIP_IMMATERIAL` | 以上皆不满足 | **不等于"偏差不存在"，只等于"这批数据测不出来"** |

`S3` 的措辞是刻意写死的：不显著有两种来源（真无差异 / 功效不足），
把 `S3` 说成"证明了偏差可以忽略"就是 R3 意义上的编造。

5. A 组与历史 `b50_v3` 的装置校验说明：若不一致，先查管道，不许直接解读组间差

## 5. 已知局限（写进任何引用本结果的报告）

1. **在市值只有 50 只**。csi300 当日成分的等距抽样，不是全市场 5,575 只。
   所以本探针的"在市侧"本身仍是幸存者池，只是退市侧补齐了。
   **不能把 312 只并集称为"全市场池"**，准确说法是"退市侧全量 + 在市侧 50 只样本"。
2. **时间分布不对称**。退市股在退市日之后没有数据，B 组的窗口天然集中在前段。
   若市场环境随时间变化，组间差会混入时间效应。缓解手段是按窗口起始年份分层报告（§4-4），
   但**不能完全消除**，所以 S1 的结论强度上限是"伴随时间构成差异的组间差"。
3. **退市原因未分层**。财务造假退市与吸收合并退市的经济含义完全不同，
   本探针不区分（名单里没有可靠原因字段），只能作为整体处理。
4. **2017 年前退市的标的不在其中**（行情源不可得，`no_quote`），
   所以本探针修的是「2017 年后那部分幸存者偏差」，对更早区间仍是"看起来没偏差、实际有"。
5. **A 组含 3 只本地既有文件、47 只为本次新下载**，两组都取自腾讯源 qfq，
   但复权基准日不同会带来水平值差异；本探针比的是**窗口收益率的分布**，不是价格水平，影响有限。
