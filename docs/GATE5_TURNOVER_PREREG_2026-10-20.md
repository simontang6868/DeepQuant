## 0. 为什么做这个，以及为什么判据是**双侧**

### 0.1 第三块拼图

Gate 3 与 Gate 4 拼出一条重要信息：**2016 分界不是全市场现象**（反转前正后负，低波动前≈0 后正）。
要判断这个分界有多普遍，还需要**第三块**异象。交易活跃度（换手率/成交量）是 A 股文献里
**被报告得最多**的横截面异象之一，且本项目**有成交量数据**——不需要财报、不需要市值、不需要 PIT 成分。

### 0.2 ⚠️ 一个必须先声明的口径偏离

严格的换手率 = 成交量 / 流通股本。**本项目没有历史股本数据**（分红表只含送转，不含增发/配股/解禁），
因此**无法**计算真实换手率。本预登记改用**自身历史标准化的交易活跃度**：

```
amt_ratio = mean(过去 21 个交易日成交额) / mean(过去 250 个交易日成交额)
```

- 分子 = 近期活跃度；分母 = 该股自身的长期常态水平；
- **除以自身历史**天然剔除了"大盘股成交额一直大"的规模混淆（这是关键）；
- 与文献"换手率"同属"交易活跃度"维度，但**不是同一个量**。

### 0.3 为什么判据必须是双侧（本预登记与 Gate 2~4 最大的不同）

文献对"活跃度 → 未来收益"的方向给出**相反的两种先验**：

| 先验 | 方向 | 来源 |
|---|---|---|
| A 股**换手率水平**异象：高换手股票被散户过度追捧而高估 | 高活跃 → **低**收益（d < 0） | A 股散户主导 + 彩票偏好的大量文献 |
| **异常成交量溢价**（high-volume premium）：异常放量吸引关注、推高后续需求 | 高活跃 → **高**收益（d > 0） | Gervais, Kaniel & Mingelgrin (2001) |

两者都是"活跃度"，但一个是**水平**、一个是**相对自身的变化**——本项目测的 `amt_ratio`
更接近后者。既然方向有真实歧义，**单侧检验就是把一半的先验错误当成零假设**，
所以本预登记改为：

> **H0: E[d] = 0；H1: E[d] ≠ 0（双侧，α=0.05，临界 |t| ≥ 1.96）**

并以**符号**作为结论的一部分（"方向为正/为负"），而不是把方向写进 H1。

## 3. 信号与组合（全部预先写死）

| 项 | 设定 |
|---|---|
| 信号 | `amt_ratio = mean(amt 最近 21 日) / mean(amt 最近 250 日)`，`amt = ADJ close × volume` |
| 有效数据 | 近 21 日 ≥ 19 日、近 250 日 ≥ 225 日（均 90%）；信号日价格必须可定价 |
| 组合 | `d = 0.5 × 等权(amt_ratio 最高 k 只) − 0.5 × 等权(最低 k 只)`，自融资 |
| 持仓数 k | **110**（与 Gate 2/3/4 一致，便于横向比较） |
| 再平衡 | 月度（月末收盘定信号，持有至下月末） |
| 权重 | 等权 |

**不做的事**：不做市值中性、不做行业中性、不做"成交额水平"与"异常活跃度"的拆分
（那是第二个信号，另开实验）。

## 4. 判定判据（机械可执行，跑前冻结）

### 4.1 主检验（**双侧**）

| 档位 | 触发条件（全部满足） | 标签 |
|---|---|---|
| **SUCCESS** | `n ≥ 200` **且** `MDE ≤ 1.42pp` **且** `\|t\| ≥ 1.96` | 通过；结论必须写明**方向**（t > 0 → 高活跃占优；t < 0 → 低活跃占优） |
| **INCONCLUSIVE** | `n < 200` 或 `MDE > 1.42pp` | 证据不足 |
| **FAILURE** | 不满足 SUCCESS，且不满足 INCONCLUSIVE | 失败（未检出） |

`MDE = 2.8016 × sd(d) / √n`（与 Gate 2~4 同一约定）。

### 4.2 必报项：2016 分段（**不参与判定**，但必须并列引用）

- 段 A = 信号月 2006-01 ~ 2015-12；段 B = 2016-01 ~ 2026-09
- 报告两段的 `n / mean(d) / t / sd / MDE`，以及两段差的 **Welch t 与 p**

**跑前写死的判读规则**（四选一，逐字照抄）：

| 条件 | 报告措辞 |
|---|---|
| 两段差 p ≥ 0.05 且两段均 `\|t\| ≥ 1.96` | **"效应跨段持续"** |
| 两段差 p < 0.05 且仅段 A 达 `\|t\| ≥ 1.96` | **"效应在 2016 后断裂"** |
| 两段差 p < 0.05 且仅段 B 达 `\|t\| ≥ 1.96` | **"效应在 2016 后才出现"** |
