## 1. 为什么做这一阶段

SURGE 是唯一在真实费率下"由负转正"的信号（券商费率测算：+0.0694pp，t=+2.134），
但那次测算里 **SURGE 的冲击成本 = 0，因为从未建模**（阶段 L 没算过）。
而 SURGE 的换手是 **24.41%/月**（exQ5 是 18.3%，1.33 倍），参与率与冲击都更高。

本阶段补上这最后一项。

**不新增策略、不改信号定义、不调参、不换窗口**——只是把阶段 L 缺的那一项补上。

## 5. 三个必须一起读的点

### 5.1 ⭐ 显著性完全由前段驱动

| 段 | W=1,000万 | W=3,000万 | W=5,000万 | W=1亿 |
|---|---:|---:|---:|---:|
| **2007-2015** | +0.1135 (t=+2.63) | **+0.1412 (t=+3.09)** | +0.1421 (t=+3.06) | +0.1401 (t=+2.99) |
| **2016-2026** | −0.0298 (t=−0.77) | **+0.0109 (t=+0.26)** | +0.0194 (t=+0.45) | +0.0223 (t=+0.51) |

**后段任何资金档都不显著**（t ≤ +0.51，净值 +0.01~+0.02pp ≈ 零）。

按阶段 P 确立的纪律：两段各自显著 ≠ 稳定；而这里连"两段各自显著"都不成立——
**只有前段显著**。所以全样本 t=+2.20 不能读作"SURGE 在近十年仍有效"。

（⚠️ 分段在本阶段只作描述性，不参与判定。）

### 5.2 与 exQ5 不同：SURGE 有规模上限

阶段 J 发现 exQ5 的净值随 W **单调上升**、区间内无拐点。SURGE 不是：

- 净值 A：+0.0355 → +0.0703 → **+0.0753** → +0.0760（在 5,000 万后基本饱和）
- 净值 B：+0.0085 → +0.0247 → +0.0171 → **−0.0052**（**先升后降，1 亿转负**）
- 打平 η\*：1.30 → **1.50** → 1.25 → **0.89**（非单调，3,000 万处最耐冲击）

原因：SURGE 换手 24.41%（exQ5 是 18.3%），规模越大、成交越多，冲击增长快过
现金残留的改善。**在 1 亿档，η\* = 0.89 已落在文献区间内**
→ 那里"是否被冲击杀死"取决于 η 的真实取值，不能断言。

### 5.3 主口径虽显著，但贴边

W=3,000 万时 CI 下界仅 **+0.0075pp**。净值 +0.0703pp，下界几乎是零。
→ 它不是"稳健为正"，而是"在 Amihud 模型下勉强为正"。

## 6. 判定

按预登记 §4 的冻结判据（主口径 = EM_DEFAULT + 冲击 A）：

| W | A | B(η=1) |
|---|---|---|
| 1,000 万 | ✗ (t=+1.173) | ✗ |
| 3,000 万 | ✓ (t=+2.196) | ✗ |
| 5,000 万 | ✓ (t=+2.319) | ✗ |
| 10,000 万 | ✓ (t=+2.306) | ✗ |

→ 非全部 pass 且非全部不 pass → **`SURGE_SCALE_DEPENDENT`**

⚠️ 这个档位名只覆盖了"规模"这一维。必须同时说明第二维：
**换成冲击 B 后，任何资金档都不 pass** —— 所以它同时是"冲击模型依赖"的。
预登记的四种档位是互斥取首个匹配，故取 SCALE_DEPENDENT；
两个维度都在本节如实报告。

## 7. 修的三个实现缺陷（都在跑之前/中被单测抓出）

1. **`np.searchsorted` 用在未排序数组上** —— `codes` 的顺序不是列号顺序，
   直接二分会**静默取错股票的 ILLIQ**（不报错）。构造时先 `argsort`，
   并加 `local_of()` 强制校验严格递增。单测钉住。
2. **`covered` 误当 f_inv** —— `covered`（能买到的标的比例，≈0.999）
   与 `1 − uninvested`（已投资资金比例，≈0.952）差约 4.8pp。
   第一版误用前者，把净值高估约 0.005pp。这是 §10"现金残留"陷阱的变体。
   修正后 3,000 万档 net 从 +0.0738 降到 **+0.0703**。单测钉住两者区分。
3. **`net_stats` 遇 NaN/短序列直接崩溃** —— 与阶段 Q 的 `fm()` 同一类缺陷，
   这里漏了。改为打标 + 用有效子集。单测钉住。

## 8. 结论与限定

### 可以主张

1. SURGE 的冲击成本**已被建模**，参与率 `P/ADV` 中位 0.008%~0.076%——绝对量很小。
2. 在东方财富/中原**默认费率 + Amihud 冲击**下，W ≥ 3,000 万时样本内净值
   显著为正（+0.070~+0.076pp，t=+2.20~+2.32）。
3. 但**换成 η=1 后全部不显著**，且 1 亿档转负（η\* = 0.89 落在文献区间内）。

### 不可以主张

1. ❌ **不主张 SURGE 可用。** 后段（2016-2026）任何资金档都不显著。
2. ❌ 不把"全样本 t=+2.20"读作"近十年仍有效"——它完全由前段驱动。
3. ❌ 不主张存在最优资金规模——只是**在 1 亿档出现规模惩罚**，η\* 非单调。
4. ❌ 显著 ≠ 可交易；全部样本内。

### 对既有结论的处置

- 阶段 L 的 `SURGE_AVOID_ABSORBED`（0.3% 口径）**保留不修改**。
- 本阶段新增的是"真实费率 + 冲击"口径下的结论，
  两者**并存**，引用必须同时给出口径 + 冲击模型。
- 券商费率测算里那个 "+0.0694 / t=+2.134（冲击=0）"
  应被本阶段的 **+0.0703 / t=+2.196（含冲击 A）** 取代
  （净值略高的原因是本阶段 f_inv 按月计算、且现金残留口径更准确）。
