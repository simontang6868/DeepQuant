## 1. 问题

既有全部实验的收益都这么算：

```
fwd = ffill(月末最后交易日 nxt) / ffill(信号日 pos) − 1
```

信号在 `pos` 日收盘生成，成交价也用 `pos` 日收盘——**看到收盘价的同时按它成交**。
真实最早只能 `pos+1`。对反转策略这被认为不是小事：效应若集中在第 1 天，
这么多实验就等于都在数一个拿不到的收益。

### 1.1 三格设计（同一批持仓，只改收益起算点）

| 格 | 成交价 | 说明 |
|---|---|---|
| **V0** | `ffill(pos)` | 阶段 C 的 D 格，必须逐位复现 |
| **V1** | `ffill(pos+1)` | 纯「晚一天」 |
| **V2** | `ffill(e)`，e = 首个 `tradable` 日（≤5 日） | 真实可执行 |

**主检验**：`Δ = spread(V1) − spread(V0)`（纯延迟）
**交叉验证**：`Δ' = spread(V2) − spread(V1)`（顺延的额外代价）

## 3. D1：真正重要的发现——**第 1 天的 spread 是负的**

| 区间 | 多头 | 空头 | **spread** | 占三段之和 |
|---|---:|---:|---:|---:|
| `pos → pos+1`（第 1 天） | +0.3571 | +0.4104 | **−0.0533** | **−4.0%** |
| `pos+1 → pos+5`（第 2~5 天） | +1.0729 | +0.4907 | **+0.5823** | 43.7% |
| `pos+5 → nxt`（剩余） | +0.3241 | −0.4796 | **+0.8037** | 60.3% |

（三段 spread 之和 1.3326pp，与全期 1.3164pp 差 1.2%，来自分段复利与缺失对齐。）

**第 1 天多头涨 0.36%，空头涨 0.41%——赢家涨得更多。这是动量，不是反转。**

于是"放弃第 1 天"不是损失，而是**省掉了一个负的 spread**。这就是 Δ 为正的原因。

时点结构因此是：

```
第 1 天     赢家惯性（spread −0.05，反向）
第 2~5 天   反转启动（spread +0.58，占 44%）
第 6 天起   持续下行（spread +0.80，占 60%）
```

**这直接否证了预登记 §6 的前提之一**（"短期反转在 1 日尺度上最强"）。
至少在本项目的 21 日反转构造上，第 1 天是**动量**，反转从第 2 天才开始。

### 3.1 D2：Δ 几乎完全由第 1 天驱动

`第 1 天 spread` 与 `Δ` 的相关 **r = −0.9818**（n=237 月）。

这不是巧合：把 `spread(V1) − spread(V0)` 展开，它**就是** `−spread(第1天)` 加上很小的复利残差。
r 接近 −1 说明分解是自洽的，Δ 的全部内容就是"第 1 天那一段"。

换句话说：**本实验的主检验在数学上等价于"第 1 天的 spread 是否为 0"**，答案是"不为 0，是负的"。

**97% 的标的次日就能成交**，所以 V2 与 V1 的差异很小（`Δ' = 0.06pp`），这与实测一致。

### D4 腿规模

多头中位 484 → 482，空头 486 → 483。缩 0.4%~0.6%，可忽略。

### D5 分年度 Δ（pp/月）

```
2007 −0.251   2008 +0.230   2009 +0.385   2010 +0.686   2011 +0.039
2012 +0.210   2013 −0.096   2014 +0.404   2015 −0.242   2016 −0.343
2017 +0.091   2018 +0.168   2019 +0.172   2020 +0.416   2021 −0.281
2022 −0.286   2023 +0.295   2024 −0.075   2025 −0.174   2026 −0.566
```

**方向不稳定**：2010 是 +0.686，2026 是 −0.566。全样本不显著（t=0.60）正是这种年份间
正负抵消的结果，而不是"每年都接近 0"。

**这一条必须写清楚**：`LAG_COST_NEGLIGIBLE` 是**全样本平均**的结论，不是"每年都无所谓"。
若某个特定年份策略依赖第 1 天的动量，那一年晚一天会有 0.5pp 量级的影响。

## 5. 这个结果改变什么、不改变什么

### 5.1 改变

- **"按信号日收盘成交"这个前视口径，数值上不必再纠正。** 之前的担心可以撤掉：
  它确实不可执行，但它对结论没有实质影响。
- 反过来，**V1/V2 的 spread 更高**（1.3632 / 1.4234 vs 1.3164），说明既有数值是**保守**的。
  这与阶段 C-2 的结论方向一致——两次敏感性分析都指向"既有数值偏低，不是偏高"。

### 5.2 不改变

- Gate 2/3/6 与阶段 C 的**任何**判定。本实验只量化口径代价，不重算结论。
- M1/M2 层级。V1/V2 的净@0.3% 是 t=1.26 / 1.43，仍不显著。
- M4 结构阻塞（做空腿不可得），一寸没动。
- **不意味着"可以按次日收盘价成交"**。V2 只处理了"哪一天"，没处理"那一天什么价"
  —— 没建模开盘价、没建模冲击成本、没建模 T+1 之外的日内滑点。

## 6. 局限（含一处预登记内部不一致）

| 项 | 说明 |
|---|---|
| **预登记 §1 与 §3.2 冲突** | §1 写"三格共用同一批持仓（含 §5 约束）"，§3.2 写"V1 可能买到当天涨停的票、V2 顺延避开涨停"。两者不能同时成立——涨停票已被 §5 剔出腿。本实验按 **§1** 执行（更基础，且是"Δ 不含选股差异"成立的前提）。后果：**V2 的顺延只处理停牌，不处理涨停。** |
| 平仓日不顺延 | 买入是唯一延迟来源；做空腿不可得，测平仓延迟无现实意义 |
| 只改"哪一天的收盘价" | 不使用开盘价，不模拟日内成交价、不模拟冲击成本 |
| D5 的年份不稳 | `LAG_COST_NEGLIGIBLE` 是全样本结论，不是逐年结论 |
| 做空腿不可得 | M4 结构阻塞，`d` 不是可实现组合收益 |
| ST 无历史标记 / `after_last_data` 不可区分 | 沿用既有已知限制 |
