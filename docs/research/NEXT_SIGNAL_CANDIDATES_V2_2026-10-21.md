## 0. 先算清楚：新门槛意味着什么

阶段 I 实测的 **恒等式**：`alpha_avoid ≡ 0.25 × (R_bench − R_Q5)`。

所以要拿到 `alpha ≥ 0.30pp`，需要的最坏组相对池的差距是：

```
R_bench − R_Q5 ≥ 1.2 pp/月
```

参照：MAX5 的这个 gap 只有 **≈0.90pp** → alpha 0.2307（理想）/ 0.1634（可成交）/ 0.0507（成本后）。
**exQ5 差得远。** 新候选必须比它更强，或者至少同量级但可成交折损更小。

**这个门槛很可能在纯价量空间里没有候选能满足。** 这本身是一条值得记录的结果——
如果筛选完发现没有一个候选有理由达到 0.3pp，那就该停止找信号，而不是降低门槛。

## 1. 文献检索结果（先查文献，不许先跑）

### 1.1 ★ 异常交易量 / 异常换手率（ATR）

| 来源 | 结论 |
|---|---|
| 中央财经大学《投机交易与股票回报》 | 构造 **ATR**（从总成交量中分离投机部分）；**ATR 十等分最高−最低月均 −1.87%**，控制常见风险因子与事件冲击后仍显著 |
| 学位论文（投资者意见分歧） | 定义**月度异常交易量 = 本月成交额 / 上月成交额**，与滞后一月收益**显著负相关**；控制规模、BM、流动性、动量后仍显著；高异常量后 12 个月内换手率与特质波动率都大幅上升 |
| 薛冰、张兵、王婉菁《金融评论》2021 | **日度**换手率效应；机制是 **T+1 + 卖空约束**：当日买入无法卖出、悲观者无法做空 → 高换手当日高收益、次日隔夜反转；**A+H 交叉上市检验：港股（T+0、卖空约束弱）不存在此效应** |

**为什么这条对本项目特别合适**：
- 它的机制解释（T+1 + 卖空约束导致高估无法被套利）与本项目 §9.1「横截面异象天然是空头侧现象」
  **是同一个机制**——本项目已经从两个独立信号（反转 0.21、MAX5 0.24）测出这个结构；
- 因此它天然适合 **避免型**动作（排除异常放量最高的 20%），正是 §9.2 推荐的形态；
- 十等分价差 1.87pp/月，是目前查到的**量级最大**的 A 股纯价量异象。

### 1.2 ⚠️ 换手率「水平」——**不可用**（非单调）

上海财大《换手率：流动性还是不确定性》（2000-2015 沪深 A 股）：

> 换手率与预期收益**不是单调负向，而是倒 U 形**。
> 低换手段：换手率越高，收益越高；高换手段：换手率越高，收益越低。
> **分界点在横截面换手率的 36% 分位点。**

→ 推论：**可以做"排除最高"，但不可以做"买最低"**——后者会落在正向段上，方向相反。
这与本项目 §9.2「避免型 vs 买入型」完全一致，是又一次独立印证。

## 3. 本轮的构造（待可行性检查确认后冻结）

```
SURGE = mean(近 21 个交易日的日成交额) / mean(前 21 个交易日的日成交额)
```

- 不需要流通股本（用一个"相对自身历史"的放量比值，规避数据约束）；
- 与文献"本月成交额 / 上月成交额"在交易日口径下**是同一个东西**；
- 组合 = **排除 SURGE 最高的 20%**，其余等权；基准 = 池内等权；
- 池 = as-of 全 A + 252 日；样本 2007-2026；NW(3)；双侧 1.96。
