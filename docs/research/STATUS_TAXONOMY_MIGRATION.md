# 实验状态与策略成熟度分离：迁移设计（阶段 D）

> **状态**：设计稿 + 历史状态重新归类。**不改任何历史报告原文**，只在原处加注并在此集中登记。
> **动机**（外部审阅意见原文）：
> "SUCCESS 在工程上很方便，但需要确保团队内部不会把 SUCCESS 理解为'策略成功'。
>  Gate 3 虽然通过了某个预登记检验，但扣成本后不显著、skip=0/5 也不显著。"
>
> "如果你们现有的 FAILURE 实际上只是'未达到成功标准'，那它并不一定等于'证伪'。"

---

## 1. 旧状态体系的问题

现在每份 Gate 报告只有一个标签：`SUCCESS` / `FAILURE`。它把至少 7 件不同的事压成了一个词：

| 被压在一起的维度 | 例子 |
|---|---|
| 统计检验是否达到预登记门槛 | Gate 6：t=4.52 → 达到 |
| **功效是否足以看见目标效应** | Gate 1：MDE=1.43pp，对 0.3pp 的功效仅 17.8% → **看见也看不见** |
| 数据是否可信 | Gate 3 首版含 249 只免检退市股（D-1） |
| 协议是否被遵守 | Gate 3 曾按持有月末过滤，丢了 1 个月观测（已修正） |
| 经济意义是否足够大 | Gate 6：spread 1.477pp/月，但只覆盖 20% 的股票 |
| 扣成本后是否还成立 | Gate 3：0.1% 后 t=1.24 **不显著**；Gate 6：0.1% 后 t=3.54 显著、0.3% 后 t=1.57 不显著 |
| 交易是否可行 | A 股做空腿基本不可得；1,000 只/腿需千万级资金 |

**"SUCCESS" 只覆盖第一行。** 把它当成"策略成功"是最危险的误读。

## 2. 新体系：两层、正交

### 2.1 第一层 `StatisticalVerdict`（统计检验结果）

只有 4 个取值，**判据必须是预登记里写死的机械条件**。

| 取值 | 定义 | 常见误读 |
|---|---|---|
| `PASS` | 满足预登记的全部成功条件 | ≠ 策略可用 |
| `FAIL` | 在**有效检验**条件下，未满足成功条件，**且置信区间能排除目标效应** | ≠ 效应不存在 |
| `INCONCLUSIVE` | **功效不足**（MDE 远大于目标效应）或样本不足 → 无论结果如何都不构成证据 | 最容易被误标为 FAIL |
| `INVALID` | 数据/实现/协议存在重大缺陷 → 结果不可用 | 不等于"结果为零" |

**关键区分**：`FAIL` 与 `INCONCLUSIVE` 的界线是 **MDE 与目标效应的比值**。

> 若 `MDE > 目标效应`，即使 t=0.1 也不能说"没检出"——**你本来就看不见**。
> 这条界线本项目的动作阈值定为：`MDE / 目标效应 ≤ 1.0` 才算"看得见"。

### 2.2 第二层 `MaturityLevel`（策略成熟度，7 个独立门槛）

每一项都是**独立的前置条件**，不是分数累加。任一项未过，就不能进下一层。

| 层 | 门槛 | 判据 | 本项目现状 |
|---|---|---|---|
| **M0** | 未验证交易可行性 | 默认状态 | 全部 Gate |
| **M1** | 统计显著 + **扣成本后仍显著** | 0.1% 单边成本后 \|t\| ≥ 1.96 | **仅 Gate 6** |
| **M2** | 扣 0.3% 单边成本后仍显著 | \|t\| ≥ 1.96 | **无**（Gate 6 = 1.57） |
| **M3** | 通过交易约束（涨跌停/一字板/停牌） | 加约束后 \|t\| ≥ 1.96 | **未做**（阶段 C 才做） |
| **M4** | 通过容量与资金约束 | 按阶段 4.1，k=1000 只/腿需千万级；且做空腿不可得 | **不满足**（A 股做空腿不可得 → **结构阻塞**） |
| **M5** | 通过样本外（真·未来数据） | 训练/验证时间隔离 | **未做** |
| **M6** | 通过模拟交易 | 撮合、滑点、T+1、涨跌停成交 | **未做** |

### 2.3 ⚠️ 一个必须写明的结构性问题

Gate 6 是**多空各半的自融资组合**（`d = 0.5×long − 0.5×short`）。
**A 股个股做空基本不可得**（融券券源稀缺、成本高、且监管限制）。

→ 这意味着 **Gate 6 的 d 不是一个可实现的组合收益**，它只是一个"多空相对强弱"的统计量。

**后果**：即使 M1~M3 全过，M4 也会卡在"做空腿不可得"。
若要继续，只能改成**单边多头 + 基准**的构造——而那是**另一个实验**（须新预登记）。

**这条必须写进任何对外材料的显著位置**，否则"t=4.52"会被读成"能赚钱"。

## 3. 历史状态重新归类（不改原文，集中登记）

| 实验 | 旧标签 | 新 `StatisticalVerdict` | `MaturityLevel` | 理由 |
|---|---|---|---|---|
| **Gate 1**（月频动量） | `FAILURE` | **`INCONCLUSIVE`** | M0 | **功效不足**：MDE=1.43pp，对目标 0.30pp 的功效仅 **17.8%** → 本来就是"看不见"，不能叫"没检出" |
| **Gate 2**（反转 2016-2026） | `FAILURE` | `FAIL` | M0 | 方向为负且 MDE=0.81pp 对 1.42pp **看得见**，`t=−1.70` 未达 \|1.96\| → 有效检验下的 FAIL |
| **Gate 3**（反转 2007-2015） | `SUCCESS` | `PASS` | **M0**（非 M1） | 0.1% 成本后 t=1.24 **不显著** → 达不到 M1 |
| **Gate 4**（低波动） | `FAILURE` | `FAIL` | M0 | MDE=0.537pp 对文献 1.08pp **看得见**，t=0.868 → 有效检验下的 FAIL |
| **Gate 5**（活跃度） | `FAILURE`（双侧） | `FAIL` | M0 | MDE=0.426pp，双侧检验，t=0.155 → 有效检验下的 FAIL |
| **Gate 6**（全 A 反转） | `SUCCESS` | `PASS` | **M1** | 0.1% 后 t=3.54 显著（M1 ✅）；0.3% 后 t=1.57（M2 ❌）；交易约束未建模（M3 ❌）；做空腿不可得（M4 结构阻塞） |

### 3.1 Gate 1 的标签是错的，这是本次归类最重要的发现

Gate 1 的原报告把结果写成 `FAILURE`（A 股月频动量不存在）。
但它的设计：52 只池、k=10、n=125、**MDE = 1.43pp**。

若目标是检出 0.30pp/月（文献里月频动量的量级），则该设计的功效只有 **17.8%**。
**一个功效 17.8% 的实验，无论结果是什么，都不能作为"不存在"的证据。**

正确标签：**`INCONCLUSIVE`（证据不足）**，不是 `FAILURE`。

> 这与 D-1 是同一类错误的两种表现：
> D-1 把"未知"当成"无"；Gate 1 把"看不见"当成"没有"。
> **两者都会制造虚假的确定性。**

处置：在 `docs/GATE1_*` 原报告顶部加注"标签应改为 INCONCLUSIVE"，原文保留。

### 3.2 Gate 3 从 SUCCESS 降到 M0 不是否定它

Gate 3 的**统计检验**确实 PASS（t=2.12 ≥ 1.96，MDE=0.641 ≤ 1.42）。
但它在**成本后**不显著（0.1% 单边 → t=1.24），因此成熟度停在 M0。

**"PASS + M0" 是一个完全正常的组合**，不应被读成矛盾：
统计上看见了效应，但经济上还不足以覆盖交易成本。

## 4. 报告写作规范（强制）

今后任何 Gate 报告的开头必须写成二元组：

```
统计判定：PASS / FAIL / INCONCLUSIVE / INVALID
成熟度：M0 / M1 / ... / M6
```

不得只写一个词。且必须附三行：

1. **MDE 与目标效应**（证明检验有效或无效）；
2. **成本后结果**（证明是否只存在于纸面）；
3. **可实现性**（做空腿、资金门槛、交易约束）。

### 4.1 禁止表述清单

| 禁止 | 应改为 |
|---|---|
| "策略成功" | "统计检验通过（M1）" |
| "因子不存在" | "在 MDE=X pp 的设计下未检出" |
| "证明了反转被套利掉" | "在 532 池上未检出"（Gate 6 已否证这一点） |
| "复现了文献" | "方向与量级在同口径下接近"（并说明池/成本差异） |
| "接近可用" | 直接报 t 值与门槛的差距 |

## 5. 迁移是否影响历史结论

| 项 | 影响 |
|---|---|
| 数值结果 | **无影响**（判据没变，只是标签变） |
| Gate 1 的标签 | `FAILURE` → `INCONCLUSIVE`（**结论强度下降**，不是上升） |
| Gate 3 的标签 | `SUCCESS` → `PASS + M0`（**读法收紧**） |
| Gate 6 的标签 | `SUCCESS` → `PASS + M1`（**首次达到 M1，但 M4 结构阻塞**） |
| 已提交的报告 | **不改原文**，加注 + 在本文件集中登记 |

**没有任何一项变宽松。** 全部是收紧或等价。

## 6. 与路线图的关系

路线图阶段 5 的准入清单必须改用本体系：

```
进入阶段 5（策略实现）的前置：
  M1 ✅（扣 0.1% 成本后显著）

```

**当前唯一达到 M1 的是 Gate 6**，而它卡在 M4。
