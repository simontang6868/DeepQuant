## 0. 为什么先写这份，而不是直接开跑

### 0.1 三次教训

| 教训 | 代价 |
|---|---|
| **选题前没查文献** | Gate 1 用整个 gate "发现"了 A 股月频动量不显著——这是文献里 20 年前的常识 |
| **先跑到底才发现构造不可用** | 阶段 E：alpha 只有 0.28pp，做完全部诊断才发现它只有多空价差的 21% |
| **在定名单池上做因子实验** | Gate 2/3 的"反转消失了"是 532 池的选择偏差，全 A 上根本不成立 |

### 0.2 反 data-snooping 的三条硬约束

1. **先查文献，再定候选**。文献里没有先验的因子，不进候选池（哪怕"试一下说不定有"）。
2. **不许"跑一下看哪个 t 高"再决定测哪个**。本次评估只做**数据可得性验证**
   （能不能算出这个变量），不做任何收益计算。
3. **候选数量≤4**。测 20 个因子挑出 1 个显著的，那是抽奖不是研究。

## 2. 候选清单（按文献证据强度排序）

### 候选 1：MAX 效应（前 5 大日收益均值）★ 推荐

| 项 | 内容 |
|---|---|
| **定义** | `MAX5 = mean(过去 21 个交易日中最大的 5 个日收益)` |
| **文献先验** | Bali, Cakici & Whitelaw (2011, JFE) 原版；**A 股多次独立复现**（清华、cfrn 多篇）；方向**负向**：高 MAX → 未来收益低（彩票偏好） |
| **关键细节** | **中国市场因为 T+1 与涨跌停，要用"前 5 大日收益"而非单日 MAX**（Zhu & Zhang 2020 的口径）。这一点必须在预登记里写死——用单日 MAX 会低估效应 |
| **数据** | 只需 ADJ 日收益 ✅ |
| **单边多头可测性** | ✅ **强**。多头 = 买**低** MAX（最"不彩票"的股票）。方向明确，不需要做空腿 |
| **重叠风险** | ⚠️ 中。低 MAX 股票往往同时是低波动、低换手。Gate 4（低波动）已验证 FAIL——**必须先检查 MAX 与波动率的相关性**，否则可能只是重复 Gate 4 |
| **实现难度** | 低（只需 rolling 排序） |
| **已知反面证据** | 因子层面存在"factor MAX premium"（正向），但那是**因子**排序，与**股票**排序相反。本实验做股票层面，不受影响 |

### 候选 2：52 周高点距离（PTH）

| 项 | 内容 |
|---|---|
| **定义** | `PTH = close(t) / max(close[t-250:t])`，越接近 1 越靠近高点 |
| **文献先验** | George & Hwang (2004)；A 股：张峥等 (2005) 报告显著；多篇学位论文（锚定偏差）支持**正向**（越近高点，未来收益越高） |
| **⚠️ 证据冲突** | 国信金工全样本实测 **RankIC = −1.07%，呈反转特征**（越近高点，收益越**低**）；另一篇报告"不显著有效，仅熊市显著、剔除 1/2/7/8 月后有效" |
| **数据** | ✅ 只需 ADJ 收盘 |
| **单边多头可测性** | ✅ 多头 = 买接近高点的（若按学术方向）或买远离高点的（若按券商实测）——**方向本身是要检验的，不能预设** |
| **重叠风险** | ⚠️ 中。PTH 与 21 日反转、12-1 动量都相关 |
| **实现难度** | 低 |
| **评价** | 证据冲突本身不是排除理由，反而是"值得测"的信号——但**必须双侧检验**（方向未知），且要在报告里把两边文献都列出来 |

### 候选 3：名义低价股溢价

| 项 | 内容 |
|---|---|
| **定义** | 直接按 `close(t)` 排序（注意：是**名义价格**，不是复权价） |
| **文献先验** | 《金融研究》2017：A 股存在显著低价股溢价（1999-2014，17.5 万样本）；西南财大 2022 复现 |
| **⚠️ 证据冲突** | 刘玉珍等（Management Science 2026）：动量只存在于**高价股**，散户偏爱低价股；另有观点认为"低价股长期收益更差" |
| **数据** | ✅ 但**必须用 EXEC（不复权）价格**——复权价不是投资者看到的数字 |
| **单边多头可测性** | ✅ 多头 = 买低价股（若溢价存在） |
| **重叠风险** | ⚠️⚠️ **高**。低价股与小市值、ST、流动性差高度相关。本项目无市值与 ST 标记，**无法剥离** → 结论会是"低价股效应"与"小盘+垃圾股效应"的混合 |
| **实现难度** | 极低 |
| **评价** | 证据强度够，但**混杂无法控制**，即使测出显著也说不清是什么。降级 |

### 候选 4：特质波动率（IVOL）✗ 不推荐

| 项 | 内容 |
|---|---|
| **文献先验** | Ang et al. (2006) 负向；A 股：有研究报告负相关（清华）、有研究报告**正相关且"未发现特质波动之谜"**（西南大学）、2026 年 SSRN 论文称该谜题在总收益上**是脆弱的**（用深度学习预测 IVOL 后消失） |
| **评价** | **方向都不确定**，且结论依赖 IVOL 的估计方法（市场模型 / 三因子 / 预测模型）。用它做主信号，等于把"估计方法的选择"和"因子的存在性"混在一起。**排除** |

## 3. 排序与建议

| 排名 | 候选 | 文献强度 | 数据 | 单边可测 | 混杂风险 | 建议 |
|---|---|---|---|---|---|---|
| **1** | **MAX5** | ★★★ | ✅ | ★★★ | 中（需查与波动率重叠） | **先做这个** |
| 2 | 52 周高点 PTH | ★★（冲突） | ✅ | ★★ | 中 | 次选，双侧检验 |
| 3 | 低价股 | ★★（冲突） | ✅ | ★★ | **高（无法剥离）** | 不做，除非先买市值数据 |
| — | IVOL | ★（方向不定） | ✅ | — | — | **排除** |

### 3.1 为什么 MAX 排第一

1. **方向明确且单一**：高 MAX → 低收益，各文献一致（不像 PTH 与低价股那样正反都有人说）；
2. **A 股有专门的复现**，且有"用前 5 大日收益"这个本地化细节——说明有人认真做过；
3. **只需价量**，零新增数据依赖；
4. **单边多头天然可测**：买低 MAX 即可，不需要空头腿；
5. 行为机制清晰（彩票偏好），不是纯统计挖掘。

### 3.2 但必须提前承认一个风险（**已实测，见 §4.1**）

**低 MAX 的股票大概率是低波动、低换手、大盘的"无聊股"。**
Gate 4（低波动）已经 FAIL。如果 MAX 的效应大部分来自波动率暴露，那这次只是在重复 Gate 4。

**这个担心已经实测为真（相关 0.88）。** 处置写在 §5.1：主检验必须是**波动率分层后的 MAX5**，
原始 MAX5 只作描述性对照。**这一步在跑收益之前就定了**，不是事后补的。

## 4. 数据可得性验证（已跑，只验变量能不能算，没算任何收益）

脚本 `scripts/check_max5_feasibility.py` → `reports/MAX5_FEASIBILITY.json`。
它**刻意不碰任何未来收益**——一算收益就变成"试跑挑因子"了。

| # | 检查 | 结果 | 判断 |
|---|---|---|---|
| ① | 日收益可算 | 非正价 **0** 个；\|r\| 最大 261.31%（复牌/上市首日，非错误） | ✅ |
| ② | 21 日窗口有效日覆盖率 | 均值 **96.87%**，最低 53.67%；237 个月，池中位 2,562 只 | ✅ |
| ③ | MAX5 横截面区分度（pp） | min +0.41 / P25 +2.47 / 中位 **+3.23** / P75 +4.32 / max +12.81 | ✅ 区分度充分 |
| ④ | **MAX5 vs 21 日波动率（秩相关）** | **+0.8796** | ⚠️ **超过 0.8** |
| ④ | MAX5 vs 21 日反转 | −0.5113 | 中等（合理：高 MAX 多为近期涨得多的） |
| ④ | MAX5 vs 52 周高点距离 | +0.1809 | 弱——PTH 相对独立 |
| ⑤ | 250 日窗口覆盖 | `min_listed_days=252` 已保证 | ✅ |

### 4.1 第 ④ 项是这次评估最重要的发现

**MAX5 与 21 日波动率的横截面秩相关高达 0.88。** 后果很直接：

> 低 MAX5 = 低波动。Gate 4（低波动）已经 **FAIL**。
> 如果直接测原始 MAX5 并得到显著结果，**无法区分是"MAX 效应"还是"波动率效应"**——
> 而后者本项目已经测过了。

这正是 §3.2 提前写下的风险，现在有数字了。相关 0.88 意味着 MAX5 约 **77%** 的横截面排序
可由波动率解释（0.88² ≈ 0.77），独立部分仅约 23%。

**所以 §5 的预登记草案必须改**（见下）。这不是看到收益才改，是看到**变量构造**才改——
合规，且必须改。

### 4.2 附带结论：PTH 比 MAX5 更独立

`MAX5 vs 52 周高点距离 = +0.18`，比波动率那条低一个数量级。
如果 MAX5 因为共线性被降级，**PTH 是更有独立性的第二候选**——尽管它的文献方向有冲突。

## 5. 下一轮预登记要写死的东西（据 §4 修订）

### 5.1 若走 MAX5：主检验必须是"波动率分层后的 MAX5"

原始 MAX5 的检验被**明确降为描述性**，不进判定。理由是 §4.1 的 0.88。

```
主检验：
  每月先把池按 21 日波动率分成 5 层（等频），
  再在每层内按 MAX5 分成 5 组，
  取每层最低 MAX5 组与最高 MAX5 组的等权收益差，
  5 层按层内标的数加权平均 = MAX5 的层内价差 Δ_t

判据：|NW t| ≥ 1.96 且 |Δ| ≥ 0.30pp（同阶段 C 的经济门槛）
```

**这个设计的意义**：它问的是"在波动率相同的股票之间，MAX5 还能预测收益吗"。
- 若**是** → 这是真正独立于波动率的发现，Gate 4 的 FAIL 不影响它；
- 若**否** → MAX5 只是波动率的影子，这条线直接关闭，不必再花一个 gate。

**对照**（描述性，不参与判定）：原始 MAX5 的五分位价差，用来量化"共线性让结果偏了多少"。

### 5.2 其余写死项

| 项 | 取值 |
|---|---|
| `MAX5` | 21 个交易日内**最大的 5 个**日收益的均值（A 股本地化口径，Zhu & Zhang 2020） |
| 池 | as-of 全 A（与阶段 C / Gate 6 同口径），**不用定名单池** |
| k | 分层后每层内的分组，不额外设 k |
| 基准 | 池内等权（与阶段 E 同口径，便于对照） |
| 检验 | **双侧**（阶段 E 的教训：别预设方向） |
| 成本 | 月度 `2×换手×费率`，**必须走 `cost_of()`**（成本段已错过三次） |
| 诊断 | MAX5 vs 波动率/反转/PTH 的相关；原始 MAX5 的价差；分层后各层的 Δ 是否同号 |
| 新档位 | `MAX_EFFECT_ABSORBED_BY_VOL` —— 若分层后不显著，用这个标签代替 `NOT_DETECTED`，语义更准 |

### 5.3 若走 PTH：双侧 + 明确写"文献方向冲突"

`PTH` 的学术证据（锚定→动量）与券商实测（反转）方向相反。
预登记必须**把两边都列出来**并声明"方向未知、双侧检验"，
否则事后无论哪个方向都能说成"符合预期"。
