## 0. 为什么必须换构造（而不是"再测一次"）

九个实验里，Gate 6 是唯一达到 M1 的。但它的统计量 `d` 是**多空相对强弱**，
不是能拿到的收益。具体障碍（按严重程度）：

| 障碍 | 严重度 | 能否绕过 |
|---|---|---|
| A 股个股融券券源稀缺、成本高、监管限制 | **致命** | 只能换构造 |
| 做空需要保证金，占用资金，`d` 的自融资假设不成立 | 高 | 换构造 |
| 涨跌停/停牌在空头腿上的阻塞方向与信号相关 | 中 | 已在阶段 C 量化（−5.8%~−7.1%） |
| 容量：k=486~1019 只/腿，一手成本可能上千万 | 中 | 换构造后只买一侧，压力减半 |

**关键判断**：前两条不是"数据问题"，是**市场制度**问题。再多的敏感性分析都绕不过去。

## 1. 三个候选方案

### 方案 A：单边多头 + 自建等权基准（推荐）

```
R_long,t  = 当月多头组合（最低分 20%）的等权收益
R_bench,t = 当月 as-of 池内**全部**可投资标的的等权收益
alpha_t   = R_long,t − R_bench,t
```

| 优点 | 缺点 |
|---|---|
| **不需要任何外部数据**，基准与池同源，可比 | 等权基准**不是可投资的指数**（没有对应 ETF） |
| 与 Gate 6 共用同一批持仓，只是去掉空头腿 | 基准含大量小盘股，与"市值加权市场"不同 |
| 成本、容量都能实测 | 多头组合 beta 可能与基准差很多（需报 beta） |

### 方案 B：单边多头 + 中证全指（000985）

用中证全指的月度收益作基准。数据可从 `csindex-home/perf/index-perf?indexCode=000985` 取
（本项目已验证 `H00300` 全收益指数可取，需 Referer）。

| 优点 | 缺点 |
|---|---|
| 基准可投资（有 ETF），更贴近实盘 | 新增数据依赖；指数成分与 as-of 池不同源 |
| 市值加权，与"市场收益"直觉一致 | 需要额外的数据验收流程 |

### 方案 C：单边多头 + 沪深300 + beta 中性化

| 优点 | 缺点 |
|---|---|
| 最贴近机构实盘（对冲 beta） | 需要 beta 估计，多一层假设；沪深300 与全 A 池错配严重 |

### 1.1 选型决定

**主检验用方案 A。** 理由：

1. **零新增数据依赖**——阶段 E 的目的是回答"去掉空头腿还剩多少"，
   引入新数据源会把"构造问题"和"数据问题"混在一起，而这正是本项目反复吃亏的地方。
2. **与 Gate 6 严格可比**：同一批持仓、同一个池、同一个窗口，只去掉空头腿。
   Δ 里不含池/数据差异。
3. 方案 B 作为**对照**（若能取到数据），方案 C **暂不做**（beta 中性化是另一个问题）。

**这个决定写在预登记之前，不是看到结果才选的。**

## 2. 方案 A 的精确定义

### 2.1 多头组合（与 Gate 6 / 阶段 C 的 D 格完全一致）

- 池：as-of 全 A（252 日门槛、ADJ/EXEC 双覆盖、纯 A 股）
- 排序：`score = close(t−1)/close(t−21) − 1`，**取最低分的 k 只**
- `k = max(1, min(round(0.20 × n_pool), n_pool // 2))`
- 交易约束：建仓日涨停/一字板剔出（阶段 C §5）
- 收益：`fwd = ffill(nxt)/ffill(pos) − 1`

### 2.2 基准

```
R_bench,t = mean( fwd_i,t )  对当月池内全部可投资标的 i
```

**注意**：这里的"池内全部"= 当月能算出信号且有前瞻收益的标的（与每月 `n_pool` 一致），
不是全市场 5,444 只。这样基准与选股池严格同源。

### 2.3 alpha 与 beta

```
alpha_t = R_long,t − R_bench,t
beta    = OLS(R_long ~ R_bench) 的时间序列斜率（描述性，不中性化）
```

**不做 beta 中性化**。理由：中性化后的 alpha 依赖 beta 估计窗口的选择，
那是"再引入一个自由参数"。本实验只报 beta，让读者自己判断 alpha 里有多少是 beta 收益。

## 3. 主检验

```
H0: E[alpha] = 0
```

- **双侧**（方向先验已被 Gate 2 部分否证：2016 后反转在定名单池上为负，不能假设一定为正）
- Newey-West 滞后 3
- 窗口 2007-01 ~ 2026-09（与 Gate 6 一致）

### 3.1 判据（四档）

| 档位 | 条件 |
|---|---|
| **LONGONLY_ALPHA_CONFIRMED** | `n ≥ 150` 且 `\|NW t\| ≥ 1.96` 且 `\|alpha\| ≥ 0.30 pp/月` |
| **LONGONLY_ALPHA_SMALL_BUT_SIGNIFICANT** | `n ≥ 150` 且 `\|NW t\| ≥ 1.96` 且 `\|alpha\| < 0.30 pp/月` |
| **LONGONLY_ALPHA_NOT_DETECTED** | `n ≥ 150` 且 `\|NW t\| < 1.96` |
| **INCONCLUSIVE** | `n < 150` 或 NW 有效样本 < 100 |

**0.30pp/月的依据**：等于阶段 C 的经济门槛，也等于"月度成本 @0.1% 的两倍"。
如果 alpha 连两倍成本都不到，扣完成本什么都不剩。

---

## 4. 必须同时报的三件事（否则结论会被误读）

### 4.1 成本后的 alpha

```
月度成本 = 2 × 单边换手 × 费率      （不是 × 12 年化，阶段 C 在这里出过错）
```

多头腿换手要**实测**，不能套用"月度全换手"。

### 4.2 容量

k=486~1019 只，按一手成本算需要多少钱。已知（阶段 4.1）：一手成本中位 1,203 元、
P90 6,061、P99 29,908、最大 221,800（2021 年）。

**若一手总成本超过 1,000 万，这条策略对小资金不可行**——这与"统计显著"是两件事。

### 4.3 beta

若 beta 显著偏离 1，`alpha` 里就混了"承担更多市场风险"的补偿，不能全算作选股能力。

---

## 5. 不做的事（明确划界）

| 不做 | 理由 |
|---|---|
| beta 中性化 | 引入自由参数（估计窗口），是另一个实验 |
| 行业中性化 | 本项目无行业分类数据；且反转的行业集中度本身就是效应来源之一 |
| 市值加权基准 | 无流通市值数据；等权是"零假设基准"（随机选股的平均） |
| 用股指期货对冲 | 期货基差、保证金、展期都是新问题，且与"个股做空不可得"是两码事 |
| 优化权重（风险平价、最小方差） | 那是策略优化，不是构造迁移；会引入大量可调参数 |

## 6. 预期与允许的结果

**预期 `alpha > 0` 且小于 `d`**。理由：

1. 去掉空头腿 = 去掉一半的信息，alpha 必然小于多空价差；
2. 但 alpha 也不该是 0——若反转在多头侧完全无效，那 Gate 6 的 d 就全部来自空头腿，
   这本身是一个重要发现。

**允许的结果**：

- **alpha 不显著**：说明 Gate 6 的效应主要来自空头腿（"赢家回落"而不是"输家反弹"）。
  这是一个**有价值的否证**，必须如实报告，且意味着单边多头这条路走不通。
- **alpha 显著但成本后不显著**：M1 不过，与 Gate 6 同命。
- **alpha 显著且成本后显著**：**仍然不是"能赚钱"**——容量、冲击成本、T+1 都还没建模。

**禁止**：因为 alpha 不显著就改 k、改窗口、改基准、改成本档。
