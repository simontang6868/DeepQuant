## 0. 这个实验要回答什么

阶段 C 的 §5 只授权了两类剔除：建仓日涨停/一字板剔多头、平仓日跌停/一字板剔空头。
**建仓日或平仓日的停牌没有被授权剔除**，于是：

| 情形 | 只次 | 阶段 C 的处理 |
|---|---:|---|
| 空头腿平仓日 `no_bar`（真停牌） | 4,145 | 保留 |
| 多头腿建仓日 `no_bar`（真停牌） | 1,103 | 保留 |
| 建仓/平仓日 `after_last_data`（退市或数据截断） | 74 | 保留 |
| **合计** | **5,322** | **全部保留** |

占 289,566 个检查点的 **1.8%**。保留的含义是**假设这些票能按当日收盘价成交**——
实际上停牌买不到、退市更卖不掉。**方向是偏乐观的。**

本实验量化这个乐观有多大。

### 0.1 为什么不是"顺延成交"

更真实的做法是"顺延到下一个可交易日买入"。但那样收益必须改成 `fwd[nxt] / fwd[e']`，
**收益起算点变了** → 与 Gate 6 / 阶段 C 不可比，而且"顺延几天算放弃"没有预登记依据。

所以本实验只做**剔除**（与 §5 已有的两类剔除同构），顺延留作后续、另开预登记。
**这个取舍写在这里，不是看到结果才决定的。**

## 3. 主检验

```
Δ_t = spread_t(V1) − spread_t(V0) = 2 × [d_t(V1) − d_t(V0)]
```

- 只在 V0、V1 都有观测的月份上配对（预期 237 个月）

### 3.1 判据（四档，机械判定）

| 档位 | 条件（全部满足） |

| **SUSPENSION_EFFECT_MATERIAL** | `n ≥ 150` **且** `\|NW t\| ≥ 1.96` **且** `\|mean(Δ)\| ≥ 0.30 pp/月` |

## 4. 机制诊断（描述性，不参与判定）

本实验的核心不只是"Δ 多大"，而是"为什么"。

| # | 诊断 | 说明 |
|---|---|---|
| D1 | 被剔标的数与占比（多头/空头，按年） | 停牌是否集中在特定年份（2015 股灾 / 2020 疫情） |
| D2 | **被剔多头标的的前瞻收益均值 vs 保留多头** | 若不剔除者的收益系统性更高 → 剔除确实削弱效应，这就是机制 |
| D3 | 被剔空头标的的前瞻收益均值 vs 保留空头 | 同上，方向相反 |
| D4 | 每月被剔比例与当月 Δ 的相关 | 剔除越多的月份，Δ 是否越负 |
| D5 | 剔除后腿的规模变化（n_long / n_short 的前后对比） | 确认不是把腿削到失真 |

D2/D3 是本实验**最重要的输出**：如果被剔者的收益与保留者没有差异，那么"偏乐观"这个担心
本身就没有机制支撑，可以撤掉。

## 6. 预期方向（写死，防止事后合理化）

- `mean(Δ)` **预期为负**：被剔的"输家"是反转效应的收益来源，买不到它们 → 多头腿少赚 → spread 下降。
- 幅度**预期不大**（被剔占 1.8%），但**方向明确**。
- 若实测为正且显著，说明剔除反而提高了效应——那必须给出机制解释，不能一句"符合预期"带过。
