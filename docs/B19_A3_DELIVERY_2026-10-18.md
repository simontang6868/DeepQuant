## 2. 四项口径的落地方式（逐条对应裁决）

| 裁决 | 实现 | 验证 |
|---|---|---|
| **A3-①** 权重记账 `min_commission` **生效**；订单名义金额 = 权益 × \|Δw\|，复用 `compute_fees` | 订单金额由 `equity_open × |Δw|` 折算股数，费用**只调** `compute_fees`，未写第二份公式 | `test_min_commission_binds_on_small_orders`（20 只等权 → 每笔正好 5 元） |
| **A3-②** 停牌 **冻结最后可用收盘价 + 计 `stale_valuation_count`**；冻结价只估值不交易；单期 stale 权重 > 5% 标低可信 | `PortfolioState.n_stale_positions` / `stale_weight_ratio` / `low_confidence_valuation`；冻结期间不可交易 | `test_suspended_symbol_is_valued_at_frozen_price`、`test_no_fill_on_suspended_day` |
| 卖出先于买入 | 同一执行日先遍历卖出（代码升序）再遍历买入；卖出所得当日计入可用现金 | `test_sells_execute_before_buys_on_rebalance_day` |
| 涨跌停顺延 | **买侧放弃、卖侧顺延**（不对称，理由见规格 §4）；顺延期间市值计入权益、不计入可用现金 | `test_buy_blocked_by_limit_up_is_abandoned_not_chased`、`test_sell_blocked_by_limit_down_is_deferred_to_next_day`、`test_deferred_sell_still_unfilled_at_end_is_recorded_not_faked` |

**关于「复用 `run_backtest`」的技术澄清**（规格 §0 已展开）：`run_backtest` 是单标的单持仓循环，
无法表达共享现金池，**不能**套在循环里冒充组合（那是 N 个独立账户）。因此复用的是它的
**撮合原语**，循环重写。这句话不是声明，而是被 `test_portfolio_engine_parity.py` 钉住的：
同一标的、同一天、同一笔交易，两条路径的**成交价 / 股数 / 费用 / 逐日权益**必须一致（3 条断言全通过）。

## 3. 本轮抓到的口径错误（保留记录，R5）

**错误**：`lots` 口径下，部分卖出用了「1 股粒度」而规格写的是「整手」。

拧出来的是端到端测试：3 只标的月频调仓，`lots` 口径出现一笔 **623 股**的卖出，
与被断言的「整手倍数」冲突。

**判断**：**实现是对的，规格是错的**。A 股规则是「买入必须 100 股整数倍；卖出允许零股
（零股需一次性卖出）」。买卖两侧的粒度本来就不对称。若卖出也按 100 股取整，
`lots` 口径会残留卖不掉的零股，反而更不真实。

**处置**：改规格 §2（明确写出买卖不对称）、在代码卖出分支加注释说明原因、
把测试断言收窄为「仅买入是整手倍数」。**没有为了让测试变绿而改实现**。

这条错误值得留下，因为它说明一件事：口径文档写错时，代码会忠实地跟着错，
而只有端到端用例会同时照出两者。

## 4. 组合层现在能做什么 / 不能做什么

**能做**：
- 多标的、共享现金池、月末调仓、目标权重 → 逐笔成交 → 连续净值 → 组合绩效（A6）；
- 权重记账（主）与整手约束（附）**并行报告**，同一批信号两种口径；
- 停牌/涨跌停/资金不足全部留痕（`blocked` 列表），不静默吞掉；
- 权益恒等式与现金非负逐日自检，违反即 `RuntimeError`（不产出可疑净值）。

**不能做（明确边界）**：
- 不做空、不加仓分批、不模拟部分成交与冲击成本；
- 不按板块区分 10%/20% 涨跌停（组合层对全部标的用同一 `price_limit`）；
- 不单独记账现金分红（前复权隐含再投资）；
- **未使用时点成分股** → 任何基于它跑出的横截面结果都带幸存者偏差，只能标「上界估计」；
- **不做信号设计**：组合层只负责「给定目标权重怎么记账」，不负责「选哪些股」。

最后一条尤其重要：A3 交付**不等于** Gate 1 开始。横截面动量的信号定义、参数（J=6/skip=1）
与停止条件仍按 B18 §6 的先验协议走，且必须在 A3 之上另行实现，不在本轮。
