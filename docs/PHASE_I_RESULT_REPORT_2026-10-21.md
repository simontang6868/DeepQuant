## 1. 复现闸门：两套独立实现逐位一致

这是本阶段最有价值的一件事，值得放在最前面。

| 量 | 阶段 H | 本阶段独立实现 | 差 |
|---|---:|---:|---:|
| `n_months` | 237 | 237 | 0 |
| `alpha_mean_pp` | +0.230703 | **+0.230703** | 0 |
| `t_nw` | +6.357163 | **+6.357163** | 0 |
| 段 2007-2015 | +0.237627 | **+0.237627** | 0 |
| 段 2016-2026 | +0.224905 | **+0.224905** | 0 |

**"独立"不是形容词**：

- 分组：本阶段用 `searchsorted` 在边界值数组上定位；阶段 F/H 用 `argsort` + 逐段切片写回。
  237 个月里**逐元素不一致的月份数 = 0**，包括不能整除的月份和大量并列的月份（单测覆盖）。
- MAX5：本阶段用 `np.partition`；阶段 F/H 用 `np.sort` 取尾 5 个。两者**逐位相等**。
- MAX5 中位逐月均值 **3.2323pp**，与可行性报告的 3.23234pp 一致。

所以阶段 H 那个 +0.2307 **不是某个函数的产物**，而是一个可重复的量。
（这也是项目第一次做到：两个脚本、两套算法、同一个数。）

## 3. ⚠️ 预期方向第三次被否证，而且机制这次很清楚

预登记 §4.2 写的是「预期 V1 **略高于** V0，幅度 +0.02~+0.10pp」，
依据阶段 C-2 的经验（被剔多头 fwd +1.22 < 保留 +1.75）。

**实测 −0.067292pp，方向相反。** 这是本项目第三次把方向猜反。

预登记 §4.2 要求"若 V1 低于 V0，必须单独解释"，所以分解已经算出来了：

| | 下期收益 |
|---|---:|
| 被剔除（买不到）的标的 | **+7.1304pp** |
| 保留的标的 | +1.6167pp |
| 差 | **+5.5137pp** |
| 每月被剔比例 | 1.34% |
| 对 alpha 的贡献 | **−0.0740pp**（与实测 −0.0673 吻合） |

**一句话：买不到的那些股票，恰恰是下个月涨得最多的那些。**

这和阶段 C-3 的发现完全对得上：**第 1 天不是反转，是动量**。
涨停当天的标的有惯性，次日继续涨 —— 把它们剔掉，等于剔掉了组合里最强的部分。

那为什么阶段 C-2 的经验是反的？因为那里剔的是**反转策略的多头腿**（上月的输家）。
输家涨停 = 反弹，反弹之后熄火；而这里的池是"全池减去最高 MAX5"，涨停是真实动量。
**同一个"剔除涨停"的动作，在不同池里方向可以相反** —— 这条以后不能再泛化引用。

### 4.1 但"被成本吸收"这个名字需要拆开看

| 口径 | 净 alpha @0.3% | t_net | 是否过 C |
|---|---:|---:|---|
| **V0（不可成交）** | +0.1208 | **+2.499** | 过 |
| **V1（可成交）** | +0.0502 | **+1.038** | **不过** |

两者的成本完全相同（0.1132pp/月）。差别**全部来自可成交约束的 −0.067pp**。

所以严格说：**不是成本吃掉了 exQ5，是"买得到"这件事吃掉了它。**

但机制分解表明真正的杀手是 §2 的可成交剔除，不是费率本身。

换个角度：如果只按 V0 口径报告（+0.2307，t=6.36），这个构造看起来非常好；
可一旦要求"这些票真的能买到"，它就掉到 t=1.04。**这个落差就是阶段 I 存在的意义。**

## 5. 容量：`weight_mae` 又一次证明了它抓不住现金

| 资金 | 可买只数（覆盖） | 未投资比例 | weight_mae |
|---|---:|---:|---:|
| 150 万 | 1,249（59.1%） | 22.62% | 0.0185pp |
| 300 万 | 1,583（78.7%） | 20.31% | 0.0123pp |
| 500 万 | 1,714（90.4%） | 17.57% | 0.0089pp |
| **1,000 万** | **1,894（98.5%）** | **12.32%** | **0.0053pp** |
| 3,000 万 | 1,936（99.9%） | 4.75% | 0.0023pp |

**看 1,000 万那一行**：覆盖 98.5%，权重偏离 0.0053pp（完美等权），
但**有 12.32% 的资金趴在账上没投出去**。

这就是 MEMORY §10 那条教训的实证：整手取整产生的现金残留，
会让 `weight_mae` 看起来毫无问题（0.0053pp 远低于 0.5pp 门槛）。
**如果只看 mae，这一档会被判"容量可行"；加上未投资比例才挡住。**
预登记要求两个条件同时满足是对的，两个指标都必须报。

可负担子集（W=1,000 万）的 alpha = **+0.1784pp（t=3.769）**，高于 V1 的 +0.1634
—— 描述性，不参与判定。剔除规则按一手金额、不按信号值，所以不是选股偏好。

## 6. 诊断：需要修正一个说法

| | 全样本 | 2007-2015 | 2016-2026 |
|---|---:|---:|---:|
| **R_Q5（最高 MAX5 组的绝对收益）** | **+0.5296pp** | **+1.3326pp** | **−0.1427pp** |
| R_bench（反推） | +2.648pp | +2.283pp | +0.757pp |

**Q5 组在大部分时间里是上涨的**（全样本 +0.53pp/月，只有 48.1% 的月份为负）。

所以我此前在阶段 G/H 里那句「效应在**高 MAX5 会跌**」**说得不准确**，需要修正为：

> 效应在于 **Q5 系统性跑输池平均**（`R_bench − R_Q5 ≈ 0.9pp/月`），
> 而不是 Q5 绝对下跌。

修正的意义：如果谁按"高 MAX5 会跌"去理解，就会期待它在熊市里特别有效 ——
但数据显示它是**相对**现象，两段里 R_Q5 从 +1.33 变到 −0.14（绝对值大幅下降），
而与池的差距却稳定在 0.95 → 0.90。**稳定的那个量是相对差距，不是绝对收益。**

其余：Q5 成员与上期重叠 36.5%（持续性中等）；分年度 alpha 有 19 个年度为正、1 个为负（2013 −0.18）。

## 7. 成熟度与处置

```
M1 需要：EXQ5_CONFIRMED ∧ 容量在 1,000 万可行
实际：   EXQ5_COST_ABSORBED（C 不过）∧ 未投资 12.32% > 5%
→ M0
```

**两项都没过，且是不同原因**（一个是成本后不显著，一个是现金残留）。

处置：
- **不改变**阶段 F（多空价差）与阶段 G（单边买 Q1）的判定，口径不同；
- **修正**阶段 H 的评估结论：阶段 H 说"统计与成本都过关，卡在容量"，
  那是在**不可成交口径**下。可成交口径下，@0.3% 成本也不过；
  阶段 H 原文保留，此处加注；
- exQ5 作为可执行策略：**关闭**。它统计上真实、跨期稳定，但**在能买到的股票里**，
  0.3% 成本后不显著，且需要 3,000 万以上资金才能把现金残留压到 5% 以内。

## 8. 预登记自身的两处缺陷（不改预登记，只登记）

   又写"两者结果必须逐元素一致" —— 不 import 就无从比较。

## 9. 诚实限定（必须随结论引用）

1. **本阶段不提供样本外证据。** exQ5 是在同一批数据上由阶段 F 的构造代数推出的。
   本阶段提供的是"实现独立 + 判据前置 + 可成交口径"，不是新样本。
   真正的样本外需要 2026-10 之后的前瞻数据或另一个市场。
2. `alpha_exQ5 ≡ 0.25 × (R_bench − R_Q5)` 是**恒等式**，不是新因子。
3. 分年度方向并非逐年稳定（2013 为 −0.18，2025 仅 +0.02），
   "不衰减"指的是**两段**而非逐年。
