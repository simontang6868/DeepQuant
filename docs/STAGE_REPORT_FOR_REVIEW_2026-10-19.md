## 3. 第 3 层：策略是否显示统计优势（核心结果）

### 3.1 设计（预登记 v1.3，先于结果冻结）

| 项 | 设定 |
|---|---|
| 假设 | A 股 50 只池、月度调仓的简单横截面动量，是否取得**相对同池等权基准**的稳健超额 |
| 信号 | 60 日动量、skip 5 日、取前 20%、等权、月度调仓、次日开盘成交 |
| 主实验参数 | **单参数组合，自由度 = 0**（无调参空间，故不存在「换组参数试试」的解释空间） |
| IS / OOS | OOS = 2021-01 ~ 2024-12，**48 个月** |
| 基准 | **同池等权**（非沪深 300；本地无指数数据） |
| 判据 | 三档机械判据：成功 / 失败 / 证据不足；冲突优先级 `失败 > 证据不足 > 成功` |
| 多重检验 | 12 组敏感性 + Benjamini–Hochberg 校正 |

### 3.2 结果

| 指标 | 值 |
|---|---|
| n | 48 个月 |
| mean(d)（月均配对超额） | **−0.003961 /月**（−0.40pp/月） |
| std(d) | 0.048257 |
| t | **−0.569**（双侧 p = 0.5723） |
| 胜率（d > 0 月份） | **41.7%**（20/48） |
| **95% CI** | **[−0.017974, +0.010051] /月（跨 0）** |
| 敏感性 12 组中 mean(d) > 0 | **2 组**（S5、S8） |
| BH 校正后 q ≤ 0.05 | **0 组**（12 组 q 全为 0.8744） |
| 排除 `600809.SH` 后重跑 | mean(d) = −0.003284，t = −0.464 → **符号未翻转** |

**判定：`failure`。触发的判据三条**：`mean(d) ≤ 0`、`t < 1.0`、`敏感性正组数 = 2 ≤ 4`。

### 3.3 协调层独立复核（重要，供专家核验）

我没有直接采信 B 线报告，而是从 `gate1_out/032a11f591553e25/monthly_paired.csv` 的 48 行原始数据**独立复算**：

| 项 | B 线报告 | 我复算 | 结论 |
|---|---|---|---|
| mean(d) | −0.003961 | −0.003961 | ✅ 一致 |
| std(d) | 0.048257 | 0.048257 | ✅ 一致 |
| t | −0.569 | −0.5687 | ✅ 一致 |
| 胜率 | 41.7% | 20/48 = 41.67% | ✅ 一致 |
| **OOS 窗口内复利累计** | 报告表列 **+331.43% / +357.89%** | **+35.2% / +66.36%** | ⚠️ **不一致，见下** |

**关于累计收益那两列**：差异不是算错，而是**口径标注缺失**——`sensitivity.csv` 的 `strategy_total_return` / `benchmark_total_return` 是**全程（2017-02 ~ 2024-12）累计**，不随判定窗口 `eval_end` 截断。B 线已在 `KNOWN_ISSUES_RESEARCH` §2.3 把它记为缺陷 **D2**。

> 由此得到一个可直接写进结论的事实：**OOS 48 个月内，策略 +35.2% vs 同池等权 +66.4%，累计跑输约 31pp** —— 方向与 `mean(d) < 0` 一致，但**幅度不构成统计显著**（CI 跨 0）。

**给专家的提示**：如果只看报告表格里的 `+331%`，会误以为策略大幅跑赢基准。**这是本轮最容易误读的一处，建议评审时特别核对。**

### 3.4 这个「失败」到底有多强（B 线自评，我认为准确）

1. **`t = −0.569` 远未达显著**，CI 跨 0 → 不能说「已证明显著跑输」。
2. **统计功效不足**：σ ≈ 0.048/月，要检出 0.003/月 的边际需约 **160 个月**观测；本轮只有 48 个月（30%）。
   → **「失败」判定比「成功」判定可靠，但两种判定都不强。**
3. **参数自由度已为 0**，所以「换组参数就有效」不成立——那属于新实验，不属于本研究。
