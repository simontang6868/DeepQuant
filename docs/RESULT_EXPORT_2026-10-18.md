# 结果导出（2026-10-18）

上一版「仍不解决」清单里的第 5 条：**没有结果导出**。当时界面上的说法是
「要留存自己截图」——把留档成本推给用户，这不算解决问题。这一轮补上。

## 1. 导出什么

### 单标的回测（`POST /backtests` 的结果页）

| 按钮 | 文件 | 内容 |
|---|---|---|
| 绩效摘要 CSV | `..._summary.csv` | 初始/期末权益、累计盈亏、收益率、年化、波动、回撤（峰值/谷底日）与不可计算指标 |
| 成交明细 CSV | `..._fills.csv` | 成交ID、订单ID、日期、标的、方向、价格、数量、成交额、佣金、印花税、过户费、费用合计 |
| 订单明细 CSV | `..._orders.csv` | 含**未成交**订单及其拒单原因 |
| 账户逐日状态 CSV | `..._states.csv` | 逐日现金、持仓、成本、收盘价、市值、总资产、估值状态 |
| 资产曲线 PNG | `..._equity.png` | 页面上已渲染的曲线，2× 缩放、白底 |
| 完整结果 JSON | `..._full.json` | 后端原始响应全量（含 config / limitations / 指纹） |

### 组合回测（`POST /portfolio-backtests` 的结果页）

在「绩效 / 逐日状态 / 成交 / PNG / JSON」之外，多两类：

| 按钮 | 内容 |
|---|---|
| 被阻挡订单 CSV | 日期、标的、方向、原因、请求数量、实际成交 |
| 调仓目标权重 CSV | 每个调仓日逐标的的目标权重（长表） |
| 数据指纹 CSV | 逐标的名称、行数、区间、来源文件、原始 CSV 的 SHA-256 |
| 口径声明 CSV | limitations / 数据质量 / 不完整原因 / 一致性问题，分类列出 |

**为什么单独列被阻挡订单**：只导出成交会让人以为组合按目标权重完整建仓了。
3 只等权的实测里有 46 笔被阻挡、43 笔成交——阻挡比成交还多。

## 2. 三个设计取舍

### 2.1 文件名自带口径

`deepquant-portfolio_51sym_2019-01-02_2024-12-31_<时间戳>.csv`

不叫 `export.csv`。三个月后打开一份 `export (3).csv` 没有任何人知道它跑的是什么。
时间戳用 `20261018-235207` 而非 ISO 字符串——后者的 `:` 在 Windows 文件名里非法，
会让下载静默失败。

### 2.2 CSV 纯净、口径走 JSON

CSV 只放表头 + 数据行：

- 缺失值**留空**，不写 0、不写 `-`、不写「暂无」——后两者会被当成有效数据参与计算；
- 比例字段保留**原始小数**（0.1234），不写 "12.34%"。

完整的费用来源、涨跌停设定、幸存者偏差提示、数据指纹只在 JSON 存档里。
混在一起会两头不讨好：注释行让 `pd.read_csv` 错位，纯数据又丢了「这是模拟费率」这个前提。

### 2.3 PNG 失败必须说出来

SVG → canvas 在无头环境（jsdom）必然失败。此时抛 `PngExportError` 并在界面上显示
`role="alert"` 的红色提示，**并且告知替代方案**（改用 JSON 存档或截图），
而不是安静地存下一个 0 字节或全白的文件——那会让用户以为已经保存好了。

所有失败路径统一拼上同一句兜底提示，避免出现「报错了但不知道该怎么办」。

## 3. 两个实现上的坑（已处理）

**字体丢失**：recharts 的 `<text>` 靠 CSS 继承字体，序列化成独立 SVG 后这层继承没了，
中文会掉回默认衬线体。所以显式把当前 computed 字体栈写进 `<style>`。

**尺寸为 0**：`ResponsiveContainer` 下的 SVG 常只有 viewBox 没有显式 width/height，
不补齐的话画出来是 0×0 或按默认 300×150 裁切。

另外，CSV 公式注入防护**只对字符串生效**。数字（含负数）不参与——
负收益率 `-0.1853` 开头正好是 `-`，若一并加前缀就会把它变成文本列，那才是真的毁数据。

## 5. 顺手修掉的一个测试缺陷

`test_main_dry_run_with_exclusion_runs_no_backtest` 原本断言
「`gate1_out/` 不存在或为空」。它想守的是「dry-run 不产生副作用」，
但写法把结论建立在工作区恰好干净之上——一旦真跑过一次，目录留下，
这条就会假失败，而真正要守的东西反而没测到。

改为**运行前后目录快照比对**（相对路径 → 字节数 + mtime_ns）：
无论目录之前存不存在，都能正确断言「dry-run 没有改动任何东西」。

**一个必须点出的点**（来自 `INDEX.md` 的自我纠正）：排除跑内部自带的
