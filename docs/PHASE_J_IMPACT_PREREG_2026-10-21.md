## 0. 先说清楚能做什么、不能做什么

**本项目没有任何盘中数据**（无逐笔、无买卖盘、无委托簿）。
只有日频 OHLCV + 分红。所以：

- ❌ **不可能测量**真实的冲击成本；
- ✅ 只能用**流动性代理变量**建模，并明确承认这是模型，不是实测。

因此本阶段**不产生“实测冲击成本”**，只产生两类东西：

1. 一个**无需自由参数**的估计（Amihud 线性）；
2. 一个**打平门槛**（平方根模型需要 η，我们不猜 η，而是反解 η\*）。

**结论的表述必须保留“模型依赖”这个限定，不许说成实测。**

## 2. 两个模型（都报，不许只报好看的那个）

设组合资金 `W`，持仓 `k` 只，等权 → 单标的仓位 `P = W / k`。
每期被交易的标的集合 `T_t`（成员变动），单边换手 `to_t`。

### 2.1 模型 A：Amihud (2002) ILLIQ（线性，**无自由参数**）

```
ILLIQ_i,t = mean_{21 个交易日}( |r_i,d| / DV_i,d )      单位：收益 / 元
交易 P 元的价格冲击（收益）≈ ILLIQ_i × P
组合冲击 impact_t^A = mean_{i ∈ T_t}( ILLIQ_i,t × P )
```

`|r|` 取自 **ADJ**（避免除权日跳变污染），`DV` 取自 **EXEC**（真实成交金额）。
两者是同一天的属性，直接相除合法。

### 2.2 模型 B：平方根冲击（Almgren et al. / Gatheral）

```
冲击_i = η × σ_i,daily × sqrt( P / ADV_i )
组合冲击 impact_t^B(η) = mean_{i ∈ T_t}( η × σ_i × sqrt(P / ADV_i) )
```

`η` 是自由参数。**我们不许猜 η**——改为计算**打平门槛 η\***：

```
η* = 使得 mean(net_t) = 0 的那个 η
```

然后与文献常用区间（η ∈ [0.1, 1.0]）比较：
- `η* < 0.1` → 即使在最乐观假设下也打平不了，**彻底关闭**；
- `η* > 1.0` → 即使在最悲观假设下也过得去。

## 3. 三轮摩擦的完整口径（这是本阶段的主统计量）

逐月构造净值序列：

```
net_t(W) = f_inv,t × alpha_V1,t   −   comm_t   −   impact_t(W)
             ↑                        ↑            ↑
         现金残留折损              佣金(0.3%)    冲击(A 或 B)
```

| 项 | 定义 |
|---|---|
| `alpha_V1,t` | 阶段 I 的 V1 逐月 alpha（`phasei_out/8f5c35121fdb/monthly.csv` 的 `alpha_v1_pp`） |
| `f_inv,t` | `1 − 未投资比例`，用**阶段 I 同一套** `capacity_of` 规则（按一手金额从高到低剔 + 整手取整） |
| `comm_t` | `2 × to_t × 0.003 × 100`（pp/月） |
| `impact_t` | 模型 A 或 B |

**为什么把现金残留折损放进去**：12.32% 的资金趴在账上，这部分拿不到 alpha。
阶段 I 只把它当成"容量门槛"，没有算进收益；本阶段必须算。
（**注意**：这里按"以投入资本计的 alpha"口径，即 `f_inv × alpha`。
  现金相对**基准**的拖累另作描述性报告，见 §6。）

统计：对 `net_t` 做 NW(3)，双侧 1.96。

## 5. 判据（三态，预登记写死）

令 `t(W)` = `net_t(W)` 的 NW t 值。

| 判定 | 条件 |
|---|---|
| `NET_AFTER_EXECUTION_SIGNIFICANT` | **所有** W 上 `\|t\| ≥ 1.96` |
| `NET_AFTER_EXECUTION_SCALE_DEPENDENT` | 部分 W 上 `\|t\| ≥ 1.96`，部分不过 |
| `NET_AFTER_EXECUTION_ABSORBED` | **所有** W 上 `\|t\| < 1.96` |

**主统计量是"全部执行摩擦之后"的净值**，不是"冲击成本"这一项。
因为单独看冲击没有意义——真正要回答的是"这套东西还能不能用"。

## 6. 归因（必报，把三种摩擦分开）

对每个 W，报告：

| 折损项 | 数值（pp/月） |
|---|---:|
| 起点 alpha_V1 | +0.1634 |
| 现金残留折损 | `(1 − f_inv) × alpha_V1` |
| 佣金 @0.3% | `2 × to × 0.003 × 100` |
| 冲击（模型 A） | `mean(impact^A)` |
| 冲击（模型 B, η=1） | `mean(impact^B(1))` |
| **净** | 上面的差 |

**归因的目的是回答"到底是谁杀死了它"**，而不是给一个笼统的"不可用"。

另外**描述性**报告（不参与判定）：现金相对基准的拖累 `(1 − f_inv) × mean(R_bench)`。
这一项是 beta 性质，方差大、会掩盖信号，因此**不并入主统计量**，
但必须报出来——否则读者会误以为"未投资只是少赚一点 alpha"。

## 7. 预期方向与机制（写完再跑）

### 7.1 预期：冲击成本在 1000 万量级上**可忽略**

依据：`P = W/k`。W=1000 万、k≈1,894 → **P ≈ 5,281 元**。
而 A 股日均成交额中位数在千万级以上 → **参与率 `P/ADV` 远小于 0.1%**。

- 模型 A（Amihud）预期 **< 0.01pp/月**；
- 模型 B 在 `η=1` 下预期 **0.01 ~ 0.10pp/月**（取决于低流动性个股的参与度）。

### 7.2 预期：真正杀死它的是**现金残留 + 佣金**，不是冲击

粗算（用阶段 I 的 f_inv 与 to=18.3%）：

| W | f_inv | f_inv × alpha | 佣金 | 净（未计冲击） |
|---|---:|---:|---:|---:|
| 150 万 | 0.774 | 0.1265 | 0.110 | **+0.017** |
| 1000 万 | 0.877 | 0.1433 | 0.110 | **+0.033** |
| 3000 万 | 0.953 | 0.1556 | 0.110 | **+0.046** |

以 `se ≈ 0.0361`（= 0.163411 / 4.528365）估算，最好的一档 t 也只有 **≈ 1.3**。

→ **预期判定：`NET_AFTER_EXECUTION_ABSORBED`，且主因是现金残留 + 佣金，冲击几乎无关。**

## 8. 诊断（必报）

1. **参与率分布** `P / ADV` 的中位 / P90 / P99 / 最大 —— 若 P99 > 5%，说明存在真正难买的标的；
2. **ADV 分布**（池中位、P10）—— 给出流动性的量级感；
3. **ILLIQ 的横截面分布** —— 确认不是少数极端值主导；
4. **打平 η\*** 在每一档 W 上的值；
5. **两段（2007-2015 / 2016-2026）** 的净值与冲击 —— 看冲击是否恶化。
