# 阶段 S 预登记：exQ5 现代段（2016-2026）可执行性结项检验

- 冻结时间：2026-10-22
- 预登记编号：`phaseS-exq5-modern-era-v1`
- 类型：**确认性检验**（有预登记、有唯一主检验、有写死判据）
- 主题：exQ5 在 2016-2026（"现代段"）单独口径下，成本后净 alpha 是否可检出

---

## 0. 为什么开这一阶段

项目使命是检验**可执行性**。阶段 R 用同一把尺子量 SURGE 时发现：
它的全样本显著性**完全由 2007-2015 驱动**，后段任何资金档都不显著 → 判死。

而 exQ5（项目唯一存活信号）从未被单独量过现代段：

1. 阶段 O 的 B 判据只查了 `net_BASE_3000w` 的后段 t=2.5813（已披露）；
2. **更保守的 √ 冲击模型（η=1）从未进入过 exQ5 的净值**——阶段 O 只收取了
   Amihud 常数上界 0.000784pp，而 √ 模型的全样本均值是 0.018996pp，**大 24 倍**；
3. 后段的 MDE、事后功效、bootstrap 区间从未报告；
4. 其他费率口径（STRESS / CONSERVATIVE / 1000 万档）的后段从未报告；
5. 后段的执行环境（现金残留、可选股票数、换手、冲击）从未与净值一起评估。

本阶段补上这一刀。它是 exQ5 的**结项检验**：要么拿到"现代段可执行"的正式证据，
要么拿到"现代段未检出"的正式证据。**两种结果都照实报告。**

**本阶段不新增策略、不调参数、不换构造、不重算选股**，只读阶段 O / 阶段 J
已冻结的逐月产物，按预登记公式构造新净值序列。

## 1. 主检验（唯一判定）

### 1.1 数据（只读，sha256 校验，不一致拒绝运行）

| 文件 | sha256 |
|---|---|
| `phaseo_out/ac7aa2830ab0/monthly.csv` | `768e49a9462cd7c00f3aacfcdb1e87bbe37bb75b348cd6fd85809e12493a4152` |
| `phasej_out/f76de8a277f6/monthly.csv` | `6f1961bdc2709c98b637ef545a8a90e2f76b3e2f1983974c827e35dffb859235` |

两个文件必须逐行按 `signal_date` 对齐，n=237，2007-01 → 2026-09。

### 1.2 主序列（冻结公式，单位 pp）

```
net_S_3000w(t) = net_BASE_3000w(t) + 0.00078376 − 0.01899561
```

- `+0.00078376`：**退回**阶段 O 收取的 Amihud 冲击常数上界
  （= 阶段 J `by_capital["3000万"].impact_A_pp`）；
- `−0.01899561`：改收 **√ 冲击模型 η=1** 在 W=3,000 万的常数
  （= 阶段 J `by_capital["3000万"].impact_B_eta1_pp`）。
  这是两个冲击模型中**更保守**的一个（全样本均值 0.018996 vs Amihud 0.000784）。
- 口径：BASE 真实费率（佣金 0.025% 双边 + 印花税 0.05% 仅卖出 + 过户费 0.001%
  双边）+ 现金残留 + √ 冲击 η=1。

**为什么用常数而不是逐月序列**：3,000 万档没有逐月 √ 序列（阶段 J 只落了
1,000 万档的逐月序列）；常数法正是**阶段 O 自身的方法论**（它对 Amihud 就用
常数上界）。已核实该常数会**高估**后段成本（后段逐月 √ 冲击均值只有前段的
35%，见 §2 副检验 6），因此主检验是**保守**的；逐月精确版列副检验 3/4。

### 1.3 统计口径（全部写死）

- 分段：`signal_date ≥ 2016-01-01` 为现代段（n=129），此前为前段（n=108）
- 对现代段序列求：均值、Newey–West（Bartlett 核，L=3）的 se 与 t、双侧 p
- ⚠️ **单位铁律**：序列单位是 pp；`newey_west()` 入参必须是**小数**（pp/100），
  读 `mean_pp` / `se_nw_pp`。直接传 pp 会放大 100 倍（本项目踩过两次）
- 标准误同时报 iid 与 NW 两套（alpha 序列有负自相关 → se_NW 常小于 se_iid）
- **MDE = 2.8016 × se_nw**（双侧 5%、功效 80%）——必报
- 事后功效 = `Φ(|t|−1.96) + Φ(−|t|−1.96)`（|t|=1.96 时恰为 50%）
- bootstrap：月份整段重抽 2,000 次（seed=20261022），报 95% 分位区间
  （稳健性交叉验证，**非**判定依据）

### 1.4 判据（三档，写死）

| 档位 | 条件 | 含义 |
|---|---|---|
| `MODERN_ERA_ALPHA_DETECTED` | \|t_nw\| ≥ 1.96 **且** 均值 > 0 | 现代段成本后 alpha 可检出 |
| `MODERN_ERA_ALPHA_NOT_DETECTED` | \|t_nw\| < 1.96 | 未检出（必须同报 MDE 与功效） |
| `MODERN_ERA_ALPHA_NEGATIVE` | \|t_nw\| ≥ 1.96 **且** 均值 < 0 | 现代段翻负 |

⚠️ 三档都**不得**表述为"证明现代段可用 / 不可用"。第一档的标准表述只能是：

> "在 BASE 真实费率 + √ 冲击 η=1 口径下，现代段 129 个月的成本后净 alpha
> 均值为 X pp（NW t=Y，MDE=Z pp）；检验能力为 Z pp，无法排除小于 Z 的真值。"

## 5. 预期方向与机制（写死，跑完不得改口）

**可算量基础**（全部来自已披露数字，不新看结局变量）：

- 后段 `net_BASE_3000w` = +0.129408pp，t_nw=2.5813 → 反推 **se_nw(后段) ≈ 0.0501pp**
- 主序列后段点估计 ≈ 0.129408 + 0.000784 − 0.018996 = **+0.111196pp**
- 若 se 不变 → **t ≈ 2.22**；MDE ≈ 0.140pp；事后功效 ≈ 0.60

→ **预期判定：`MODERN_ERA_ALPHA_DETECTED`（t 落在 2.0 ~ 2.6）**。

**机制**：exQ5 的效应来自排除 MAX5 最高的 20%——彩票偏好下 Q5 系统性跑输
（结构 9.4：稳定的是**相对差距**，不是绝对收益）；其机制基础
（T+1 + 卖空约束 → 高估无法被套利）在 2016 后未变。与 SURGE
（事件驱动型关注度，会被更快套利）不同，**没有先验理由**预期它在现代段消失。
已核实的执行环境变化反而有利：后段换手下降 25%（0.218→0.163）、
可选股票数翻倍（1,321→3,063）、√ 冲击降至前段的 35%。

**同时预期**：STRESS 口径后段仍不显著（全样本 t=1.27）；
CONS@1000万 后段边缘（全样本 t=3.12，后段量级约 0.082pp）。

**若实测与预期相反，照实报告，不得改口。** 尤其若主检验落
`MODERN_ERA_ALPHA_NOT_DETECTED`，结论必须写成"现代段未检出，MDE=X pp"，
**不得**说成"衰减了"——衰减是阶段 P 的差值问题，本阶段不检验差值。
