# 阶段 Q 预登记：增量信息检验（"独立信号"这个说法到底成不成立）

- 冻结时间：2026-10-21
- 预登记编号：`phaseq-incremental-information-v1`
- 类型：**确认性检验**
- 主题：在控制波动率与彼此之后，MAX5 / SURGE 是否仍有横截面预测力

---

## 0. 为什么开这一阶段

阶段 N 审计的阻塞清单 **B5**：*增量信息检验无预登记*。

阶段 N 做过一次 Fama-MacBeth，但它是**探索性**的。而我们在
专家报告 / 评审包里已经把结论写成：

> "MAX5、异常放量（SURGE）在控制波动率后仍显著，且**彼此独立**，不是旧因子的影子。"

**"独立"这个词目前只有探索性证据支撑。** 本阶段把它做成确认性检验。

同时，分层界定审计 §C 已经写明的四件事（不许混为一谈）：

| 层次 | 含义 | 现状 |
|---|---|---|
| 低相关 | 秩相关低（MAX5 0.88 vs SURGE 0.35） | 已测 |
| 控制波动率后的条件收益差 | 层内价差仍显著 | MAX5 保留 68.6%、SURGE 保留 56% |
| **控制多个信号后的增量信息** | **FM 回归中的偏斜率** | **仅探索性** ← 本阶段 |
| 统计独立 | 分布独立 | 从未主张，也不测 |

**低相关 ≠ 独立 ≠ 有增量信息。** 本阶段只测第三层。

## 1. 检验设计

### 1.1 数据面板

与阶段 N 完全相同（便于做复现闸门），并额外加一层可成交约束作为副检验：

| 项 | 值 |
|---|---|
| 池 | as-of 全 A（`build_mask` + `MIN_LISTED_DAYS=252`） |
| 窗口 | 2007-01-01 ~ 2026-10-31，月末调仓点 |
| 信号 | MAX5（21 日窗口内前 5 大日收益均值，`TOP_N=5`） |
| | SURGE（近 21 日 / 前 21 日**日均成交额**之比，`MIN_VALID` 各 ≥19 日） |
| | VOL（同 21 日窗口日收益标准差，ddof=1） |
| | **REV21（过去 21 日收益 = P[pos−1]/P[pos−WIN] − 1）** |
| 前瞻收益 | `ffill[nxt] / ffill[pos] − 1`（与阶段 F/L/M 同口径） |
| 横截面变换 | **秩 z-score**（`argsort` 两次后标准化），抗异常值 |

### 1.2 ⚠️ 对阶段 N 的一处**修正**：REV 的定义

阶段 N 用的是 `rev = ret[pos]`——**单日**收益。
而本项目（Gate 6 / 阶段 C / 阶段 E）的反转定义是 **21 日形成期收益**。

单日收益基本是噪声，用它当"控制反转"变量等于**没控制**。
本阶段改用 **REV21 = P[pos−1] / P[pos−WIN] − 1**（过去 21 日收益，正值=赢家）。

**这不是调参择优**，是把控制变量改成与项目既有定义一致的东西。
为可追溯，**两种定义都跑**，阶段 N 的定义作为**复现闸门**。

### 1.3 主检验：Fama-MacBeth 横截面回归

逐月（t = 1…237）做横截面 OLS：

```
fwd_i,t = β0 + β1·z(MAX5) + β2·z(SURGE) + β3·z(VOL) + β4·z(REV21) + ε_i,t
```

取 237 个月的斜率序列，用 **Newey–West（Bartlett，L=3）** 判显著，临界 **1.96**（双侧）。
单位：**pp / 1 个横截面秩标准差**。

**两个并列主假设**（关于两个不同变量的两个不同命题，不做多重检验校正，
两点都完整报告；理由见 §5 局限）：

- **H_MAX5**：β1 ≠ 0，文献方向为**负**（高 MAX5 → 未来收益低）
- **H_SURGE**：β2 ≠ 0，文献方向为**负**（高异常换手 → 未来收益低）

### 1.4 判据（写死）

| 档位 | 条件 |
|---|---|
| `INCREMENTAL_CONFIRMED` | \|t_NW\| ≥ 1.96 **且** 符号为负（文献方向） |
| `INCREMENTAL_ABSORBED` | \|t_NW\| < 1.96 |
| `INCREMENTAL_DETECTED_WRONG_SIGN` | \|t_NW\| ≥ 1.96 但符号为正 |

**保留率**（必报，描述性）：`多元偏斜率 / 单变量斜率`。
它是"控制掉其他信号后还剩多少"的直接读数，比 p 值更直观。

### 1.5 复现闸门（用阶段 N 的**原定义**跑一遍）

以阶段 N 的定义（REV = 单日收益）重跑同一回归，必须与阶段 N 的探索性结果
逐位一致（容差 1e-4）：

| 变量 | 阶段 N 报告值 |
|---|---:|
| MAX5 | −0.209127 pp/sd，t_NW = −1.2871 |
| SURGE | **−0.232875 pp/sd，t_NW = −2.8327** |
| VOL | −0.114457 pp/sd，t_NW = −0.7012 |
| REV | +0.029855 pp/sd，t_NW = +0.3485 |

不一致则**拒绝继续**（脚本直接退出）。

## 4. 预期方向（必须写；⚠️ 并声明预期被污染）

用**可算的量**判断：

- SURGE 与 MAX5 的秩相关只有 **+0.48**（阶段 L 复核 +0.4775），远低于
  MAX5 与波动率的 +0.88。→ 两者的重叠有限，**不会被彼此完全吸收**。
- 波动率对 SURGE 的解释力更低（+0.35）。

→ **预期：SURGE 的偏斜率显著（β2 < 0，\|t\| ≥ 1.96）；MAX5 的偏斜率较弱。**

### ⚠️ 诚实声明：这个预期**不是干净的先验预测**

我已经看过阶段 N 的探索性结果（SURGE t=−2.83 显著、MAX5 t=−1.29 不显著），
该结果**直接塑造了这个预期**。因此：

- 若实测与预期一致，**它是"对一个探索性发现的重复"**，
  其证据强度**低于**真正前瞻性的预测；
- 本阶段相对阶段 N 有一处**真实改动**（REV 单日 → 21 日），
  所以也不是纯粹的复跑；
- 无论结果如何都照实报告，**不得**把"与预期一致"说成"预测成功"。

## 5. 局限（预登记时就写明）

1. 两个并列主假设**不做多重检验校正**。理由：它们是关于两个不同变量的
   两个不同命题，不是同一命题的多次检验。两个 p 值都完整报告，
   评审者可自行加校正。
2. FM 回归对变量间关系施加了**线性**假设；S2 的层内回归部分缓解这一点。
3. 本阶段测的是**信息含量**，**不是可执行性**。显著 ≠ 可交易（纪律第 7 条）。
4. 全部样本内。
