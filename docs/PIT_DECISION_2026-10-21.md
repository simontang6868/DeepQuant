# PIT 决策：自建 as-of 宇宙 vs 采购（已拍板：先自建，暂不采购）

> 日期：2026-10-20（晚）→ 2026-10-21（凌晨）｜ 决策人：单线（Agent 协调层）
> 上游：`docs/PIT_DATA_SOURCE_EVALUATION_2026-10-20.md`（当时结论"免费直取历史 PIT 不存在"）

---

## 0. 结论（一行）

**自建 as-of 可投资宇宙在技术与成本上都可行 → 先自建，暂不采购；采购只在"必须区分'是否在指数成分内'"时才立项。**

---

## 1. 上一轮为什么停在"采购"

上一轮把"PIT 成分股"当成一件事：**拿到历史时点的沪深300 成分名单**。
逐个试过：

| 候选 | 结果 |
|---|---|
| 新浪"历史成分"表 | ❌ 只到 2009，2010 后全缺 |
| 中证 OSS 成分 xls | ⚠️ 只有**当前**成分，无历史分日期版本 |
| 中证官网 | ❌ SPA，news/notice/list API 全 404 |
| CSMAR | 需学术授权 |
| Tushare Pro | ¥200 起（2000 积分） |

于是结论写成"免费直取历史 PIT 不存在"，停在采购上。

---

## 2. 这一轮的新发现：**PIT 的目的可以不用成分名单达到**

PIT 成分名单只是**手段**，真正要解决的问题是：

> 回测时，**不能用"未来才知道谁会成功"来决定当时能买什么**。

要达到它，至少需要两件事：

| 需求 | 是否必须依赖成分名单 | 本轮实测 |
|---|---|---|
| ① 哪些股票在 t 时点**已上市且可交易** | **否**——用**上市日期**即可 | ✅ 免费可得 |
| ② 哪些股票在 t 时点**已退市** | 否——用**退市日（行情序列终点）**即可 | ⚠️ 见 §3 |
| ③ 某股**是否在沪深300 成分内** | **是** | ❌ 仍无免费直取 |

**关键洞察**：第 ③ 条只在"复制指数"或"成分股内选股"这类命题里才必要。
而本项目所有横截面实验的命题都是"**在这个可投资集合里，信号有没有预测力**"——
只需要 ① 和 ②。**所以自建 as-of 宇宙就能解锁 4.3，不必先买数据。**

## 3. 自建方案的可行性实测

| 项 | 实测 |
|---|---|
| 全 A 代码 + **上市日期** | ✅ 东财 `push2 clist`（`f26` = 上市日期）可用；**但 `pz≥100` 会被断连**，需用 `pz=5` 分页或改走新浪 |
| 全 A 代码（稳定版） | ✅ 新浪 `Market_Center.getHQNodeData(node=hs_a)` 分页取到 **5,574 行 → 沪深 A 股 5,223 只**，0 失败 |
| 行情抓取吞吐 | ⚠️ 腾讯分页实测 **≈0.9 只/秒**（8 workers）→ 5,223 只约 **100 分钟** |
| 磁盘 | ⚠️ 约 **1.5 GB**；当前剩余 **19 GB**，够用但不宽裕 |
| 退市历史名单 | ❌ **仍未解决**。现有 249 只退市股来自既有文件（`data/qfq_mult/delist/`），**来源与完整性未记录**；全市场历史退市名单暂无免费直取 |

### 3.1 残余缺口（必须写进任何使用自建宇宙的实验）

1. **历史退市名单不完整**：2007 年以来退市的股票，若不在我们已有的 249 只里，
   会被当成"从未存在"→ 仍有**幸存者偏差**，只是比现在小得多；
2. **ST / 停牌 / 涨跌停状态**：as-of 宇宙目前只按"上市 + 有价"过滤，
   真实可交易性（ST 5% 限幅、长期停牌、一字板）未建模；
3. **北交所**：本次代码表只含沪深（`m:0/m:1`），不含北交所。

## 4. 决策与触发条件（写死）

| 决策 | 内容 |
|---|---|
| **主路线** | **自建 as-of 宇宙**（已启动全 A 行情抓取，见 §5） |

| 采购时的选择顺序 | ① Tushare Pro ¥200（成本明确、个人可买）② CSMAR（需学术授权）③ 公告抓取（最后手段，成本最高） |
