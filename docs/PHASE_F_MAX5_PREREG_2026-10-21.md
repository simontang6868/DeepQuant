## 0. 这个实验要回答什么

**在波动率相同的股票之间，MAX5 还能预测收益吗？**

### 0.1 为什么主检验必须是"分层后"而不是原始 MAX5

可行性检查实测（`reports/MAX5_FEASIBILITY.json`）：

```
MAX5 与 21 日波动率 的横截面秩相关 = +0.8796     （237 个月的平均）
```

`0.88² ≈ 0.77` —— MAX5 约 **77%** 的横截面排序可由波动率解释。
而 **Gate 4（低波动）已经 FAIL**。

所以若直接测原始 MAX5：

> 得到显著结果时，**无法区分是"MAX 效应"还是"波动率效应"**；
> 后者本项目已经测过，且是失败。

**这个判断基于变量构造的共线性，与收益无关**——因此在预登记之前就改设计是合规的。
原始 MAX5 的价差**降为描述性对照，不参与判定**。

## 1. 变量定义（写死）

| 变量 | 定义 |
|---|---|
| `ret_t` | ADJ 日收益 `close_t / close_{t−1} − 1` |
| **`MAX5`** | 信号日前 **21 个交易日**内，**最大的 5 个日收益**的算术平均 |
| **`VOL`** | 同一 21 个交易日日收益的**样本标准差**（ddof=1） |
| 有效窗口 | 21 日内 ≥ **19** 个有效日（与阶段 C 一致）；不足则该标的当月剔除 |

**为什么是"前 5 大"而不是单日 MAX**：A 股有 T+1 与 ±10%/20% 涨跌停，
单日极值被制度性截断，"前 5 大"是文献针对中国市场采用的代理（Zhu & Zhang 2020）。
**这个口径写死，不提供敏感性变体** —— 换口径就是新实验。

---

## 2. 宇宙与窗口

| 项 | 取值 |
|---|---|
| 池 | as-of 全 A：上市满 252 个有效交易日、ADJ/EXEC 双覆盖、纯 A 股 |
| 窗口 | 信号日 **2007-01-01 ~ 2026-09-30** |
| 再平衡 | 月末最后交易日收盘定信号，持有至下月末最后交易日 |
| 收益 | `fwd = ffill(nxt)/ffill(pos) − 1`（与 Gate 6 / 阶段 C 完全一致） |
| 极值处理 | 不缩尾、不剔除 |

**不用定名单池**——阶段 C 已证明在 518/532 这类池上做因子实验，结论会被池的选择偏差主导。

## 3. 分层构造（主检验）

```
每月 t：
  1. 池内按 VOL 升序等频分 5 层（L1 最低波动 … L5 最高波动）
  2. 每层内再按 MAX5 升序等频分 5 组（Q1 最低 MAX5 … Q5 最高 MAX5）
  3. 层内价差 = R(L, Q1) − R(L, Q5)          ← 正值 = 低 MAX5 跑赢 = 文献方向
  4. Δ_t = Σ_L w_L × 层内价差(L)，w_L = 该层标的数 / 池内标的数
```

**每组最少 5 只**。不足的层跳过并记录；若有效层 < 3，该月剔除。

### 3.1 为什么 Q1 减 Q5（而不是反过来）

文献方向是"高 MAX5 → 未来收益低"（彩票偏好）。定义 `Δ = R(Q1) − R(Q5)` 后，
**`Δ > 0` 就直接对应文献方向**，不需要读者在脑子里做符号翻转。

### 3.2 不做个股层面的交易约束（声明）

分组价差是**统计量**，不是可交易组合。本实验不做建仓日涨停剔除。

理由：阶段 C 已量化该约束的代价（**−5.83% / −7.09%**），可直接引用，不必重做。
**但成本按 Q1 等权组合的实测换手计算**（见 §5）。

## 4. 主检验

```
H0: E[Δ] = 0
```

- **双侧**（虽然文献方向明确，但阶段 E 的教训是"别预设方向"）
- Newey-West 滞后 3
- 预期 237 个月

### 4.1 判据（四档 + 一个专用档位）

| 档位 | 条件（全部满足） |
|---|---|
| **MAX5_EFFECT_CONFIRMED** | `n ≥ 150` 且 `\|NW t\| ≥ 1.96` 且 `\|Δ\| ≥ 0.30 pp/月` 且 `Δ > 0` |
| **MAX5_EFFECT_REVERSED** | `n ≥ 150` 且 `\|NW t\| ≥ 1.96` 且 `\|Δ\| ≥ 0.30 pp/月` 且 `Δ < 0` |
| **MAX5_EFFECT_SMALL_BUT_SIGNIFICANT** | `n ≥ 150` 且 `\|NW t\| ≥ 1.96` 且 `\|Δ\| < 0.30 pp/月` |
| **`MAX_EFFECT_ABSORBED_BY_VOL`** | `n ≥ 150` 且 `\|NW t\| < 1.96` |
| **INCONCLUSIVE** | `n < 150` 或 NW 有效样本 < 100 |

**`MAX_EFFECT_ABSORBED_BY_VOL` 这个档位在跑之前就写死**：分层后不显著，
最合理的解释是"原始 MAX5 的效应来自波动率暴露"。这个名字比 `NOT_DETECTED` 语义准确，
且**预先声明**避免了事后把"被吸收"说成"效应不存在"。

`0.30pp/月` 的依据：等于阶段 C / 阶段 E 的经济门槛，也等于月度成本（@0.1%）的两倍。

## 5. 必须同时报的

### 5.1 原始 MAX5 的价差（描述性对照）

同一批池、同一月份，直接按 MAX5 分 5 组的 `R(Q1) − R(Q5)`。
用来量化"共线性让结果偏了多少"：`原始价差 − 分层价差`。

**不参与判定。**

### 5.2 成本

```
月度成本 = 2 × 单边换手 × 费率        （×12 是年化，不许当月度扣）
```

换手按 **Q1 组（低 MAX5）的等权组合**实测。费率 0.1% / 0.3%。
**必须走 `cost_of()`**——成本段已错过三次。

### 5.3 各层 Δ 是否同号

5 层的层内价差分别列出。若只在某一层显著、其余为零，那说明效应来自特定波动率区间，
不是普遍规律。

## 6. 诊断（描述性，不参与判定）

| # | 诊断 | 目的 |
|---|---|---|
| D1 | 5 层各自的 Δ 与 n | 效应是否集中在某层 |
| D2 | 原始 MAX5 价差 vs 分层价差 | 共线性吸收了多少 |
| D3 | 2007-2015 / 2016-2026 分段 | 与 Gate 2/3/6 的分段结论对照 |
| D4 | 分年度 Δ | 稳定性 |
| D5 | Q1 组的 VOL 与池内 VOL 中位数对比 | 确认分层后 Q1 不是"因为低波动"而赢 |
| D6 | MAX5 与 VOL 的月度秩相关序列 | 共线性是否随时间变化 |

D5 是对照组：**如果 Q1 组的波动率显著低于池中位，说明分层没做干净**。

---

## 7. 预期

- `Δ > 0`（低 MAX5 跑赢），量级**小于**原始 MAX5 价差；
- 分层后会**显著变小**——因为 77% 的排序由波动率解释；
- **可能不显著**。若如此，判定为 `MAX_EFFECT_ABSORBED_BY_VOL`，这条线关闭。

**允许任一种结果。** 本实验的价值在于"能不能把 MAX 从波动率里分离出来"，
不在于"MAX 效应存不存在"。
